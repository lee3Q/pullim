## 🔴 지금 해야 할 것 (대표만 가능)

1. **ANTHROPIC_API_KEY 세팅** — `.env.local`에 넣어야 실제 세션 테스트 가능. 없으면 Phase 0 진행 불가.
   - 방법: Anthropic Console → API Keys → 복사 → `pullim/.env.local`에 `ANTHROPIC_API_KEY=sk-ant-...` 추가
   - 예상 비용: 세션 1회 ~$0.05-0.10
   - 프로젝트: 풀림_PMF로드맵 Phase 0

2. **텔레그램 봇 연결** — 이 보드를 폰으로 받으려면 `scripts/.env.notify` 설정 필요
   - 방법: 기존 봇 중 하나 골라서 `scripts/.env.notify`에 `TELEGRAM_BOT_TOKEN=...`, `TELEGRAM_CHAT_ID=...` 넣기
   - 1분이면 끝남

3. **Vercel 대시보드 Root Directory 설정** — `pullim`으로 설정하면 git push 자동 배포 됨. 현재 수동 배포 중.
   - 방법: vercel.com → 프로젝트 → Settings → General → Root Directory → `pullim` 입력
   - 반복 등장 (handoff 6개에서 미결로 남아있음)

4. **4/2 아산 두어스 온라인 설명회 참석** (D-5)
   - 3학년 수업과 일정 충돌 확인 필요
   - 프로젝트: 아산두어스_신청

## 💭 가치관 질문 (일상에서 고민해볼 것)

> 세션에서 반복 등장하는 추상적 질문들. 정답 없음. 생각만 해두면 다음 세션에서 더 빨리 결정됨.

1. **"기다리기 vs 이끌기"의 경계는 어디인가?**
   - 풀림은 "파악 없이 이끄는 게 문제"라고 했는데, 파악이 충분한 시점은 언제인가?
   - 엘리스 비판: Level 1에서 영원히 머무는 사용자에게도 기다려야 하나?
   - 출처: 풀림_철학개선 — 미해결 긴장

2. **"고민을 풀어야 한다"는 전제 자체가 맞는가?**
   - 한병철 비판: 풀림도 결국 "자기 개선"을 부추기는 건 아닌지
   - "아무것도 안 해도 된다"가 세션 안에서 진짜 선택지로 존재하는가?
   - 출처: 풀림_철학개선 — 한병철 비판

3. **무료 사용자에게 "완전한 경험"이란 뭔가?**
   - 요금제 결정: 양 제한 + 기록 잠금. 근데 "기록이 없는 완전한 경험"이 가능한가?
   - 상담냥 안티패턴(4턴 끊김)은 피했는데, "기록 없음"도 일종의 끊김 아닌가?
   - 출처: 요금제_구조설계 결정

4. **풀림의 "성공"을 어떻게 측정할 것인가?**
   - PMF 기준(완주율 40%, 재방문 15%)은 정했는데, 이게 "사람이 나아졌다"와 같은 건가?
   - 재방문이 많으면 좋은 건가, 의존인 건가?
   - 출처: 풀림_PMF로드맵 — PMF 판단 기준
