**FAIL 상세 — 사다리 선택지 미출력 (심각도: HIGH)**

- 원인: `qwen2.5:3b` 모델이 시스템 프롬프트의 구조화 태그 형식(`[SENSORY]...[/SENSORY]`, `[OPTIONS]...[/OPTIONS]` 등)을 따르지 않음
- 실제 Ollama 응답 예시: 자연어 텍스트만 반환, 태그 없음
- 영향: `parseResponse()` 함수가 sensoryCards/options를 파싱하지 못함 → Level 1~4에서 인터랙션 UI가 빈 채로 렌더링
- 레벨 5 (TextInput) 폴백도 조건 미충족 시 표시 안 됨
- 참고: Claude API 모드에서는 정상 동작 예상 (태그 지시 따름)

**FAIL 상세 — 직접 말하기 세션 중 서버 연결 끊김 (심각도: MEDIUM)**

- Ollama 45~64초 응답 시간으로 인해 브라우저가 `about:blank`로 이동하는 현상 발생
- Dev 서버 프로세스가 종료됨 (셸 프롬프트 복귀 확인)
- 원인: Ollama 응답 지연 중 연결 유지 실패 또는 Next.js dev 서버 자체 크래시 가능성
- 재현: 직접 말하기(level 5) 진입 후 30초 이상 대기 시

스크린샷: `04-ladder-level1-2026-04-03T14-53-10-420Z.png`, `07-level1-current-state-2026-04-03T14-55-18-940Z.png`, `08-after-ollama-wait-2026-04-03T14-55-43-661Z.png`
