# 끝판왕 컨셉 확정

**날짜**: 2026-03-19 심야
**맥락**: 시장분석 + 4차 비평 + 4차 해결 이후, 기존 V2의 한계 인식 → 근본적 재설계

## 확정 사항

### 제품 정체성
- "의사결정 도구" ❌ → **"삶의 안식처"** ✅
- 타로의 의식성 + AI의 실질성 = 합리적 타로의 완성형
- 재미가 있어야 한다. 게임성.

### 3 테마
- 🧙 **모험가**: RPG 오두막, 모닥불, 수정구슬, 현자 — 판타지 감성
- 🏙️ **전략실**: 도시 야경, 유리 책상, 렌즈, 어드바이저 — 프로 감성
- 🌿 **달빛정원**: 달빛, 꽃, 나비, 정원사, 편지 — 힐링 감성
- 같은 파이프라인, 같은 분석. 세계관+디자인+음악+용어만 다름
- 커뮤니티 무리짓기 가능성 (저그/토스/테란처럼)
- **모험가 모드로 먼저 구현**, 나머지는 검증 후 확장

### 핵심 파이프라인
리서치 → 검증 → 논의 → 관점분석(이종모델) → 논의 → 토론 → 논의 → 검증 → 결론+다음단계
- 수정구슬 = 관점 선택 (전문가의 탈)
- 이종 모델 진짜 불일치 = 핵심 갈림길
- "자네는 이미 답을 알고 있지 않은가?" → 선택 → 약속 → "기다리고 있겠네"

### 수익 모델
- 무료: 광고 시청 → 세션 1회
- 유료: 월 구독 (광고 없음 + 추가 기능)
- 웹앱 → 최종 목표는 네이티브 모바일 앱

### 음악/디자인
- AI 도구로 직접 제작 (대표 본인)
- 테마별 BGM + 효과음 + 도트 아트 에셋
