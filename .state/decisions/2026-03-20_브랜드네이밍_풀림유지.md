# 브랜드 네이밍 결정: 풀림(Pullim) 유지

> 날짜: 2026-03-20
> 상태: 확정
> 방법: 3모델 교차검증 (Claude + Perplexity + Gemini)

## 결정

**풀림(Pullim) 유지 + 부제 "마음이 풀리는 이세계"**

## 탐색 과정

1. 5방향 25개 후보 생성
2. 평가 기준(세계관 30%, 기억 25%, 확장 15%, 도메인 15%, 법률 15%)으로 상위 5개 선별
3. Claude/Perplexity/Gemini 3개 모델 병렬 리서치
4. 교차 비교 → 5개 후보 모두 유의미한 리스크 발견

## 풀림 유지 근거

- 2음절 순한글 = 한국 성공 앱 패턴 (토스, 당근, 마보)
- 동일 카테고리(멘탈케어/의사결정 앱) 충돌 0건
- 3테마 중립 우산: 얽힌 것이 풀린다 / 문제가 풀린다 / 긴장이 풀린다
- 전환 비용 0 (사업자등록, ICC, 도메인, 코드)
- Gemini의 "아디다스 PULLIM 충돌" 주장 → 검증 결과 환각(색상 코드일 뿐)

## 세계관 괴리 해결

"풀림"의 약점(상담/명상 느낌 → RPG/판타지 세계관과 괴리)은 부제로 해결:

**"풀림 — 마음이 풀리는 이세계"**

- "이세계(異世界)"가 판타지/RPG 세계관을 즉시 소환
- 20-30대 타겟이 이세계 장르를 이미 인지
- 이름은 그대로, 경험의 프레이밍만 변경
