# 비용 구조 + 구슬 재화 모델 확정

**날짜**: 2026-03-20
**맥락**: 이종모델 비용 계산 → 3자 교차검증(Claude + GLM-5 + GPT-5.4) → 구슬 재화 모델 설계

## 확정 사항

### 1. 세션 비용 (보수적 기준)
- **보수적 운영 기준: ~250원/세션** (풀 파이프라인)
- 이론 최소: ~160원, 현실 중간: ~200원, 보수적: ~250원
- 3자 교차검증 수렴 범위: 160~250원
- 시스템 프롬프트, reasoning tokens, 재시도 비용 포함 시 보수적이 맞음

### 2. 모델 선택
- Claude Sonnet 4.6 + GPT-5.4 + Gemini 3.1 Pro (모두 최상위)
- 저가 모델(mini/Flash) 사용 안 함 — 품질 저하 리스크

### 3. 구슬 재화 모델 — 점진적 소모 방식
- 세션 시작 전 고정 아님 → **진행 중에 단계마다 추가 소모 선택**
- 입장 + 듣기: 무료
- 리서치: +1구슬
- 구슬 분석 1개 모델: +1구슬 → "더 볼까?" → 추가 모델당 +1구슬
- 토론: +1구슬 (불일치 시에만 제안)
- Judge + 결론: 무료
- 결과: 가벼운 고민 1~2구슬, 무거운 고민 4~6구슬
- 라우팅 AI가 추천하되 사용자가 최종 선택

### 4. 구독 구조
- 유료: 9,900원/월, 주 50구슬, 일 제한 있음
- 무료: 주 10구슬 + 광고 4회 = 1구슬 (일 상한 있음)
- 품질은 동일 — 사용 횟수로만 차등

### 5. BEP
- 보수적 250원 기준, 유료 사용자 월 ~40세션이 BEP
- 평균 사용자는 전부 안 쓰므로 실제 마진 있음
- 가벼운 고민 비율에 따라 평균 비용 105~150원 예상

## 검증 근거
- Claude: $0.116 / 160원
- GLM-5: $0.1375 / 190원 (현실: 230~250원)
- GPT-5.4: $0.1416 / 195원 (reasoning tokens 지적)
- 리서치 소스: Perplexity (API 가격 비교)

## 미결
- 구슬 재화의 게임산업진흥법 적용 여부 (대표 법적 검토 필요)
- 실사용 데이터 확보 후 구슬 배분/주간 한도 조정
- 광고 수익 실측 (eCPM ~$15-30 기준 광고 1회 = 0.25구슬)
