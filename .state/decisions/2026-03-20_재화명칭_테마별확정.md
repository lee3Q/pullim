# 재화 명칭 확정 — 테마별 3종

> 날짜: 2026-03-20
> 상태: 확정
> 방법: 대표 직접 논의

## 결정

| 테마 | 재화명 | 톤 |
|------|--------|-----|
| 모험가 | **불씨** | 판타지 |
| 달빛정원 | **달빛** | 감성/힐링 |
| 전략실 | **크레딧** | 현실/전문가 |

## 핵심 원칙

- 불씨 1개 = 달빛 1개 = 크레딧 1개 (가치 동일)
- 재화는 시간 경과 + 광고 시청으로 충전 (무료 버전)
- 가벼운 질문 = 재화 1개, 무거운 질문 = 여러 개 소모
- 분석 렌즈(수정구슬 10개)와 재화는 별개 개념

## 리필 UX

- 모험가: "불씨를 모으는 중..."
- 달빛정원: "달빛을 기다리는 중..."
- 전략실: "크레딧을 모으는 중..."

## 탈락 사유

- 구슬: 분석 렌즈와 재화 이중 의미 혼동 우려 → 렌즈와 재화 분리
- 매듭/타래/수: 전략실에서 게임 느낌 → 전략실은 전문가 서비스 톤 유지
- 칩: 카지노 뉘앙스
