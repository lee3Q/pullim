## 핵심 맥락 (다음 세션이 반드시 알아야 할 것)

### 에셋 + 스타일링
- 모든 이미지 WebP 최적화 완료 (총 이미지 ~600KB, BGM ~20MB)
- BGM preload="none" (on-demand) — 모바일 성능 대응
- Galmuri 폰트는 layout.tsx `<link>` 태그로 로딩 (CSS @import는 Tailwind 4와 충돌)
- `image-rendering: pixelated`은 고해상도 AI 이미지에 효과 없어서 제거 (GLM-5 지적)

### Hydration 이슈 해결
- CrystalSelector `Math.random()` → index 기반 고정값
- CSS `background` shorthand → `backgroundColor`/`backgroundImage` longhand 분리
- React Strict Mode `setTimeout` 중복 → `clearTimeout` cleanup 추가
- ChatInput 한국어 IME 이중 전송 → `isComposing` + `submittingRef` 가드

### 3테마 구조
- 각 테마가 독립 page.tsx (adventure/strategy/garden) — 95% 코드 중복, MVP 단계라 허용
- ThemedBackground 통합 컴포넌트: 테마별 그라디언트+배경이미지+파티클(불꽃/없음/반딧불)
- useBGM 훅: tracks 파라미터로 테마별 곡 전달, 곡 전환 버튼
