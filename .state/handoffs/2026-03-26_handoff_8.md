### 복붙 매크로 (scripts/paste-macro.sh)
- `p` — 다음 프롬프트를 Chrome 활성 탭에 자동 전송
- `ppp` — Chrome 활성 탭에서 최신 이미지 URL 추출 → curl 다운로드 → 올바른 이름으로 자동 저장 (Gemini는 403 — Chrome만 가능)
- `p watch` — 다운로드 폴더 감시, 새 이미지 자동 저장
- `p goto N` / `p goto name` — 특정 위치로 이동
- `p status` — 진행 현황 체크리스트
- alias: `p`, `ppp` (.zshrc 등록 완료)

### 훅 수정
