## 핵심 맥락 (다음 세션이 반드시 알아야 할 것)

- **GLM 로컬 전용**: `.env.local`에 GLM_API_KEY/GLM_BASE_URL/GLM_MODEL 설정 완료. Vercel에는 안 넣음(로컬 실험용). 배포 서버는 ANTHROPIC_API_KEY 없으면 demo mode.
- **GLM 작동 방식**: z.ai 게이트웨이(https://api.z.ai/api/anthropic) + Anthropic SDK baseURL 오버라이드. `isDemoMode()`가 GLM 키 있으면 demo 스킵하도록 수정됨.
- **LLM_MODE 변경**: `local` → `api`. 이제 로컬에서 `npm run dev` 하면 GLM-5로 사다리 세션 실행됨.
- **AI QA 한계 확인**: Playwright는 기능(버튼/텍스트) 테스트만. UX 감각/이미지 매핑은 대표 직접 체크 필요. 이번 밤배치 결과(스크린샷)로 대표가 직접 판단.
- **Playwright + Chromium 설치 완료**: `pullim/` 폴더에. 배치에서 재설치 불필요.
- **배포 서버 demo mode 상태 유지**: 실사용자가 진짜 AI 응답 받으려면 Vercel에 ANTHROPIC_API_KEY 필요. 아직 미완.
