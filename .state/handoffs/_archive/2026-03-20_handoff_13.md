## 핵심 맥락 (다음 세션이 반드시 알아야 할 것)

### Demo 모드 구조
- `lib/demo.ts` — isDemoMode()는 `!process.env.ANTHROPIC_API_KEY`로 판단
- Vercel에 ANTHROPIC_API_KEY 없음 → 자동 demo 모드, 비용 0원
- ANTHROPIC_API_KEY 넣으면 자동으로 실제 AI 전환 (코드 변경 불필요)
- 6개 API 라우트 모두 demo 분기: listen/research/analyze/debate/conclude/judge
- listen은 SSE 스트리밍 시뮬레이션 (30ms 간격 청크)

### 테마별 톤 분리
- listen/debate/conclude API에 `theme` 파라미터 전달
- 모험가: 고어체(~일세, ~인가), 전략실: 존댓말(~입니다), 달빛정원: 감성 반말(~이에요)
- analyze/research/judge는 테마 무관 (분석 데이터)

### 타임라인 렌더링 (중요)
- `researchAtIndex`, `analysisAtIndex` 상태로 대화 분할점 기록
- 렌더링: [리서치 전 대화] → [데이터 카드] → [카드 후 대화] → [구슬 선택/분석] → [분석 후 대화] → [결론]
- 3개 페이지(adventure/strategy/garden) 모두 동일 패턴 적용

### UX 피드백 반영
- 헤더 sticky + backdrop-blur (스크롤해도 홈 버튼·BGM 접근 가능)
- StageIndicator sticky top-[52px] (헤더 아래 고정)
- 리서치 후 대사 2개→1개 합침 (카드가 빨리 보이게)
- 전략실: 선택 버튼에 전문가 이름 표시 (expertLabel)
- 달빛정원: 선택 버튼에 "꽃봉오리" 표시, CrystalAnalysisView에서 crystalLabel 활용
- 홈 아이콘(🧙/🏙️/🌿) 클릭 → 홈 이동
- 데모 안내 배너: 홈 상단 "체험판입니다. 예시 답변이 제공됩니다."
