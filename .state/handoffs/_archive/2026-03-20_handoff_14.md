데모에서 메시지 순서가 뒤섞이고 중복 표시되는 버그 수정. 원인: (1) async 함수 내 stale closure로 researchAtIndex/analysisAtIndex 분할 지점 오류, (2) React key 중복으로 DOM 잘못 렌더링. 3개 테마 페이지(adventure/strategy/garden) 모두 동일 패턴 수정 완료, 빌드 성공.

## 핵심 맥락 (다음 세션이 반드시 알아야 할 것)

### 버그 원인 (2가지)
1. **Stale closure**: `setResearchAtIndex(dialogues.length + 1)` — async 함수(callResearchAPI, callAnalyzeAPI)가 생성 시점의 `dialogues.length`를 캡처해 실제보다 작은 인덱스 설정 → 데이터 카드/분석 결과의 삽입 위치가 잘못됨
2. **React key 충돌**: `dialogues.slice(splitR).map(renderDialogue)`에서 slice 내부 0-based 인덱스를 key로 사용 → 첫 번째 slice와 key 충돌 → React가 DOM 재사용 오류로 메시지 중복 렌더링

### 수정 방법
- `dialoguesRef` (useRef) 추가: 매 렌더마다 `dialoguesRef.current = dialogues` 동기화. async 함수 내에서 최신 길이 참조
- `dialogues.length + 1` → `dialoguesRef.current.length` (ref는 await 사이의 렌더에서 갱신되므로 정확)
- key를 글로벌 인덱스로 변경: `(d, i) => renderDialogue(d, splitR + i)`
