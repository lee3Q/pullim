## 핵심 맥락 (다음 세션이 반드시 알아야 할 것)
- **반응형 전략**: html font-size 스케일링(md:18px, xl:20px)으로 모든 rem 기반 값이 비례 확대됨. 개별 컴포넌트에 md:/lg: 브레이크포인트도 추가. 이 두 레이어가 합산되므로 추후 font-size 조정 시 주의.
- **컨테이너 패턴**: max-w-sm → `max-w-sm md:max-w-lg lg:max-w-xl` (홈/파악/결과), max-w-lg → `max-w-lg md:max-w-2xl lg:max-w-3xl` (세션 페이지), max-w-md → `max-w-md md:max-w-xl lg:max-w-2xl` (게임/분석 컴포넌트)
- **치트 버튼**: inferCheatAction이 behind-the-scenes.ts에 추가됨. 현재 감각 레벨 치트→전략실 제안, 분석 레벨 치트→달빛정원 제안, 동일 테마 2회 연속→다른 테마 제안, 누적 3회→접어두기. ladder-store에 cheatCount 상태 추가.
- **이미지 수정**: StoryDiscovery는 고정 height 대신 aspect-[16/9] 사용. PersonalityResult는 md:w-52 + sizes prop 추가. 중복 max-w-sm 제거(래퍼가 처리).
