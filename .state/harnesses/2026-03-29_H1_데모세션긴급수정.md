# 하네스: 데모 세션 긴급 수정

## 목표
데모 모드(API 키 없음)에서 사다리 세션이 끝까지 자연스럽게 진행되도록 수정한다.

## 현재 상태
- P1 스트리밍 태그 노출: **이미 수정됨** (LadderSession.tsx:608)
- P2 데모 응답 빈약: 레벨당 3개, 테마 무관. 같은 말 반복.
- P3 데모 끝까지 불가: 요약 생성이 API 호출이라 데모에서 실패.

## 작업 항목

### Task 1: 데모 응답 확충 (demo-ladder.ts)
- 각 레벨(1-5)의 응답을 3개 → **8개**로 확충
- 5개 테마(모험가/달빛정원/전략실/천문대/종말)별 톤 변형 적용
  - 모험가: 모험/갈림길 비유
  - 달빛정원: 자연/꽃/계절 비유
  - 전략실: 데이터/분석적 톤
  - 천문대: 별/우주/꿈 비유
  - 종말: 극한/생존/본질 비유
- getDemoLadderResponse에 theme 파라미터 추가
- 기존 테마 무관 응답은 모험가 기본값으로 유지 (하위호환)

### Task 2: 데모 세션 완주 플로우 (demo-ladder.ts + LadderSession.tsx)
- 데모 전용 요약 생성 함수 추가 (getDemoSummary)
  - 테마별 3개 요약 텍스트 하드코딩
  - 사용자의 최근 선택을 참조하여 개인화된 느낌의 요약
- LadderSession.tsx의 generateSummary에서 데모 모드 분기 추가
  - API 호출 대신 getDemoSummary 사용
- 데모에서도 "오늘은 여기까지" 버튼이 정상 작동하도록

### Task 3: API Route 데모 분기 개선 (route.ts)
- getDemoLadderResponse 호출에 theme 전달
- sensoryLadderContext에서 테마 정보 추출하여 전달
