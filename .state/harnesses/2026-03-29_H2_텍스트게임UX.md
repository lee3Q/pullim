# 하네스: 사다리 세션 텍스트 게임 UX

## 목표
사다리 세션 레벨 1-4를 "텍스트 게임이라고 착각할 만큼" 시각적+서사적으로 개선한다.

## 철학 근거
- "텍스트 게임이라고 착각할 만큼 부담없고 즐겁게" (풀림_미션과_진짜UX 6장)
- "게임 식이든, 질문으로 고르게 하든 자신을 알고있냐 모르냐 파악 후" (풀림_진짜시작)
- "직접 말하게 할 수 있지만, 그러고 싶지 않은 사람에겐 늘 선택지와 추천선택이 있어서 진행을 계속할 수 있다"

## 현재 상태
- 사다리 레벨 1-4는 선택지 UI이나, 시각적으로 빈약 (배경 없음, 진행감 없음)
- /images/levels/ 에 5테마×5레벨=25장 이미지가 이미 존재하지만 사용되지 않음
- 진입 화면: "직접 말할게 / 선택지 보여줘 / 느낌으로 할래" — 텍스트 게임 느낌 없음

## 작업 항목

### Task 1: 진입 화면에 "텍스트 게임" 모드 명시 (LadderSession.tsx)
- 기존 진입 옵션을 재구성:
  - 🎮 **이야기로 풀어볼래** (Level 1-4, 선택지 기반) → 텍스트 게임 [추천]
  - 💬 **직접 말할게** (Level 5, 자유 대화)
- "이야기로 풀어볼래" 선택 시 Level 1에서 시작 (감각부터)
- "직접 말할게" 선택 시 Level 5에서 시작 (기존과 동일)

### Task 2: 레벨별 배경 이미지 표시 (LadderSession.tsx)
- 현재 테마 + 현재 레벨에 따라 배경 이미지 표시
- 이미지 경로: `/images/levels/{테마명}_level{N}.png`
  - 테마명 매핑: 모험가→adventure, 달빛정원→garden, 전략실→strategy, 천문대→stargazer, 종말→apocalypse
- 세션 화면 상단에 반투명 배경으로 이미지 표시 (높이 약 30vh)
- 레벨 변경 시 fade 트랜지션으로 이미지 전환

### Task 3: 레벨별 내러티브 텍스트 (새 상수 추가)
- 각 레벨 진입 시 짧은 내러티브 한 줄 표시 (텍스트 게임 분위기)
- 테마별×레벨별 = 25개 내러티브
  - 예시 (모험가 Level 1): "갈림길 앞에 섰다. 모닥불이 흔들린다."
  - 예시 (달빛정원 Level 3): "달빛 아래 물웅덩이에 무언가가 비친다."
- 레벨 인디케이터 옆에 표시 (기존 LEVEL_LABELS 대체)

### Task 4: 선택지 UI 게임화 (각 Level 컴포넌트)
- SensoryLevel: 카드가 "아이템 선택" 느낌으로 표시 (이모지 크게, 라벨 아래)
- ComparisonLevel: 좌우 분할 카드가 "두 갈래 길" 느낌
- AnalysisLevel: 분석 카드가 "두루마리/편지" 느낌 (theme.gameUI.dialogueStyle 활용)
- ChoiceLevel: 선택지가 "행동 명령어" 느낌 ("> 선택지텍스트" 형태)
