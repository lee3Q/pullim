# 하네스: 약속(Promise) 기능 기반 코드

## 목표
"아는데 행동 못 하는" 사용자에게 if/then 약속을 권유하는 기능의 기반 코드를 구현한다.

## 철학 근거 (풀림_철학개선.md "약속" 섹션)
- 파악 중 반복 패턴 감지 → "전에도 이런 고민 했었어"
- "이거 하나만 약속해볼래?" → 작은 if/then 규칙 생성
- 다음 세션에서 "그거 했어?" 확인
- 약속 = 실험 (틀려도 데이터), 리텐션 장치, 유대 강화
- 실패해도 "풀림을 켜는 것만으로 발전" — 자기이해→자기변화 전환점

## 작업 항목

### Task 1: 타입 정의 (ladder-types.ts에 추가)
```typescript
export interface PullimPromise {
  id: string;
  createdAt: number;
  sessionTheme: string;
  // if/then 구조
  trigger: string;     // "~할 때" (if)
  action: string;      // "~해볼래" (then)
  // 상태
  status: 'active' | 'completed' | 'failed' | 'skipped';
  checkedAt?: number;
  reflection?: string; // 사용자의 후기
}
```

### Task 2: 약속 스토어 (새 파일: promise-store.ts)
- localStorage 기반 (키: `pullim_promises`)
- createPromise(trigger, action, theme) → PullimPromise
- getActivePromises() → PullimPromise[]
- checkPromise(id, status, reflection?) → void
- getPromiseHistory() → PullimPromise[] (전체)

### Task 3: 세션 종료 시 약속 제안 UI (SessionSummary.tsx 수정)
- 세션 요약 아래에 "약속" 섹션 추가
- "오늘 이야기에서 하나만 약속해볼래?"
- 약속 trigger/action은 세션 대화에서 추출 (데모에서는 하드코딩 예시)
- 수락/거절 선택지
- 거절해도 OK — "다음에 해도 돼" (풀림다운 톤)

### Task 4: 세션 시작 시 약속 확인 UI (LadderSession.tsx 진입 화면)
- active 약속이 있으면 진입 화면에 표시
- "지난번에 약속한 거, 해봤어?"
- 했어 / 못했어 / 스킵
- 응답 → promise-store에 기록
- 못했어도 긍정적 톤: "괜찮아, 이것도 하나의 발견이야"
