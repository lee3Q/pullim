# 하네스: 이미지 매핑 수정 + 아포칼립스 배포 준비

## 목표
이미지 참조 오류를 수정하고, 아포칼립스 테마를 포함한 최신 코드를 빌드+커밋한다.

## 작업 항목

### Task 1: 이미지 경로 수정
- `pullim/src/lib/themes/index.ts`에서 모든 테마의 asset 경로가 실제 파일과 일치하는지 검증
  - strategy-bg: .webp와 .png 모두 존재 → 현재 참조(.webp) 정상
- story-scenes.ts의 모든 imagePath가 실제 파일과 매핑되는지 확인
  - `/assets/discovery/` 내 파일 존재 확인
  - `/images/v3/` 내 파일 존재 확인
  - 누락 파일이 있으면 가장 가까운 기존 이미지로 대체 참조
- 천문대 파악 이미지 (stargazer_1~10.png) 존재 확인

### Task 2: 아포칼립스 테마 코드 확인
- themes/index.ts에 종말 테마 데이터 존재 확인
- story-scenes.ts에 아포칼립스 15장면 존재 확인
- stargazer 페이지(/stargazer/[id]/page.tsx)에서 천문대+종말 분기 존재 확인
- 홈 페이지에 종말 카드 존재 확인

### Task 3: 빌드 검증 + 커밋
- `cd ~/study/main/pullim/pullim && npx next build` 실행
- 빌드 통과 시: 모든 변경사항 git add + git commit
- 커밋 메시지: "fix: 이미지 경로 수정 + 데모 스트리밍 태그 수정"
- git push (Vercel 자동 배포 트리거)

## 제약
- 이미지 파일 자체를 생성하지 마라 — 경로 참조만 수정
- 빌드 통과 필수
- 기존 테마 데이터 구조 변경 금지

### Task 4: 상태 정합성 자동 검증 (evening-report.sh 보강)
- evening-report.sh의 PROMPT에 상태 정합성 검증 지시 추가:
  ```
  리포트 생성 후, 추가로 상태 정합성을 검증하라:
  1. .state/handoffs/ 에서 오늘 날짜 핸드오프를 읽어라
  2. .state/queue.md를 읽어라
  3. 핸드오프에서 완료된 항목이 queue에 [x] 안 되어있으면 자동 수정하라
  4. 핸드오프에서 신규 발견된 항목이 queue에 없으면 추가하라
  5. .state/ceo-board.md도 동일하게 검증하고 수정하라
  6. 불일치가 있었으면 리포트에 "⚠ 상태 정합성 N건 수정" 섹션을 추가하라
  ```
- 이 검증이 매일 22:00에 자동 실행되어 상태 drift를 구조적으로 방지
