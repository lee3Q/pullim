# 하네스: 내면사고(Behind-the-Scenes) 데모 모드 개선

## 목표
데모 모드에서도 이면사고 레이어가 의미 있게 동작하도록 개선한다.

## 현재 상태
- behind-the-scenes.ts: 규칙 기반 inferStateSync() — 항상 동작 ✅
- behind-llm.ts: Gemini Flash Lite 호출 — API 키 없으면 실패 → 폴백
- inferState(): LLM 시도 → 실패 시 규칙기반 폴백
- **문제**: 규칙 기반만으로는 toneAdjustment가 매우 제한적 (4가지 고정 문구)

## 철학 근거
- "대화 이면에서 계속 생각을 해서 태도를 결정하게 하는거지" (풀림_진짜시작)
- "답변 길이 변화, 응답 시간, 선택 패턴, 대화 참여도" 비언어적 신호 수집

## 작업 항목

### Task 1: 규칙 기반 추론 강화 (behind-the-scenes.ts)
- toneAdjustment 문구를 4개 → 12개로 확충
- 복합 조건 추가:
  - fatigue + opening → "쉬고 싶지만 말하고 싶어하는 상태. 부담 없이 따라가라."
  - confident + dissatisfied → "방향은 알지만 제시된 것이 맞지 않는다. 다른 각도를."
  - 첫 턴 (turnCount === 0) → "아직 모르는 상태. 가볍게 시작하라. 판단하지 마라."
- 레벨별 특화 톤 조정:
  - Level 1-2에서 struggling → "선택지를 더 단순하게"
  - Level 3에서 dissatisfied → "분석 각도를 완전히 바꿔라"
  - Level 5에서 fatigue → "질문 줄이고 공감으로"

### Task 2: 이면사고 표시 토글 개선 (BehindToggle 확인)
- 이면사고 표시 토글 UI가 존재하는지 확인
- 없으면: 설정(useSettings)에 showBehindThoughts 추가
- 표시 모드에서는 현재 inference 상태를 세션 UI에 작게 표시
  - "💭 [피로감지] 가볍게 전환 중..." 형태
  - 데모에서 이것이 차별화 포인트: "이 AI가 나를 어떻게 파악하는지 보여주는 토글"

### Task 3: 데모 모드 이면사고 시뮬레이션
- 데모 모드에서 LLM 호출이 실패해도, 규칙기반 결과를 시각화
- behind-thought API가 실패해도 UI에 "💭 생각 중..." 표시 유지
- 규칙기반 결과를 기반으로 한 짧은 설명 텍스트 생성 함수 추가
