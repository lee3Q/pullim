# 하네스: 반자동화 파이프라인 3단계 검증 + 4단계 (하네스 자동 생성)

## 목표
3단계(아침/밤 리포트 + launchd)가 이미 구현되어 있음. 검증만 하고 4단계로 진입.
4단계: 밤 리포트 기반 → claude -p가 하네스 초안 생성 → 대표 텔레그램 승인 → 배치 실행.

## 현재 상태 (3단계 — 이미 구현됨)
- morning-report.sh: claude -p Sonnet으로 생성, 실패 시 텔레그램 알림. **동작 확인됨** (2026-03-29 morning 존재)
- evening-report.sh: 같은 구조. launchd 22:00 예약됨
- launchd plist: com.pullim.morning (08:00) + com.pullim.evening (22:00) 모두 등록 + launchctl active
- night-batch.sh: 완료/실패 시 curl로 텔레그램 직접 전송 (notify-telegram.sh 미경유, 정상)

## 작업 항목

### Part A: 3단계 검증 (빠르게)

#### A-1. 아침 리포트 실제 품질 확인
- `cat .state/daily/2026-03-29_morning.md` 내용 확인
- routines.md 포맷(Level 1 + Level 2) 맞는지 확인
- 3/29 아침에는 시스템 미가동 → **3/30 08:00 텔레그램 수신 확인** (🔴 대표 확인)

#### A-2. 밤 리포트 테스트 (수동 1회)
- `bash ~/study/main/pullim/scripts/evening-report.sh` 수동 실행
- 생성된 .state/daily/2026-03-29_evening.md 확인
- 텔레그램 수신 확인

#### A-3. 프로젝트 파일 갱신
- .state/projects/반자동화_파이프라인.md 3단계 체크리스트 전부 [x] 처리
- 4단계 진입 표시

### Part B: 4단계 구현 — 하네스 자동 생성

#### B-1. 밤 리포트에 "다음 작업 하네스 초안" 섹션 추가
- evening-report.sh의 PROMPT에 추가 지시:
  ```
  리포트 끝에 "## 다음 작업 하네스 초안" 섹션을 추가해.
  - queue.md + projects/ 에서 다음 우선순위 작업 1개 선택
  - 해당 작업의 하네스 초안 작성 (목표, 작업 항목, AC)
  - 하네스를 .state/harnesses/YYYY-MM-DD_자동초안.md 에 저장
  ```

#### B-2. 텔레그램 승인 플로우 추가
- telegram-bot.js에 새 기능:
  - 밤 리포트 전송 후 인라인 키보드: [✅ 이 하네스 실행] [✏️ 수정 필요] [⏭ 내일로]
  - ✅ 선택 → night-batch.sh에 하네스 경로 전달 → 밤배치로 자동 실행
  - ✏️ 선택 → "claude code에서 수정해" 안내
  - ⏭ 선택 → 아무것도 안 함

#### B-3. night-batch.sh 하네스 실행 연결
- night-batch.sh에 `--harness <path>` 옵션 추가
- 하네스 파일을 claude -p의 프롬프트로 전달하는 모드

#### B-4. 통합 테스트
- evening-report.sh 수동 실행 → 하네스 초안 생성 확인
- 텔레그램에서 ✅ 버튼 → 밤배치 트리거 확인

## 완료 기준 (AC)

- [ ] 프로젝트 파일 3단계 [x] 처리
- [ ] evening-report.sh가 하네스 초안 자동 생성

- [ ] ✅ 승인 → night-batch.sh가 하네스 기반 배치 실행
- [ ] 전체 플로우 1회 통합 테스트 통과
