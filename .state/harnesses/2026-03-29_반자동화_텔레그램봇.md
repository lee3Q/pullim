# 하네스: 반자동화 파이프라인 2단계 — 텔레그램 봇 완성

## 목표
telegram-bot.js 는 이미 구현되어 있고, 단방향 알림도 동작 중.
남은 작업: PM2 설정 + 실패 fallback + 리포트 스크립트 연결.

## 현재 상태
- telegram-bot.js: 310줄, polling + 인라인 키보드 구현 완료
  - /start, /help, /status, /queue, /board, /report, /batch, /health 명령어 있음
  - 콜백: 리포트 생성(morning/evening), 배치 실행(확인→실행) 처리
- 단방향 알림: notify-telegram.sh 로 동작 확인됨
- 봇 토큰 + chat_id: .env.notify 에 저장됨

## 작업 항목

### 1. PM2 설정
- 파일: `scripts/ecosystem.config.js` (이미 존재 여부 확인)
- 내용:
  ```js
  module.exports = {
    apps: [{
      name: 'pullim-bot',
      script: 'scripts/telegram-bot.js',
      cwd: '/Users/sanggyulee/study/main/pullim',
      cron_restart: '0 */24 * * *',  // 24시간마다 재시작
      autorestart: true,
      max_restarts: 10,
      restart_delay: 5000,
    }]
  };
  ```
- PM2 시작: `pm2 start scripts/ecosystem.config.js`
- PM2 저장: `pm2 save`
- PM2 startup 등록: `pm2 startup` (macOS launchd 자동 시작)

### 2. 실패 fallback
- telegram-bot.js 의 리포트 생성 / 배치 실행에서 실패 시 텔레그램 메시지 전송
- 현재 코드에 이미 `리포트 생성 실패 (code: ${code})` 있음 → 확인만
- 배치 실행 실패도 같은 패턴인지 확인
- night-batch.sh 에 완료/실패 시 notify-telegram.sh 호출 추가 (이미 있을 수 있음)

### 3. morning-report.sh / evening-report.sh 존재 확인
- 이 스크립트들이 실제로 존재하고 동작하는지 확인
- 없으면 생성:
  - morning-report.sh: claude -p 로 프로젝트 상태 + WebSearch 뉴스 요약 생성 → .state/daily/YYYY-MM-DD_morning.md
  - evening-report.sh: claude -p 로 밤 리포트 + 사다리식 결정 선택지 생성 → .state/daily/YYYY-MM-DD_evening.md
- 리포트 생성 후 텔레그램으로 자동 전송

### 4. 통합 테스트
- PM2 로 봇 시작 → /status 명령 → 정상 응답 확인
- /report → 아침 리포트 생성 → 텔레그램 수신 확인
- /health → 시스템 상태 확인
