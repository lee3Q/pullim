# 하네스: 이미지 프롬프트 100장 생성 + p도구 배치 실행

## 목표
아포칼립스 45장 포함 총 100장 이미지 프롬프트를 작성하고 p도구 배치로 생성까지 완료한다 (만료 임박).

## 작업 항목
- 아포칼립스 테마 세계관 검토 (기존 코드 + 유형 8개 확인) 후 45장 프롬프트 작성 (파악 15 + OG 8 + 레벨 5 + 마케팅 3 + 기타)
- 나머지 55장 프롬프트 작성: 천문대 OG 8 + 앱스토어 12 + 마케팅 15 + UI연출 15 + 랜딩 5
- 프롬프트 파일 `/scripts/prompts-v5.txt` 형식으로 저장 (기존 파일 패턴 준수)
- p도구(`~/study/main/pullim/scripts/paste-macro.sh`) 배치 실행 — 브라우저 준비 후 `ps` 명령어로 순차 전송
- 생성 완료 후 `map-images.sh`로 파일명 매핑 + 코드 연결 확인
