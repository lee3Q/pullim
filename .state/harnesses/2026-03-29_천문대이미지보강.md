## 단일 트랙

### 1. 천문대 scenes bgImage 코드 연결
- **읽기**: `pullim/src/lib/themes/index.ts` (line 399~455, stargazer scenes)
- **할 일**: 아포칼립스와 동일 패턴으로 bgImage 추가. 매핑:
  - ENTER → `/assets/stargazer-enter-bg.png` (enter-bg를 session-enter 대신 사용, 파일 존재)
  - LISTEN → `/assets/stargazer-listen-bg.png`
  - RESEARCH, VERIFY, DISCUSS_1, CRYSTAL_SELECT, CRYSTAL_ANALYZE, DISCUSS_2 → `/assets/stargazer-research-bg.png`
  - DEBATE, DISCUSS_3, JUDGE, CONCLUDE → `/assets/stargazer-conclude-bg.png`
  - COMPLETE → `/assets/stargazer-conclude-bg.png` (complete-bg 없으므로 conclude 재사용)
- **산출물**: themes/index.ts 수정
- **핵심**: 아포칼립스 패턴과 1:1 매칭. 기존 gradient/particle 건드리지 않고 bgImage만 추가.

### 2. 누락 이미지 프롬프트 작성
- **읽기**: `scripts/prompts.txt` (현재 랜딩 5장), 기존 천문대 이미지 스타일 참조 (stargazer-enter-bg.png 등의 프롬프트는 scripts/prompts-v3.txt에 있을 수 있음)
- **할 일**: 아래 7장 프롬프트를 p도구 포맷(# filename.png + 설명 + --- 구분)으로 prompts.txt **뒤에 추가**:
  - stargazer-session-enter-bg.png (세션 진입 배경)
  - stargazer-complete-bg.png (완료 배경)
  - stargazer_11.png ~ stargazer_15.png (파악 장면 11~15)
- **산출물**: scripts/prompts.txt 수정 (기존 5장 뒤에 7장 추가 = 총 12장)
- **핵심**: 천문대 세계관(밤하늘, 별, 망원경, 인디고/퍼플 톤) 일관성. 기존 stargazer 이미지 톤 참조.
- **⚠️**: p도구 포맷 필수 (# filename.png 헤더 + --- 구분자)
