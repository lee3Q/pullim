# 하네스: GLM 플레이라이트 UI 실험

## 목표
GLM-5가 활성화된 로컬 개발 서버에서 Playwright로 사다리 세션을 실제로 돌린다.
선택지가 제대로 렌더링되는지, 응답 포맷이 정상인지, UI가 깨지지 않는지 확인한다.

## 현재 상태
- `.env.local`에 GLM_API_KEY, GLM_BASE_URL, GLM_MODEL 설정 완료
- `isDemoMode()` — GLM 키 있으면 demo mode 스킵
- Playwright 미설치

## 작업 항목

### Task 1: Playwright 설치 + 설정
**실행:**
```bash
cd ~/study/main/pullim/pullim

npx playwright install chromium
```

**파일: `playwright.config.ts` 생성**
```typescript

export default defineConfig({
  testDir: "./tests/e2e",
  timeout: 120_000,
  use: {
    baseURL: "http://localhost:3000",
    headless: true,
    screenshot: "on",
    video: "off",
  },
  webServer: {
    command: "npm run dev",
    url: "http://localhost:3000",
    reuseExistingServer: false,
    timeout: 60_000,
  },
});
```

### Task 2: 사다리 세션 테스트 스크립트 작성
**새 파일: `tests/e2e/ladder-glm.spec.ts`**

테스트 시나리오:
1. 홈 진입 → 고민 입력 ("요즘 진로가 너무 막막해") → 파악 단계 진입
2. 각 선택지가 렌더링되는지 확인 (3개 이상)
3. 선택지 클릭 → 다음 질문 로드 확인
4. 3턴 이상 진행 → 분석 단계 진입 확인
5. 스크린샷 저장: `tests/screenshots/glm-{테마}-{단계}.png`

**테스트 흐름:**
```typescript
import { test, expect } from "@playwright/test";

const THEMES = ["모험가", "전략실", "달빛정원", "천문대", "종말"];
const CONCERNS = [
  "요즘 진로가 너무 막막해",
  "친구 관계가 힘들어",
  "번아웃이 온 것 같아",
  "돈 걱정이 너무 많아",
];

for (const theme of THEMES) {
  test(`GLM 사다리 세션 — ${theme}`, async ({ page }) => {
    const concern = CONCERNS[THEMES.indexOf(theme) % CONCERNS.length];

    // 홈 진입
    await page.goto("/");
    await page.screenshot({ path: `tests/screenshots/glm-${theme}-01-홈.png` });

    // 고민 입력
    const textarea = page.locator("textarea").first();
    await textarea.fill(concern);
    await page.screenshot({ path: `tests/screenshots/glm-${theme}-02-고민입력.png` });

    // 테마 선택
    const themeBtn = page.locator(`text=${theme}`).first();
    if (await themeBtn.isVisible()) await themeBtn.click();

    // 시작 버튼 클릭
    const startBtn = page.locator("button").filter({ hasText: /시작|탐색|파악/ }).first();
    await startBtn.click();

    // 4~5턴 반복
    for (let turn = 1; turn <= 5; turn++) {
      // 응답 대기 (최대 90초 — GLM 응답 시간)
      try {
        await page.waitForSelector("[class*='option'], [class*='choice'], [class*='btn']", {
          timeout: 90_000,
        });
      } catch {
        await page.screenshot({ path: `tests/screenshots/glm-${theme}-${String(turn + 2).padStart(2, "0")}-타임아웃.png` });
        break;
      }

      await page.screenshot({ path: `tests/screenshots/glm-${theme}-${String(turn + 2).padStart(2, "0")}-${turn}턴.png` });

      // 선택지 확인
      const options = page.locator("[class*='option'], [class*='choice']");
      const count = await options.count();
      if (count === 0) {
        // 선택지 없으면 자유 입력 시도
        const input = page.locator("input, textarea").last();
        if (await input.isVisible()) {
          await input.fill("잘 모르겠어");
          await page.keyboard.press("Enter");
        }
      } else {
        await options.first().click();
      }

      await page.waitForTimeout(2_000);

      // 세션 종료 감지
      const isEnded = await page.locator("text=/요약|완료|결과/").isVisible().catch(() => false);
      if (isEnded) {
        await page.screenshot({ path: `tests/screenshots/glm-${theme}-99-종료.png` });
        break;
      }
    }
  });
}
```

제약:
- 선택지 셀렉터가 정확하지 않으면 실제 DOM을 보고 수정
- 스크린샷은 `tests/screenshots/` 폴더에 저장
- 각 테마마다 독립 실행 (병렬 아닌 순차)
