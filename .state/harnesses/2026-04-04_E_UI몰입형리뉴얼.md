## 디자인 방향 (대표 확정)

### 핵심 원칙
1. **배경 = 세계관**: 이미지를 카드 안에 가두지 않고, 화면 전체 배경으로 깔기
2. **파티클 애니메이션**: CSS-only. 테마별 분위기 (모험가=반딧불, 달빛정원=꽃잎, 천문대=별똥별, 종말=재/연기, 전략실=안개)
3. **텍스트가 배경 위에**: 반투명 overlay 위에 텍스트 직접 표시
4. **글래스모피즘**: 선택지/입력/말풍선에 backdrop-blur + 반투명
5. **모바일 우선**: 메인 타겟 모바일. 선택지 너비 적절 조절.

### 두 가지 뷰 모드

#### A. 텍스트게임형 (카드형 → 리뉴얼)
- 전체 화면 배경 이미지 (현재 28vh → 100vh, position: fixed, object-fit: cover)
- 배경 위 반투명 그라데이션 overlay (아래로 갈수록 어두워짐 — 텍스트 가독성)
- 내러티브 텍스트: 가운데 정렬, fade-in, serif 폰트 (기존 font-rpg 유지)
- 선택지: 글래스모피즘 버튼 (backdrop-blur-md, bg-white/10, border-white/20)
- 레벨별 선택지 배치: Level1-3은 세로 스택, Level4는 2x2 그리드 유지

#### B. 대화형 (리뉴얼)
- 동일한 전체 화면 배경 + 파티클
- 대화 메시지: 글래스모피즘 말풍선 (AI=왼쪽, 사용자=오른쪽)
- AI 말풍선: bg-white/10 backdrop-blur, 텍스트 왼쪽 정렬
- 사용자 말풍선: bg-white/20 backdrop-blur, 텍스트 오른쪽 정렬
- 입력창: 하단 고정, 글래스모피즘

### 네비게이션 (유지, 스타일만 수정)
- 레벨 인디케이터: 상단, 반투명 배경
- "오늘은 여기까지" 버튼: 유지, 글래스모피즘 스타일
- 카드형↔대화형 전환: 유지
- 이전/다음 네비게이션: 유지

## Task 1: CSS 파티클 시스템 (신규 파일)

**할 일**: `pullim/src/components/session/Particles.tsx` 생성

CSS-only 파티클 애니메이션 컴포넌트:
```tsx
interface ParticlesProps {
  theme: "모험가" | "전략실" | "달빛정원" | "천문대" | "종말";
}
```

테마별 파티클:
- **모험가**: 반딧불 (작은 노란 원, 랜덤 float + glow)
- **전략실**: 안개 (큰 흰색 원, 느린 drift, 매우 낮은 opacity)
- **달빛정원**: 꽃잎 (작은 분홍 타원, 회전하며 낙하)
- **천문대**: 별똥별 (작은 흰 점, 대각선 이동 + trail)
- **종말**: 재/먼지 (작은 회색 원, 느린 상승)

구현 방식: CSS @keyframes + position: absolute + pointer-events: none
파티클 개수: 15~25개 (모바일 성능 고려)

**산출물**: `pullim/src/components/session/Particles.tsx`
**핵심**: CSS-only (canvas/JS 라이브러리 금지). 모바일 성능 우선. pointer-events: none 필수.

7. **대화형에서도 동일한 배경** — 현재는 대화형에서 배경 숨기는데, 보이게 변경

**산출물**: `LadderSession.tsx` 수정
**핵심**: viewMode가 "card"든 "chat"이든 배경은 항상 전체 화면. 레벨 전환 시 이미지 fade.

## Task 3: 텍스트게임형 (카드형) 뷰 리뉴얼

**읽기**: `LadderSession.tsx` 카드형 뷰 섹션 (1097~1148번 줄), 레벨 컴포넌트들

**할 일**:
1. 카드 컨테이너 스타일 변경:
   - 기존: 카드 안에 내용 → 새로: 배경 위에 직접 텍스트
   - `rpg-panel` 등 카드 배경 제거, 텍스트만 표시
2. 내러티브 텍스트: 가운데 정렬, 큰 font-size (1.1rem), serif, text-shadow for 가독성
3. AI 응답 텍스트: Betwixt처럼 가운데 정렬, fade-in
4. 레벨 컴포넌트 스타일 수정:
   - `SensoryLevel.tsx`: 2x2 그리드 유지, 버튼을 글래스모피즘으로
   - `ComparisonLevel.tsx`: 동일
   - `AnalysisLevel.tsx`: 맞아/아닌데/모르겠어 → 글래스모피즘 버튼
   - `ChoiceLevel.tsx`: Level 4 선택지 → 글래스모피즘
   - `TextInputLevel.tsx`: textarea + 전송 → 글래스모피즘 입력창
5. 카드 네비게이션 (이전/다음): 유지, 반투명 스타일

**글래스모피즘 공통 클래스** (globals.css에 추가):
```css
.glass-btn {
  backdrop-filter: blur(12px);
  -webkit-backdrop-filter: blur(12px);
  background: rgba(255, 255, 255, 0.08);
  border: 1px solid rgba(255, 255, 255, 0.15);
  color: rgba(255, 255, 255, 0.9);
  transition: background 0.2s;
}
.glass-btn:hover, .glass-btn:active {
  background: rgba(255, 255, 255, 0.15);
}
.glass-input {
  backdrop-filter: blur(12px);
  -webkit-backdrop-filter: blur(12px);
  background: rgba(0, 0, 0, 0.3);
  border: 1px solid rgba(255, 255, 255, 0.15);
  color: rgba(255, 255, 255, 0.9);
}
```

**산출물**: 레벨 컴포넌트 5개 수정, `globals.css` 수정
**핵심**: rpg-button/rpg-panel 클래스를 glass-btn으로 교체. 기존 기능(클릭, 선택, 제출) 절대 건드리지 않는다.

## ⚠️ 주의사항

1. **기능 변경 금지**: UI 스타일만 수정. 사다리 로직, 레벨 감지, 응답 파싱, behind-the-scenes 등 기능 코드 절대 건드리지 않는다.

3. **기존 파일 먼저 읽기**: 수정 전 반드시 파일 전체 읽고 최신 코드 위에 수정.

5. **배경 이미지 경로**: 기존 `getBackgroundImage()` 함수 그대로 사용. 경로 변경 금지.
6. **파티클 성능**: CSS-only, 15~25개 제한, will-change 사용, 모바일 60fps 유지.
7. **Betwixt 레퍼런스**: `/tmp/betwixt-ref/` 스크린샷 참고하되, 풀림 세계관에 맞게 적용.
