# 세션 로그

> append-only. 세션마다 한 엔트리 추가. 새 세션은 최근 N개 또는 최근 N일 읽고 시작.
> transcript 풀 데이터는 `~/pp/아카이브/세션_백업/`에 자동 저장되니, 자세한 내용은 거기서.

**필드**:
- **목적**: 이 세션에서 풀려는 것
- **행위**: 한 일 (진단/제작/논의/실행 등)
- **근거**: 왜 이 방향이었는지 (3개월 후 "왜 그랬지?" 방지)
- **산출물**: 만들어진 것 (파일, 커밋, 결정)
- **차단**: 막힌 것 (있을 때만)
- **다음**: 다음 세션 우선순위 (구체 동사 + 대상)

**태그**: `#시스템` `#메타` `#코드` `#리서치` `#교실30` `#침실` `#전략실` `#모험가` 등 자유롭게.

**회고**: 월간. 한 달치 엔트리 검토 → 인사이트 추출 → 가장 오래된 transcript 정리.
