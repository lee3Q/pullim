# 3소스 병렬 리서치

## 문제
단일 AI 리서치는 깊이/사례/수치 중 하나만 강함. 소스별 강점이 다름.

## 방법
3개 도구를 **동시에** 돌린다:
1. Claude WebSearch — 즉시 합성, 정량 데이터 (ICLR 벤치마크 등)
2. Perplexity — 실전 사례 + 실명 + 매출 수치, 인용 풍부
3. Gemini Deep Research — 가장 깊은 탐색, 학술+실무 종합 보고서

## 결과 (2026-03-18 검증)
- Gemini: 압도적 깊이 (MAST 분류, Memory Bank, Judge Agent, CounselBench)
- Perplexity: 실전 사례 최고 (SiteGPT $15K MRR, Brdge AI, invoicing SaaS $2K MRR)
- Claude: 정량 근거 강함 (ICLR 2025 수치, sycophancy 58.19%)
- **3개 간 불일치 지점이 가장 가치 있는 발견**

## 재사용 조건
- 중요한 방향 결정 전 리서치가 필요할 때
- 단일 소스로는 확신이 안 될 때
- Perplexity/Gemini 프롬프트는 prompts/ 참조

## 교훈
- 심층 리서치 = Gemini, 사례 = Perplexity, 즉시 합성 = Claude
- 리서치 자체보다 **3개 합성 과정**에서 인사이트가 나옴
