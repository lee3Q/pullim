# 교차 모델 검증 프로토콜

## 문제
단일 LLM은 sycophancy 58%, 틀린 의견에도 63.7% 동의. 이종 모델 조합은 91% vs 동종 84%.

## 방법
1. 질문을 **3인칭으로 재구성** ("한 창업자가 X를 고려 중인데..." — sycophancy 13.6% 감소)
2. 최소 2개 이종 모델에 동일 질문
3. **일치점은 넘기고, 불일치 지점에 집중** — 이게 진짜 의사결정 포인트
4. 불일치가 있으면 3번째 모델로 3자 판정

## 사용 가능 모델 (2026-03 기준)
- Tier 1: Claude Opus/Sonnet/Haiku
- Tier 2: GLM-5 (/cross-check), GPT 5.1, Perplexity(GPT 5.4/Kimi/Sonnet), Gemini
- Tier 3: dolphin-llama3 (오프라인, 검열 없음), qwen2.5-coder

## 구현
- /cross-check 커맨드: GLM-5를 같은 세션에서 비대화형 호출
- gg 터미널 alias: GLM-5 별도 세션

## 재사용 조건
- 수치/주장의 사실 여부 확인
- 중요 의사결정 전
- 채점/평가 시 (공부 sycophancy 방지)
