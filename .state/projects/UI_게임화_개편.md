# UI 게임화 개편

**상태**: 진행 중
**현재 단계**: 1. 리서치 → 2. 요구사항 결정화 (Ouroboros Interview)
**생성일**: 2026-03-21
**우선순위**: 높음

## 배경
- 데모 피드백: AI 인간 이미지 → "B급 연애게임" 인식 (26세 여성/남성 모두)
- 리서치 확인: AI 연애앱 337개가 전부 메신저 UI + 실사 캐릭터
- 대표 결정: 게임성 텍스트 어드벤처 UI로 전환
- 학술 근거: 게임 프레이밍 = 치료적으로도 메신저 UI보다 우월 (Gemini Deep Research)

## 핵심 방향
- 메신저 UI → 텍스트 선택지 게임 UI
- AI 인간 이미지 → 동물/마스코트 캐릭터
- 테마별(모험가/전략실/달빛정원) 완전 다른 UI
- 선택지 기반 진행 + 자유 입력 보조

## 단계 (워크플로우 + Ouroboros)
1. **리서치** — 완료 ✅
   - AI 연애앱 시장 리서치 (리서치/AI_연애앱_시장_리서치_2025.md)
   - 텍스트 선택지 게임 UI 리서치 (리서치/텍스트_선택지_게임_UI_리서치.md)
   - 데모 피드백 (테스트/데모피드백/2026-03-20_데모피드백.md)

2. **요구사항 결정화** — Ouroboros Interview 활용 ← 현재
   - 모호한 요구사항 → 구체적 Seed spec으로 변환
   - 대표와 인터뷰로 범위/우선순위 확정

3. **설계** — Ouroboros Seed 생성
   - Interview 결과 → 실행 가능한 Seed spec
   - 테마별 UI 컴포넌트 설계

4. **실행** — Ouroboros Execute
   - Seed 기반 코드 구현
   - 테마별 순차 진행 (1개 테마 완성 → 나머지)

5. **검증** — Ouroboros Evaluate + /cross-check
   - 데모 피드백 기준으로 검증
   - "연애앱 느낌 나는가?" 테스트
