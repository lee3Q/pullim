# 고민 라우팅
**상태**: 진행 중
**현재 단계**: 2. 설계 완료 (기획cc + 설계cc 통과) → 3. 실행 대기
**생성일**: 2026-03-21
**현재 아키텍처 기준일**: 2026-03-26

> **아키텍처 변경 주의**: 1~2단계는 기존 6단계 파이프라인(ultimate) 기준으로 설계/완료됨.
> 3단계 실행부터는 양방향 사다리 세션(lib/session/ ladder-*) 기준으로 재정의.
> 기존 ultimate 파이프라인은 `api/ultimate/`에 병존 중 (mode=ladder 분기).

## 목표
고민 수준/성격을 자동 감지하여 적절한 세션 레벨로 라우팅.
비용 절감(모델 저비용화 연계) + 사용자 경험 개선(간단한 고민에 과잉 프로세스 제거).
