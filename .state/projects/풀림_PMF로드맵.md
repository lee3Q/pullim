## PMF 판단 기준
- 세션 완주율 > 60%
- 7일 내 재방문율 > 25%
- "매우 실망" 응답 > 40% (Sean Ellis test)

## 모델 결정 (교차검증 후 확정 예정)
- 테스트: Claude Haiku 4.5 (PIPELINE_MODEL 환경변수 오버라이드)
- 실전 Listen: Claude Sonnet 4.6 (한국어 Socratic 품질 우선)
- Behind-thought: Gemini Flash Lite (무료, 유지)
- 비용: 세션당 ~186원, 캐싱 시 ~149원

## 핵심 원칙
1. 기능 < 사용자: 기능 추가보다 사용자 확보 우선
2. 코칭 도구 포지셔닝: 의료기기/치료 포지셔닝 절대 금지 (Woebot 교훈)
3. 속도: 1인 창업의 장점 = 빠른 피드백 루프
4. 비용 관리: 월 100세션 = ~18,600원, 관리 가능
