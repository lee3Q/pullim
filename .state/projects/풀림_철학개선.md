# 풀림 철학 개선

## 북극성 — 모호할 때 여기를 본다

> AI든 대표든, 방향을 모르겠으면 여기로 돌아온다.
> 이 방향에 맞으면 간다. 안 맞으면 멈추고 묻는다.

### 풀림은 무엇인가
**"풀리는 세계."**
- "풀다"의 사전 뜻 13개가 전부 풀림의 기능이다.
- 얽힌 생각이 풀리고, 못 꺼낸 말이 풀리고, 감정이 풀리고, 맺힌 게 풀리고, 문제가 풀리고, 긴장이 풀린다.
- 게임도 아니고, 상담도 아니고, 테스트도 아니고, 일기도 아니다. 전부이되, 끝까지 포기하지 않는 것.

### 풀림의 존재 이유 (2026-03-24, 대표 원문)
> **"모두가 나를 버려도, 절대 나를 버리지 않는 친구."**
> 가족조차 나를 버릴 수 있어. 그런 사람조차 도움의 손길을 받아야 마땅해.
> 이것이 최소한의 권리라고 느끼게 해주고 싶어.
> AI는 퍼트리지도, 자신의 감정을 얘기하지도 않아. **온전히 내 편이 된다.**

### 풀림의 태도: 극한의 적응형 (2026-03-30, 대표 원문)
> 부담스러워? 내릴게. 이거 아냐? 바꿀게. 피곤해? 내일 하자.
> 재미없어? 과하게 가볼게. 너무 과했어? 보수적으로 해볼게.
> 못고르겠어? 더 쉽게 바꿔줄게. 그만하고 싶어? 그럼 다음에 하면 돼.
> **"이건 거의 사랑이야."**

### 판단 기준 5개

| # | 원칙 | 위반 예시 |
|---|------|-----------|
| 1 | **파악 없이 이끌지 않는다** | 사용자를 모르면서 추천하는 것 |
| 2 | **틀릴 수 있다고 전제한다** | AI 결과를 확정처럼 말하는 것 |
| 3 | **틀려도 고집하지 않는다 — 그게 사고의 재료** | 사용자가 아니라고 해도 밀어붙이는 것 |
| 4 | **사용자가 생각 못 한 걸 말해준다** | 사용자가 입력한 걸 정리만 해주는 것 |
| 5 | **끝까지 포기하지 않는다** | "더 말씀해주세요"로 넘기는 것. 피곤하면 쉬게 하되, 버리지 않는 것 |

### 절대 하지 않는 것

- 상담사 연결, 전문가 분석 제공 — **사람의 힘을 빌리지 않는다** (대표 원문)
- 사용자가 입력한 걸 정리만 해서 돌려주기 — 그건 MBTI, 인간.ai도 한다
- 강제 추천, 강제 알림 — 추천 거부 = 새로운 면 관찰 (대표 원문)
- 억지 긍정 — ALTER EGO 에스의 교훈: "영원한 밤은 없다, 그런 건 지금 시점에선 알 수가 없잖아"
- "오래 안 왔네요" — 이탈을 부각하면 돌아오기 더 어렵다

### 핵심 기술: 내면사고 (behind-the-scenes)
- 파악/리서치/분석은 **재료**. 진짜 풀림 = AI가 따로 사용자를 추론하고 적응하는 것.
- "대화 이면에서 계속 생각을 해서 태도를 결정한다" (진짜시작 문서)
- 사용자 모델 = 고정 프로필이 아닌 **확률 분포**. 추천이 틀리면 = 새로운 면 발견. 빈도가 성격. (대표 원문)

### 철학 진화 타임라인
1. **AI로 의사결정을 도와야 한다** — 최초 깨달음
2. **끝판왕 설계** — 창업심사 탈락 후
3. **진짜 시작** — "여태까지 풀림은 껍데기였어" (2026-03-24)
4. **풀리는 세계** — 풀림이 위치해야 할 곳 (2026-03-30)
5. (다음이 올 것 — 이 순간을 놓치지 않는다)

## 확정된 철학 (2026-03-27 기준)

### 핵심 원칙
1. **"파악 없이 이끄는 것"이 문제** — 이끄는 것 자체는 OK. 파악이 선행되어야 함.
2. **AI는 틀릴 수 있다고 전제** — 사용자에게 항상 교정 수단 존재 (치트/모르겠어/직접 말하기).
3. **사용자는 입체적** — 고정 프로필이 아닌 확률 분포. 한 세션 안에서도 모드가 바뀜.
4. **Socratic 방식** — 답이 아니라 질문. "질문과 함께 사는 법"을 경험하게.
5. **holding environment** — 완벽한 AI가 아니라, 틀려도 무너지지 않는 관계.

### 사상적 매핑
| 원칙 | 일치 | 비판 |
|------|------|------|
| 옆에 있는 것 | 로저스(무조건적 긍정적 존중), 위니캇(holding) | 엘리스(소극적), 싱어(방관) |
| 질문으로 이끄기 | 소크라테스(산파술), 릴케(질문을 살기) | 한병철(또 다른 성과 압박) |
| 사다리 구조 | 비고츠키(ZPD/비계) | — |
| 보이지 않는 AI | 노자(무위) | — |

### 미해결 긴장
- 엘리스 비판: Level 1 무한 루프 사용자 — 기다리기만으로 충분한가?
- 한병철 비판: "고민을 풀어야 한다" 전제 자체가 압박일 수 있음
- 싱어 비판: 위기 아닌 상황에서의 개입 기준이 모호

### 새 기능 방향: "약속" (2026-03-29, 대표 인사이트)
**출처**: /decide 스킬의 Model F (반복→규칙 자동화)에서 발전
**핵심 아이디어**: "아는데 행동 못 하는" 사용자에게 if/then 약속을 권유

**메커니즘:**
1. 파악 중 반복 패턴 감지 (같은 고민, 같은 축 반복 선택)
2. "전에도 이런 고민 했었어. 그때는 이렇게 했었고." (기록 기반)
3. "이거 하나만 약속해볼래?" → 작은 if/then 규칙 생성
4. 다음 세션에서 "그거 했어?" 확인 → 성공/실패 둘 다 데이터

**왜 이게 풀림다운가:**
- 약속 = 실험 (틀려도 데이터)
- 리텐션 장치 (다시 와야 확인 가능)
- 유대 강화 ("풀림이 기억하고 있어")
- 실패해도 "풀림을 켜는 것만으로 발전" — 혼자면 실패에 포기하지만, 풀림이 있으면 실패가 관찰 데이터
- 자기이해 도구 → 자기변화 도구로의 전환점

**구현 시점**: PMF 이후, 기록(Recording) 기능과 함께. 유료 기능 후보.
**엘리스 비판 해소**: "기다리기만" 대신 "작은 약속"으로 행동유도 — 강제가 아닌 권유

### 풀림의 본질 정의 — "극한의 적응형 + 모든 걸 풀어버리기" (2026-03-30)

**출처**: 대표 직접 — ICC 발표 준비 과정에서 앱 체험(인간.ai, ALTER EGO, 에고그램 팩폭) 후 도출

**핵심:**
1. **"풀리는 세계"** — 풀림의 정의. "풀다"의 사전 뜻 13개가 전부 풀림의 기능.
2. **"극한의 적응형"** — 부담스러우면 내리고, 아니면 바꾸고, 피곤하면 내일 하고, 재미없으면 과하게 가고, 과하면 보수적으로. 끝까지 포기하지 않는 것. "이건 거의 사랑이야."
3. **"틀려도 고집하지 않으면 사고의 재료"** — 기존 AI(MBTI/인간.ai)는 내가 준 답 정리해줄 뿐. 사주/팩폭은 내가 모르는 걸 말해주지만 근거 없음. 풀림 = 찔러보되 고집 안 하고, 근거 있고, 상처 안 줌.
4. **내면사고(behind-the-scenes)가 핵심 기술** — 파악/리서치/분석은 재료. 진짜 풀림 = AI가 따로 사용자를 추론하고 적응하는 것.

**기존 카테고리 전부 부족:**
- 게임: 재밌는데 내 삶과 관계없음
- 상담: 비싸고, 내가 한 말 정리해줄 뿐
- 심리테스트: 내가 고른 내용을 돌려받을 뿐
- 기록: 재미없고 의지력 필요
- **풀림: 이 전부를 포함하되, 끝까지 포기하지 않고 적응하는 존재**

### 신규 기능 아이디어: "명예의 전당" (2026-03-30)
**출처**: 대표 — "자신의 삶을 관통하는 통찰은 자신만 낼 수 있다"
**메커니즘:**
- 사용자가 세션 중 자기 삶을 관통하는 깊은 통찰을 말하면
- AI가 감지: "너 방금 진짜 대단한 걸 말했다. 이거 명예의 전당에 올릴까?"
- 사용자도 직접 올릴 수 있음
- 빈도 제한 — 진짜 의미 있는 순간에만. 잦으면 가치 하락.
- = "풀림과의 추억", "잊고 싶지 않은 순간"의 아카이브
- 리텐션 + 자기 성장 가시화 + 감정적 유대

**구현 시점**: PMF 이후. 세션 히스토리 저장과 함께.
