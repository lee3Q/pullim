# 풀림 일일 루틴 시스템

> 매일 아침/밤 30분씩. Claude가 자동 실행하고, 대표는 판단만.

## 아침 루틴 (30분)

대표가 세션을 열면 Claude가 순서대로 실행한다.

| 시간 | 누가 | 뭘 |
|------|------|----|
| 0-8분 | Claude | **일일 리포트 생성** — queue.md + projects 읽고 아래 포맷으로 `.state/daily/YYYY-MM-DD_morning.md` 작성 |
| 0-8분 | Claude | **풀림 체험** — Playwright로 홈→파악→세션 풀코스 1회. 깨진 거/어색한 거 리포트에 추가 |
| 8-15분 | 대표 | **리포트 확인** — 🔴 항목 판단 (승인/거부/보류), 오늘 집중 포인트 한 줄 |
| 15-30분 | Claude | **첫 작업 착수** — 큐 1번 항목 즉시 실행 |

## 밤 루틴 (30분)

대표가 "마무리" 또는 세션 종료 신호를 보내면 Claude가 실행한다.

| 시간 | 누가 | 뭘 |
|------|------|----|
| 0-5분 | Claude | **queue.md 갱신** — 완료 [x], 새 발견 추가, 우선순위 재정렬 |
| 5-10분 | Claude | **프로젝트 파일 갱신** — 오늘 작업 반영 |
| 10-15분 | Claude | **/handoff 실행** — 세션 핸드오프 문서 생성 |
| 15-20분 | Claude | **밤 리포트 생성** — `.state/daily/YYYY-MM-DD_evening.md` |
| 20-25분 | 대표 | **내일 방향** — 한 줄이면 충분 ("내일 디자인 매칭 집중" 등) |
| 25-30분 | Claude | **밤샘 배치 준비** — 있으면 `scripts/start-batch.sh` 태스크 구성 |

## 낮 체크인 (3시간 간격)

밤배치 외에는 대표가 ~3시간마다 확인한다. Claude는 자율 실행하되 체크인 시점에 맞춰 정리.

| 시점 | Claude | 대표 |
|------|--------|------|
| 체크인 시 | 진행 상황 3줄 요약 + 다음 할 것 | 확인, 방향 조정 있으면 한마디 |
| 체크인 사이 | 큐 순서대로 자율 실행 | 안 봐도 됨 |

체크인 요약 포맷 (Claude가 자동):
```
지금: [뭐 하고 있었는지]
완료: [체크인 사이 끝낸 것]
다음: [이제 뭐 할지]
```

## 두어스 수집 (항상 ON)

아산두어스 마감(04-20)까지, 모든 작업 중 두어스 소재가 될 만한 것을 자동 감지:
- 기술 역량 증빙 (구현 완료, 검증 통과 등)
- Born Global 논거 (문화 무관, 1인 개발 파이프라인)
- MVP 사용 데이터/체감
- 수집 시 → 아산두어스_신청.md "수집 로그"에 자동 추가

## 리포트 포맷

### 아침 리포트 (`.state/daily/YYYY-MM-DD_morning.md`)

사다리 방식: Level 1만 먼저 보여주고, "이해했어"하면 Level 2, "더 알려줘"하면 Level 3.

```markdown
# 아침 리포트 — YYYY-MM-DD

## Level 1 — 한눈에 (여기만 먼저 읽기)
- 지금: [한 줄 — 어디까지 왔는지]
- 다음: [한 줄 — 오늘 뭐 할지]
- 판단: [있으면 한 줄 / 없으면 "없음, 다 자율 실행"]

## Level 2 — 프로젝트별 (이해했으면 여기)

### 큐 현황
즉시: N개 | 🔴 대표확인: N개 | 보류: N개

### 프로젝트
| 프로젝트 | 단계 | D-day | 다음 액션 |
|----------|------|-------|-----------|
| 이름 | N단계 | D-N | 한 줄 |

### 🔴 대표 판단 필요
1. **항목명** — 맥락 1줄. 추천: [A] or [B]
(없으면 "없음")

### 오늘 추천 작업 (30분 단위)
1. 작업명 (~N분) — 왜 지금
2. 작업명 (~N분) — 왜 지금
3. 작업명 (~N분) — 왜 지금

## Level 3 — 상세 (더 알려줘 하면 여기)

### 체험 피드백
- Playwright 결과 또는 수동 확인 메모

### 두어스 수집 노트
- 어제/오늘 작업 중 두어스에 쓸 만한 소재

### 기술 맥락
- 어제 작업의 기술적 결정사항, 남은 이슈
```

### 밤 리포트 (`.state/daily/YYYY-MM-DD_evening.md`)

```markdown
# 밤 리포트 — YYYY-MM-DD

## Level 1 — 한눈에
- 오늘: [한 줄 — 뭘 했는지]
- 내일: [한 줄 — 뭘 할지]
- 판단: [내일 필요한 거 / "없음"]

## Level 2 — 상세

### 오늘 완료
- [x] 항목 — 결과 한 줄

### 내일 이어갈 것
1. 항목 — 현재 상태

## 큐 변동
- 추가: N개 (항목명)
- 완료: N개
- 우선순위 변경: (있으면)

## 두어스 수집 (오늘분)
- 소재 한 줄 설명

## 밤샘 배치
- 실행: Y/N
- 태스크: (있으면 목록)
```

## 자동화 트리거

| 트리거 | 실행 |
|--------|------|
| `/pullim` (세션 시작) | 아침 루틴 자동 시작 |

| 작업 완료 시 두어스 소재 감지 | 수집 로그 자동 추가 |

## 백그라운드 자동 리포트 (선택)

세션 없이 리포트만 미리 생성하려면:
```bash
cd ~/study/main/pullim
claude -p "queue.md와 projects/ 읽고 .state/daily/$(date +%Y-%m-%d)_morning.md 에 아침 리포트 생성해. 리포트 포맷은 .state/routines.md 참고." --model sonnet
```
시스템 cron에 등록하면 매일 기상 전 자동 생성 가능.
