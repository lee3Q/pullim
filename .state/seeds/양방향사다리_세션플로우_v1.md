# Seed: 양방향 사다리 세션 플로우

## Goal
풀림의 기존 6단계 파이프라인(LISTEN→RESEARCH→ANALYZE→DEBATE→JUDGE→CONCLUDE)을 **양방향 사다리 통합 세션**으로 전면 교체한다. 사다리 안에서 경청, 분석, 감각화가 자연스럽게 섞이며, 각 레벨마다 명시적으로 다른 UI를 제공한다.

## Context
- 스택: Next.js 15, React 19, TypeScript, Tailwind CSS 4, Zustand, Claude API (Sonnet), SSE streaming
- 기존 코드 활용 가능한 것: PersonaConfig(3테마), BehaviorSignals, ProbabilityProfile, crisis-detector, sensory-ladder.ts(프롬프트 빌더)
- 기존 코드 교체 대상: StageName 타입, 세션 페이지의 단계 전환 로직, listen/route.ts의 턴 기반 종료 로직
- 홈 화면(page.tsx)은 이미 "오늘 어떤 마음이야?" → 파악/입력 두 경로 구현 완료

## 핵심 설계 원칙 (반드시 준수)
1. **사용자 모델 = 확률 분포** — 고정 프로필 아님. 세션마다 다른 면 관찰. 빈도가 성격.
2. **추천 = 관찰 도구** — 틀린 추천이 시스템을 더 정확하게 만든다. 모든 선택지에 항상 추천 표시.
3. **이면 사고 루프** — 수집(비언어 신호) → 추론(사용자 상태) → 조정(태도/톤/레벨) 순환. 수집만으로 끝나면 안 됨.
4. **말이 아닌 행동으로 파악** — 사용자가 "안다"고 말해도 행동이 일치하는지, 만족하는지 이면에서 확인.
5. **고민 없어도 진입 가능** — 진입 상태 3가지: 고민있음 / 심심 / 궁금. 사다리 레벨과는 별도 차원.

## 사다리 5레벨 상세

### Level 5 (최상단): 직접 말하기
- **UI**: 자유 텍스트 입력 + 미니멀 채팅 인터페이스
- **AI 역할**: Socratic 질문 (Powerful Question, Mirroring, Reframing)
- **선택지**: 없음 (자유 입력). 단, 하단에 "선택지 보여줘" 폴백 버튼
- **도구**: 없음 — 사용자가 직접 표현

### Level 4: 선택지 + 추천
- **UI**: 3~4개 선택지 버튼 + 추천 하이라이트 + "직접 쓰기" 옵션
- **AI 역할**: 맥락 기반 선택지 생성 + 1개 추천 표시
- **선택지 규칙**: 이모지 + 짧은 텍스트, 마지막은 항상 "모르겠어"
- **도구**: 리서치 제안 ("이거 찾아볼까?"), 간단한 정보 제공

### Level 3: 분석 제안
- **UI**: AI 분석 카드 + "맞아" / "아닌데" / "모르겠어" 3버튼
- **AI 역할**: "이렇게 보이는데 맞아?" 형태의 분석 제시
- **도구**: 극단화, 타인시점, 사후가정법, 제거법, 시나리오몰입
- **분석이 맞으면**: 다음 질문으로 깊어짐 (같은 레벨 유지 또는 올라감)
- **분석이 틀리면**: "그럼 어떤 쪽이야?" → 새 분석 또는 내려감

### Level 2: 감각 변형
- **UI**: 대비되는 2개 카드 (이미지+텍스트) + "이쪽이 더 끌려?" + "둘 다 아닌데" 버튼
- **AI 역할**: 고민을 두 가지 감각적 대비로 변환
- **도구**: 코인플립, 가치경매, 선택지인격화, 타임머신, 빠른직관질문
- **예시**: "10년 뒤 A를 선택한 너" vs "10년 뒤 B를 선택한 너" → 어떤 쪽?

### Level 1 (최하단): 감각
- **UI**: 이미지/이모지 카드 3~4장 + 탭으로 선택 + "다 별로야" 버튼(치트선택지)
- **AI 역할**: "이거 좋아?" 수준의 단순 감각 질문
- **도구**: 신체반응 ("이거 생각하면 가슴이?"), 이미지 기반 직관
- **핵심**: 말 못하는 사람도 끝까지 진행 가능. 아기에게 간식 갖다주듯.

## 레벨 이동 메커닉

### 내려가기 (명시적)
- 모든 레벨에 "모르겠어" 버튼 존재 (Level 1 제외 — 최하단)
- 누르면 한 단계 아래 UI로 전환
- Level 1에서도 모르겠으면 → "오늘은 여기까지" or 다른 감각 카드 제시 (포기 없음)

### 올라가기 (자연스러움)
- AI가 유도하지 않음. 사용자가 스스로 올라감:
  - Level 1에서 확실히 고르면 → Level 2 카드가 자연스럽게 등장
  - Level 2에서 한쪽을 강하게 선택 → Level 3 분석 제안
  - Level 3에서 "맞아" 연속 → Level 4 선택지 등장
  - Level 4에서 "직접 쓰기" 선택 → Level 5로 전환
- **이면 사고가 올라가기를 판단**: 선택 확신도(응답시간+변경횟수)가 높으면 다음 레벨 요소 자연스럽게 혼합

## 세션 진입

### 진입 화면 (세션 시작 직후)
사용자가 시작 레벨을 선택한다. 추천은 프로필 기반으로 표시:
```
오늘은 어떻게 시작할까?

[💬 직접 말할게]          ← Level 5
[📋 선택지 보여줘] ⭐추천  ← Level 4 (기본 추천)
[🎴 느낌으로 할래]        ← Level 1~2
```
- 추천 기준: 프로필의 selfAwareness + approachStyle
- 첫 사용자(프로필 없음): Level 4 기본 추천

### 진입 상태 3가지 (홈 화면에서 결정됨)
| 진입 상태 | 세션 내 행동 |
|-----------|-------------|
| 고민있음 | 고민 해결 방향으로 사다리 운영 |
| 심심 | 철학/심리학 이야기화 → 가치관 수집 |
| 궁금 | 자기 분석 → 패턴 확인 |

## 이면 사고 레이어

### 수집 (매 턴)
| 신호 | 수집 방법 |
|------|-----------|
| 응답 시간 | 메시지 전송 ~ 사용자 응답까지 ms |
| 선택 패턴 | 추천 수락/거부, 선택지 변경 횟수 |
| 메시지 길이 변화 | 이전 N턴 대비 증감 |
| 참여도 변화 | 응답시간+길이 복합 지표 |
| 치트 피드백 | "다 별로야" / 불만족 버튼 탭 횟수+시점 |

### 추론 (매 턴, LLM 호출 전)
수집된 신호를 `readBehavior()` 확장 → 현재 사용자 상태 추론:
- 피로/이탈 위험 → 가볍게 전환 or 마무리 제안
- 결정 어려움 → 레벨 내려가기 넛지 (직접 제안 아닌 선택지 단순화)
- 마음 열림 → 현재 레벨 유지, 깊어지기
- 확신 증가 → 다음 레벨 요소 자연 혼합

### 조정 (시스템 프롬프트 주입)
추론 결과를 `[BEHAVIOR_CONTEXT]` + `[SENSORY_LADDER]` 블록으로 시스템 프롬프트에 주입.
AI는 이 지시를 따르되 사용자에게 직접 언급하지 않음.

## 치트 선택지 (명시적 불만족 피드백)
- 모든 레벨의 선택지에 항상 존재: "다 별로야" / "이거 아닌데" / "뭔가 다른 거"
- UI: 작지만 항상 보이는 버튼 (선택지 하단 또는 우측)
- 누르면: 이면 사고 레이어에 "불만족" 이벤트 기록 + AI가 다른 접근 시도
- 3회 연속 시: "오늘은 이 주제 접어둘까?" 제안

## 세션 종료

### 사용자 주도 종료
- 항상 접근 가능한 "오늘은 여기까지" 버튼 (우상단 또는 하단)
- 누르면: 세션 요약 카드 표시 (오늘 발견한 것 1~3줄)

### AI 제안 종료
- **트리거**: 사용자가 구체적 행동/해결책을 언급했을 때만
- 판단 기준: Level 4~5에서 "~해야겠다", "~할래" 등 행동 의지 표현 감지
- AI: "정리해볼까?" 제안 → 수락 시 세션 요약 + 다음 행동 정리
- **절대 하지 않는 것**: 감각 레벨(1~2)에서 종료 유도. 감각 탐색은 끝없이 계속 가능.

## 테마별 분기
3개 테마 유지. 사다리 구조는 동일하되:
| 테마 | 톤 | 감각 소재 | 분석 프레임 |
|------|-----|-----------|------------|
| 모험가 | 고어체, 현자 | 모험 이야기, 자연 | 여정/선택 비유 |
| 달빛정원 | 반말, 친구 | 꽃/빛/계절 | 감정/관계 비유 |
| 전략실 | 존댓말, 비서 | 전략보드/차트 | 비용/리스크 프레임 |

## Acceptance Criteria (행동 기준)

### 필수 (MVP)
1. 사용자가 Level 1(감각)에서 시작해서 "모르겠어" 없이 Level 5(직접 말하기)까지 자연스럽게 올라갈 수 있다
2. 사용자가 Level 5에서 시작해서 "모르겠어"를 3번 눌러 Level 2까지 내려가도 세션이 끊기지 않고 계속된다
3. 모든 선택지에 추천이 표시되고, 추천과 다른 것을 골라도 자연스럽게 진행된다
4. "다 별로야" 치트 선택지가 모든 레벨에 존재하고, 누르면 AI가 다른 접근을 시도한다
5. 각 레벨의 UI가 명시적으로 다르다 (Level 1=이미지카드, Level 4=버튼, Level 5=텍스트입력)
6. "오늘은 여기까지" 버튼이 항상 접근 가능하고, 누르면 세션 요약이 표시된다
7. 3개 테마(모험가/달빛정원/전략실)에서 각각 다른 톤으로 동작한다

### 이면 사고 (MVP)
8. 응답시간, 선택패턴, 메시지길이 3종이 매 턴 수집된다
9. 수집된 신호가 다음 턴의 AI 응답 톤/접근에 반영된다 (시스템 프롬프트 주입)
10. 치트 선택지 탭이 이벤트로 기록된다

### 통합 (MVP)
11. 홈 → "고민이 있어" → ThemeSelector → 새 사다리 세션으로 진입한다
12. 홈 → 파악 완료 → "고민도 풀어볼래?" → 프로필 데이터가 세션에 전달된다
13. 기존 listen/route.ts API가 사다리 레벨 컨텍스트를 받아 적절한 응답을 생성한다

### 진입 분기 + 관찰 (MVP)
14. 심심/궁금 진입 시 세션이 고민 모드와 다르게 동작한다 (이야기화/자기분석 방향)
15. 사용자가 추천과 다른 선택을 하면 그 데이터가 ProbabilityProfile에 반영된다 (틀린 추천 = 관찰 데이터)
