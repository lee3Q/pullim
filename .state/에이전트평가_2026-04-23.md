# 에이전트 병렬 평가 — 2026-04-23

대표 지시: "시장에서 먹힐지 조사 / 에이전트 평가 및 반영"

## Agent 1: 시장 적합성 (완료)

### Market Fit
- Pain은 있지만 좁음. "discomfort" 수준에 가까움 → 지불 의사 5-8%
- Heavy user 예측: HSP/회피형/내향 여성 25-34, ADHD 외재화 타입
- 기반 설치 대비 월 9,900원 지불은 주 3회+ 사용자

### 경쟁자
- **Wysa/Woebot**: CBT 처방. 풀림 비처방은 차별화 O
- **Replika**: romantic-companion drift — 풀림의 소크라테스식과 거리 멂 (좋음)
- **트로스트/마인드카페**: 상담 매칭 → 풀림이 "상담 전 단계" 포지션 가능
- **Finch**: 게이미피케이션. 풀림이 배지/스트릭 의도적 거부 — 용감하나 리텐션 무기 포기
- **ChatGPT 맨입**: 진짜 경쟁자. 사다리·세계관·편지로 차별화하지만 사용자가 그걸 알기 전 이탈

### Top 3 Risks
1. **온보딩 과부하** — 5세계·사다리·치트·편지·약속. Power user 최적, 신규 적대적
2. **LocalStorage 락인** — 기기 바꾸면 전당·약속·편지 증발. **감정 데이터 축적이 핵심 가치인데 휘발**
3. **위기 대응 책임** — RED 차단해도 소송 리스크. 면책 + 보험/법률 검토

### Top 3 Opportunities
1. **"상담 대기 중" 세그먼트** — 정신과 초진 대기 2-8주. B2B2C
2. **퇴사/이직 결정 니치** — 원티드/잡플래닛 제휴
3. **교회·명상센터·학교 번들** — SaaS 라이선스

### Radical Suggestion
**"풀림의 편지"를 주간 → 실시간 종이 엽서**로. 월 3,900원 구독자에게 실물 발송. 디지털 포화 시대 moat. localStorage 이슈도 "편지 보관함"으로 우회.

## Agent 2: 철학-제품 정합성 (완료) — 7.5/10

### 최강 / 최약
- **최강**: #2 "틀릴 수 있다고 전제" — BEHIND_THE_SCENES + tap-to-correct + cheat 3-branch. 업계 드문 수준.
- **최약**: #4 "사용자가 생각 못 한 걸 말해준다" — ladder/테마는 탐색 구조만, AI가 사용자 시야 밖 제시한다는 보장 없음.

### Shadow Mission Leak (중요)
1. **풀림의 편지** — parroting(#2) + 부재 강조(절대금지) 동시 위반 가능
2. **Fatigue card "rest today"** — forced positivity 우회 ("괜찮아질 거야" 대신 보호적 포지티브)
3. **Breath interlude on fatigue detection** — 파악 없이 개입(#1) 프록시 위반 가능

### Philosophy Gap
**신규 원칙 후보 #7**: "개입하지 않을 용기" / "말하지 않는 것이 풀림일 때가 있다"
- 현 6원칙은 모두 "AI가 할 것". "하지 않을 것"이 금지목록으로만 존재
- 능동적 기능 늘수록 침묵의 가치 누락

### Dialectic Concern (#6)
- 절반 진짜, 절반 feature framing
- 다른 원칙은 AI 태도, #6만 세션 구조 — 카테고리 오류
- **붕괴 위험**: "모은다"가 강제되면 AI가 단정 → #2(틀릴 수 있다) 위반
- **권고**: #6을 원칙에서 "세션 구조 원리"로 재분류 OR "사용자가 스스로 모을 때만"으로 제약 명시

## Agent 3: UX 마찰 감사 (완료) — 가장 행동 가능한 발견

### Top 5 마찰 (심각도순)
1. **홈 인지 과부하 (치명)** — 9개 의사결정 지점. 2AM 사용자 이탈.
2. **🎮 이야기 vs 💬 직접 이분법 (고)** — 🎮 "놀이" 톤이 위기 사용자와 부정합.
3. **Level 4 [추천] 배지 (고)** — 우울 상태에서 권위로 읽혀 자기 판단 위축.
4. **Crisis Tier A 모달 (치명 가능)** — 모달=차단. 전화 허들 너무 높음. 인라인 + 문자 옵션 + "여기 있을게" 선행 필요.
5. **다 별로야 카운터** — 판결로 느껴짐. "접어둘까?"는 포기 제안으로 오독 가능.

### 숨은 접근성 갭
- 저문해력 / 스크린리더(이모지) / 인지피로 / 색약 / 미세운동 장애

### 톤/카피 위반
- ⏳ 미완 세션 카드 → "미제출 과제" / "포기의 증거"
- 💫 약속 / 🪷 한 문장 **카운트 표시 = 게이미피케이션** → 자책 유발 가능
- [추천] 배지 = 자율성 침해
- "오늘은 여기까지" — 사용자 vs AI 주체 혼재 시 *쫓겨남* 감각

### 1시간 내 배포 가능 수정
1. 홈 "그냥 시작할게" 단일 기본 CTA (최상단)
2. Crisis 모달 → 인라인 3버튼 ("여기 있을게" / 109 문자 / 전화 / 계속)
3. [추천] 제거 + Level 4 옵션 3개 하드캡 + "모르겠어" 별도 분리

### 창업자에게 던지는 질문 (근본)
> "미완 세션 카드와 약속 카운트는 사용자를 **돌아오게 하는 장치**인가, 아니면 사용자의 **자책을 강화하는 장치**인가?"

→ 이 답에 따라 풀림이 "멘탈케어"인지 "habit tracker with feelings"인지 갈린다.
