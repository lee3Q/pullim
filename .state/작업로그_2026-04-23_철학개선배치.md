- 전체/별표 필터
- 각 항목: 테마 태그 + 날짜 + 직전 AI 질문(context) + 사용자 원문
- ↗ 공유 (navigator.share 또는 clipboard)
- ☆/⭐ 별표 토글
- × 삭제 (confirm)

### 보이지 않지만 AI에 주입되는 것들
- 📊 최근 피드백 이력 (misread rate, 직전 5분 내 교정 여부)

- 📊 `seed=` 파라미터 있으면 "사용자가 한 단어로: ..." 주입
- 📊 `resume=1`이면 `session-trail`을 `[PRIOR_SESSION_CONTEXT]`로 변환 주입
- 📊 `light=1`이면 `[LIGHT_MODE]` 블록 주입
