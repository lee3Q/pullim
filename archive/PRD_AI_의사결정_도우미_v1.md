## 1. 문제 정의

사람들은 중요한 결정 앞에서 고통받는다.

| 현상 | 구체적 예시 |
|------|-----------|
| 뭘 모르는지 모른다 | "이직해야 하나?" — 뭘 기준으로 판단해야 하는지조차 모름 |
| 혼자 반추한다 | 같은 걱정을 밤마다 반복. 진전 없음 |
| 정보 과잉 | 검색할수록 혼란. 블로그마다 다른 말 |
| 방법을 몰라서 못 한다 | 의사결정 프레임워크가 수십 개지만, 어떤 상황에 뭘 쓸지 모름 |
| AI가 있지만 구조가 없다 | ChatGPT에 "이직해야 할까요?" → 장단점 나열 → 여전히 모르겠음 |

**핵심 문제**: 좋은 의사결정 방법은 이미 존재한다. 문제는 일반인이 "어떤 상황에 어떤 방법을 쓸지" 모른다는 것이다.

## 2. 해결책

**"고민을 고통이 아니라 흥미로운 분석으로 바꿔주는 AI 의사결정 도우미"**

### 핵심 메커니즘

AI가 답을 주지 않는다. 대신:
1. **상황을 자동 분류**하고 (라우팅)
2. **맞는 질문 세트를 던지고** (Socratic questioning)
3. 사용자가 답하면서 **스스로 명확해지게** 하고
4. 세션 끝에 **의사결정 정리 문서**를 생성하고
5. 시간이 지나면 **"그 결정 어떻게 됐어?"**를 추적한다

### 사용 흐름

```
고민 입력 ("이직해야 할까?")
    |
[0층] 감정/컨디션 체크 ("지금 감정적으로 힘든 상태야?")
    |
[1층] AI 자동 라우팅 (가역성/중요도/긴급성 판단)
    |    -> "이건 커리어 전환 결정이네. 깊은 프로토콜로 갈게."
    |
[2층] 상황 맞춤 질문 세트 (5-7개)
    |    -> "지금 회사에서 가장 불만인 점 3가지는?"
    |    -> "이직하면 뭐가 달라질 거라 기대해?"
    |    -> "이 결정이 실패한다면, 왜일까?" (Pre-mortem)
    |
[3층] 의사결정 정리 문서 자동 생성
    |
[추적] 1주/1개월 후 "그 결정 어떻게 됐어?"
```

## 3. 기존 제품과의 차별점

### 3-1. ChatGPT 자유 대화 vs 우리

| ChatGPT | AI 의사결정 도우미 |
|---------|-------------------|
| 사용자가 질문해야 함 | AI가 질문을 던짐 (Socratic) |
| 답변 위주 | 정리 위주 (사용자가 결론 도달) |
| 산발적 | 의사결정 프레임워크 자동 선택 |
| 결과물 없음 | 의사결정 정리 문서 자동 생성 |
| 후속 없음 | 추적 + 패턴 학습 |
| 맥락 리셋 | 의사결정 히스토리 축적 |

### 3-2. 경쟁 제품 비교

| 제품 | 방식 | 타겟 | 우리와의 차이 |
|------|------|------|-------------|
| SkillWee | 시뮬레이션 결과 보여줌 | 일반 성인 | 답을 줌. 라우팅/Socratic 없음 |
| Cogito Coach | Socratic questioning | 학생/청소년 | 가장 유사하나 학생 특화. 라우팅 없음 |
| Decision AI | AI 추천 | 일상 선택 | 단순 추천. 구조화 없음 |
| Decision Mentor | 기준 점수화 | 개인/팀 | MCDA만 제공. 상황별 전환 없음 |
| Socra | Socratic + Feynman | 학습자 | 학습 특화. 의사결정 전용 아님 |
| Rocky | AI 코칭 | B2B 리더십 | 기업 중심. 개인 의사결정 아님 |

### 3-3. 우리만의 차별점 (경쟁 제품에 없는 것)

1. **자동 라우팅**: 고민의 종류/중요도를 AI가 판단해서 맞는 방법론을 자동 선택
2. **0층 Being 체크**: 감정/컨디션 점검 후 "지금 결정해도 되는 상태인지" 확인
3. **의사결정 히스토리 + 패턴 학습**: "너는 관계 결정에서 항상 회피해" 같은 개인화
4. **"안 한다" 선택지**: 모든 결정에 "지금 안 한다"를 정식 옵션으로 포함
5. **한국 시장 1호**: 한국어 의사결정 코치 B2C 앱 현재 없음

## 4. 타겟 사용자

### 1차 타겟: 진로/이직 고민자 (20-30대)
- "이 회사 다녀야 하나, 이직해야 하나"
- "대학원 가야 하나, 취업해야 하나"
- 왜: 가장 빈번하고, 구조화 효과가 큰 영역

### 2차 타겟: 관계 갈등 당사자
- "헤어져야 하나, 계속 만나야 하나"
- "이 친구와 거리를 둬야 하나"

### 3차 타겟: 생활 결정자 (전연령)
- "독립해야 하나", "축의금 얼마 내야 하나", "이사해야 하나"

**MVP는 1차 타겟(진로/이직)에 집중.**

## 5. 핵심 기능 (MVP)

### Must Have (MVP)
| 기능 | 설명 |
|------|------|
| 고민 입력 | 자유 텍스트로 고민 입력 |
| 자동 라우팅 | AI가 고민 유형/중요도 판단 -> 질문 세트 선택 |
| Socratic 질문 세트 | 상황별 구조화된 질문 5-7개 (진로 특화) |
| Pre-mortem 질문 | "이 선택이 실패한다면 왜?" 자동 삽입 |
| 의사결정 정리 문서 | 세션 끝에 1페이지 정리 자동 생성 |

### Should Have (v1.1)
| 기능 | 설명 |
|------|------|
| 감정 상태 체크 (0층) | 세션 시작 시 컨디션 확인 |
| 추적 알림 | 1주 후 "그 결정 어떻게 됐어?" 리마인더 |
| 의사결정 히스토리 | 과거 결정 목록 + 결과 기록 |

### Nice to Have (v2)
| 기능 | 설명 |
|------|------|
| 패턴 분석 | "너는 X 결정에서 항상 Y 편향이 있어" |
| 다중 프레임워크 | 진로 외 관계/재정/생활 도메인 확장 |
| 커뮤니티 | 비슷한 고민 사례 (익명) 공유 |

## 6. 기술 스택 (MVP)

### 옵션 A: 웹 챗봇 (최소 구현)
- Frontend: Claude Artifacts 또는 Next.js
- Backend: Claude API (Socratic 질문 생성 + 정리 문서 생성)
- DB: Supabase (사용자 히스토리)
- 비용: 세션당 약 500-2,000원 (Claude API)

### 옵션 B: 기존 플랫폼 활용 (더 빠른 검증)
- Claude Code + CLAUDE.md로 프로토타입 구현
- 실제 사용자에게 터미널 기반으로 테스트
- 반응 확인 후 웹/앱으로 전환

**권장: 옵션 B로 빠르게 검증 -> 옵션 A로 확장**

## 7. 비즈니스 모델

### 수익 구조
- 무료: 월 3회 세션
- 프리미엄: 월 5,000-10,000원 (무제한 + 히스토리 + 패턴 분석)

### 시장 규모 추정
- 한국 20-30대 인구: 약 1,300만 명
- "중요한 결정에 고민 중": 연간 최소 1회 이상 = 대부분
- 유료 전환율 3% 가정 -> TAM 약 39만 명 x 연 6-12만원 = 234-468억원
- 초기 현실적 목표: 유료 사용자 1,000명 (월 500-1,000만원)

### 유닛 이코노믹스
- CAC (고객 획득 비용): SNS/커뮤니티 기반 -> 초기 5,000원 이하
- LTV (생애 가치): 월 7,500원 x 평균 6개월 = 45,000원
- LTV/CAC > 9 -> 건강한 구조

## 8. 창업자 강점

### "1년간 AI로 모든 중요한 의사결정을 해온 실 사용자"

| 실제 사용 사례 | 방법 |
|--------------|------|
| 진로 변경 (노무사 시험 결정) | 에이전트 팀 토론 |
| 연애 관계 종합 분석 | 다면 분석 + 최종 보고서 |
| 영어 학습 방식 결정 | 6인 전문가 + 천재3 + 비판1 토론 |
| 일일 의사결정 자동화 | 밤 회의 시스템 |
| 의사결정 체계 자체 설계 | 5개 분야 리서치 + 4명 에이전트 토론 (오늘) |

- 비개발자이기 때문에 일반인의 어려움을 직접 안다
- 형(Q00)이 ouroboros(Socratic interview 시스템) 개발자 -> 기술 자문 가능
