## 즉시 개선 (이번 주)

- 스크립트: 박도현 3/14 작성
- 채널: 대표 3/15 확보
- ChatGPT vs 풀림 A/B 비교: 서윤하 3/20

### 2. Opus → Sonnet 다운그레이드
- 세션 비용: 543원 → 80~120원 (추정, 실측 필요)
- 모든 `claude-opus` 참조 → `claude-sonnet-4-6` 교체
- 담당: 한재원, 3/14

### 3. 안전/법적 기초 구축
- 이용약관 + 면책조항 초안: 최서영 3/16
- 법률 자문 연결: 박도현+대표 3/20
- 위기 감지 2-tier 명문화 (L1 키워드 + L2 LLM): 서윤하+최서영 3/17
- **서영 거부권**: 위 완료 전 신규 사용자 확대 금지

### 4. API 보안
- rate limit (IP당 분 5회, 일 20세션): 한재원 3/16
- Sentry 모니터링: 한재원 3/16
- API 프록시화 (클라이언트 키 노출 차단): 한재원 3/16

### 5. 차별화 정의
- "ChatGPT 대비 7,500원의 가치" 한 문장 초안 3개: 서윤하 3/17

## MVP 착수 시 개선

### 8. DB 연동 (Supabase)
- 세션 저장 → 데이터 록인 주장의 물리적 기반
- 위기 대응 로그 아키텍처 포함

### 9. 인증 최소 구현
- 유료/무료 구분
- 결제 연동

### 10. 타임아웃 해결
- 파이프라인 단계별 스트리밍 분할
- Supabase Realtime으로 진행 상태 표시

## 에이전트 팀 운영 개선

### Before
- 안건: 내부 문서 작업, PPT, 발표 대본 등
- 95% 문서, 5% 코드
- 라운드 2 크로스체크 형식화

### After
- 안건: **사용자 피드백 기반만**
- 내부 문서 작업용 회의 중단
- 크로스체크는 "근본 비판" 포함 필수 (표면적 피드백 금지)
