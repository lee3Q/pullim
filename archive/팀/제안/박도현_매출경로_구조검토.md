친구 조언 "어떻게 돈 버냐가 핵심" — 맞습니다. 심사위원은 "좋은 아이디어"에 점수를 주는 게 아니라 **"이 팀이 실제로 돈을 벌 수 있는가"**에 점수를 줍니다. 현재 신청서는 시장 분석과 경쟁사 분석은 탄탄한데, 정작 **"그래서 언제, 어떻게, 얼마를 버느냐"가 설득력 있게 연결되어 있지 않습니다.**

## 1. 매출 경로 강화 — 슬라이드 9, 16, 17 개선안

### 1-1. 슬라이드 9 (비즈니스 모델) — 현재 상태와 문제

**현재**: 플로우차트 + 수익원 3줄 나열
**문제**:
- "왜 사용자가 돈을 내는가"가 빠져 있음
- 무료→유료 전환 논리가 없음 ("월 3회" 제한이 왜 전환을 유발하는지 설명 없음)
- B2B EAP와 정부 그랜트는 지금 단계에서 심사위원이 신뢰하기 어려움 (매출 다각화보다는 핵심 경로 집중이 필요)

**개선안**:

```
슬라이드 9 — 비즈니스 모델 (개선)

### 핵심 매출 경로: "고민 → 정리문서 → 돈"

[무료 체험] 월 3회 세션 무료 → 의사결정 정리 문서 체험
    ↓
[WOW 모먼트] "내 고민이 1페이지로 정리됐다" — 이게 핵심 가치
    ↓
[전환 트리거] 4번째 고민이 생겼을 때 → 유료 구독 결정
    ↓
[유료 구독] 월 7,500원 (무제한 세션 + 히스토리 축적 + 패턴 분석)
    ↓
[잠금 효과] 3개월 차 → 의사결정 히스토리 5건+ 축적 → 이탈 비용 상승

### 왜 돈을 내는가?
1. 정리 문서 = 눈에 보이는 산출물 (상담 앱에 없는 것)
2. 히스토리 축적 = 시간이 지날수록 가치 증가 (전환 비용 상승)
3. 심리상담 1회 5~20만원 vs 풀림 월 7,500원 = 가격 차이 27배

### 수익원 (우선순위)
| 순위 | 수익원 | 가격 | 시점 |
|------|--------|------|------|
| 1 | B2C 프리미엄 구독 | 월 7,500원 | 5~6월 (MVP 출시 후) |
| 2 | 정부 지원금 | 변동 | 현재 진행 중 (동아리 250만) |
| 3 | B2B EAP | 인당 월 3,000~5,000원 | 9월~ (PMF 확보 후) |
```

**포인트**: "수익원이 3개 있다"보다 **"무료→WOW→유료 전환이 왜 일어나는가"**를 스토리로 보여줘야 합니다. 심사위원은 수익 구조의 논리를 봅니다.

### 1-2. 슬라이드 16 (소요자금 및 예상 매출) — 현재 상태와 문제

**현재**: 비용표 + 매출 목표표 + 유닛 이코노믹스 3줄
**문제**:
- 6개월 후 갑자기 유료 1,000명이 나타남. **어떻게 1,000명이 되는지 경로가 없음**
- LTV/CAC > 9는 너무 낙관적. CAC 5,000원은 초기 커뮤니티 바이럴 가정인데, 근거가 약함
- "비용 320만원, 매출 750만원" — 왜 이게 가능한지 설명이 없으면 허수처럼 보임

**개선안**:

```
슬라이드 16 — 소요자금 및 예상 매출 (개선)

### 소요 자금 (6개월)
| 항목 | 월 비용 | 6개월 합계 | 비고 |
|------|---------|-----------|------|
| LLM API (Claude) | 30~50만 | 180~300만 | 1,000세션/월 기준, Haiku+Sonnet 혼합 |
| 서버 (Vercel+Supabase) | 5만 | 30만 | 무료 티어 + 소규모 |
| 도메인/SSL | - | 3만 | 연 1회 |
| 마케팅 (SNS/커뮤니티) | 10만 | 60만 | 에브리타임 광고, 블라인드 게시글 |
| 시제품 디자인/테스트 | - | 50만 | 1회성 |
| **합계** | | **약 320~440만** | |

### 사용자 성장 시나리오 (보수적)
| 시점 | 월 방문자 | 가입자 | 유료 전환 | MRR |
|------|----------|--------|----------|-----|
| 5월 (MVP 출시) | 500 | 100 | - | 0원 |
| 6월 | 1,000 | 250 | 13명 (5%) | 10만원 |
| 7월 | 2,000 | 600 | 45명 (누적) | 34만원 |
| 동아리 종료 후 3개월 | 5,000 | 1,500 | 150명 | 113만원 |
| 동아리 종료 후 6개월 | 10,000 | 3,000 | 300명 | 225만원 |
| **12개월 후 목표** | **20,000** | **6,000** | **1,000명** | **750만원** |

* 전환율 5%, 가입 전환 20%, 월 이탈률 10% 가정
* 1,000명 도달 시점: MVP 출시 후 약 12개월 (동아리 활동 포함 약 14개월)

### 유닛 이코노믹스 (보수적 추정)
| 항목 | 낙관 | 보수적 | 비고 |
|------|------|--------|------|
| CAC | 5,000원 | 15,000원 | SEO/커뮤니티(무료) + 유료 광고 혼합 |
| LTV | 45,000원 | 30,000원 | 평균 체류 4~6개월 × 7,500원 |
| LTV/CAC | 9.0 | 2.0 | 2.0 이상이면 스케일 가능 |
| 그로스 마진 | 70% | 55% | API 비용 변동 고려 |
| 손익분기 | 유료 100명 | 유료 200명 | 월 고정비 약 100~150만원 |
```

**포인트**:
- "6개월 후 1,000명" → "12개월에 걸쳐 1,000명까지 성장하는 경로" 로 바꿈
- 낙관/보수적 양쪽 시나리오를 모두 제시 → 심사위원 신뢰도 상승
- CAC를 현실적으로 올림 (5,000원 → 15,000원 보수적 추정)

### 1-3. 슬라이드 17 (핵심 성과지표 및 재무 목표) — 현재 상태와 문제

**현재**: 지표 표 + 재무 목표 3줄
**문제**:
- "동아리 기간"과 "동아리 종료 후"가 혼재. 심사위원이 "이 동아리에서 뭘 달성할 건데?"를 명확히 못 봄
- NPS 40, 전환율 5%는 좋은 목표인데, **이 숫자가 왜 이 숫자인지** 근거가 없음
- 재무 목표가 "동아리 종료 후 6개월"인데, 동아리 심사에서 그건 너무 먼 미래

**개선안**:

```
슬라이드 17 — 핵심 성과지표 (개선)

### 동아리 기간(3~7월) 목표 — "우리가 증명할 것"

| 단계 | 지표 | 목표치 | 측정 방법 | 왜 이 숫자? |
|------|------|--------|----------|-------------|
| 3월 검증 | Socratic 수동 테스트 | 5명 완료 | 대면/카톡 인터뷰 | Mom Test: 5명이면 패턴 포착 가능 |
| 5월 MVP | 프로토타입 배포 | 완료 | Vercel 배포 URL | 기술 실행력 증명 |
| 5~6월 | 베타 사용자 | 20명 | 가입 수 | 최소 통계 유의 표본 |
| 5~7월 | 세션 완료율 | 60% 이상 | 시작 → 정리문서 생성 | 업계 평균 대비 높은 수준 |
| 6~7월 | NPS | 40 이상 | 사용 후 설문 | Sean Ellis 40% 테스트: PMF 신호 |
| 7월 | 유료 전환 의향 | 5명 이상 | "5,000원 내겠냐" 직접 질문 | 20명 중 25% = 강한 WTP 신호 |

### 동아리 이후 확장 목표 (참고)
- 6개월 후: 유료 150명, MRR 113만원 (손익분기 근접)
- 12개월 후: 유료 1,000명, MRR 750만원
- 18개월 후: B2B EAP 파일럿 1건 + 예비창업패키지 선정
```

**포인트**: 동아리 기간 목표를 **"증명할 것"**으로 프레이밍. 심사위원은 "이 팀이 5개월 안에 여기까지 갈 수 있나?"를 본다.

### 전체 구조 문제: 슬라이드 흐름

현재 슬라이드 번호 순서가 **논리적 스토리라인과 다릅니다.**

현재 순서: 표지(1) → 계기(2) → [빈](4) → 시장(5) → 경쟁사(6) → 페르소나(7) → 고객분포(8) → BM(9) → 설문(15) → 자금/매출(16) → 지표(17) → 팀(18) → 진행과정(19) → 비전(20) → 마케팅(21) → [빈](22-24) → 월별(25)

**권장 스토리라인** (심사위원 관점):

```
1. 표지 — 누구인가
2. 창업 계기 — 왜 이걸 하는가
3. 시장 분석(5) — 시장이 있는가
4. 고객 분포(8) — 누가 고통받는가
5. 고객 페르소나(7) — 구체적으로 누구인가
6. 아이템 설명(4) — 뭘 만드는가 [현재 비어있음]
7. 경쟁사 분석(6) — 왜 기존 해결책으론 안 되는가
8. 비즈니스 모델(9) — 어떻게 돈을 버는가 ★
9. 소요자금/매출(16) — 얼마가 필요하고 얼마를 버는가 ★
10. 핵심 지표(17) — 뭘 증명할 건가 ★
11. 시제품 현황(22-24) — 지금 뭐가 있는가 [현재 비어있음]
12. 설문조사(15) — 검증 계획
13. 진행 과정(19) — 어디까지 왔는가
14. 월별 활동/예산(25) — 앞으로 뭘 할 건가
15. 마케팅(21) — 어떻게 알릴 건가
16. 팀 소개(18) — 누가 하는가
17. 비전(20) — 최종적으로 어디까지 가는가
```

이 순서가 "문제 → 기회 → 솔루션 → 수익 → 실행 → 팀 → 비전"의 표준 피치덱 구조입니다.

## 3. 빈 슬라이드 전략 (PM 방향 제시)

### 3-1. 슬라이드 4: 아이템 설명

**이 슬라이드가 신청서에서 가장 중요합니다.** 심사위원이 "그래서 뭘 만드는 건데?"를 가장 먼저 보는 곳입니다.

**방향**:

```
### 아이템 설명 — "풀림(Pullim)은 이런 서비스입니다"

[도입 전] 고민이 생겼을 때
- ChatGPT에 물어봄 → 장단점만 나열, 여전히 모르겠음
- 친구에게 물어봄 → "잘 생각해봐" 끝
- 혼자 반추 → 같은 걱정 반복, 잠 못 잠
- 심리상담 → 1회 5~20만원, 예약 2주 대기

[도입 후] 풀림을 쓰면
- 고민 입력 → AI가 맞춤 질문을 던짐 (15분)
- 3단계 파이프라인: 듣기(감정 정리) → 풀기(구조화) → 착지(결정+행동)
- 세션 끝에 의사결정 정리 문서 1장이 나옴
  (문제정의 / 맥락 / 선택지 / 평가 / 리스크 / 결정 / 근거 / 첫 행동)
- "상담받고 뭐가 달라졌는지 모르겠다" → 종이 한 장으로 달라짐

[핵심 차별점] 한국 멘탈케어 앱 중 "의사결정 정리 문서"를 생성하는 서비스는 없다.
```

**핵심**: "전/후 비교"가 심사위원에게 가장 직관적. 파이프라인을 "듣기→풀기→착지" 3단계로 단순하게 보여줄 것.

### 3-2. 슬라이드 22-24: 시제품 개발 현황

## 5. 핵심 약점 지적 (PM으로서 정직하게)

### 약점 1: N=1 문제
현재 모든 검증이 대표님 본인 경험에 의존합니다. 3/10 수동 테스트가 첫 외부 검증인데, **이 결과를 신청서에 반영할 수 있느냐가 관건**입니다.

→ **3/10 테스트 결과가 긍정적이면**: 슬라이드 15(설문조사)에 "사전 검증" 섹션에 실제 결과 1줄 추가. 이것만으로도 신뢰도가 크게 올라감.
→ **3/10 테스트가 부정적이면**: 솔직하게 "이런 피드백을 받았고, 이렇게 개선할 것"으로 바꿈. 심사위원은 솔직한 팀을 선호.

### 약점 2: 1인 팀
팀 소개가 대표님 1명. 이건 약점이 될 수 있지만, **"AI 에이전트 팀 5명으로 시장 분석, 포지셔닝, 제품 설계를 수행했다"**를 추가하면 "AI 도구를 실전에서 쓸 줄 아는 팀"으로 전환됩니다. 동아리니까 팀원 모집이 활동 목표에 포함되어도 자연스럽습니다.

### 약점 3: "ChatGPT면 되잖아" 반론 미비
경쟁사 분석(슬라이드 6)에서 기존 멘탈케어 앱과는 잘 비교했지만, **가장 강력한 경쟁자인 ChatGPT와의 차별화**가 본문에 약합니다. PRD에는 비교표가 있는데 신청서에 빠져 있습니다.

→ 슬라이드 6 경쟁사 비교표에 "ChatGPT" 열을 추가하거나, 슬라이드 4(아이템 설명)에서 "전/후" 비교 시 ChatGPT를 명시적으로 대비하는 것을 권장합니다.

## 7. [추가] 슬라이드 16 보강 — 유료 1,000명 역산 퍼널

### 핵심 질문: "1,000명이 어디서 오는가?"

기존 슬라이드 16에 성장 시나리오 표는 있지만, **"그 숫자가 어디서 나오는 건데?"**에 대한 답이 없다. 심사위원은 테이블 숫자가 아니라 **퍼널의 논리**를 본다. 아래를 슬라이드 16 하단 또는 별도 보조 슬라이드로 삽입할 것.

```
### 유료 1,000명 역산 퍼널 — "답을 찾게 하는 AI. 찾은 결론은 정리해준다"

[출발점] 한국 멘탈케어 앱 MAU 16만명 (마인드카페 + 트로스트)
  이 사람들은 이미 "고민을 앱으로 풀어보겠다"는 행동을 하고 있다.
  공통 불만: "상담받고 나서 뭐가 달라졌는지 모르겠다"
  → 풀림이 해결하는 것: "답을 찾게 하는 AI. 찾은 결론은 정리해준다"

[퍼널 역산]

  ① 인지 (Awareness)
     - 멘탈케어 앱 MAU 16만 + 진로/이직 고민 검색자
     - 채널: 앱스토어 SEO("심리상담 앱"), 에브리타임, 블라인드
     - 12개월 누적 노출: 약 200,000명
     - 근거: 멘탈케어 키워드 월 검색량 5만+, 에브리타임 진로 게시글 월 3만+

  ② 설치/방문 (Acquisition)
     - 전환율: 10% (노출 → 설치/방문)
     - = 20,000명
     - 근거: 앱스토어 평균 전환율 5~15%, 무료 앱 + 멘탈케어 카테고리 상위

  ③ 무료 체험 (Activation)
     - 전환율: 30% (설치 → 첫 세션 완료)

       → "답을 찾게 해줬고, 결론이 정리됐다" — 이 경험이 유료 전환의 핵심

  ④ 유료 전환 (Revenue)
     - 전환율: 5% (무료 체험 → 유료 구독)
     - = 300명 (단순 계산)
     - 근거: 멘탈케어 앱 유료 전환율 3~7% (마인드카페 추정 4~5%)

  ⑤ 유지 + 반복 (Retention & Referral)
     - 월 이탈률: 10% (보수적)
     - 자연 유입 반복: 정리 문서 공유 링크 → 신규 유입 (k-factor 0.1~0.3)

| 단계 | 수치 | 전환율 | 근거 |
|------|------|--------|------|

| 월 이탈 | -10% | - | SaaS 평균, 보수적 적용 |

### 왜 이 퍼널이 작동하는가? — 공식 카피와의 연결

"답을 찾게 하는 AI. 찾은 결론은 정리해준다."

1. **인지 단계**: "상담받고 뭐가 달라졌는지 모르겠다"는 기존 사용자 불만 → 풀림은 "결론이 정리된다"로 차별화
2. **WOW 모먼트**: 첫 세션 끝에 정리 문서를 받는 순간 → "답을 찾게 해줬다"를 체감
3. **유료 전환**: 무료 3회로 정리 문서의 가치를 확인 → 4번째 고민부터 "이 경험에 돈을 낸다"
4. **잠금 효과**: 히스토리가 쌓일수록 "내 결정 패턴"이 보이기 시작 → 떠날 이유가 줄어듦

핵심: 돈을 내는 이유는 "AI가 좋아서"가 아니다. **"내 결론이 1페이지로 정리됐다"**는 산출물 때문이다. 이 산출물이 기존 멘탈케어 앱에는 없다.
```

**포인트**: 역산 퍼널은 "위에서 아래로 쏟아부으면 몇 명 남느냐"의 논리다. 심사위원이 "1,000명? 근거는?" 물었을 때, 이 퍼널 한 장이 답이 된다.

**왜 이렇게 하는가:**
- 슬롯 1(BM 본체)은 필수. 양식이 요구하는 것.
- 슬롯 2(안전)는 "추가 슬라이드 가능" 허락을 활용. BM 예시 자리에 넣으면 양식 구조를 깨지 않으면서 핵심 메시지를 추가할 수 있다.
- 슬롯 3(역산 퍼널)은 매출의 핵심 근거. BM 직후에 "왜 이 숫자가 가능한가"를 보여주는 것이 논리적.
- 슬롯 4-6은 우리에게 해당하는 BM 예시가 없으므로, **삭제하지 않고**(양식 필수 항목 유지) 빈 채로 두거나 "해당 없음"으로 표기.

### 10-2. 안전 슬라이드 삽입 위치 확정

**위치: BM(슬라이드 9) 직후, 양식 10번 슬롯에 배치.**

근거:
1. 심사위원이 "돈 버는 구조"를 본 직후 → "근데 AI 멘탈케어 안전해?"라는 의문이 자연스럽게 떠오르는 시점
2. 여기서 바로 답하면 → 신뢰가 확보된 상태로 매출 숫자(역산 퍼널, 소요자금)로 넘어감
3. "안전한 구조 위에서의 성장"으로 읽히게 만드는 배치
4. 양식의 BM 예시 슬롯(10번)을 활용하므로 양식 구조를 깨지 않음
