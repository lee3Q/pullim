## 의견

대표님, 단도직입적으로 말하겠습니다.

손정원 테스트 데이터 1건은 **패턴이 아니라 신호**입니다. "사람들은 사고하는 걸 싫어한다"는 손정원 개인의 관찰이지, 시장의 결론이 아닙니다. 내일 부모님 테스트는 **완전히 다른 세대, 다른 고민 유형**에서 풀림이 어떻게 작동하는지 보는 겁니다. 1회 테스트 결과로 제품 철학을 흔들면 안 됩니다.

다만 긴급 회의에서 합의된 하이브리드 전환(질문 70% + 인사이트 30%)은 "피벗이 아니라 미세 조정"이라는 판단에 동의합니다. 이건 데이터가 말해준 겁니다. 풀기 단계 16턴은 누가 봐도 길었고, 중간 인사이트 없이 질문만 반복하면 GPT와의 차별점이 사라집니다.

**부모님 테스트의 핵심 목적은 "50대가 AI와 고민 대화를 할 수 있는가?"입니다.** 만족도나 WTP보다, 행동 관찰이 우선입니다. 디브리핑에서 나온 말보다 대화 중 표정/반응이 더 정직합니다.

**교수님 자문은 테스트가 아닙니다.** 제품을 보여주지 마세요. 사업 관점 질문 + 테스터 소개 요청. 교수님이 "이거 되겠다/안 되겠다" 말하는 건 의미 없습니다. 교수님이 줄 수 있는 건 **네트워크와 시장 관점**입니다.

## 산출물 2: 교수님 자문 질문 리스트

### 자문 목적
1. **사업 타당성에 대한 외부 시각** 확보
2. **테스터 소개 요청** (20-30대 학생/직장인)
3. 신청서 "교수님 자문을 받았다"는 한 줄 근거

### 자문 오프닝 스크립트 (30초)

> "교수님, AI 기반 생각 정리 서비스를 준비하고 있습니다. 사용자가 고민을 입력하면 AI가 맞춤 질문을 던져서 생각을 정리하고, 끝나면 정리 문서가 자동으로 나옵니다. 기존 심리상담 앱들이 '감정 케어'에서 끝나는데, 저희는 '감정 정리 + 의사결정 구조화'까지 갑니다. 1회 테스트를 했고, 내일 마감인 창업동아리 신청서를 준비 중입니다. 사업 관점에서 조언을 여쭙고 싶습니다."

### 질문 리스트 (5개 핵심 + 2개 부가)

**[시장/타당성]**

1. "AI 멘탈케어 시장에서 '질문으로 생각을 정리해주는' 접근이 차별화가 될 수 있다고 보시나요? 아니면 결국 ChatGPT에 수렴한다고 보시나요?"
   - 의도: "GPT랑 뭐가 다르냐" — 손정원도 물었고, 교수님 관점에서 이 질문의 답을 듣고 싶음

2. "1인 창업으로 시작하는데, 이 단계에서 가장 먼저 증명해야 할 것이 뭐라고 보시나요?"
   - 의도: Customer Discovery 우선순위 외부 검증

3. "월 7,500원 구독 모델인데, 이 가격대에서 멘탈케어 앱이 한국 시장에서 가능하다고 보시나요?"
   - 의도: 가격 현실성 체크 (손정원 WTP 5,000원 이하와 교차 검증)

**[팀/실행]**

4. "1인 팀에서 AI 프롬프트 설계 + 개발 + 사용자 테스트를 병행하고 있는데, 이 단계에서 팀원을 먼저 모아야 할까요, 아니면 MVP를 먼저 만들어야 할까요?"
   - 의도: 실행 순서에 대한 외부 관점

5. "창업동아리 5개월(3-7월) 안에 어떤 결과를 보여줘야 의미 있는 검증이 될까요?"
   - 의도: 성과지표 기대치 외부 보정

**[부가 — 분위기 봐서]**

6. "이 분야에서 참고할 만한 해외 사례나 논문이 있을까요?"
   - 의도: 레퍼런스 확보

7. "혹시 주변에 이런 서비스에 관심 있을 만한 학생이나 직장인이 계시면 테스트 참여를 부탁드려도 될까요?"
   - 의도: **테스터 소개 요청** (핵심 목적 중 하나)

### 자문 클로징 스크립트

> "바쁘신데 시간 내주셔서 감사합니다. 말씀해주신 [핵심 1가지] 부분이 저희가 가장 고민하던 부분인데 큰 도움이 됐습니다. 혹시 테스트에 참여해주실 수 있는 분이 계시면 정말 감사하겠습니다."

## 산출물 3: PPT 슬라이드 13 테스트 결과 반영안

콘텐츠 명세서 기준 슬라이드 13(순번) = 양식 #15 = "고객 설문조사" 슬라이드.

### 현재 내용 (수정 전)

```
[대표 확인 필요] 3/10 수동 테스트 결과 1줄 추가 예정 (테스트 후)
```

### 수정 후 내용

**제목**: 고객 검증

**사전 검증 (정성적)** — 기존 유지
- 창업자 본인이 1년간 AI 의사결정 시스템을 직접 설계/사용하며 문제와 효과를 체험
- AI 에이전트 팀 + Perplexity 리서치로 시장/경쟁 검증 완료
- 기존 멘탈케어 앱 사용자 리뷰 분석: "상담 후 뭐가 달라졌는지 모르겠다" 공통 불만 확인

**수동 테스트 1회 결과 (2026.03.09)** — 신규 추가 박스
```
대상: 20대 대학생 (진로/생활 고민)
방식: 질문 기반 1:1 AI 대화 → 정리 문서 자동 생성
결과:
  - 대화 30턴, 핵심 고민 리프레이밍 성공
    ("잠을 줄이자" → "깨어있는 시간의 밀도를 높이자")
  - 만족도 3.5/5
  - 테스터 추천 문구: "고민 정리해주는 AI"
  - 상담 경험 대비: "실질적 해결책에서 더 나았다"
  - 핵심 피드백: 중간 결과물 요구 → 질문+인사이트 하이브리드로 즉시 개선
```

**동아리 활동 중 검증 계획** — 기존에서 업데이트
```
1. [진행중] 수동 테스트 (3월, 3~5명) — 1회 완료, 2회차 진행 예정
2. 웹앱 프로토타입 베타 테스트 (5월, 10~20명)
3. 사용 후 만족도 설문 (NPS, 정리 문서 유용성, 재사용 의향)
```

**가격** — 별도 1줄 (하단, 작은 폰트)
```
구독 가격 7,500원/월 (가격 테스트 예정)
```

### 슬라이드 13 디자인 노트
- "수동 테스트 1회 결과" 박스를 **강조 색상**으로 처리 — 심사위원에게 "이미 실행하고 있다"는 인상
- 리프레이밍 성공 사례는 Before→After 화살표로 시각화
- "가격 테스트 예정"은 의도적으로 작게 — 7,500원이 확정이 아님을 보여주되 눈에 띄지 않게
- "질문+인사이트 하이브리드로 즉시 개선" — 피드백 대응 속도를 보여주는 문구

### PPT 반영 시 주의

1. **WTP 5,000원 이하는 PPT에 넣지 마세요.** 심사위원에게 "사용자가 비싸다고 했다"를 먼저 보여줄 이유 없음. 7,500원 유지 + "가격 테스트 예정"으로 충분.
2. **"GPT랑 뭐가 달라"도 넣지 마세요.** 이건 우리가 해결할 과제이지, 심사위원에게 보여줄 취약점이 아님.
3. **넣을 것: 리프레이밍 성공 + 상담 대비 우위 + 즉시 개선 대응.** 테스트를 했고, 유의미한 결과가 있고, 피드백에 즉시 대응했다는 3박자.
