## 상세 판정

### 1. [안전] 인사이트 2단 확인 — 승인

> 인사이트 제시 → "이게 맞아?" 확인 → 부정 시 즉시 철회

**근거**: CBT의 협력적 경험주의(Collaborative Empiricism) 원칙에 부합한다. 치료자가 해석을 제시하고 내담자가 검증하는 구조. 2단 확인은 인사이트가 "처방"이 아니라 "가설"임을 행동으로 보여주는 장치다. 예시 문구도 적절하다.

---

### 2. [안전] 인사이트 단정 금지 — 승인

> "~이다" 금지. "~일 수도 있다" 필수.

**근거**: 임상에서 추측형 표현(tentative language)은 내담자의 자율성을 보호하는 기본 기법이다. 특히 AI가 단정형으로 인사이트를 제시하면, 사용자가 "AI가 나를 분석했다"는 인상을 받아 심리적 안전감이 깨진다. Woebot 피드백에서도 "AI가 나를 판단하는 느낌"이 이탈 원인 1위였다.

---

### 3. [안전] 역전 질문 제한 — 수정

> 현재: 수면장애/건강 위기 맥락에서 역전 질문 금지

**판정 근거**: 방향은 맞지만 범위가 좁다. 역전 질문("만약 그 선택을 이미 했다고 치면")은 **상실/애도 맥락**에서도 위험하다. "만약 이혼을 이미 했다고 치면 기분이 어때?"는 최근 이혼 당사자에게 재외상(re-traumatization)을 유발할 수 있다. 관계 상실, 사별, 해고 직후 등 **비가역적 상실을 겪고 있는 맥락**도 금지 범위에 포함해야 한다.

**수정 문구**:
```
[안전] 수면장애/건강 위기/비가역적 상실(사별, 이혼 직후, 해고 직후 등) 맥락에서는 역전 질문 금지. 신체적 고통이나 현재 진행 중인 상실을 반전시키는 것은 위험.
```

---

### 4. [안전] YELLOW 인사이트 제한 — 수정

> 현재: YELLOW에서 인사이트 최대 1개

**판정 근거**: YELLOW 상태는 절망/무가치감이 감지된 상태다. 이 상태에서 인사이트는 아무리 추측형이어도 "분석당하는 느낌"을 줄 수 있다. YELLOW에서는 감정 수용과 부드러운 탐색이 핵심인데, 인사이트 1개를 허용하면 Sonnet이 "1개는 괜찮으니까"라는 판단으로 부적절한 타이밍에 삽입할 리스크가 있다.

**수정 문구**:
```
[안전] YELLOW에서 인사이트 0개. YELLOW 감지 시 인사이트 삽입 금지. 감정 수용 + 탐색 질문만.
```

**서윤하에게**: 원안 "최대 1개"는 Opus급 모델이라면 타이밍 판단이 가능하겠지만, Sonnet 4.6 기준으로는 hard rule "0개"가 더 안전하다. YELLOW에서 인사이트가 필요한 상황 자체가 거의 없고, 있더라도 질문으로 전환하는 것이 임상적으로 맞다.

### 5. [안전] 50대 위기키워드 추가 — 수정

> 현재 YELLOW: "늙어서 쓸모없다", "자식한테 짐", "이 나이에 뭘", "죽을 때가 됐다", "살아서 뭐하나", "내 인생 끝났다"
> 현재 RED: "유서", "보험금", "정리하고 가야지", "자식들 다 컸으니", "더 이상 짐이 되기 싫다"

**판정 근거**: 핵심 키워드는 잘 잡았지만, 50대 위기 연구에서 반복 출현하는 표현 몇 개가 빠져 있다. 오탐보다 미탐이 위험하다는 원칙에 따라 보충한다.

**YELLOW 추가**:
- "나만 없으면 다 잘 돼" — 자기 소거 표현, 50대 가장/주부에게 흔함
- "짐만 된다" / "폐만 끼친다" — "자식한테 짐"의 변형이지만 배우자/직장 맥락에도 등장
- "이제 갈 때 됐다" — "죽을 때가 됐다"의 완곡 표현

**RED 추가**:
- "재산 정리" / "명의 변경" — 구체적 사후 준비 행동. "보험금"과 같은 층위
- "마지막 여행" / "한 번만 더 보고" — 이별 준비 뉘앙스. 맥락 기반 감지 필요 (키워드 단독 매칭은 오탐 높음, 전후 맥락으로 판단)

**수정 문구**:
```
YELLOW 50대 추가: "늙어서 쓸모없다", "자식한테 짐", "이 나이에 뭘", "죽을 때가 됐다", "살아서 뭐하나", "내 인생 끝났다", "나만 없으면 다 잘 돼", "짐만 된다", "폐만 끼친다", "이제 갈 때 됐다"

RED 50대 추가: "유서", "보험금", "정리하고 가야지", "자식들 다 컸으니", "더 이상 짐이 되기 싫다", "재산 정리", "명의 변경"
(맥락 기반 감지: "마지막 여행", "한 번만 더 보고" — 전후 맥락이 상실/이별 준비일 때만 RED 판정)
```

### 6. [안전] 50대 위기대응 톤 — 승인

> YELLOW 해요체: "그런 마음이 드실 수 있어요. 혹시 요즘 자주 그러세요?"
> RED 해요체: "지금 저는 당신 편이에요. 너무 힘드실 땐 전문가분 도움이 진짜 힘이 돼요."

**근거**: 톤 가이드라인 v1의 "따뜻한 존댓말" 원칙을 준수하고 있다. "~하십시오"체를 피하면서도 존중을 유지하는 톤이다. RED에서 "당신 편이에요"는 고립감을 느끼는 50대에게 연결감을 주는 표현으로 적절하다. 전문기관 안내 후 "괜찮으실 때 다시 오셔도 돼요"도 문을 닫지 않는 원칙에 부합한다.

---

### 7. [안전] GREEN/YELLOW/RED 3층 구조 — 수정

> 기존 Tier A/B 2층 → GREEN/YELLOW/RED 3층 전환

**판정 근거**: 3층 구조 자체는 내가 제안한 것이고 승인한다. 그러나 **YELLOW에서 RED로 에스컬레이션하는 기준**이 프롬프트에 명시되어 있지 않다.

현재 프롬프트에는 YELLOW에서 "지속적 절망 감지 시(같은 맥락 2턴 이상)" 전문가 권유까지는 있지만, **YELLOW가 RED로 전환되는 조건**이 빠져 있다. YELLOW에서 대화를 유지하다가 갑자기 구체적 자살 언급이 나왔을 때, Sonnet이 "아직 YELLOW니까 대화 유지"라고 판단할 리스크가 있다.

**추가 문구**:
```
[에스컬레이션 규칙]
YELLOW 대화 중 RED 키워드가 1개라도 등장하면 즉시 RED 프로토콜로 전환한다.
YELLOW 상태에서 같은 맥락 3턴 이상 절망 표현이 지속되고, 강도가 증가하면 RED로 격상한다.
에스컬레이션은 단방향이다. RED → YELLOW 복귀 없음. RED 진입 시 세션 종료까지 RED 프로토콜 유지.
```

## 추가 제안 (빠진 안전 항목)

### A. 감정 고조 시 중간 정리 스킵 규칙

현재 중간 정리가 3회 고정인데, YELLOW 상태에서 "여기까지 정리해보면..."을 삽입하면 **분석당하는 느낌**이 강해질 수 있다. YELLOW 감지 후에는 중간 정리를 생략하거나, 정리 대신 감정 반영("지금 많이 힘든 거구나")으로 대체해야 한다.

**제안 문구**:
```
[안전] YELLOW 감지 후 중간 정리 형식 변경: "여기까지 정리해보면" 형식 금지. 대신 감정 반영으로 대체.
예: "지금까지 들으면서, 정말 무거운 걸 혼자 안고 있었구나 싶어." (해요체: "정말 무거운 걸 혼자 안고 계셨구나 싶어요.")
```

### B. 인사이트 철회 후 사과 금지

2단 확인에서 부정 시 "즉시 철회"는 좋은데, 철회 시 "미안" 같은 사과 표현은 AI가 틀렸다는 인상을 주고, 사용자가 "AI도 못 알아보는 내 문제"라는 자기비하로 연결될 수 있다. 철회는 하되 사과 없이 방향 전환.

**제안 문구**:
```
[안전] 인사이트 철회 시 사과 금지. "미안", "잘못 봤다" 대신 "그렇구나. 다르게 볼게." / "그럼 다른 각도에서 보자."
(해요체: "그렇군요. 다른 쪽에서 한번 볼게요.")
```
