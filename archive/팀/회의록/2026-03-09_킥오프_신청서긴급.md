## 라운드 2 — 크로스체크 + 토론

### 3개 쟁점 토론 (서윤하 × 최서영, 대표 참여)

**쟁점 1: "답 안 준다" vs "결정까지 정리" 모순**
- 합의: 모순 아님, 표현 문제. "답을 찾게 하는 AI"로 통일.
- 대표 최종: "결론은 같이 해나갑니다" (동행 톤)

**쟁점 2: 질문 7개 상한**
- 합의: hard cap 삭제, soft guideline. 7개 이후 부드럽게 착지 유도.
- 대표 피드백: "계속할까요?" 금지. "더 얘기하고 싶어?" 톤.
- 도피반응 대응: 억제 금지. "너에게 줄 편지가 거의 완성됐어" 식 달래기.
- 서윤하 착지 유도 톤 가이드 작성 완료: 제안/서윤하_착지유도_톤가이드.md

**쟁점 3: 위기 키워드 UX**
- 합의: 2-tier 체계.
  - Tier A (맥락적/비유적): 대화 유지 + 자연 안내
  - Tier B (구체적/급박): 역할 전환 (탐색 질문 중단, 공감+안내)
- Gemini식 "맥락 무시 + 전화번호 투척" 명확히 배제
- 맥락 기반 감지 (단순 키워드 매칭 X)
- 위기 키워드 리서치 완료: 제품/위기키워드_리서치_2026-03-09.md

## 대표 피드백 기록

1. pullim/ 코드는 대표가 직접 만든 것. API key만 넣으면 작동.
2. 질문 수 제한 반대 — 깊은 대화 원하는 사용자 수요도 고려
3. Gemini식 위기 대응 UX 최악 — 맥락 유지하면서 자연 안내
4. 마인드카페 등은 상담사 연결 서비스 — 우리와 본질적으로 다름
5. "같이 해나갑니다" — 파트너/동행 철학
6. 상표권 "풀림" 겹침 가능성 — 나중에 확인 필요
7. 파일/데이터 관리 시스템 필요
8. COS가 비서실장 역할 더 자각해야 함 — 스스로 판단하고 돌려
