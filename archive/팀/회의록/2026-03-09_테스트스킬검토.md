## 합의사항

1. **위기 키워드를 프롬프트에 명시적으로 넣지 않는다** — Opus 모델의 맥락 판단에 맡김. 키워드 리스트는 내부 참조 문서로 보관 (위기키워드_리서치_2026-03-09.md)
2. **첫 인사 문구를 수정한다** — "고민 있어?" → "자꾸 떠오르는 거 있어? 큰 거 아니어도 돼."
3. **리프레이밍 예시 3개를 풀기 단계에 추가한다** — "1년 뒤의 나" 대신 "친한 친구가 같은 상황이면" 사용 (서영 안전 검토 반영)
4. **Tier A에 지속적 절망 시 soft 전문상담 안내를 추가한다**
5. **Tier B에 세션 마무리 문구를 추가한다**
6. **분석 보고서에 "아하 모멘트" + "감정 변화" 섹션을 추가한다**
7. **WTP는 세션 종료 후 첫 걸음 문서를 보여준 뒤 대표가 수동으로 물어본다**
8. **테스트 운영: 대표는 세션 중 자리를 비우고, 종료 후 5분 디브리핑을 진행한다**
9. **착지 마무리 문구 "남겨줄게" → "남겨놓을게" 수정**
10. **감정 체크 질문을 듣기 초반 + 착지 마지막에 자연스럽게 삽입한다**

## 프롬프트 수정 제안

### 1. 첫 인사 (서윤하 → 서영 통과)
- 원문: `"안녕! 나는 풀림이야. 요즘 머릿속에서 맴도는 고민 있어? 편하게 얘기해봐."`
- 수정안: `"안녕, 나는 풀림이야. 요즘 머릿속에 자꾸 떠오르는 거 있어? 큰 거 아니어도 돼."`
- 근거: "고민"은 무거운 단어. "자꾸 떠오르는 거"로 진입 장벽 낮춤

### 2. 리프레이밍 예시 추가 (서윤하 → 서영 크로스체크)
- 위치: 2단계 풀기 섹션 하단
- 추가 내용:
```
[리프레이밍 예시 — 모델 참조용, 그대로 사용하지 않는다]
- "그게 해결되면, 그 다음은 뭐가 달라져?"
- "만약 그 선택을 이미 했다고 치면, 지금 기분이 어때?"
- "가장 친한 친구가 같은 상황이면, 너는 뭐라고 할 것 같아?"
```
- 서영 수정: "1년 뒤의 네가 본다면" → "가장 친한 친구가 같은 상황이면" (자기 비하 트리거 회피)

### 3. 착지 마무리 (서윤하)
- 원문: "오늘 얘기한 거, 정리해서 남겨줄게."
- 수정안: "오늘 얘기한 거, 정리해서 남겨놓을게."
- 근거: 톤 가이드 v1 — "해준다" 금지 원칙

### 4. Tier A 지속적 절망 대응 추가 (서영)
```
- 지속적 절망이 감지되면 (같은 맥락 2턴 이상):
  "혼자 안고 있기엔 무거운 거 같아. 마음 전문가한테 얘기해보는 것도 진짜 도움이 돼."
  (전문기관 번호는 제시하지 않는다 — Tier A 수준이므로 톤 급변 방지)
```

### 5. Tier B 세션 마무리 추가 (서영)
```
- 전문기관 안내 후: "오늘 여기까지 하자. 네가 괜찮을 때 다시 와도 돼."
- 세션을 부드럽게 종료하되, 문을 닫지 않는다.
```

### 6. 감정 체크 질문 삽입 (도현 제안 → 윤하 설계)
- 듣기 초반: 자연스럽게 "지금 어떤 기분이야?" (첫 질문 이후)
- 착지 마지막: "지금은 좀 어때?" (마무리 흐름에서)
- 프롬프트에 명시적 지침 추가: "듣기 초반과 착지 마지막에 감정 상태를 자연스럽게 확인한다."

**판정: 조건부 통과**

| 항목 | 결과 | 비고 |
|------|------|------|
| Tier A 대응 | 수정 후 통과 | 지속적 절망 시 soft 전문상담 안내 추가 |
| Tier B 대응 | 수정 후 통과 | 세션 마무리 문구 추가 |
| 톤 안전성 | 통과 | "옆에 앉은 똑똑한 친구" 톤은 적절. 단, AI 과의존 방지는 운영 레벨에서 관리 |
| 위기 키워드 처리 | 통과 | 프롬프트 미포함, 모델 맥락 판단 활용 |
| 웰니스 경계 | 통과 | 진단/치료 표현 없음, 정답 제시 없음 |
| 면책 | 해당 없음 | 테스트 단계이므로 면책 고지 불필요. MVP 시 필수 |

**운영 조건 (프롬프트 외):**
1. 대표는 세션 중 자리를 비운다 (솔직한 응답 보장)
2. 세션 종료 후 5분 디브리핑 필수 ("어땠어?", "불편한 부분?")
3. Tier B 감지 시 대표에게 즉시 보고 (기존 프롬프트에 이미 있음)

## WTP 질문 설계

### 타이밍
세션 종료 → 첫 걸음 문서를 보여준 후 → 문서를 읽는 시간을 준 뒤 → 질문

### 질문 세트 (순서대로)
1. "방금 이런 식으로 고민 정리해주는 앱이 있으면, 써볼 것 같아?"
   → 관심 확인
2. "한 달에 몇 번 정도 쓸 것 같아?"
   → 사용 빈도 = 가치 인식
3. "무료로 월 3번 쓸 수 있고, 무제한으로 쓰려면 월 7,500원이면 어때?"
   → 가격 앵커링 (커피 2잔 프레임)
4. "얼마면 적당할 것 같아?"
   → 자유 가격 응답
5. "지금 쓰는 거 중에 이걸 대체할 수 있는 게 뭐야?"
   → 경쟁 대안 파악

### 추가 디브리핑 질문 (WTP 후)
- "어디서 제일 좋았어?" → 핵심 가치
- "어디서 좀 어색했어?" → UX 마찰
- "친구한테 이거 추천하면 뭐라고 소개할 것 같아?" → 한 줄 포지셔닝 검증
