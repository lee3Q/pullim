## 배경: v2 전환 트리거

대표 직접 v1 테스트 (세션2, 프롬프트 v3 final):
- 고민: 열심히 하고 있는데 밤마다 무너질 것 같은 불안
- 핵심 발견: "잠재력 공포" — 처음으로 탈출구 없이 서 있는 것
- 프롬프트 품질: 인사이트 A, 톤 A, 턴 수 준수 — **품질 자체는 양호**
- 만족도: 3/5
- WTP: "유료면 안 씀. 다른 LLM이랑 차이 못 느낌"
- **대표 판단**: "ChatGPT + 프롬프트와 다를 게 없다" → 차별화 필수

---

## 핵심 결정: 싱글 LLM → 멀티 에이전트 토론 기반 (v2)

### 전원 합의 내용
- 현재 v1(싱글 LLM + 프롬프트)에는 모트가 없다
- 멀티 에이전트 + 축적 메모리가 차별화

### 팀원 발언 요약

**한재원(CTO)**:
- "전부 가능, MVP 10일"
- 차별화 3레이어: 상태 관리 + 오케스트레이션 + 안전 레이어
- "프롬프트를 복사하면 끝이지만, 파이프라인은 복제 불가"

**서윤하(AI Lead)**:
- "현재 모트 없음 인정"
- 최강 모트 = 축적 데이터 록인 (개인 데이터 복제 불가)
- v1 프롬프트 품질은 좋았으나 차별화가 안 됨

**박도현(PM)**:
- 창업계기와 제품 불일치 지적 — "에이전트 팀 토론 경험이 창업 계기인데, 정작 제품은 싱글 LLM"
- 병원 비유 제안: "전문의 여러 명 의견 들어보는 경험"
- 전문가 3명 제한 제안 → 대표 기각 (추천이 기본이므로 선택 피로 논리 성립 안 함)

---

## v2 설계 핵심

| 항목 | 내용 |
|------|------|
| 에이전트 수 | 3명 (사용자 선택 또는 추천) |
| 분석 방식 | 병렬 독립 분석 → 토론 (선택 관점에 반론) |
| 전문가 풀 | 넓게 유지 (추천이 기본, 직접 선택은 보너스) |
| 진행도 | 5단계 게이지 |
| 리포트 | 화면 출력 (파일이 아니라 바로 보여줌) |
| 핵심 메시지 | "전문가를 대체하는 게 아니라, 비용을 최소화하여 다양한 관점에서 의견을 들어보는 경험" |
