## 라운드 1 — 팀원 발언 요약

### 박도현(PM)
- 스토리라인 문제: 창업계기 없으면 Founder-Problem Fit이 심사위원에게 3초 안에 전달 안 됨
- 치명적 NG 우선순위: 창업계기 → 고객페르소나+분포 → 스톡이미지 교체 → AI 생성 사진 교체 → 경쟁사 5열
- 카피 불일치 발견: 표지의 "이야기를 듣고, 같이 나아갑니다"가 수정 프롬프트 기준이지만, 최종 명세서는 "감정은 듣고, 결론은 정리한다" — **대표 확정 필요**

### 한재원(CTO)
- 기술 아키텍처 슬라이드 완전 누락 — "프롬프트가 아니라 파이프라인" 설명 불가
- **Claude Max Plan $200/월 예산 미포함 — 가장 심각한 예산 오류**
  - A안: 자비 명시(250만 유지) / B안: 총액 420만으로 상향
- 스톡이미지 → pullim.vercel.app 실제 스크린샷 교체 필수
- 543원 산출 내역(Haiku+Sonnet+Opus) 표기 권고
- "API key 연결 시 즉시 작동" → "현재 데모 배포 중"으로 수정 (조건부 표현 제거)

### 서윤하(AI Lead)
- 5단계 파이프라인이 슬4에서 3단계로 축약됨 (④착지, ⑤정리문서 생성 누락)
- 전문가 추천/직접 선택 메커니즘이 어디에도 없음 — v2 핵심 차별화 누락
- 정리 문서 "자동 생성" 키워드 누락 (세션 끝에 자동으로 생성된다는 것이 불명확)
- 슬14 "5단계"라 쓰고 4개만 나열 — 숫자-내용 불일치 즉시 수정 필요

### 최서영(Domain)
- **Veto 조건 2가지**: ①면책 고지("전문 심리상담을 대체하지 않습니다") 없으면 Veto / ②웰니스 포지셔닝 미명시 시 Veto
- "냉철한 분석 에이전트" → 금지 표현 위반, "구조적 분석 중심의 대화 방식"으로 교체
- "우울감이 감지되면" → 진단적 언어, "감정적 어려움 신호가 감지되면"으로 교체
- "결론의 책임은 온전히 사용자에게" → 톤 조정 필요, 명세서 원문("면책이 아니라 제품 핵심 메커니즘")으로 교체
- 업계 교훈 블록(Woebot/Yara AI) 없음 — 3블록 구조 복원 필요
