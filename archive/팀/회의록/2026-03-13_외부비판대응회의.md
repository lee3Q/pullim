## COS 종합

### 합의 사항 (전원 동의)

1. **인터뷰 최우선**: 코딩 멈추고 사람 만난다. Solution Interview 최소 10명 (목표 20명).
2. **Opus → Sonnet 즉시 다운그레이드**: 비용 543원 → 80~120원. 품질 차이 실측.
3. **이용약관 + 면책 팝업 즉시 배포**: 최서영 초안 → 법률 자문 → 배포.
4. **API 보안**: rate limit + 인증 최소 구현. 한재원 담당.
5. **위기 감지 2-tier 명문화**: L1 키워드 + L2 LLM 문맥 분류. 서윤하+최서영 공동.

### 쟁점 (의견 갈림)

| 쟁점 | 쪽 | 결론 |
|------|-----|------|
| DB 붙이는 시점 | 한재원: MVP 착수 시 / 박지훈(컨설턴트): 즉시 | **한재원 안 채택** — CD 단계에서 DB는 오버엔지니어링. MVP 착수 동시 연동 |
| v2 파이프라인 호출 수 | 박지훈: 과잉 / 한재원: 설계 의도 | **서윤하+한재원 최적화 검토** — 불필요한 호출 식별 후 축소 |
| 에이전트 팀 회의 지속 여부 | 박지훈: 중단 / 팀: 유지 | **조건부 유지** — 사용자 피드백 기반 안건만. 내부 문서 작업용 회의 중단 |

### 서영 거부권 조건

> 이용약관 + 위기 감지 프롬프트 + 전문기관 연결이 실제 작동 확인되기 전까지 **신규 사용자 온보딩 확대 거부**.
