# 제품 비전 재정의 회의
> 일시: 2026-03-16 (42차 세션)
> 안건: "풀림은 하나의 세계" 기반 제품 포지셔닝 및 모드 구조 재정의

## 결정사항

| 항목 | 결정 |
|------|------|
| 외부 포지셔닝 문장 | 보류 유지 — 인터뷰 20명 결과 후 결정 |
| 내부 비전 명문화 | "공간" 기반 1페이지 초안 → 도현 작성 |
| SYSTEM_BASE_V2 문구 | "역할→공간" 수정 → 서윤하 초안, 서영 크로스체크 후 확정 |
| ALTER EGO | MVP 밖. 별도 설계. 인터뷰 데이터 먼저. |
| 모드 분기 구조 | mode 파라미터 A방식 (엔드포인트 분리 아님) |
| STAY/SOLVE 5번째 축 | 보류 — 인터뷰에서 "그냥 말하고 싶었다" 3회 이상 나오면 재논의 |
| 번아웃/연애 모드 안전 기준 | 서영이 Tier 조정안 + 면책 문구 업데이트 |
| ALTER EGO 거부권 기준표 | 서영 완성 → 윤하에게 전달 |

## 합의 내용 요약

### 비전 해석 (박도현)
- 해석 B 채택: "하나의 세계" = 내부 설계 원리. 외부 메시지 변경 없음.
- 인터뷰 가설 2개 추가: ①같은 앱을 다른 고민에도 쓸 의향 ②누적 히스토리 가치 인식

### 기술 영향 (한재원)
- 코드 즉시 변경 없음. mode 파라미터 A방식.
- user_id nullable 추가 (세션 히스토리 확장 대비)
- ALTER EGO = 별도 엔드포인트(/api/alter-ego), 윤하+서영 설계 후 착수

### AI 파이프라인 (서윤하)
- SYSTEM_BASE_V2 "역할→공간" 문구 수정 필수
- STAY/SOLVE 축: 인터뷰 데이터 확인 후 재논의 (조건부 보류)
- 듣기 단계 열린 끝 옵션 → 인터뷰 이후 설계

### 안전/윤리 (최서영)
- 포지셔닝 전환해도 웰니스 법적 선 유지
- 번아웃/연애 모드 → Tier B 민감도 상향 필요
- ALTER EGO 거부권 기준 확정:
  - **가져가지 말 것**: 신체화 반응 설계, 중독 루프(스트릭/배지/FOMO), 감정 의존 유도 캐릭터
  - **가져갈 것**: 판단 없는 대기, 페르소나 온기(의존 없이), 일관된 정체성
  - 회색지대 4개 항목 → 윤하 초안에 표시, 서영이 일괄 검토
