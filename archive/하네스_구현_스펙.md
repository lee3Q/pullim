## 개요

현재 AI 앱(Woebot/Wysa/ChatGPT/Claude)은 사용자가 **말한 것**에만 반응한다.
풀림 하네스는 **말하지 않은 것**과 **반복 회피 패턴**까지 읽는다.

차별화 2레이어:
1. **행동 시그널 기반 네거티브 앵커 자동 갱신** — 회피 패턴 → 다음 세션 응답 규칙 자동 조정
2. **침묵 적응 프롬프팅 (Silence-Adaptive Prompting)** — 대화 구조 빈칸 감지 → 리프레이밍 질문 자동 설계

## 레이어 1: 행동 시그널 기반 네거티브 앵커

### 개념
OpenAI Memory = 사용자가 말한 사실 저장.
풀림 = 사용자가 말하지 않은 회피 패턴 추출 → 네거티브 앵커로 변환 → 다음 세션 시스템 프롬프트에 자동 삽입.

### 구현 단계

**Sprint 1 (지금): 시그널 수집 스키마 설계**

```sql
-- session_events 테이블
CREATE TABLE session_events (
  id UUID PRIMARY KEY,
  session_id UUID REFERENCES sessions(id),
  user_id UUID,
  event_type TEXT, -- 'SKIP' | 'PAUSE' | 'RETRY' | 'ABORT'
  question_id TEXT,
  timestamp TIMESTAMPTZ,
  context JSONB -- 해당 시점 대화 맥락 스냅샷
);
```

수집 항목 (조건 B — 코드 전 문서화):
- `SKIP`: 선택지를 고르지 않고 다음으로 넘김
- `PAUSE`: 응답 지연 (타이핑 시작 후 취소)
- `RETRY`: 동일 질문 유형에 재질문
- `ABORT`: 특정 단계에서 세션 이탈

**선행 조건 (서영 조건 A/B/C):**
- A: 온보딩 동의 UI — "대화 패턴이 다음 세션 개선에 활용됩니다" + 구체 항목 명시
- B: 이 문서 (수집 항목 목록 코드 전 문서화)
- C: 수집↔주입 경로 코드 레벨 분리 (Sprint 1에서 주입 경로 없음, 주석이 아닌 구조로)

---

**v2.5 (10세션 이상 사용자): 네거티브 앵커 자동 주입**

흐름:
1. 세션 완료 → Haiku가 session_events 분석 (세션당 추가 비용 ~50-100원)
2. 상위 회피 패턴 3-5개 추출 → `user_negative_anchors` 테이블 저장
3. 다음 세션 시스템 프롬프트에 자동 삽입:

```
[이 사용자 맞춤 응답 규칙]
다음 패턴의 응답은 이 사용자에게 가치 없다:
- {anchor_1}
- {anchor_2}
- {anchor_3}
```

```sql
-- user_negative_anchors 테이블
CREATE TABLE user_negative_anchors (
  id UUID PRIMARY KEY,
  user_id UUID,
  anchor_text TEXT,
  source_event_type TEXT,
  confidence FLOAT,
  applied_count INT DEFAULT 0,
  created_at TIMESTAMPTZ,
  updated_at TIMESTAMPTZ
);
```

**안전 상수 (서영 제시 — 코드에 하드코딩):**
- 위기 감지 민감도는 네거티브 앵커 학습으로 낮아지지 않음
- 질문 수 상한(7개)은 맥락 무관 고정
- "전문가 상담 권유" 멘트는 앵커 대상에서 제외

**v3 (추후): 사용자 직접 하네스 편집**
- 사용자가 자신의 앵커 목록을 보고 수정할 수 있는 UI
- "내 AI 사용 규칙 설정" 화면

## 레이어 2: 침묵 적응 프롬프팅 (Silence-Adaptive Prompting)

### 개념
사용자가 "A, B 중 뭐가 나아요?"라고 물었을 때 실제 고민은 C인 경우.
C는 말 안 했다. 풀림은 대화 구조의 빈칸(말하지 않은 것)을 감지해서 그쪽으로 리프레이밍 질문을 설계한다.

### 구현 위치
듣기(LISTEN) 단계 Sonnet 프롬프트 내부.

### 구현 로직

```
[침묵 적응 분석 레이어]
사용자 발화에서 다음을 감지:
1. 명시된 선택지 뒤에 숨은 실제 질문 (surface vs deep question)
2. 반복 회피하는 키워드/주제 (언급했다가 바로 넘어간 것)
3. 감정 어조와 텍스트 내용의 불일치

감지 시: 표면 질문에 직접 답하지 말고, 빈칸을 향해 리프레이밍 질문 1개 삽입.
예) "이직할까요?" → "지금 회사를 떠나는 게 두려운 게 아니라, 새로운 곳에 가도 같은 상황이 반복될까봐 걱정되는 건 아닐까요?"
```

### 관련 파일
- SKILL.md (서윤하 담당): 침묵 적응 트리거 조건 명문화
- `prompts-v2.ts` (재원 담당): LISTEN 단계 프롬프트에 레이어 삽입
