# Inner Reasoning (내면 사고 계층)

Pullim의 내면 사고 계층은 사용자의 부담을 줄이는 적응형 조절 장치입니다.

## 핵심 원칙

**이것은 사용자를 조종하기 위한 은닉 장치가 아닙니다.**

내면 사고 계층은 대화의 흐름을 읽고, 사용자가 덜 부담을 느끼도록 프롬프트를 조절합니다. 사용자의 선택을 바꾸거나, 특정 방향으로 유도하거나, 사용자 모르게 정보를 수집하지 않습니다.

## 두 가지 모드

### 규칙 기반 (기본)

- `ENABLE_BEHIND_LLM=false` (기본값)
- 외부 API 호출 없음
- 미리 정의된 규칙으로 대화 맥락 파악
- 타이밍, 톤, 프롬프트 구조 조절
- 프라이버시: 외부로 데이터 전송 없음

### LLM 기반 (선택)

- `ENABLE_BEHIND_LLM=true`로 활성화
- `GOOGLE_AI_API_KEY` 필요
- 행동 신호와 대화 맥락을 외부 모델(Gemini)로 전송
- 더 정교한 적응 가능
- **주의**: 사용자 데이터가 외부 API로 전송됨

## 무엇을 조절하는가

- **프롬프트 톤**: 사용자의 현재 상태에 맞게 질문 방식 조정
- **응답 길이**: 사용자가 지쳐 보이면 짧게, 몰입하면 깊이
- **안전 가드**: YELLOW 감지 시 safety guard를 프롬프트에 주입
- **난이도**: 사다리 단계 자동 조정 제안

## 무엇을 하지 않는가

- 사용자의 결정을 대신하지 않음
- 특정 선택지를 우대하지 않음
- 사용자 모르게 정보를 수집하지 않음
- 감정을 조작하지 않음

## 구현

- `src/lib/session/behind-llm.ts` — LLM 기반 추론 (server-only)
- `src/app/api/behind-thought/route.ts` — API 엔드포인트 (opt-in 가드)
- `src/lib/safety/crisis-detector.ts` — 위기 감지는 별도 계층

## 프라이버시 고려

규칙 기반 모드에서는 어떤 사용자 데이터도 외부로 전송되지 않습니다. LLM 기반 모드를 활성화하면 대화 내용이 외부 API로 전송되므로, 공개 배포 시 사용자에게 이 사실을 명시해야 합니다.
