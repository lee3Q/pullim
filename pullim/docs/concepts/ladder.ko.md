# Adaptive Ladder (적응형 사다리)

Pullim의 대화 시스템은 사용자의 표현 역량에 맞춰 난이도를 조절하는 5단계 사다리 구조입니다.

## 5단계 구조

### Level 1 — 감각 (Sensory)

가장 낮은 진입 장벽. 글을 쓰지 않아도 됩니다.

- 이미지, 색상, 단어 선택으로 시작
- "지금 어떤 느낌인가요?"에 그림으로 응답
- 복잡한 사고나 언어 표현이 어려울 때 사용

### Level 2 — 비교 (Comparison)

제시된 옵션 중 하나를 고릅니다.

- "A와 B 중 어느 쪽이 더 가까운가요?"
- 자신의 상태를 기존 프레임에 대입
- 직접적인 표현 대신 선택으로 의사 전달

### Level 3 — 분석 확인 (Analysis)

AI가 정리한 패턴을 확인하거나 수정합니다.

- "이렇게 정리했는데 맞나요?"
- 자신의 생각이 외부 시각으로 재구성된 것을 검토
- 동의/수정/재시도 선택

### Level 4 — 선택 (Choices)

행동 대안 중 하나를 선택합니다.

- 구체적인 다음 단계 옵션 제시
- "이 중에서 하나를 골라보세요"
- 실행 가능한 행동으로 수렴

### Level 5 — 자유 대화 (Free Text)

완전한 열린 대화.

- 어떤 형태로든 자유롭게 표현
- AI가 맥락을 유지하며 응답
- 가장 높은 표현 자유도

## 적응 원리

사다리는 사용자가 힘들면 내려가고, 표현 가능하면 올라갑니다.

```
표현이 어려움 → Level 1-2 (선택 기반)
표현이 가능함 → Level 4-5 (개방형)
중간 → Level 3 (확인/수정)
```

이 구조의 핵심은 **사용자의 현재 상태에 맞춘다**는 것입니다. 높은 단계가 "더 나은" 것이 아닙니다. 지금 사용자가 편안하게 응답할 수 있는 단계가 올바른 단계입니다.

## 구현

- `src/lib/session/ladder-store.ts` — 상태 관리
- `src/lib/session/ladder-types.ts` — 타입 정의
- `src/app/api/ladder/` — API 엔드포인트
- `src/components/session/` — UI 컴포넌트

## Demo Mode

`LLM_MODE=demo`에서는 모든 단계가 큐레이션된 예시 데이터로 동작합니다. API 키가 필요하지 않습니다.
