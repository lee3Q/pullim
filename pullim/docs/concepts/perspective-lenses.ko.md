# Perspective Lenses / Crystals (관점 렌즈 / 구슬)

Pullim의 구슬(Crystal)은 재화가 아니라 관점 렌즈입니다.

## 구슬이란

각 구슬은 사용자의 고민을 다른 분석 각도에서 바라보게 해주는 렌즈입니다. 하나의 고민을 여러 관점에서 해체하여, 사용자가 스스로 판단할 수 있는 사고 재료를 제공합니다.

## 기본 구슬

| 구슬 | 관점 | 역할 |
|------|------|------|
| 금화 (Gold Coin) | 가치 | 무엇이 중요한지 밝히기 |
| 나침반 (Compass) | 방향 | 어디로 가고 싶은지 탐색 |
| 거울 (Mirror) | 자기 인식 | 스스로를 어떻게 보는지 반영 |
| 저울 (Scale) | 균형 | 장단점, 이익과 비용 비교 |
| 모닥불 (Campfire) | 감각 | 몸과 감정이 말하는 것 듣기 |

## 핵심 원칙

### AI 분석은 진실이 아닙니다

구슬이 제시하는 분석은 "정답"이 아닙니다. 사고의 재료입니다. 사용자는 AI의 분석을 읽고, 동의하거나 반박하거나 무시할 수 있습니다.

### 전문가 사칭 금지

구슬은 특정 분야의 전문가 역할을 하지 않습니다.

- 심리 전문가, 의료 전문가, 법률 자문, 재무 조언자를 사칭하지 않습니다.
- "전문가의 시각에서 본다면..." 같은 표현을 사용하지 않습니다.
- 각 관점은 하나의 해석 가능성일 뿐입니다.

### 재화가 아닙니다

구슬은 사용하고 사라지는 소모성 재화가 아닙니다. 사용자가 원할 때 언제든 모든 관점을 탐색할 수 있어야 합니다.

## 구현

- `src/lib/types-ultimate.ts` — CrystalName 타입 정의
- `src/lib/themes/index.ts` — 구슬별 레이블 및 설정
- `src/components/ultimate/CrystalSelector.tsx` — 선택 UI
- `src/components/ultimate/CrystalAnalysisView.tsx` — 분석 결과 UI
- `src/app/api/ultimate/analyze/` — 분석 API

## Demo Mode

`LLM_MODE=demo`에서는 큐레이션된 예시 분석이 반환됩니다. 모든 구슬의 분석 내용을 확인할 수 있습니다.
