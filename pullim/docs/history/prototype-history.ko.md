# Prototype History (프로토타입 역사)

Pullim이 오픈소스 적응형 성찰 엔진이 되기까지의 과정입니다.

## 창업 프로토타입

Pullim은 원래 창업 프로젝트의 프로토타입으로 시작되었습니다. AI 기반 개인 맞춤형 의사결정 보조 도구를 목표로 기획되었습니다.

## 실험 기간

초기에는 다양한 접근 방식을 실험했습니다:

- **멀티에이전트 구조** — 여러 AI 에이전트가 역할을 나누어 사용자의 고민에 접근
- **게임적 UI** — RPG 스타일의 대화 인터페이스, 캐릭터 시스템
- **구슬(Crystal) 시스템** — 관점 렌즈로서의 구슬 도입
- **테마 엔진** — 분위기별 시각/대화 환경

이 실험들에서 유효한 부분은 유지되고, 불필요한 복잡성은 제거되었습니다.

## 철학 중심 재정리

ICC(대학 창업 지원 프로그램) 심사 이후, 프로젝트의 방향을 재검토했습니다. 비즈니스 모델보다 **도구 자체의 가치**에 집중하기로 결정했습니다.

이 과정에서:

- "치료"나 "상담" 프레임에서 벗어남
- "적응형 성찰 엔진"으로 정체성 재정립
- 안전망을 기반 계층으로 격상
- 사용자 주도권을 최우선 원칙으로 명문화

## 오픈소스 전환

v0.1에서 프로젝트를 오픈소스로 공개합니다:

- MIT 라이선스 적용
- 상업적 기능(광고, 결제, 구독)은 비활성화
- Demo Mode로 API 키 없이 전체 기능 체험 가능
- 실험적 기능(ultimate pipeline, debate, judge)은 명시적으로 분리
- 안전 정책과 한계를 문서화

## 포함하지 않는 것

이 역사 문서에는 다음이 포함되지 않습니다:

- 비공개 신청서 내용
- 사업 계획서 세부 내용
- 실제 사용자 세션 기록
- 개인 기록 및 메모
- Claude Memory 내용
