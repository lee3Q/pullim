# Crisis Safety Policy (위기 안전 정책)

Pullim의 위기 감지 시스템은 모든 LLM 호출 전에 실행되는 기반 계층입니다.

## 3단계 분류

### GREEN — 일반 대화

- 위기 징후 미감지
- 정상적인 성찰 대화 진행
- 모든 기능 사용 가능

### YELLOW (Tier B) — 주의

**감지 기준:** 절망, 무가치감, 포기, 도피 욕구

**시스템 동작:**
- `safetyGuard`를 프롬프트에 주입
- 자기가치감 보호 규칙 활성화
- 대화는 계속되되 안전 장치 포함
- `bannerType: "inline"` — 인라인 안내 표시

**사용자에게:**
- 부드러운 안내 메시지
- 핫라인 정보 (inline)
- 대화 중단 없음

### RED (Tier A) — 즉시 중단

**감지 기준:** 자살, 자해, 소멸 욕구, 구체적 계획/방법

**시스템 동작:**
- **LLM 호출 즉시 중단**
- `shouldHalt: true` 반환
- 어떤 AI 응답도 생성하지 않음
- `bannerType: "modal"` — 모달 알림

**사용자에게:**
- 명확한 위기 안내 메시지
- 핫라인 정보 (modal)
- 전문 기관 연결 안내

## 우선순위 규칙

Tier A와 Tier B 키워드가 동시에 감지되면 **항상 Tier A를 우선**합니다.

## 안전 모드 우선순위

위기 감지 시:
- 테마, 페르소나, 게임 UI 등 모든 장식 요소보다 **안전 응답이 우선**합니다.
- 사용자 경험이 흐름을 잃더라도 안전 리소스 노출이 먼저입니다.
- `safetyMode`는 `themes`, `personas`, `characters` 설정을 오버라이드합니다.

## 치료/진단/응급지원이 아님

Pullim의 위기 감지는 **안전망**이지 **치료 도구가 아닙니다**.

- 위기 감지가 임상적 진단을 대체하지 않습니다.
- YELLOW/RED 응답이 상담이나 치료가 아닙니다.
- 감지되지 않았다고 해서 위기가 없다는 의미가 아닙니다.
- 실제 위기 상황에서는 반드시 전문 기관에 연락하세요.

## 공백 난독화 대응

사용자가 의도적으로 공백을 삽입하여 키워드를 회피하려는 경우(예: "죽 고 싶 다")에도 감지됩니다. 입력 정규화 과정에서 공백을 제거한 후 키워드 매칭을 수행합니다.
