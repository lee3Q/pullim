# Limitations (한계)

Pullim을 사용하기 전에 알아야 할 한계입니다.

## AI는 틀릴 수 있습니다

- Pullim의 모든 AI 응답은 생성된 텍스트입니다. 사실이 아닐 수 있습니다.
- 분석, 제안, 요약은 참고 자료일 뿐입니다. 중요한 결정은 반드시 직접 확인하세요.
- 위기 감지 시스템이 모든 위험을 감지하지 못할 수 있습니다. 감지되지 않았다고 안전을 보장하지 않습니다.

## 전문 조언 대체 불가

Pullim은 다음을 대체하지 않습니다:

- **전문 상담** — 심리 상담, 정신건강 서비스
- **의료 진단** — 질병 진단, 치료 방안
- **법률 자문** — 법적 권리, 소송, 계약
- **재무 조언** — 투자, 자산 관리, 세무
- **응급 서비스** — 급성 위기, 자해, 타해

위기 상황에서는 **전문 기관, 주변 사람, 응급 서비스**를 먼저 찾으세요.

## 호스팅 배포 리스크

Pullim을 공개적으로 배포하는 경우:

1. **Rate Limit 미구현** — 모든 API 라우트에 요청 제한이 없습니다. 실제 API 키를 연결하면 비용 남용이 발생할 수 있습니다.
2. **인증 없음** — 모든 API 엔드포인트가 공개 접근 가능합니다.
3. **Body Size 제한 없음** — 요청 본문 크기 제한이 없습니다.
4. **에러 메시지 노출** — API 에러 시 `error.message` 내용이 응답에 포함될 수 있습니다.

공개 배포 전에 [SECURITY.md](../../SECURITY.md)를 반드시 확인하세요.

## 데이터 저장

- **기본**: 세션 데이터는 브라우저 localStorage에 저장됩니다.
- **Supabase 연동 시**: 세션 데이터가 외부 데이터베이스에 저장됩니다. RLS(Row Level Security) 정책 설정이 필요합니다.
- **LLM 기반 내면 사고 활성화 시**: 대화 내용이 외부 AI API로 전송됩니다.

## 언어 제한

- 위기 감지 키워드는 한국어로 작성되어 있습니다. 다른 언어에서는 감지율이 크게 낮아집니다.
- UI 텍스트와 프롬프트는 주로 한국어로 작성되어 있습니다.

## 데모 모드 한계

- 데모 모드(`LLM_MODE=demo`)의 응답은 큐레이션된 예시 데이터입니다.
- 실제 AI 분석 결과와 다릅니다.
- 개인화되지 않은 일반적인 내용입니다.
