# 마인드카페 체험 후기

## 기본 정보
- 카테고리: 복합 (AI챗봇 + 커뮤니티 + 상담연결 + 심리테스트)
- 과금: 유료

## 첫인상
- 가입 요구: 소셜로그인 + 개인정보
- UI 느낌: 깔끔함
- 분위기: 전문적이나 복잡

## 핵심 기능
- 전문가 상담 연결 (핵심)
- 심리테스트/진단
- 익명 커뮤니티
- AI 챗봇 (거의 안 쓰는 듯)

## 체험 흐름
전문가와의 연결이 핵심인 플랫폼. 실제 상담 연결이 원활하며 규모가 가장 큼.

## 장단점

### 좋은 점
- 전문가 접근성 높음
- 규모가 크고 상담 연결 원활
- 신뢰감 있는 분위기

### 아쉬운 점
- 과금 부담
- UI 복잡
- 상담의 매개만 할 뿐, 실제 문제 해결 되는지 불확실
- 새로운 시장이 아닌 기존 시장(상담)에 연결만 하는 플랫폼

## 풀림과 비교
- **겹치는 것**: 거의 없음
- **풀림이 나은 점**:
  - AI 직접 개입 (매개 아닌 직접 해결)
  - 의사결정 도구로서의 기능
  - 게임화, 몰입감
  - 낮은 진입장벽
- **참고할 점**: 커뮤니티, 실제 상담, 콘텐츠는 풀림에 없음

## 종합 평가
- 별점: 3점
- 한줄평: 시장 규모는 크지만 매개만 하는 플랫폼, 과금 부담 있음

## ICC 발표 차별화 포인트
- 풀림은 **AI가 직접 개입**하여 문제를 해결 (매개 X)
- 풀림은 **의사결정 도구** (상담 연결 X)
- 풀림은 **게임화 + 몰입감**으로 접근
- 풀림은 **낮은 진입장벽** (무료/가벼운 시작)
