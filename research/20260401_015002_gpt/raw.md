# 챗봇/상담앱 첫 메시지 단계 이탈률  
앱 업계 통계에 따르면 초기 온보딩 단계에서의 이탈이 매우 높다. 예를 들어 Slack은 **첫 메시지 전송**을 핵심 “aha 모먼트”로 보고 있으며, 이를 경험한 사용자는 더 오래 남는다【80†L167-L175】. 실제로 업계 평균으로 신규 사용자의 75% 이상이 첫 주 이내에 이탈하는 것으로 보고되었다【80†L119-L127】. 특히 입력 필드가 많아질수록 완료율이 급감하는데, 조사에 따르면 양식에 필드가 한 개 추가될 때마다 약 5–7%의 사용자가 이탈한다【80†L219-L222】. 정신건강 챗봇에서도 자유 입력 단계가 길어지면 마찬가지로 이탈이 늘 수 있다. 실제로 챗봇 UX 권고사항에서는 “사용자가 혼란스럽거나 타이핑 피로를 느껴 중단율(dropoff)이 올라간다”며, 가능한 빠른 응답 버튼(퀵리플라이)을 제공해 자유형 질문 대신 고정 선택지를 쓰는 것이 이탈률을 낮추는 방법으로 제안되었다【15†L117-L121】.  

# “무슨 말을 써야 할지 모르겠다” 현상  
자유형 텍스트 입력에서 사용자는 종종 **‘뭘 말해야 할지’ 망설인다**. 이에 대한 사용자 조사는 직접적으로 많지 않지만, 저널링·자기성찰 분야에서는 비슷한 문제를 인정하고 있다. 예를 들어 음성 일기 가이드에서는 “무엇을 말해야 할지 모르는 경우가 문제(Challenge)”라며, 주변 상황이나 신체 감각 묘사를 시작으로 글쓰기 유도를 권장한다【65†L361-L369】. 즉, 질문이 너무 개방적이면 사용자가 초기 응답을 내지 못해 참여가 중단될 수 있다. 이러한 현상은 멘탈헬스 앱에서도 보고되는데, 한 연구에서는 사용자가 “앱을 왜 써야 할지 모르겠다”고 말할 만큼 동기와 방향성을 찾기 힘들다고 지적한 바 있다(“왜 이 앱을 써야 하는지 모르겠어요”【53†L105-L112】).  

# 자기폭로 장벽(self-disclosure barrier)과 입력 부담  
챗봇의 **자기폭로(self-disclosure) 장벽**은 정신건강 대화에서 중요한 이슈다. 연구에 따르면, 챗봇은 인간 상담사보다 사용자의 “판단 두려움”을 줄여 익명성이 강화된 안전한 공간을 제공하므로 민감한 감정 표현에 유리하다【70†L258-L266】. 반면 감정 공감 능력 부족 때문에 신뢰 관계 형성에는 한계가 있어, 챗봇을 사람으로 인식시켰을 때 사용자가 더 많은 사적 정보를 털어놓는 것으로 나타났다【78†L69-L78】. 즉, 인간처럼 느껴지면 자기폭로가 늘어나지만, 챗봇임을 알면 사용자들이 다소 방어적으로 변하기도 한다【78†L69-L78】. 한편 텍스트 입력 자체가 부담이 되어 **타이핑 피로**나 **빈칸 불안(blank-page anxiety)**을 유발할 수 있다. 실제로 한 연구는 “반복 과업으로 인한 피로”를 사용자 참여 저하 요인으로 꼽았고【56†L135-L143】, 음성 저널링 앱 안내서에서는 “더 이상 타이핑 피로와 빈칸 불안이 없어야 한다”며 음성 입력 전환을 장려했다【67†L592-L600】.  

# 텍스트 입력 vs 선택지 방식 참여율 비교  
실제 실험에서도 텍스트 기반 챗봇과 버튼형(메뉴형) 인터페이스의 참여도 차이가 관찰되었다. Nguyen 등(2022)은 여행 예약 과제를 통해 챗봇(UIs)과 메뉴형 UI를 비교했는데, 챗봇 사용 시 인지적 부하가 높아지고 자율감이 낮아져 만족도가 떨어짐을 확인했다【82†L95-L99】. 즉, 대화형 챗봇은 메뉴 기반 UI에 비해 사용자 만족을 낮추는 경향이 있다. 반면 고정된 조건(제약이 있는 과제)에서는 메뉴 인터페이스 만족도가 높았으나, 반대로 사용자가 스스로 기준을 정하는 열린 과제에서는 메뉴 UI 만족도가 낮아졌고, 이 경우 챗봇 인터페이스가 더 나은 경험을 제공할 수 있음을 시사했다【75†L379-L388】. 요약하면, **구조화된 과제**는 선택형 UI가, **자유형 과제**는 대화형 챗봇이 상대적으로 참여율을 높일 여지가 있다는 연구 결과이다.  

# 멘탈헬스 앱 리뷰의 입력 불만 패턴  
앱 사용자 리뷰에서도 입력 관련 불만이 자주 나타난다. 예를 들어 “입력이 귀찮다”, “뭘 써야 할지 모르겠다” 같은 표현이 반복적으로 언급된다. 한 국내 연구는 사용자들이 ‘반복되는 과제 피로감’을 호소한다고 밝혔으며【56†L135-L143】, 저널링 관련 자료에는 ‘타이핑 피로’와 ‘빈칸 불안’ 같은 개념을 언급하며 자유 텍스트 입력의 어려움을 지적하고 있다【67†L592-L600】. 이러한 증언들은 실제 앱 리뷰에서도 나타나는데, 사용자는 반복적 글쓰기나 구체적 지시가 없는 입력을 “번거롭고 부담된다”고 느껴 중도 이탈하거나 참여도를 낮춘다.
