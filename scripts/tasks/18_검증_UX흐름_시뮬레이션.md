끝판왕 파이프라인의 UX 흐름을 3가지 시나리오로 시뮬레이션해줘.

참고: /Users/sanggyulee/study/main/pullim/제품/끝판왕_파이프라인_설계_2026-03-19.md

시나리오 1: "이직할까 말까" (커리어 고민, 20대 남성)
시나리오 2: "남자친구와 헤어져야 할까" (관계 고민, 20대 여성)
시나리오 3: "창업할까 취업할까" (진로 고민, 대학생)

각 시나리오에서:
1. 9단계 전체 흐름을 실제 대화처럼 작성 (현자 대사 포함)
2. 구슬 선택 → 분석 결과 → 토론 → 결론까지 풀 시뮬레이션
3. 사용자 개입 포인트에서 현실적인 사용자 반응 시뮬레이션
4. "잘 모르겠어요" 분기와 "사실 맞아요" 분기 모두
5. UX에서 어색한 부분, 끊기는 부분, 개선이 필요한 부분 표시

이것은 실제 테스트 전 드라이런. 문제를 미리 발견하기 위함.
