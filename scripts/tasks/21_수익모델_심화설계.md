설계:
1. 무료 티어 (광고 모델)
   - 어떤 광고? (배너? 리워드 비디오? 네이티브?)
   - 광고 삽입 타이밍 (세션 시작 전? 중간? 끝?)
   - 예상 eCPM 및 수익 시뮬레이션
   - 게임성과 연계: "광고를 보면 추가 구슬 1개 해금"

2. 유료 구독 티어
   - Standard vs Pro 상세 기능 차이
   - 가격 시뮬레이션 (7,500원 vs 다른 가격대 A/B 테스트 설계)
   - 무료→유료 전환 트리거 설계

3. 인앱 구매 (게임성)
   - 프리미엄 구슬 (특별 관점): "시간여행자의 구슬" — 10년 후 시점에서 봄
   - 프리미엄 테마 스킨
   - 특별 캐릭터
   - 가격대: 1,000~5,000원/건

4. B2B 라이선스
   - 대학 진로상담센터용 커스텀 버전
   - 기업 EAP용 커스텀 버전
   - 가격 구조 (유저당? 기관당?)

5. 유닛이코노믹스 재계산
   - 이종 모델 3개 (Claude + GPT + Gemini) + Tavily + Judge 포함
   - 세션당 실제 비용 재추정
   - 각 수익 모델별 마진
