끝판왕 컨셉의 마케팅 전략을 설계해줘. "삶의 안식처" + "합리적 타로" + "게임성"을 어떻게 팔 것인가.

1. 브랜딩
   - 이름: "풀림"을 유지할지, 새 이름이 필요한지 (모험가/안식처 세계관에 맞는 이름 후보 10개)
   - 태그라인 후보 5개
   - 로고 방향 (도트 아트? 구슬? 모닥불?)

2. 런칭 전략
   - 티저: "모험가여, 곧 모닥불이 켜집니다" — 어떤 채널에서?
   - 베타 모집: 어떤 메시지로, 어디서, 몇 명
   - 바이럴 요소: 세션 결과 공유 ("나는 금화/나침반/거울의 구슬로 세상을 봤다")

3. 채널별 전략
   - 에브리타임 (대학생): 고민 게시판에 직접 가치 제공 → 자연 유입
   - 인스타그램: 도트 아트 + 모닥불 감성 콘텐츠
   - 유튜브 쇼츠: "실제 고민을 넣어봤습니다" 시리즈
   - 링크드인: 커리어 의사결정 사례
   - 틱톡: "현자가 나한테 한 말" 숏폼

4. 커뮤니티 설계
   - "모험가들의 모닥불" / "달빛정원" / "전략실 라운지"
   - 테마별 정체성 → 소속감 → 리텐션
   - 디스코드? 자체 커뮤니티? 에브리타임?

5. 콘텐츠 캘린더 (첫 3개월)
   - 주 단위 계획
