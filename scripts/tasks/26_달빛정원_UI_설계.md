설계:
1. 달빛정원만의 시각 언어
   - 컬러 팔레트 (달빛 = indigo/silver/soft green)
   - 핵심 비주얼: 달, 정원, 꽃, 나비, 이슬
   - 밤 감성 (고민은 밤에 하니까)

2. 화면별 와이어프레임 (ASCII mockup)
   - 홈: 달빛 아래 정원 벤치 + "오늘 밤, 어떤 이야기를 가져왔나요?"
   - 오브젝트 선택: 구슬 대신 꽃/나비/이슬 등
   - 분석: 꽃잎이 펼쳐지며 인사이트 표시
   - 토론: 나비들이 날아다니며 관점 전달
   - 결론: 편지 형태로 정리 ("당신에게 보내는 편지")
   - 종료: 달이 지고 새벽빛 + "다시 찾아오세요"

3. CSS 애니메이션 명세
   - 달빛 반짝임
   - 꽃 피어나기
   - 나비 날갯짓
   - 이슬 맺히기

4. 사운드 디자인 방향
   - 밤 자연 소리 (귀뚜라미, 바람)
   - 부드러운 피아노 앰비언트
