# 홈 화면 데모 유도 카피 개선

## 프로젝트
풀림 (~/study/main/pullim/pullim/) — Next.js 15 + React 19 + TypeScript + Tailwind CSS 4

## 현재 상태
홈 화면(pullim/src/app/page.tsx)에 기분 선택 버튼이 있지만, 첫 방문자가 "이걸 왜 해야 하지?"에 대한 동기 부여가 부족.

## 작업
page.tsx의 홈 화면 상단(기분 선택 전)에 데모 유도 문구 추가.

1. 헤더 영역에 추가할 내용:
   - 메인 카피: "3분이면 나를 알 수 있어요"
   - 서브 카피: "10가지 장면에서 선택하면, AI가 당신의 유형을 읽어냅니다"
   - CTA 느낌: 기존 "오늘 어떤 마음이야?" 섹션과 자연스럽게 연결

2. 스타일:
   - 판타지 세계관에 맞는 톤 (Gowun Batang 폰트 이미 적용됨)
   - 그라데이션 텍스트 or 은은한 glow
   - 모바일 중심 (max-w-md)

3. 주의:
   - 기존 기분 선택 UI는 건드리지 말 것
   - 카피 위치는 기분 선택 버튼들 바로 위
   - page.tsx만 수정

## 검증
- `npm run build` 통과
