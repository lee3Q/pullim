# 모바일 반응형 점검 + 수정

## 프로젝트
풀림 (~/study/main/pullim/pullim/) — Next.js 15 + React 19 + TypeScript + Tailwind CSS 4

## 목적
피드백 받을 사람들 대부분 모바일. 주요 화면이 모바일(375px~414px)에서 깨지지 않는지 점검.

## 점검 대상 파일
1. `pullim/src/app/page.tsx` — 홈 화면
2. `pullim/src/components/discovery/StoryDiscovery.tsx` — 파악 장면
3. `pullim/src/components/session/LadderSession.tsx` — 사다리 세션
4. `pullim/src/app/globals.css` — 전역 스타일

## 점검 항목
각 파일을 읽고 다음을 확인:
- 이미지가 뷰포트를 넘어가지 않는지 (max-w, object-fit)
- 텍스트가 잘리거나 넘치지 않는지 (overflow, word-break)
- 버튼이 충분히 크고 터치 영역이 확보되는지 (min-h-[44px])
- 가로 스크롤이 발생하지 않는지 (overflow-x-hidden)
- 키보드가 올라왔을 때 입력 영역이 보이는지

## 수정 원칙
- 문제 발견 시 Tailwind 클래스로 최소한 수정
- 데스크톱 레이아웃을 깨뜨리지 않는 범위에서
- `npm run build` 통과 확인
- 문제 없으면 수정하지 말 것
