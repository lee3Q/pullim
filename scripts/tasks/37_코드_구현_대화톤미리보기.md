# "풀림이라면 이렇게 대화했을 거예요" 미리보기 보강

## 프로젝트
풀림 (~/study/main/pullim/pullim/) — Next.js 15 + React 19 + TypeScript + Tailwind CSS 4

## 선행 작업
36번 태스크에서 PersonalityResult.tsx와 personality-type.ts가 생성되어 있어야 함.

## 목적
유형 결과 화면에서 "풀림이라면 이렇게 대화했을 거예요"를 실제 대화처럼 보여주기.
사용자가 "아 이런 식으로 나한테 말해주는구나"를 느끼게.

## 작업

### personality-type.ts의 각 유형에 pullimConversation 추가
기존 `pullimTone` 문자열 외에, 실제 대화 예시 3턴 추가:

```ts
pullimConversation: [
  { role: "pullim", text: "..." },
  { role: "user", text: "..." },
  { role: "pullim", text: "..." },
]
```

유형별로 다른 톤:
- 조용한 전략가 → 차분하고 구조적인 질문
- 감각적 모험가 → 따뜻하고 감각적인 비유
- 신중한 공감자 → 공감 먼저, 천천히
- 직관적 돌파자 → 직접적이고 핵심을 찌르는
- (나머지 4유형도 각각)

### PersonalityResult.tsx에 대화 미리보기 섹션 추가
- 채팅 버블 UI (pullim은 왼쪽, user는 오른쪽)
- 판타지 세계관 카드 안에 배치
- "풀림이라면 이렇게 대화했을 거예요" 제목
- 대화 3턴을 순차적으로 보여주기 (fade-in 애니메이션은 선택)
