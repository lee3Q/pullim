# 에러 바운더리 + 로딩 스켈레톤 UI

## 프로젝트
풀림 (~/study/main/pullim/pullim/) — Next.js 15 + React 19 + TypeScript + Tailwind CSS 4

## 작업

### 1. 에러 바운더리
`pullim/src/app/error.tsx` 생성 (Next.js App Router 컨벤션):
- 판타지 톤의 에러 화면
- "길을 잃었나 봐요. 다시 돌아가볼까요?" 느낌
- 홈으로 돌아가기 버튼
- 다크 테마 (#12101a 배경)

### 2. 로딩 UI
`pullim/src/app/loading.tsx` 생성:
- 간단한 로딩 애니메이션 (CSS only, 라이브러리 X)
- 판타지 느낌의 로딩 텍스트
- 다크 테마

### 3. 세션 페이지 로딩
`pullim/src/app/adventure/[id]/loading.tsx`, `garden/[id]/loading.tsx`, `strategy/[id]/loading.tsx` 생성:
- 각 테마 색상에 맞는 로딩 UI
