# 사다리 세션 UI 판타지 톤 통일

## 프로젝트
풀림 (~/study/main/pullim/pullim/) — Next.js 15 + React 19 + TypeScript + Tailwind CSS 4

## 현재 상태
- 사다리 세션 컴포넌트: `pullim/src/components/session/LadderSession.tsx`
- 레벨별 컴포넌트: `pullim/src/components/session/levels/` 안에 Level1~5
- globals.css에 판타지 CSS 변수 정의됨 (.fantasy-card, .fantasy-btn 등)

## 작업
1. LadderSession.tsx를 읽고 현재 스타일 확인
2. 레벨별 컴포넌트(Level1Sensory~Level5Direct)를 읽고 스타일 확인
3. 판타지 세계관에 안 맞는 모던 UI 요소를 판타지 톤으로 수정:
   - 카드: .fantasy-card 클래스 활용
   - 버튼: .fantasy-btn 클래스 활용
   - 배경: 다크 테마 (#12101a)
   - 폰트: 이미 Gowun Batang 적용되어 있으면 OK
4. globals.css의 기존 판타지 클래스를 최대한 재사용

## 주의
- 기능 변경 없이 스타일만 수정
- 치트 버튼, 이면사고 토글 등 기능 요소 건드리지 말 것
- `npm run build` 통과 확인
