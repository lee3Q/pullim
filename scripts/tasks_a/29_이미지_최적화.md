# 디스커버리 일러스트 이미지 최적화

## 프로젝트
풀림 (~/study/main/pullim/pullim/)

## 문제
`public/assets/discovery/` 이미지가 장당 2~8MB. 모바일에서 장면 전환 시 느림.
총 33장, 약 220MB. 목표: 장당 200KB 이하.

## 작업
1. `sips` (macOS 내장)로 모든 discovery 이미지를 리사이즈+압축:
   - 최대 가로 1024px (모바일 2x 해상도면 충분)
   - JPEG 변환 (품질 80%)
   - 원본 백업: `public/assets/discovery/originals/`에 복사

2. 실행 명령어:
```bash
cd ~/study/main/pullim/pullim
mkdir -p public/assets/discovery/originals

for f in public/assets/discovery/*.png; do
  [ -f "$f" ] || continue
  cp "$f" "public/assets/discovery/originals/$(basename $f)"
  sips -Z 1024 "$f" --out "$f" 2>/dev/null
done
```

3. Next.js Image 컴포넌트 사용 여부 확인:
   - `pullim/src/components/discovery/StoryDiscovery.tsx`에서 이미지를 어떻게 로드하는지 확인
   - `<img>` → `<Image>` (next/image)로 변경하면 자동 WebP 변환 + lazy loading
   - 이미 `<Image>`면 width/height 속성 확인

4. 프리로드 추가:
   - 현재 장면 다음 장면 이미지를 `<link rel="preload">` 또는 `new Image().src` 로 미리 로드

## 검증
- 이미지 파일 크기가 200KB 이하인지 확인
- `npm run build` 통과
- 원본이 originals/ 에 백업되어 있는지 확인
