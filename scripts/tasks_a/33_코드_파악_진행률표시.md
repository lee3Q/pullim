# 파악(Discovery) 진행률 표시 UI

## 프로젝트
풀림 (~/study/main/pullim/pullim/) — Next.js 15 + React 19 + TypeScript + Tailwind CSS 4

## 현재 상태
- StoryDiscovery.tsx에서 30장면(테마당 10장면)을 진행하지만 진행률 표시 없음
- 사용자가 얼마나 남았는지 모르면 이탈할 가능성 높음

## 작업
`pullim/src/components/discovery/StoryDiscovery.tsx`에 진행률 바 추가.

1. scene phase에서 상단에 진행률 표시:
   - 텍스트: "3/10" 형태 (현재장면/전체장면)
   - 얇은 프로그레스 바 (primaryColor 사용)
   - 위치: 장면 카드 상단, 판타지 세계관에 맞게 미니멀하게

2. 구현:
   - phase === "scene" 일 때만 표시
   - intro, outro, continue-prompt에서는 숨김
   - `sceneIndex + 1` / `story.scenes.length` 로 계산
   - Tailwind CSS로 스타일링 (별도 CSS 파일 만들지 말 것)

3. 디자인:
   - 프로그레스 바 높이 2px, 배경 반투명, 채워진 부분은 primaryColor
   - 텍스트는 작게, 반투명 (opacity-60)
   - 판타지 세계관 손상하지 않는 범위에서 최소한으로

## 검증
- `npm run build` 통과
- intro/outro에서 프로그레스 바가 안 보이는지 확인
