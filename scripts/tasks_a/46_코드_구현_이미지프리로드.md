# 스토리 장면 이미지 프리로드

## 프로젝트
풀림 (~/study/main/pullim/pullim/) — Next.js 15 + React 19 + TypeScript

## 문제
장면 전환 시 다음 이미지 로드에 시간이 걸려 전환이 느림.

## 작업
StoryDiscovery.tsx에서 현재 장면 렌더링 시 다음 장면 이미지를 미리 로드.

1. story-scenes.ts에서 각 장면의 imagePath 구조 확인
2. StoryDiscovery.tsx에 useEffect 추가:
   ```tsx
   useEffect(() => {
     // 다음 2장면 이미지 프리로드
     const nextScenes = story.scenes.slice(sceneIndex + 1, sceneIndex + 3);
     nextScenes.forEach(scene => {
       if (scene.imagePath) {
         const img = new window.Image();
         img.src = scene.imagePath;
       }
     });
   }, [sceneIndex, story.scenes]);
   ```
3. intro 단계에서 첫 장면 이미지도 프리로드

## 주의
- 한 번에 2장만 프리로드 (메모리 절약)
- `npm run build` 통과 확인
