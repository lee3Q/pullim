# Service Worker 이미지 캐싱 강화

## 프로젝트
풀림 (~/study/main/pullim/pullim/)

## 현재 상태
`pullim/public/sw.js` 존재

## 작업
1. sw.js를 읽고 현재 캐싱 전략 확인
2. discovery 이미지 (`/assets/discovery/*`)에 대해 cache-first 전략 추가:
   - 첫 로드 시 캐시에 저장
   - 이후 방문에서는 캐시에서 로드 (네트워크 요청 안 함)
   - 캐시 이름: `pullim-images-v1`
3. 다른 에셋 (`/assets/*`)도 cache-first로

## 코드 예시
```js
// fetch 이벤트에서
if (url.pathname.startsWith('/assets/')) {
  event.respondWith(
    caches.match(event.request).then(cached => {
      if (cached) return cached;
      return fetch(event.request).then(response => {
        const clone = response.clone();
        caches.open('pullim-images-v1').then(cache => cache.put(event.request, clone));
        return response;
      });
    })
  );
}
```
