# 파악 완료 → 유형 결과 화면 구현

## 프로젝트
풀림 (~/study/main/pullim/pullim/) — Next.js 15 + React 19 + TypeScript + Tailwind CSS 4

## 핵심 목표
파악(Discovery) 완료 후, 선택 데이터 기반으로 "당신은 ~~ 유형이네요" 결과 화면을 보여준다.
심리테스트처럼 재미있는 결과 → 완주 동기 부여 → UI 피드백 수집.

## 현재 흐름
1. page.tsx: 기분 선택 → 테마 선택 → StoryDiscovery 시작
2. StoryDiscovery.tsx: `onComplete(profile, selections)` 호출
3. page.tsx의 `handleDiscoveryComplete`에서 profile을 localStorage에 저장 → 세션 시작으로 이동

## 변경할 흐름
StoryDiscovery 완료 → **유형 결과 화면** 표시 → (선택) 세션 시작 or 피드백

## 구현

### 1. 유형 산출 로직 (새 파일)
`pullim/src/lib/personalization/personality-type.ts` 생성:

ProbabilityProfile의 5차원 데이터를 조합하여 유형 결정:
- approachStyle: analytical(-1) ↔ intuitive(+1)
- riskTolerance: cautious(-1) ↔ adventurous(+1)
- copingStyle: problem_solving(-1) ↔ empathy(+1)
- decisionSpeed: deliberate(-1) ↔ spontaneous(+1)
- selfAwareness: low(-1) ↔ high(+1)

유형 8가지 (상위 3차원 조합):
1. 조용한 전략가 — analytical + cautious + problem_solving
2. 감각적 모험가 — intuitive + adventurous + empathy
3. 신중한 공감자 — analytical + cautious + empathy
4. 직관적 돌파자 — intuitive + adventurous + problem_solving
5. 분석적 탐험가 — analytical + adventurous + problem_solving
6. 따뜻한 수호자 — intuitive + cautious + empathy
7. 대담한 설계자 — analytical + adventurous + empathy
8. 자유로운 치유자 — intuitive + cautious + problem_solving

각 유형에 대해:
```ts
interface PersonalityType {
  id: string;
  name: string;           // "조용한 전략가"
  emoji: string;          // "🧭"
  description: string;    // 2-3문장 설명
  pullimTone: string;     // "풀림이라면 이렇게 대화했을 거예요" 미리보기 (1-2문장)
  strengths: string[];    // 강점 2-3개
  blindSpots: string[];   // 놓치기 쉬운 것 1-2개
}
```

함수: `getPersonalityType(profile: ProbabilityProfile): PersonalityType`

### 2. 결과 화면 컴포넌트 (새 파일)
`pullim/src/components/discovery/PersonalityResult.tsx` 생성:

Props:
```ts
interface Props {
  type: PersonalityType;
  profile: ProbabilityProfile;
  theme: ThemeType;
  primaryColor: string;
  onContinue: () => void;  // 세션 시작 or 홈으로
}
```

레이아웃 (모바일 중심, 판타지 스타일):
- 유형 이모지 + 이름 (크게)
- description (설명)
- "풀림이라면..." 미리보기 (카드 형태, 대화 버블처럼)
- 강점 / 놓치기 쉬운 것 (아코디언 or 간단 리스트)
- 하단 버튼: "대화 시작하기" (onContinue)
- 스타일: Gowun Batang 폰트, primaryColor 활용, 다크 테마(bg-[#12101a])

### 3. page.tsx 수정
`handleDiscoveryComplete`에서:
- 바로 세션으로 이동하지 말고, 결과 화면(PersonalityResult) 표시하는 state 추가
- state: "home" → "discovery" → **"result"** → "session"
- result 단계에서 PersonalityResult 렌더링
