# 익명 피드백 폼 (Supabase 연동)

## 프로젝트
풀림 (~/study/main/pullim/pullim/) — Next.js 15 + React 19 + TypeScript + Tailwind CSS 4

## 선행 작업
- 36번 태스크에서 PersonalityResult.tsx가 생성되어 있어야 함
- Supabase 환경변수 설정 완료 (.env.local에 NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEY)
- Supabase에 feedback 테이블 생성 완료:
  ```sql
  id bigint (auto), created_at timestamptz, personality_type text,
  rating int (1-5), message text, user_agent text
  ```

## 작업

### 1. 피드백 폼 컴포넌트 (새 파일)
`pullim/src/components/discovery/FeedbackForm.tsx` 생성:

Props:
```ts
interface Props {
  personalityType: string;  // 유형 이름
}
```

UI:
- "맘에 드시나요? 솔직한 피드백 부탁드려요" 제목
- 별점 (1-5, 이모지 별 or 하트)
- 텍스트 입력 (placeholder: "UI, 결과, 경험 뭐든 자유롭게...")
- "익명으로 보내기" 버튼
- 전송 후 "감사합니다!" 메시지

### 2. Supabase 저장
```ts
import { getSupabase } from "@/lib/supabase/client";

const supabase = getSupabase();
if (supabase) {
  await supabase.from("feedback").insert({
    personality_type: personalityType,
    rating,
    message,
    user_agent: navigator.userAgent,
  });
}
```

Supabase가 없으면(환경변수 미설정) → 전송 버튼 숨기고 "피드백 준비 중" 표시

### 3. PersonalityResult.tsx에 피드백 폼 추가
- 결과 화면 하단 ("대화 시작하기" 버튼 위)에 FeedbackForm 배치
- PersonalityResult에 personalityType name을 FeedbackForm에 전달

## 스타일
- 판타지 세계관에 맞는 다크 테마
- 입력 필드: border-purple-500/30, bg-white/5
- 버튼: primaryColor 기반
- 모바일 중심

- `npm run build` 통과 확인
