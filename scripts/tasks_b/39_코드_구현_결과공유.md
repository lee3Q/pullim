# 유형 결과 공유 기능

## 프로젝트
풀림 (~/study/main/pullim/pullim/) — Next.js 15 + React 19 + TypeScript + Tailwind CSS 4

## 선행 작업
36번 태스크에서 PersonalityResult.tsx가 생성되어 있어야 함

## 목적
심리테스트 바이럴의 핵심 = 결과 공유. "나는 감각적 모험가래!" 하고 공유할 수 있어야.

## 작업

### PersonalityResult.tsx에 공유 버튼 추가

1. **링크 복사** 버튼:
   - 현재 URL을 클립보드에 복사
   - `navigator.clipboard.writeText(window.location.href)`
   - 복사 후 "복사됨!" 피드백 (2초간 표시)

2. **네이티브 공유** (Web Share API):
   - `navigator.share` 가능하면 네이티브 공유 버튼 표시 (모바일)
   - 공유 데이터:
     ```ts
     {
       title: `나는 "${typeName}" 유형이래!`,
       text: `풀림에서 3분만에 알아낸 나의 유형: ${typeName}. ${description}`,
       url: window.location.href,
     }
     ```
   - Web Share API 없으면 링크 복사만 표시

3. UI 위치:
   - 유형 이름 바로 아래, 설명 위
   - 작은 아이콘 버튼 (공유 + 복사)
   - 판타지 톤에 맞게

## 주의
