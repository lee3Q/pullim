# 스토리 장면 선택지 텍스트 퇴고

## 프로젝트
풀림 (~/study/main/pullim/pullim/)

## 작업
`pullim/src/lib/personalization/story-scenes.ts`의 장면 텍스트를 퇴고.

1. 모든 장면(30개)의 narrative, 선택지 텍스트를 읽기
2. 개선 방향:
   - 딱딱한 설명 → 몰입감 있는 서술 (소설 느낌)
   - 선택지가 너무 뻔하면 → 더 고민되는 선택지로
   - 각 테마(모험가/달빛정원/전략실) 톤 일관성
   - 한국어 어색한 표현 수정
3. signals 값은 변경하지 말 것 (프로필 산출에 영향)

## 주의
- signals, id, recommended 등 데이터 필드 절대 수정 금지
- narrative/description/choices의 text만 수정
- 테마별 세계관 톤 유지 (모험가=탐험, 정원=치유, 전략실=분석)
- `npm run build` 통과 확인
