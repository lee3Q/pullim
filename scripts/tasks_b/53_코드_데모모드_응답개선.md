# 데모모드 응답 더 자연스럽게 개선

## 프로젝트
풀림 (~/study/main/pullim/pullim/)

## 현재 상태
사다리 세션에 데모 모드 존재 — API 키 없이 미리 정의된 응답으로 UX 흐름 테스트 가능.

## 작업
1. 데모 모드 관련 코드 찾기:
   - LadderSession.tsx 또는 ladder-store.ts에서 "demo" 검색
   - listen route에서 demo 분기 확인
2. 데모 응답 텍스트를 읽고:
   - 기계적인 응답 → 실제 상담사처럼 자연스러운 톤으로 퇴고
   - 각 레벨(1~5)에 맞는 응답 톤 차별화:
     - Level 1 (감각): 짧고 따뜻한 반응
     - Level 2 (감각변형): 비유적 질문
     - Level 3 (분석제안): 통찰 있는 관찰
     - Level 4 (선택지+추천): 구조적 제안
     - Level 5 (직접말하기): 깊은 공감 + 명확화 질문
3. 데모 응답 수 늘리기 (각 레벨 최소 3개 이상 랜덤 선택)

## 주의
- 데모 모드 로직은 유지, 텍스트만 개선
- `npm run build` 통과 확인
