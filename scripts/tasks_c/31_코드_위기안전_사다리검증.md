# 위기 안전 시스템 사다리 경로 검증

## 프로젝트
풀림 (~/study/main/pullim/pullim/) — Next.js 15 + React 19 + TypeScript

## 확인 대상
사다리 세션(mode=ladder)에서 RED 위기 감지가 정상 작동하는지 코드 레벨 검증.

## 관련 파일
- `pullim/src/lib/safety/crisis-detector.ts` — 위기 감지 로직
- `pullim/src/app/api/ultimate/listen/route.ts` — 메인 API 라우트
- `pullim/src/components/session/LadderSession.tsx` — 사다리 세션 컴포넌트
- `pullim/src/lib/session/ladder-store.ts` — 사다리 상태 관리

## 검증 항목
1. listen route에서 mode=ladder일 때 crisis-detector가 호출되는지 확인
2. SSE 응답에서 crisis 플래그가 클라이언트까지 전달되는지 확인
3. LadderSession 컴포넌트에서 CrisisAlert 모달이 연결되어 있는지 확인
4. 누락이 있으면 수정

## 수정 원칙
- 문제 없으면 수정하지 말 것
- 문제가 있으면 최소한의 수정으로 해결
- `npm run build` 통과 확인
