## 작업
다크 배경(#12101a)에서 텍스트가 충분히 읽히는지 확인.

1. globals.css, page.tsx, StoryDiscovery.tsx, LadderSession.tsx에서 텍스트 색상 확인
2. WCAG AA 기준 (4.5:1 대비비) 미달 항목 수정:
   - text-white/50 → text-white/70 이상
   - text-gray-500 → text-gray-400 이상
   - text-purple-300 on #12101a → OK (확인만)
3. 버튼 텍스트가 배경 대비 읽히는지 확인
