## 3자 일치 사항

1. **`claude -p` + cron = 밤샘 배치의 표준 패턴** — 3소스 모두 확인. 이미 검증된 방법론
2. **OpenClaw = 자율 에이전트 오케스트레이션 de facto 표준** — GitHub 145K+ stars, Telegram 기반 커맨드, 5단계 워크플로우
3. **Git branch 격리 필수** — overnight 작업은 절대 main 직접 수정 X. 별도 브랜치 → 아침 리뷰 → 머지
4. **Human-in-the-loop 승인 게이트** — 완전 자율이 아니라 "AI 실행 → 사람 승인 → 반영" 루프가 핵심
5. **1인 SaaS 실제 작동** — Base44 $80M 인수, PhotoAI $132K MRR(87% 마진), 36.3% 신규 기업이 1인 창업

## 합성 결론: 풀림에 적용할 것

### 즉시 적용 (지금 가능)

| 항목 | 방법 | 비용 |
|------|------|------|
| **아침 리포트 cron** | `crontab`에 `claude -p` 추가. queue.md+projects 읽고 daily 리포트 생성 | $0 (기존 API) |
| **overnight 안전성 강화** | 기존 `start-batch.sh`에 Git branch 격리 추가 (main 직접 수정 금지) | $0 |
| **배치 결과 알림** | `terminal-notifier` 또는 Telegram Bot으로 완료 시 푸시 | $0 |
| **세션 자동 종료** | 30-40턴 이후 /compact 또는 세션 재시작 강제 (context rot 방지) | $0 |

### 단기 (1-2주, OpenClaw 도입)

| 항목 | 방법 | 비용 |
|------|------|------|
| **OpenClaw 설치** | Mac Mini 또는 현재 MacBook에 셀프호스트 | $0 (하드웨어 기존) |
| **Telegram 브리핑** | OpenClaw → 아침 7시 Telegram으로 리포트 푸시 | $0 |
| **승인 루프** | Telegram에서 "승인"/"거부" 메시지 → OpenClaw가 실행 | $0 |
| **overnight npm 패키지** | `npm install -g @yail259/overnight` — 기존 배치 보완 | $0.18/run |

| 항목 | 방법 | 비용 |

## 핵심 인사이트

> **"AI가 실행하고, 사람은 승인한다"가 2026년 1인 창업자의 기본 패턴.**
> 완전 자율이 아니라, 잘 설계된 승인 게이트가 핵심.
> 풀림은 이미 `claude -p` 배치 + `.state/` 상태 관리를 갖추고 있어서,
> OpenClaw 도입 + Telegram 연동만 하면 "폰에서 승인만" 수준에 도달 가능.
