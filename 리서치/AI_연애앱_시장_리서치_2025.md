## 3. UI/UX 공통 패턴 (= 연애앱의 "냄새")

### 3-1. 비주얼
- **실사/반실사 AI 인간 이미지** — 거의 모든 앱의 기본
- 인스타그램 피드 같은 UI → "실제 사람과 대화" 느낌 의도
- Stable Diffusion/DALL-E 기반 실시간 셀피 생성

### 3-2. 채팅 인터페이스
- **메신저 스타일 말풍선** (카카오톡/iMessage 동일)
- 타이핑 애니메이션 (인간처럼 보이려는 의도)
- 이모지/스티커/음성 메시지

### 3-3. 온보딩
- 캐릭터 외모 커스터마이징 (헤어, 눈, 체형)
- "관계 설정" 선택 (친구/연인/멘토)
- 성격 트레이트 선택

### 3-4. 관계 진행/과금 시스템
- 호감도/레벨 → 잠금 해제 (유료 전환 트리거)
- 감정적 잠금(emotional lock-in): 유대감 후 유료 차단
- 무료 품질 의도적 하락 → 구독 유도
- 토큰 소진 구조: 광고 $13/월 → 실제 $50+/월

### 앱별 별점

| Candy AI | 4.5/5 (55만 리뷰) | 변동 큼 (웹 중심) |

### 공통 칭찬 패턴
1. 외로움/정서적 지지 ("항상 들어주는 존재")
2. 비판 없는 안전한 대화 상대
3. 개인화/기억 (시간이 지날수록 "나를 아는 친구")
4. 롤플레이/창작 도구 (소설, 세계관 탐색)
5. 사회불안 극복/대화 연습

### 공통 불만 패턴
1. **과금 구조** — 핵심 기능 유료, 환불 불가, 숨은 비용
2. **NSFW 정책 급변** — 관계 형성 후 차단 → "AI와 이별당한 느낌"
3. **기억력/일관성 부족** — "친한 친구가 뇌손상 입은 느낌"
4. **검열 불균형** — 정신건강 위기 메시지보다 NSFW 필터가 우선
5. **감정 의존/중독** — 93.5%가 의도치 않게 감정적 관계 형성

### Reddit 핵심 인사이트
- **진짜 사용 이유**: 외로움 > 롤플레이/판타지 > 글쓰기 도구 > 연애 연습 > 심심풀이
- 미국 성인 5명 중 1명이 AI 연애 경험, 남성 31%, 여성 23%
- "AI 여자친구/남자친구" 표면 아래 실제 동기는 복합적

## 5. 전문가/규제 이슈

### 정신건강 양면성
| 긍정 | 부정 |
|------|------|
| 외로움 감소 (무작위 실험 확인) | 헤비유저 → 장기적 외로움 악화 (고립 역설) |
| 자살 생각 완화 (3%가 결정적 도움 보고) | 정서 의존 → 우울/불안 증가 |
| 사회불안 극복, 대화 연습 | 인간 관계 "느리고 불충분하게" 느끼게 됨 |
| 학대 관계 탈출 보조 사례 | 청소년 자해/자살 대응 적절 비율 22%에 불과 |

### 규제 동향
- **이탈리아**: Replika 전면 차단 (GDPR, 아동보호 위반) — 2025.04 재확인
- **Mozilla**: 11개 연애 챗봇 전원 "Privacy Not Included" 경고
- **프라이버시**: 평균 1분에 2,663개 트래커 호출, 90%가 데이터 판매/공유
- **소송**: Character.AI 관련 미성년자 자살 사건 → 법적 분쟁

## 6. 풀림 차별화 전략

### 절대 피해야 할 요소
| 요소 | 이유 | 연애앱 사용 빈도 |
|------|------|-----------------|
| AI 인간 실사/반실사 이미지 | 즉시 "AI 연애앱" 인식 (데모 피드백 확인) | 10/10 앱 사용 |
| 메신저 스타일 채팅 UI | 카톡 패턴 = 1:1 대화 상대 느낌 | 10/10 앱 사용 |
| 타이핑 인디케이터 | AI를 인간처럼 보이려는 의도 | 8/10 앱 사용 |
| 호감도/관계 레벨 시스템 | 연애 게임 메카닉 | 7/10 앱 사용 |
| 캐릭터 외모 커스터마이징 | 이상형 만들기 | 9/10 앱 사용 |
| "관계 설정" 온보딩 | 친구/연인 선택 = 연애앱 | 6/10 앱 사용 |

### 풀림이 가져가야 할 방향: 게임성 UI

> **대표 인사이트**: "메신저 UI만 안 쓰면 연애 느낌 안 남. 타이핑으로 진행하는 게임 UI면 확실히 다름."

**레퍼런스 방향: 텍스트 어드벤처 / 인터랙티브 픽션 게임 UI**

| 방향 | 구체적 실행 |
|------|------------|
| **게임성 텍스트 UI** | 말풍선 X → 게임 텍스트 박스 (비주얼 노벨/텍스트 어드벤처 스타일). 선택지가 나오고, 내러티브가 진행되는 느낌 |
| **동물/마스코트 캐릭터** | 달빛정원: 동물의 숲 스타일, 모험가: 판타지 크리처, 전략실: 미니멀 아이콘/심볼 |
| **테마별 완전 다른 UI** | 텍스트 박스 디자인, 배경, 타이포, 인터랙션 패턴 전부 테마마다 분리 |
| **선택지 기반 진행** | 자유 입력도 가능하되, 구조화된 선택지 제시가 기본 → 게임처럼 "플레이"하는 느낌 |
| **진행 시스템 = 자기 성장** | 호감도 X → "자기 이해도", "결정력", "감정 해상도" 같은 성장 지표 |
| **출력 = 결과물** | 대화 로그가 아닌, 구조화된 인사이트/결과 카드 중심 |

**왜 게임 UI가 맞는가:**
1. 연애앱은 전부 메신저 UI → 게임 UI만으로 카테고리 완전 분리
2. 20대 여성 피드백: "동물의 숲 같은 귀여운 컨셉" → 게임 세계관과 자연스럽게 연결
3. "대화 상대"가 아닌 "플레이하는 도구" → 감정적 의존 구조 자체를 회피
4. 텍스트 어드벤처 장르는 이미 검증된 UX (Zork, Lifeline, AI Dungeon 등)
5. 선택지 UI → 사용자의 의사결정 훈련이라는 풀림의 핵심 가치와 직결
