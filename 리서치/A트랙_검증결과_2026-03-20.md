## 🔴 높음 — 사업계획서 전 필수 해결

### 1. 세션 비용 불일치: A1(170원) vs B2(300원)

| 산출물 | 세션당 비용 |
|--------|-----------|
| A1 이종모델 오케스트레이션 설계 | **~170원** (Claude+GPT mini+Gemini Flash) |
| B2 수익모델 심화설계 | **~300원** (Sonnet 기준) |
| 검증 해결사 종합 (2026-03-19) | **~300원** (Sonnet 기준) |

**원인**: A1이 이종모델 비용 최적화를 반영했으나, B2는 이전 세션의 "검증 해결사" 수치(~300원)를 그대로 사용. B2가 A1을 읽지 않은 상태에서 작성됨.

**영향**: 사업계획서에 170원을 쓰면 BEP/마진이 달라짐. 300원을 쓰면 A1의 비용 최적화가 반영 안됨.

**권장**:
- 이종모델 **풀 파이프라인 = ~170원** (A1 기준 — GPT mini + Gemini 무료 덕분)
- 무료 사용자 **라이트 모드 = ~300원** (Sonnet 단독 — B2 기준)
- 사업계획서에는 **양쪽 다 표기** — "풀: 170원, 라이트: 300원" → BEP 재계산 필요

### 2. ICC 데모 가능 여부 불확실

코드가 현재 **시뮬레이션 모드** — 모든 API 호출이 `setTimeout`으로 목 데이터 반환.

- 실제 API 키 미발급 (Anthropic, OpenAI, Tavily)
- API 라우트 (`/api/ultimate/*`) 미구현
- Zustand 스토어 (`ultimate-session-store.ts`) 미구현

**영향**: ICC 발표에서 데모 시연 시 "이건 목업입니다"라고 밝혀야 함. 또는 발표 전까지 최소 1개 API 연결 필요.

**권장**:
- 사업계획서에 "개발 중"으로 정직하게 기재 (검증 해결사 원칙)
- 발표 데모용으로 최소 듣기(Listen) 단계만이라도 Claude API 연결
- Vercel 환경변수에 API 키 설정하면 기존 V2는 동작함 → V2 데모도 가능

## 🟡 중간 — 작성 시 주의

### 3. 달빛정원/전략실 캐릭터 시스템의 에지 케이스 커버리지

현자 대사 시스템(v6)은 다음을 상세히 다룸:
- 입력 예외 15가지 (빈 입력, 테스트, 비한국어, 500자 초과, 다중 고민 등)
- 세션 중간 고민 전환, 자발적 종료
- 재방문 4유형 (일반, 미완료, 약속 이행, 약속 불이행)
- 듣기 단계 (침묵 적응, 빨리 넘기기, 최대 턴 초과)
- 리서치 실패, 부분 실패, 대기 대사

달빛정원과 전략실은 주요 흐름만 다루고 **에지 케이스 절반 이상 생략**.
예: 비한국어 입력, 세션 중간 메타 질문, 기능 요청, 세션 중간 고민 전환, 침묵 적응 등.

**영향**: 구현 시 달빛정원/전략실에서 에지 케이스 대응 누락 가능
**권장**: "현자와 동일" 명시로 충분. 코드에서 캐릭터 공통 에지 케이스 핸들러를 만들고 톤만 분기.
