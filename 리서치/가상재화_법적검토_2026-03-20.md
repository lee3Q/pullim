## 결론 요약

**풀림의 현재 구슬 설계는 법적으로 안전한 구간에 있다.**

| 규제 | 위험도 | 이유 |
|------|--------|------|
| 게임산업진흥법 | **낮음** | 주목적이 "상담/의사결정 보조"이고, 승부·점수·랭킹·확률형 아이템 없음 |
| 전자금융거래법 (선불전자지급수단) | **낮음** | 구슬은 자사 서비스 전용 단일 가맹점 → 등록 면제. 단, 2024 개정법 주의 |
| 전자상거래법 (환불) | **적용됨** | 유료 서비스인 이상 반드시 준수. 7일 청약철회, 미사용분 환불 의무 |
| 콘텐츠이용자보호지침 | **적용됨** | 3영업일 내 환불, 소멸 정책 고지 필요 |
| 전기통신사업법 (부가통신) | **확인 필요** | AI 서비스 = 부가통신역무. 자본금 1억 이하면 신고 면제 |
| 미성년자 보호 | **적용됨** | 결제 시 법정대리인 동의 고지 필수. 단순 체크박스로 방어 불가 |

**한줄**: 게임법의 강한 규제는 피해가지만, 전자상거래법·콘텐츠보호법·전기통신사업법은 반드시 준수해야 한다.

## 1. 게임산업진흥법 — 적용 가능성 낮음

### 법 조문

게임산업진흥법 제2조 제1호: "게임물" = 정보처리기술을 이용해 **오락**을 하거나, 부수적으로 여가·학습·운동효과를 높이도록 제작된 영상물 또는 기기.

### 풀림이 게임물이 아닌 이유

| 게임물 요건 | 풀림 설계 | 판정 |
|------------|----------|------|
| 주된 목적이 "오락" | 주된 목적이 "AI 상담/의사결정 보조" | ✅ 비해당 |
| 승부·성공/실패 구조 | 없음. 결과는 분석 리포트 | ✅ 비해당 |
| 레벨업·랭킹·점수 | 없음 | ✅ 비해당 |
| 확률형 아이템 (뽑기) | 없음 | ✅ 비해당 |
| 재산상 이익·손실 | 없음. 구슬은 서비스 이용 후 소멸 | ✅ 비해당 |

### 주의 사항

- "모험가", "현자", "달빛정원" 등 세계관 네이밍은 **게임적 인상을 줄 수 있으나**, 핵심 기능이 상담이고 승부/보상 구조가 없으므로 게임물 분류 위험은 낮음
- **절대 도입하면 안 되는 것**: 구슬을 걸고 결과에 따라 더 얻거나 잃는 구조, 구슬 간 거래/양도, 현금 전환

### 유사 사례 (타로/운세 앱)

포스텔러·점신 등 타로 앱은 코인/포인트 구매 → 운세 해석 이용 구조이나, 게임산업법 위반 제재 사례는 **공개 자료에서 확인 불가**. 실무상 전자상거래법·콘텐츠 보호법으로 관리됨.

## 2. 전자금융거래법 — 선불전자지급수단 해당 여부

### 법 조문

전자금융거래법 제2조 제14호: "선불전자지급수단" = ① 전자적으로 저장된 **금전적 가치** + ② **제3자**로부터 재화·용역 구입에 사용 + ③ 2개 업종 이상에서 사용 가능.

### 풀림 구슬이 해당하지 않는 이유

| 요건 | 풀림 구슬 | 판정 |
|------|----------|------|
| 금전적 가치 저장 (원 단위) | **아니오**. "구슬 7개"로 표시, 원(₩) 금액 미표시 | ✅ 비해당 |
| 제3자 결제에 사용 | **아니오**. 풀림 자사 서비스에서만 사용 | ✅ 비해당 |
| 2개 업종 이상 사용 | **아니오**. 풀림 서비스 단일 | ✅ 비해당 |

**근거**: 금융위원회 법령해석 — 구독 이용권이 선불전자지급수단인지 여부:
> "금액 표시 없고, 금액 차감 없고, 발행인 서비스만 이용 가능하면 선불전자지급수단 아님"

### 설계 시 지켜야 할 것

- 구슬 ↔ 원화 환산을 **사용자에게 노출하지 않을 것** (내부 원가 계산은 OK)
- "구슬 1개 = 50원" 같은 명시적 금액 매핑 UI **금지**
- 구슬의 제3자 양도·이전·현금 환전 기능 **금지**

## 3. 전자상거래법 — 반드시 준수

### 적용되는 이유

전자상거래법상 "재화 등" = 물건·용역·이용권 등 권리 **전부** 포함. 명칭 무관. "구슬"이든 "이용권"이든 유료 서비스인 이상 적용.

### 핵심 의무

#### 3-1. 청약철회 (제17조)

| 상황 | 의무 |
|------|------|
| 구매 후 7일 내, 미사용 | **전액 환불** |
| 구매 후 이용 개시 | 청약철회 제한 가능 (단, 사전 고지 필수) |
| 가분적 서비스 (구슬 단위) | 사용 구슬 제외, **미사용 구슬 환불** |

풀림의 구슬은 **가분적 서비스**에 해당 (세션별 소모). 따라서:
- 60구슬 중 20구슬 사용 후 해지 → 40구슬분 환불 의무
- "구슬 이월 불가(월초 리셋)" 정책은 약관에 명확히 고지해야 함

#### 3-2. 환불 처리 (제18조)

- 청약철회 시 **3영업일 이내** 환불
- 지연 시 지연배상금(연체이자) 부과

#### 3-3. 미성년자 고지 (제13조 제3항)

- 결제 페이지에 반드시 명시: **"법정대리인이 동의하지 않으면 미성년자 또는 법정대리인이 계약을 취소할 수 있습니다"**

### 풀림 구슬 설계 vs 전자상거래법

| 현재 설계 | 법적 이슈 | 조치 필요 |
|----------|----------|----------|
| 구슬 이월 불가 (월초 리셋) | 소멸 정책 → **약관·UI 명확 고지 필요** | ⚠️ 약관 작성 시 반영 |
| 중간 이탈 시 미소모 구슬 보존 | ✅ 가분적 서비스 요건 충족 | 좋은 설계 |
| 세션 시작 전 예상 비용 안내 | ✅ 투명성 확보 | 좋은 설계 |
| 무료 티어 광고 시청 시 충전 | 환불 대상 아님 (무료 제공) | ✅ 이슈 없음 |

## 4. 콘텐츠이용자보호지침 — 소멸·환불 기준

콘텐츠산업진흥법 제28조 근거. 문체부 고시.

### 핵심 규정

| 항목 | 규정 |
|------|------|
| 환불 기한 | 해지 통보 후 **3영업일 이내** |
| 서비스 중단 시 | 미사용분 비례 환불. 이용기간 미명시 시 **1년 기준** 환급액 산정 |
| 소멸 정책 | **사전 고지** 필수. 소멸 전 알림 권장 |

### 풀림 적용

- "무제한/평생 이용" 문구 사용 **금지** → 현재 설계에는 없으므로 OK
- 구슬 소멸(월초 리셋) 전 알림 필요: "남은 구슬 N개가 [날짜]에 소멸됩니다"
- 서비스 종료 시: 남은 구슬 비례 환불 기준을 약관에 명시

## 5. 미성년자 보호

### 적용 법률

| 법률 | 핵심 내용 |
|------|----------|
| 민법 제5조 | 미성년자 계약은 법정대리인 동의 필요. 무동의 → **취소 가능** |
| 전자상거래법 제13조 제3항 | 미성년자 결제 시 취소 가능 사실 **사전 고지 의무** |
| 청소년보호법 | 유해매체물 지정 시 성인인증 필수 |

### 풀림 특수 상황

- **멘탈케어 서비스**이므로 미성년자 이용자가 많을 수 있음
- 콘텐츠에 자해·극단적 선택 조장 요소가 없으므로 청소년유해매체물 해당 가능성 낮음
- 단, **위기 안전 RED** 프로토콜(LLM 즉시 중단 → 전문기관 안내)이 잘 작동해야 함

### 필수 조치

1. 결제 페이지에 법정대리인 동의 고지 문구 삽입
2. 고액 결제(현자 티어 19,900원/월) 시 본인인증 또는 추가 확인
3. 청소년 계정 일/월 결제한도 설정 검토

## 6. "이용권" 프레이밍으로 규제 회피 가능한가?

### 결론: 명칭으로는 회피 불가. 구조로 달라진다.

> "계약의 이름이 아니라 경제적 실질" — 전자상거래법, 금융위 해석, 대법원 판례 공통

| 명칭 변경 | 효과 |
|----------|------|
| "구슬"을 "이용권"으로 부르기 | 전자상거래법은 **동일하게 적용**. 환불·소멸 의무 변화 없음 |
| "구슬"을 "회차권"으로 부르기 | 선불전자지급수단 위험은 이미 낮음. 추가 효과 미미 |

### 구조 변경으로 가능한 것

| 규제 | 회피/완화 조건 | 풀림 현황 |
|------|-------------|----------|
| 선불전자지급수단 | 금액 미표시 + 자사 서비스 전용 + 제3자 결제 없음 | ✅ 이미 충족 |
| 게임산업법 | 승부·경쟁·확률형 요소 없음 | ✅ 이미 충족 |
| 전자상거래법 | **회피 불가** — 유료 서비스인 이상 적용 | 약관·환불 정책 정비 필요 |

## 7. 풀림 구슬 설계 — 법적 체크리스트

### ✅ 이미 안전한 부분

- [x] 주목적이 AI 상담/의사결정 (게임 아님)
- [x] 승부·점수·랭킹·확률형 아이템 없음
- [x] 구슬은 횟수형 (원 단위 금액 미표시)
- [x] 자사 서비스 전용 (제3자 결제·양도·현금 전환 없음)
- [x] 중간 이탈 시 미소모 구슬 보존 (가분적 서비스)
- [x] 세션 시작 전 예상 비용(구슬) 사전 안내 (투명성)

### ⚠️ 서비스 출시 전 정비 필요

- [ ] **약관**: 구슬 소멸 정책(월초 리셋) 명확 고지
- [ ] **약관**: 구슬 미사용분 환불 기준 (가분적 서비스 기준 비례 환불)
- [ ] **약관**: 서비스 종료 시 환불 산정 기준
- [ ] **약관**: "본 서비스는 의료행위·치료를 대체하지 않습니다"
- [ ] **약관**: "이용권은 자사 서비스 이용 목적이며, 선불전자지급수단·전자화폐가 아닙니다"
- [ ] **결제 UI**: "법정대리인 동의 없이 미성년자가 결제한 경우 취소할 수 있습니다" 고지
- [ ] **결제 UI**: 7일 내 미사용 시 전액 환불 가능 안내
- [ ] **알림**: 구슬 소멸 전 알림 ("남은 구슬 N개가 [날짜]에 소멸됩니다")
- [ ] **결제 UI**: 고액 결제(현자 티어) 시 본인인증 검토

### 🚫 절대 하면 안 되는 것

- 구슬 ↔ 원화 환산을 사용자 UI에 노출 ("1구슬 = 50원")
- 구슬 간 거래·양도·선물 기능
- 구슬을 현금·상품권·포인트로 환전
- 확률형 구슬 획득 (뽑기, 룰렛 등)
- 구슬을 걸고 결과에 따라 더 얻거나 잃는 구조
- "무제한/평생 이용" 표현

## 교차검증: Gemini 추가 발견 (Perplexity 미포함)

### 추가 쟁점 A. 전기통신사업법 — 부가통신사업자 신고

**Perplexity**: 언급 없음
**Gemini**: 상세 분석

인터넷을 통해 AI 서비스를 제공하면 **부가통신역무**에 해당. 전기통신사업법 제22조에 따라 신고 의무 발생.

- **면제 조건**: 자본금 1억 원 이하 (시행령 제30조 제1항)
- **풀림 현황**: 1인 창업, 자본금 1억 이하 → 현재는 면제
- **주의**: 투자 유치로 자본금 1억 초과 시 즉시 신고 의무 발생

**2026.1.20 방미통위 안내서** ("AI 서비스 사업자를 위한 이용자보호 관련 통신관계 법령안내서"):
- AI 서비스 = 부가통신사업자 지위 명확화
- 전기통신사업법 제50조 적용: 이용자 이익 저해 행위 금지
- 서비스 품질 저하 시에도 동일 토큰 차감 → 위반 가능

**풀림 액션**:
- 현재는 면제이지만, 투자 유치 시 신고 일정 사전 계획
- 서버 장애로 세션 실패 시 구슬 반환 로직 필수 (이미 "초과 비용은 우리가 흡수" 원칙 있으므로 확장)

### 추가 쟁점 B. 전자금융거래법 2024 개정 — 업종 요건 삭제

**Perplexity**: 구법 기준 분석 ("2개 업종 이상"이어야 선불전자지급수단)
**Gemini**: **2024.9.15 개정법 반영** — 업종 기준 완전 삭제

| 항목 | 구법 | 개정법 (2024.9.15~) |
|------|------|-------------------|
| 업종 요건 | 2개 업종 이상만 적용 | **삭제** — 단일 업종도 포함 |
| 등록 면제 (가맹점) | 10개 이하 가맹점 | **1개 가맹점**(사업주 동일) |
| 등록 면제 (규모) | 분기말 잔액 30억 이하 | 분기말 잔액 30억 미만 **AND** 연간 총발행액 500억 미만 |

**풀림 적용**:
- 풀림 = 자사 서비스 단독 = **1개 가맹점 → 등록 면제 유지**
- 발행 잔액 30억 미만 (초기 스타트업이므로 당분간 해당 없음)
- **BUT**: 향후 제휴/파트너 서비스에서 구슬 사용 허용하면 즉시 등록 의무 발생

**핵심 변경**: Perplexity 분석보다 규제가 **더 강화**된 상태. "단일 업종이니 괜찮다"는 구법 논리는 더 이상 유효하지 않음. 풀림이 안전한 이유는 "단일 가맹점(사업주 동일)"이기 때문.

### 추가 쟁점 C. 유상/무상 구슬 DB 분리 + 결제 동의 로그

**Perplexity**: 언급 없음
**Gemini**: 실무 설계 수준으로 상세

#### C-1. 유상/무상 구슬 분리 관리

유상 구매 구슬 = 상사채권 (상법 제64조, 소멸시효 5년)
무상 지급 구슬 (프로모션, 출석 보상 등) = 소멸시효 보호 대상 아님

- DB에서 유상/무상 구슬의 식별자(ID)와 메타데이터를 분리
- 사용 시 **무상 구슬을 먼저 차감** (FIFO)
- 무상 구슬은 짧은 유효기간(7일 등) 설정 가능

**풀림 액션**: 현재 설계에 유상/무상 구분이 없음. 프로모션 구슬 도입 시 반드시 분리 설계.

#### C-2. 결제 동의 로그 보관 (대법원 판례 기반)

대법원 2023.6.15. 선고 2018다214746:
> 청약철회 제한 사유의 존재 및 표시 의무 이행 사실을 **사업자가 입증**해야 한다

- 결제 직전 체크박스: "결제 즉시 서비스 이용이 개시되므로, 전자상거래법에 따른 청약철회가 제한됨에 동의합니다"
- 동의 타임스탬프 + IP + 디바이스 정보를 **불변 로그로 저장**
- 약관 한 곳에 "환불 불가"만 적는 것으로는 법적 면책 **불가**

**풀림 액션**: 결제 플로우에 명시적 동의 체크박스 + 로그 저장 시스템 설계.

### 추가 쟁점 D. 미성년자 '속임수' 방어의 한계 (민법 제17조)

**Perplexity**: 취소 가능 원칙만 언급
**Gemini**: 판례 기반 상세 분석

미성년자가 부모 카드로 무단 결제 시, 사업자가 "나이 확인란에 클릭했으니 속임수"라고 항변해도 **법원은 거의 인정하지 않음**.

- 민법 제17조의 '속임수' = **적극적 기망행위** (신분증 위조 수준)
- 단순 나이 확인 체크박스 클릭, 간편결제 비밀번호 도용 = 속임수 **아님**
- 판례: 미성년자가 부모 카드로 25회 약 180만원 결제 → 사업자 방어 실패

**풀림 액션**: 단순 체크박스로는 미성년자 결제 취소 방어 불가. **통신사 본인인증** 도입이 유일한 방어책.
