## 유닛이코노믹스 재계산 (코드 기반)

VC가 직접 코드를 읽고 토큰 비용을 계산한 결과:

| 단계 | API 호출 | 모델 | 추정 비용 |
|------|---------|------|----------|
| 라우팅 | 1회 | Haiku | ~무시 가능 |
| Listen (소크라테스 7턴) | ~7회 | Sonnet | ~$0.111 |
| 전문가 분석 (3 병렬) | 3회 | Sonnet | ~$0.032 |
| 토론 R1 (2 병렬) | 2회 | Sonnet | ~$0.017 |
| 토론 R2 | 1회 | Sonnet | ~$0.009 |
| 종합 | 1회 | Sonnet | ~$0.008 |
| Landing (2턴) | 2회 | Sonnet | ~$0.035 |
| **합계** | **~17회** | | **~$0.21 = ~290원** |

→ 분석+토론 부분만이면 543원 주장은 과장. 풀 세션은 **400~800원** (대화 길이에 따라)
→ 4세션/월 기준 마진 68% (71% 주장과 근접하나 정확하진 않음)

### 🔴 "무제한" 요금제가 시한폭탄
- 10세션/월 파워유저: 마진 20%로 추락
- 15세션/월: **적자**
- **해결**: 세션 수 상한 또는 티어 분리 필요

### BEP 재계산 (고정비 포함)
- Vercel Pro ~27,600원 + Supabase Pro ~34,500원 + 도메인 + 기타 = **~75,000원/월**
- 실제 BEP = **~55명** (40명 아님)
- "창업자가 먹고 살 수 있는" BEP = 200~300명

## TAM 현실 점검

- 글로벌 DSS $16.6B = Oracle/SAP/IBM 엔터프라이즈. **한국 B2C 앱과 카테고리 다름**
- 현실적 TAM: 한국 20~30대 AI 자기계발 유료 결제 의향자 ~50만 명
- 50만 × 9만원/년 = **450억 원** — 벤처 스케일이 아님
- **$10M ARR(153K 유료 구독자) 도달 불가능** — B2B 없이는
