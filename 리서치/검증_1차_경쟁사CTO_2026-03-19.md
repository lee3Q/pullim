## 위협도: 4/10

풀림 자체보다 **"구조화된 의사결정 코칭 > 공감적 경청" 패턴이 검증되는 것**이 위협. 검증되면 3~4주, 5천만 원 이내에 복제 가능.

## 풀림이 맞춘 것 (98명 팀이 놓친 것)

1. **"공감의 함정" 진단이 정확** — 우리 AI 챗봇 NPS 낮은 이유를 정확히 짚음
2. **"합리적 타로" 프레이밍이 탁월** — 경쟁 시장을 93억 상담 → 4.6조 점술로 확장. 우리 BD팀은 이렇게 생각해본 적 없음
3. **"답을 주지 않는 AI"가 반직관적이지만 맞음** — MentalAgora, Khanmigo 선례 지지
4. **위기 감지 시스템이 잘 만들어짐** — Tier A/B 분리, 한국 인터넷 슬랭 변형 포함
5. **전문가 페르소나의 안전 가드레일이 세련됨** — "자기 가치감 의심 방향 금지" 등

## 풀림이 틀린 것 (순진하거나 망상인 부분)

1. **🔴 사업계획서가 미구현 기술을 구현된 것처럼 서술**
   - Supabase: package.json에만 있고 src에서 import 0건. "RLS 데이터 격리" 주장은 허위
   - Gemini: 클라이언트 코드만 있고 어떤 API 라우트에서도 사용 안 함. dead code
   - 비동기 처리: 전부 동기 요청-응답. 큐/백그라운드 잡 없음
   - **"기술 실사(due diligence) 하면 신뢰 즉시 붕괴"**

2. **"LLM은 교체 가능한 인프라"는 순진함** — 프롬프트 엔지니어링은 모델 종속. Claude Sonnet 프롬프트를 GPT-4o로 돌리면 품질 저하 뚜렷.

3. **세션당 비용 재계산**: V2 풀 파이프라인 = 7+ LLM 호출 → 실제 800~1,200원. 월 6세션이면 마진 50% 이하로 추락.

4. **1,000명 유료 = 기도, 전략 아님**. 커뮤니티 포스팅으로 50명은 되나 1,000명은 불가. SEO는 6~12개월 걸림. 유료 마케팅 예산 0원.

5. **타겟 유저 역설**: AI 파워유저(풀림 발견 확률 높음) → "이미 분석 많아서 풀림 불필요". AI 비사용자(풀림 필요) → 발견 확률 낮음.

## 진짜 해자는 파이프라인이 아니라 프롬프트 라이브러리

expert-focus.ts + agent-prompts.ts에 담긴 "어떤 질문이 인지적 교착을 깨는지"에 대한 1년간의 노하우. 아키텍처는 복제 가능하나 프롬프트 품질은 쉽게 복제 불가.

## 조언 7가지

1. 사업계획서에서 미구현 기술 주장 제거
2. V2 파이프라인을 실제 제품에 연결 (백엔드 80% 완성, UI만 연결하면 됨)
3. 낯선 사람 10명 이상 유저 테스트 (현재 N=2는 노이즈)
4. Gemini 피치에서 빼기 (실제 사용 안 하면서 나열하지 말 것)
5. Supabase 연동 구현 (주말이면 가능)
6. B2B를 더 빨리 (한성대 진로상담센터 PoC = 2개월 차, 12개월 차 아님)
7. **우리(마인드카페)와 대화해라.** B2C 멘탈웰니스에서 1인 창업자 3년 생존율 2~3%. 컨셉 검증 후 플랫폼 흡수가 더 현실적 엑시트.
