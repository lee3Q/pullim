# 사업 방향성 1차 검증 — 전략 비평 (Opus)

> 날짜: 2026-03-19
> 에이전트: harsh-critic (Opus)
> 판정: **REVISE** (수정 필요, 기각은 아님)

## 🔴 치명적 발견 (즉시 수정)

### 1. 세션당 543원은 틀렸다
- 사업계획서: "Opus x3 = 391원 → 총 543원"
- **실제 코드**: claude.ts에서 ANALYSIS_MODEL = "claude-sonnet-4-6" (Opus 아님)
- archive 회의록에도 "Opus→Sonnet 다운그레이드: 543원→80~120원" 기록 있음
- **실제 비용**: Haiku 라우팅(~2원) + Sonnet 리슨(~100원) + Sonnet x3 분석(~150원) + Sonnet x4 토론(~200원) = 약 **362~452원**
- 마진이 71%가 아니라 **93~96%**. BEP도 40명이 아니라 10명 이하.
- **문제**: 심사위원이 물으면 "자기 제품 비용도 모른다" or "숫자를 부풀렸다"로 보임
- **해결**: 실제 Sonnet 기준으로 재계산. "현재 ~300원, Opus 업그레이드 시 ~543원" 범위 제시

### 2. "리서치 에이전트"와 "검증 에이전트"는 코드에 없다
- 사업계획서에 파이프라인 3번(리서치), 5번(검증)으로 명시
- **실제 코드**: Listen → Expert Select → Analyze(3 parallel) → Debate → Land. 웹검색/데이터수집 단계 없음
- **해결**: (A) 구현하거나, (B) "v3 로드맵"으로 명시하고 현재 파이프라인을 정확히 기술

## 🟡 주요 발견 (큰 수정 필요)

### 3. TAM이 지적 불성실
- "글로벌 DSS 시장 $16.6B" = Oracle/SAP/IBM 엔터프라이즈 분석 플랫폼
- 한국 B2C 모바일 앱과 카테고리가 다름
- **해결**: 글로벌 DSS TAM 삭제. 바텀업 계산 or 점신(979억)/포스텔러(100억) 같은 실제 한국 디지털 운세 시장 데이터 활용

### 4. SAM 계산이 비약
- "AI 이용률 33% × 2030세대 1,570만 = 520만"
- AI 써봤다 ≠ 의사결정 도구에 7,500원 낼 의향
- **해결**: "지난 12개월 내 자기계발 디지털 서비스(명상앱, 코칭, 타로)에 결제한 20~30대" = 50~100만 명이 더 현실적

### 5. 1,000명 유료 고객 달성 근거 없음
- 마케팅 예산 0원 (9월까지), 에브리타임+SEO만으로 12개월 내 1,000명?
- 전환율 5% 가정 → 무료 유저 20,000명 필요 → 광고 없이 6~7개월 내?
- **해결**: 현실적 퍼널 제시 (X노출→Y가입→Z무료→W유료). 목표를 200명으로 낮추거나 달성 근거 보강

### 6. 4.6조 타로 시장 수치 의심
- 출처: The Economist 2018 — 이게 한국 시장인지 글로벌인지 불명확
- **해결**: 점신 1,900만DL/979억, 포스텔러 900만/100억 같은 확인된 한국 데이터만 사용

### 7. 해자(moat)가 약함
- "파이프라인 설계 노하우"는 2~4주면 복제 가능
- **해결**: 데이터 네트워크 효과로 전환: "10세션 후 개인화 패턴 파악, 1,000유저 후 한국인 의사결정 행동 데이터셋 = 아무도 없는 데이터"

### 8. BEP 40명은 고정비 미반영
- Vercel Pro ~26,000원/월, Supabase Pro ~33,000원/월, 도메인, 에러 모니터링 등
- 실제 BEP = 50~60명 (여전히 합리적이나 정확해야 함)

## 🟢 경미한 발견

- 고객 인터뷰 2건은 통계적으로 의미 없음 (1명은 비타겟, 1명은 ChatGPT와 비교 불리)
- Gemini API 연동은 코드에 있으나 V2에서 미사용 — "Claude + Gemini" 표현 과장
- 선택형 UX "타이핑 불필요"는 과장 — 코드에 "직접 입력" 옵션 있음
- 이탈률(churn) 논의 없음. B2C SaaS 월 5~10% → 1,000명 유지하려면 월 70명 신규 필요
- LTV/CAC 계산 v2에서 빠짐 (v1 PRD에는 있었음)
- 데이터 프라이버시(PIPA) 논의 없음
- Rate limiting 없음 — 악의적 사용자가 API 비용 폭탄 가능
