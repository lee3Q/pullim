## 4/4 전원 일치 (확정 반영)

### P1. 기능 정직 분리
→ "구현 완료" 5개 + "개발 예정" 4개로 분리
→ 구현: 라우팅, Socratic, 3관점+토론, 정리문서, 위기감지
→ 로드맵: 리서치 에이전트, 검증 에이전트, 비동기, Supabase
→ Gemini 기술스택에서 삭제 (dead code)

### P2. 비용 수정
→ 543원 → **~300원** (Sonnet 기준, 200~500원 범위)
→ 마진 71% → **84~93%**
→ BEP 40명 → **~15명** (고정비 75,000원/월 포함)

### P3. TAM 바텀업
→ 글로벌 DSS $16.6B 삭제
→ **한국 디지털 자기계발/운세 시장 ~1,500~2,000억** (점신 979억 + 포스텔러 100억 + 마인드카페 93억 + 기타)
→ SAM: 50~100만 명 (디지털 자기계발 결제 경험 20~30대)
→ SOM: **200명, 연 1,800만 원**

### P4. 목표 200명 + 퍼널
→ 1,000명 → **200명**으로 하향
→ 구체적 퍼널: 노출 → 방문 → 가입 → 유료 전환율 제시
→ "200명은 PMF 검증 목표. 스케일은 데이터 후."

### P5. 리텐션 = "의사결정 저널"
→ 위클리 체크인 (실행 추적)
→ 마이크로/Quick 세션 (일상 결정, ~30원)
→ 월간 패턴 리포트 (개인화 인사이트)
→ 마일스톤 시스템 (결정력 성장 시각화)

### P6. 검증 정직 + 계획
→ "인터뷰 2건" → "외부 테스터 2명 탐색적 테스트"
→ 베타에서 N=20~30 정식 인터뷰 계획 명시

### P7. 티어 요금제
→ 무료: 월 1세션
→ 스탠다드: 7,500원 / 월 8세션
→ 프로: 14,900~15,000원 / 월 20세션 or 무제한
→ Quick Mode: 무제한 (비용 ~10~30원)

### P8. 해자 = 데이터 축적
→ Day 1: 프롬프트 품질 (약하지만 시행착오 산물)
→ 중기: 개인화 패턴 데이터 (6개월 격차)
→ 장기: 한국인 의사결정 행동 데이터셋 (유일)
→ "해자가 약하다는 걸 인정하되, 시간이 갈수록 강화되는 구조"

### P9. 네이티브 앱 삭제
→ PWA에 집중. 네이티브 앱은 PMF 후 (2027)
→ 10개월 = "PMF 검증 + 200명 유료"에 집중
