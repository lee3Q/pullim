# 로컬 AI 실험 환경 구축 — 3자 리서치 합성

> 리서치 일자: 2026-03-21
> 소스: Claude (자체) + Perplexity + Gemini Deep Research

---

## 소스별 요약

| 소스 | 핵심 발견 |
|------|-----------|
| **Claude (자체)** | 하드웨어/서빙/모델/비용/연동 5개 축 조사. Mac Studio M4 Max 64GB ~404만원, BEP 3~5년, Ollama 1순위, EXAONE 4.0 32B 한국어 최고(NC), Qwen3 Apache 2.0 최적. 풀림 연동 30분 작업(openai.ts 복사). |
| **Perplexity** | 벤치마크 수치 중심. M4 Max 64GB ~460만원, 8B Q4 40-60 tok/s, RTX 4090 130-150 tok/s. K-EXAONE KMMLU-Pro 67.3, **Kanana 1.5 8B (카카오, Apache 2.0)** 발견. vLLM-MLX가 llama.cpp 대비 21-87% 빠름. M1 8GB는 1-4B까지 실용적. |
| **Gemini** | 아키텍처 심층 분석. M4 Max 64GB ~464만원. **70B에서 Mac(22 tok/s)이 RTX 4090(12 tok/s)을 역전** — VRAM 오프로딩 때문. RTX 5090 GPU 단품 550-800만원. **BEP 경량 사용시 14.4년, 대량 개발/테스트시 1.7개월**. 멘탈케어 도메인: "기계적 공감" 문제의 임상적 한계 심층 분석. Solar Pro 3 (102B MoE, 12B active) 신규 정보. |

## 3자 일치 사항

1. **Mac Studio M4 Max 64GB가 로컬 LLM 가성비 최적** — 400~464만원, 30B 여유, 70B 가능
2. **NVIDIA GPU는 소형 모델에서 빠르지만 VRAM 벽(24-32GB)으로 70B 이상 비실용적** — 70B에서 Mac이 역전
3. **Ollama가 개인/개발용 1순위** — 설치 1줄, OpenAI API 호환, SSE 스트리밍
4. **K-EXAONE/EXAONE이 한국어 최고 성능** — KMMLU-Pro 67+ (단, NC 라이선스)
5. **Qwen 시리즈가 Apache 2.0으로 상업적 최적** — 한국어 상위권, 사이즈 선택폭 넓음
6. **M1 8GB는 3-4B까지만 실용적** — 7B는 스와핑으로 고통
7. **순수 API 절감으로는 BEP 수년 이상** — 경제적 타당성 낮음

## 불일치 / 추가 발견 (핵심)

### 가격 불일치
| 구성 | Claude | Perplexity | Gemini |
|------|--------|------------|--------|
| M4 Max 64GB | ~404만 | ~460만 | ~464만 |

→ **원인**: Claude는 48GB 상위 기본형(404만) + 메모리 업그레이드 비용을 별도 미반영. Perplexity/Gemini는 64GB CTO 완성 가격. **실제 64GB 가격은 460~464만원이 정확**.

### BEP 극적 차이 (Gemini 고유 발견)
| 사용 시나리오 | 월 API 비용 | BEP |
|-------------|-----------|-----|
| 경량 (50세션/일, 2K토큰) | 26,730원 | **14.4년** |
| 개발/테스트 집중 (10M토큰/일) | 267만원 | **1.7개월** |

→ **핵심 인사이트**: 풀림의 개발 단계에서는 Agentic AI 테스트 (다중 에이전트 토론, RAG 파이프라인 등)로 토큰 소비가 폭증할 수 있음. 이 경우 BEP가 극적으로 단축됨.

### Kanana 1.5 8B (카카오) — Perplexity에서만 발견
- **Apache 2.0** 라이선스, 한국어·영어 양방향
- KMMLU: 48.94, KoMT-Bench: 7.63/10
- 32K 컨텍스트 (128K YaRN 확장)
- 8B라 M1 8GB에서도 시도 가능
→ **풀림 관점**: 카카오 제작 한국어 특화 + Apache 2.0 = 상업적 리스크 없음. EXAONE의 대안.

### Solar Pro 3 (Upstage) — Gemini에서 상세
- 102B MoE, **12B 활성 파라미터** → 하드웨어 부담 최소
- 128K 컨텍스트
- Instruction Following 52% 향상 (IFBench 55.78)
- 복잡한 추론 30% 향상 (Arena Hard v2 62.5)
→ Claude 리서치에서는 Solar Pro 2 (31B)까지만 파악. Pro 3는 MoE 구조로 64GB에서 구동 가능성 있음.

### M4 Ultra 512GB 옵션 단종 — Gemini 고유
- 글로벌 DRAM 부족으로 512GB 옵션 조용히 단종, 현재 최대 256GB
- 96→256GB 업그레이드 비용만 270만원

### 멘탈케어 도메인 심층 분석 — Gemini 고유
- **"기계적 공감(Mechanical Empathy)" 문제**: LLM의 표면적 만족도는 높지만, CBT 관점에서 오히려 독이 될 수 있음
- 인간 치료사는 의도적 침묵, 불완전한 질문으로 자동사고를 끌어올림 → LLM은 무조건 해결책 제시 편향
- **풀림 관점**: 이것은 풀림이 이미 "답을 주지 않는 Socratic 질문" 설계로 해결하고 있는 문제. 로컬 모델에서도 이 설계 원칙 유지가 핵심.

### vLLM 동시접속 성능 — Perplexity 고유
- Ollama: 50명 동시접속 시 p99 지연 24.7초, 처리량 155 tok/s
- vLLM: 같은 조건 p99 2.8초, 처리량 920 tok/s (6배)
→ **풀림 관점**: 현재 단계에서는 Ollama로 충분. 프로덕션 로컬 서빙 필요 시 vLLM-MLX 전환.

## 합성 결론

### 확정 사항 (3자 일치, 높은 신뢰도)

1. **현재 M1 8GB로는 로컬 LLM 실험 부적합** — 3B 이하만 가능, 풀림 상담 품질 불가
2. **Mac Studio M4 Max 64GB (~464만원)가 최적 투자 대상** — 30B 여유, 70B 가능, RTX 대비 대형 모델에서 우위
3. **Ollama + OpenAI 호환 API로 풀림 연동 가장 쉬움** — local.ts 추가 30분 작업
4. **한국어 모델 1순위: Qwen3 32B (Apache 2.0)** — 상업적 자유 + 한국어 상위
5. **하이브리드 전략이 정답** — 프로덕션=Claude API, 개발/테스트/데모=로컬

### 추가 확인 필요 사항

1. **Mac Studio 구매 시점 판단**: M4 Ultra 출시 예정일 확인 → 나오면 가격 하락 가능
2. **Kanana 1.5 8B vs Qwen3 8B 한국어 품질 직접 비교**: M1 8GB에서 시도해볼 가치
3. **Solar Pro 3 64GB 구동 가능 여부**: 102B MoE지만 12B 활성 — GGUF 양자화 시 메모리 요구량 확인
4. **풀림 Socratic 질문 품질**: 로컬 32B 모델에서 [OPTIONS]/[SUMMARY] 마커 파싱 성공률 테스트 필요
5. **BEP 정밀 계산**: 풀림 실제 개발 토큰 사용량 측정 후 재계산

### 풀림 특수 고려사항

- **프라이버시**: 정신건강 데이터의 로컬 처리는 규제적 강점 (개인정보보호법)
- **Socratic 설계 호환성**: Gemini가 지적한 "기계적 공감" 문제를 풀림은 이미 설계로 해결 중. 로컬 모델에서도 "답을 주지 않는" 프롬프트 구조 유지 필수.
- **오프라인 데모**: ICC 발표, 투자자 미팅 등에서 네트워크 의존 제거

## 즉시 실행 가능한 것 (M1 8GB에서)

Mac Studio 구매 전에도 현재 M1 8GB에서 시도 가능:
1. `brew install ollama` → `ollama pull qwen3:4b` (4B 모델, 15-25 tok/s)
2. `providers/local.ts` 생성 → baseURL `http://localhost:11434/v1`
3. 풀림 listen 경로에서 로컬 모델 테스트 → 품질/속도 체감
4. 이 체험으로 Mac Studio 투자 판단 정보 확보
