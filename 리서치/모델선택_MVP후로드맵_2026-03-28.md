## Part 1: 모델 선택

### 1.1 현재 아키텍처 정리

풀림의 **실제 메인 플로우는 "사다리 세션"**이다. 끝판왕 풀 파이프라인(10구슬/토론/심판)이 아님.

| 엔드포인트 | 용도 | 현재 모델 | 사다리 세션에서 호출? |
|-----------|------|----------|-------------------|
| `/api/ultimate/listen` | 메인 대화 (Socratic 질문) | Claude Sonnet 4.6 | ✅ 핵심 |
| `/api/behind-thought` | 이면사고 분석 | Gemini Flash Lite (무료) | ✅ 보조 |
| `/api/ultimate/research` | 웹 리서치 | Perplexity Sonar | ❌ 아직 미연결 |
| `/api/ultimate/analyze` | 10구슬 병렬 분석 | Claude/Gemini 라운드로빈 | ❌ 아직 미연결 |
| `/api/ultimate/debate` | 모델 교차 토론 | Claude/Gemini 교차 | ❌ 아직 미연결 |
| `/api/ultimate/judge` | 팩트체크/논리검증 | Claude Haiku 4.5 | ❌ 아직 미연결 |
| `/api/ultimate/conclude` | 세션 결론 | Claude Sonnet 4.6 | ❌ 아직 미연결 |

**핵심 발견: 사다리 세션의 실제 비용은 Listen + Behind-thought뿐.**

### 1.2 사다리 세션 비용 시뮬레이션

**가정**: 평균 10턴, 턴당 input ~2K 토큰, output ~500 토큰

| 구성요소 | 토큰 | 모델 | 비용 |
|---------|------|------|------|
| Listen (10턴) | 20K in, 5K out | Claude Sonnet | $0.06 + $0.075 = **$0.135** |
| Behind-thought (10턴) | 5K in, 1K out | Gemini Flash Lite | **$0** (무료) |
| **세션당 합계** | | | **$0.135 = ~186원** |

프롬프트 캐싱 적용 시 (시스템 프롬프트 반복 부분):
- Input 캐시 적중률 50% 가정: $0.06 × 0.5 × 0.1 + $0.06 × 0.5 = $0.033
- **캐싱 후: ~$0.108 = ~149원**

### 1.3 테스트용 모델 — 3가지 옵션

| 옵션 | 방법 | 세션당 비용 | 난이도 | 추천 |
|------|------|-----------|--------|------|
| **A. Haiku 전환** | `claude.ts`에서 PIPELINE_MODEL을 Haiku로 변경 | ~62원 | 코드 1줄 | ✅ **추천** |
| B. Gemini Flash | listen 엔드포인트에 Gemini 분기 추가 | 0원 | 코드 수정 중간 | 품질 차이 큼 |
| C. Sonnet 그대로 | 변경 없이 Sonnet으로 테스트 | ~186원 | 변경 없음 | 비용 OK면 이것도 가능 |

**추천: 옵션 A (Haiku)**
- 이유: 코드 1줄 변경 (`PIPELINE_MODEL = "claude-haiku-4-5-20251001"`), 한국어 품질 양호, API 호환 100%
- 테스트 목적(API 흐름 확인)에 충분
- 10세션 테스트해도 620원 — 무시할 수준
- 테스트 후 다시 Sonnet으로 복원

**환경변수만 세팅하면 데모→실제 전환 자동**: `isDemoMode()`는 `ANTHROPIC_API_KEY` 없으면 true. 키 넣으면 바로 실제 모드.

### 2.3 1인 창업자 MVP 이후 우선순위 (리서치 합성)

**3자 리서치 일치사항:**
1. **사용자 > 기능**: 기능 추가보다 사용자 확보와 피드백 루프가 우선
2. **속도가 경쟁력**: 1인의 장점은 의사결정→실행 사이클이 짧다는 것
3. **하이퍼 니치**: 범용이 아닌 초특화 시장에서 시작
4. **자동화**: 반복 업무를 AI로 자동화하여 1인 운영 가능하게

**멘탈헬스 앱 리텐션 데이터:**
- 미국 18-21세의 1/5이 LLM을 멘탈헬스에 사용 (2025)
- 사용자의 2/3이 월 1회 이상 사용, 93%가 "도움됐다"
- 공통 도전: 낮은 리텐션, 디지털 리터러시, 프라이버시, 효과성 증명
