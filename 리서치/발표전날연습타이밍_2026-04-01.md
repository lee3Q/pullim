# 발표 전날 밤 최적 연습 타이밍 리서치
**날짜**: 2026-04-01  
**질문**: 졸리고 피로한 상태(22:30, 운동+샤워 직후), 발표 15시간 전, 수면 7.5~9시간 예정, 여유 3시간 — 휴식 최대화 + 발표 퍼포먼스 극대화를 동시에 달성하는 시간 배치  
**소스**: Claude 자체 리서치 + Perplexity (2-model)

---

## 소스별 핵심 발견

| 소스 | 핵심 |
|------|------|
| Claude | 수면 전 15분 소리 내어 리뷰 → 고착화 강화. 피로 상태엔 소리 내어 말하기가 최고 효율. 스페이싱 효과 수면 포함 시 더 강력. |
| Perplexity | 수면 직전 학습한 내용이 수면 첫 4~6시간에 특히 강하게 고착화됨. 단일 짧은 active recall 1회도 다음날 회상 유의미하게 향상. 불안→흥분 재해석으로 퍼포먼스 17~33% 향상 (J. Experimental Psychology). |

## 3자 일치

- **오늘 밤 10~15분 + 내일 아침 30~40분 > 둘 중 하나 몰아서** (스페이싱 + 수면 고착화)
- **수면 자체가 단일 최강 퍼포먼스 부스터** — 수면 부족 시 연습 효과 자체가 사라짐
- **피로 상태에서 긴 수동적 읽기 = 거의 효과 없음** → 짧은 능동 회상만
- **발표 2시간 전 이후 연습 중단** — 직전 cramming이 anxiety spike 유발

## 핵심 추가 발견

- **불안 → 흥분 재해석**: 발표 전 불안을 "흥분"으로 재해석하면 퍼포먼스 17~33% 향상 (J. Experimental Psychology). 내용 연습이 아닌 **상태 전환 루틴**이 직전 최선.
- **피로 상태 역설**: 인지 통제가 줄어든 피로 상태에서 절차적(procedural) 연습은 오히려 자동화에 유리할 수 있음 (Frontiers in Human Neuroscience, 2016)
- **수면 사이 재고착**: 수면이 두 세션 사이에 개입되면 첫 세션 내용이 고착 → 두 번째 세션 효율 상승

## 합성 결론 — 최적 타임라인

```
[오늘 밤 22:30~22:50] — 20분
  • 소리 내어 발표 핵심 흐름 요약 1회 (7분 런스루, 완주 목표)
  • 어색한 전환 1~2개 메모만 (지금 고치지 말 것)
  • "내일 이걸 쓸 것" 의식적으로 마무리 → 취침

[취침 23:00 → 기상 07:00~07:30] — 8~8.5시간 ← 핵심

[내일 아침 07:30~08:30] — 1시간
  • 런스루 1회 (수면 고착화 효과로 어제보다 유창할 것)
  • 약한 파트 집중 2~3회
  • 최종 런스루 1회

[11:30 이후] — 내용 연습 완전 중단
  • 오프닝 첫 문장만 머릿속 확인
  • "긴장 → 흥분" 재해석 루틴 (심호흡 + "나 지금 설레는 거야")
  • 대기 중 스크립트 읽지 말 것
```

## 핵심 원칙 3가지

1. 오늘 밤 20분이면 충분 — 피로 상태 긴 연습은 역효과
2. 수면 8시간이 연습 1시간보다 강하다
3. 발표 2시간 전엔 내용 말고 상태 관리
