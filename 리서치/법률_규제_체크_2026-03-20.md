## 1. 타로 프레이밍의 법적 지위

### 1-1. "타로" = 점술업 신고 의무?

- 한국표준산업분류 **S96992 '점술 및 유사 서비스업'** 존재
- **별도 영업신고 의무 없음**. 돈 받고 운세 보면 사업자등록(세무상 업종코드 930909) 필요
- **"타로" 단어만으로 점술업 신고 의무 발생하지 않음**

### 1-2. 사업자등록 업종 — 실무 선택지

| 선택지 | 사례 | 장단점 |
|--------|------|--------|
| **정보서비스업** (데이터베이스 및 온라인 정보 제공업) | 포스텔러 운영사 '운칠기삼' | ✅ 추천. B2B 확장 유리, "점집" 이미지 회피 |
| 점술업 (930909) | 일부 온라인 사주 서비스 | ❌ 비추. 낙인 효과 |
| 소프트웨어 개발업 + 부업종 점술업 | 혼합 구조 | 변호사/세무사 협의 필요 |

**풀림 권장**: **정보서비스업** 또는 **소프트웨어 개발업**. "AI 의사결정 코칭 도구"이므로 점술업 코드 불필요.

### 1-3. "합리적 타로" 표현 리스크

- 표시광고법: 과학적 근거 없이 "합리성·과학성" 강조 → **과장/기만 광고 소지**
- "합리적 타로로 미래를 예측" ❌
- "타로 카드 메타포를 활용한 **자기성찰/의사결정 정리 도구**" ✅

**권장 안전선**:
- 서비스 소개/FAQ/이용약관에 명시: "점성술·심리검사가 아니라, **자기 해석을 돕는 엔터테인먼트/코칭 도구**"
- 마케팅에서 "타로"는 **감성적 메타포로만** 사용. "예측/점술"과 연결 금지.

## 2. AI 심리상담/코칭 규제 (2026 기준)

### 2-1. 디지털의료제품법 (2025.1 시행)

디지털의료제품 3분류:
1. 디지털의료기기
2. 디지털융합의약품
3. **디지털의료·건강지원기기** — "의료기기는 아니지만, 의료 지원/건강 유지·향상 목적"

**풀림 판단**:
- 질병 진단/치료/예방 표방 → **❌ 적용 대상**
- "커리어·연애 선택 구조화", "자기성찰 코칭" → **✅ 안전 영역**

| 금지선 (레드) | 허용선 (그린) |
|-------------|-------------|
| "우울증을 진단/치료합니다" | "스트레스를 점검하고, 선택 기준을 정리하도록 돕는다" |
| "공황장애 예방에 효과적" | "오늘 기분/가치관을 정리해 본다" |

### 2-2. AI 기본법 (2026.1 시행)

- **11개 "고영향 AI" 분야**: 보건의료, 채용, 대출 심사 등
- **풀림**: 의료/채용/대출 의사결정에 직접 사용 안 함 → **고영향 AI 해당 가능성 낮음**
- **지켜야 할 것**: 생성형 AI 투명성 의무
  - AI 사용 사실 사전 고지
  - 결과물이 AI 산출물이라는 표시
  - 위반 시 **3천만 원 이하 과태료**

**풀림 대응**: 서비스 곳곳에 "AI 기반 자동 생성 답변이며, 전문 상담이 아님" 표기. 이미 파이프라인 설계에 자연스럽게 녹일 수 있음.

### 2-3. 방통위 생성형 AI 이용자 보호 가이드라인 (2025.2)

- 4대 원칙: 인간 존엄, 설명, 안전, 비차별
- 6가지 실행: 위험 키워드 차단, 신고 창구, AI 산출물 표시, 학습 동의 옵션 등
- **법적 구속력**: 현재 "권고" 수준이나, **향후 입법의 기준선**

**풀림 이미 대응 중**:
- ✅ RED 프로토콜 (위기 키워드 → LLM 중단 → 109 안내)
- ✅ AI 산출물 표시 (세계관 내에서 자연스럽게 가능)
- ⏳ 학습 동의 옵션 (향후 구현)

### 2-4. "상담"이라는 단어 — 현재와 미래

**현재 (2026.3)**:
- "상담"이라는 일반 용어 사용 자체는 **불법 아님**
- 정신건강복지법은 전문요원 자격/역할을 규정하지만, 단어를 독점하지 않음

**미래 리스크**:
- 국회에 **심리상담사법, 마음건강상담사법** 등 다수 법안 계류 중
- 핵심 조항: "마음건강상담사가 아닌 자는 심리서비스를 업으로 하지 못한다"
- **통과 시 민간 AI 상담/코칭 서비스에 큰 영향**

**풀림 전략**:
- 브랜드/메인 카피에서 "상담" 대신 **"코칭·가이드·리플렉션"** 사용
- "AI와 대화하며 스스로 생각을 정리하는 **의사결정 코칭 도구**"
- 향후 법안 통과 시에도 **브랜드 변경 부담이 적은 구조를 지금부터 설계**

## 3. 개인정보보호 — 민감정보와 국외이전

### 3-1. 고민 입력 = 민감정보?

- 개인정보보호법: **"건강·성생활 등에 관한 정보" = 민감정보**
- "우울해서 약 먹고 있다", "자해 충동이 있다" 등 = **정신 건강 민감정보**
- 이름 없어도 기기·계정·로그 조합으로 재식별 가능 → 여전히 개인정보

**풀림 대응 설계**:
1. 일반 개인정보 동의와 별도로 **"민감정보 처리 동의" 체크박스 분리**
2. 수집·이용 목적, 항목, 보유기간, 동의 거부 시 불이익 명시
3. **"기록을 저장하지 않는 완전 익명 모드"** 제공 → 일부 대화를 개인정보 밖으로 설계 가능

### 3-2. 해외 LLM API 사용 = 국외이전

- 국내 데이터를 해외 클라우드/API로 전송 = **PIPA상 국외 이전**
- Claude/GPT API 사용 시 모델 학습에 활용될 여지 → "제3자 제공/국외 이전"

**풀림 대응**:
1. **별도 동의서**: "해외 LLM(Anthropic/OpenAI 등)에 고민 텍스트가 전송될 수 있음" 명시
2. 수집 항목·국가·제공받는 자·보유기간 구체 적시
3. **직접 식별자(이름·전화번호)는 프롬프트 전송 전 서버에서 제거/치환**
4. 개인정보처리방침에 **국외이전 조항 + 해외 수탁자 정보** 상세 기재

### 3-3. GDPR vs 한국 동의 기준

| 항목 | GDPR | 한국 PIPA |
|------|------|----------|
| 민감정보 처리 | 명시적 동의 필수 | 별도·명시적 동의 + 추가 보호조치 |
| DPO 지정 | 의무 | 아직 의무 아님 (규모 기준) |
| DPIA | 고위험 시 필수 | 영향평가 제도 있으나 느슨 |
| 프로파일링 규제 | 엄격 | 약함 |

**중장기 전망**: AI 기본법 + PIPA 개정 + 방통위 가이드라인 → GDPR 수준에 근접할 가능성. 초기부터 GDPR 수준으로 설계하면 미래 대응 비용 최소.

## 4. 위기 대응 — 법적 의무와 설계

### 4-1. 자살예방법 + 위기 대응 의무

- 자살유발정보 차단·삭제 의무 (정보통신서비스 제공자)
- **"AI 코칭 앱이 모든 자살 암시를 112에 신고해야 한다"는 조항은 현재 없음**
- 다만, 방치 시 민사 책임 + 여론 리스크

**109 (통합 자살예방 상담전화)**:
- 2024.1.1.부터 기존 1393이 **세 자리 번호 '109'로 통합**
- 24시간 상담, 112·정신건강복지센터 연계
- **복지부는 자살 관련 안내 시 109만 사용하도록 유도**

**풀림 RED 프로토콜 업데이트**:
- 현재: 1393 + 1577-0199 → **109로 통합 필요**
- 1차: 109 (필수), 2차: 112/119 (상황에 따라)

### 4-2. 약관(면책조항) 핵심 문구 방향

1. **비의료·비상담 선언**
   > "본 서비스는 전문적 진단·치료·상담을 대체하지 않습니다. 참고·자기성찰·코칭 목적의 정보일 뿐, 의료·법률·재무 전문 자문이 아닙니다."

2. **위기상황 경고**
   > "자해·자살을 고려 중이거나 타인에게 즉각적 위해를 가할 우려가 있는 경우, 서비스를 즉시 중단하고 109(자살예방 상담전화), 112(경찰), 119(소방)에 연락해 주십시오."

3. **AI 한계 고지**
   > "응답은 생성형 AI가 자동 생성한 것으로, 부정확하거나 부적절할 수 있습니다. 모든 중요한 의사결정은 이용자 본인의 책임하에 이루어져야 합니다."

4. **책임 제한**
   > 소비자기본법·민법 허용 범위 내, 간접·부수적 손해에 대한 책임 제한

## 5. 광고/마케팅 규제

### 과대광고 위험선

| ❌ 금지 (과장/기만) | ✅ 허용 (과정 지원) |
|-------------------|------------------|
| "AI가 고민을 해결해준다" | "AI가 **고민 정리와 관점 탐색**을 도와준다" |
| "AI 코칭으로 인생이 바뀐다" | "결정을 내리기 전에 **생각을 구조화해 보는 도구**" |
| "합리적 타로로 미래를 예측" | "타로 메타포를 활용한 **자기해석 엔터테인먼트 코칭**" |

### 건강기능식품 유사 규제?

- 소프트웨어/AI 코칭 서비스만으로는 별도 "효능 리스트" 규제 없음
- **단, 질병명·치료 효과 표현 시 의료행위·의약품 광고 영역과 충돌**
- "기분 관리, 스트레스 인식, 자기이해, 의사결정 정리" = **웰빙·라이프스타일 수준**으로 표현

## 6. 레드라인 / 옐로라인 / 그린존 정리

### 🔴 레드라인 (넘지 말 것)

- 정신질환 **진단/치료/예방** 표방
- AI가 **전문 심리상담사/정신과 의사 역할**이라고 주장
- 자살유발정보에 해당하는 기능 (동반자 모집, 방법 공유 등)

### 🟡 옐로라인 (조심해서 설계)

- "합리적/과학적 타로" → **과학성 과장** 주의
- "심리상담" 전면 사용 → **심리사법 통과 시** 브랜드 리스크
- 해외 LLM API → **민감정보 국외이전 동의/데이터 최소화** 필수

### 🟢 그린존 (안전한 방향)

- 업종: **정보통신업/소프트웨어 개발업** (포스텔러 선례)
- 기능: **자기성찰·가치 명료화·선택지 정리·시나리오 탐색** 중심
- 표기:
  - "AI 기반 참고 도구, 전문 상담 아님" 고지
  - 위기 키워드 필터링 + 109·112·119 안내
  - 민감정보 별도 동의 + 해외 전송 동의

## 7. 사업계획서 반영 포인트

### ICC 발표 Q&A 방어 멘트

**Q: "타로 프레이밍이 법적으로 문제 아닌가?"**
> "풀림은 점술 서비스가 아닙니다. 타로 메타포는 UX의 일부이며, 내부는 이종 AI 모델의 데이터 기반 분석입니다. 사업자등록도 정보서비스업으로 진행하며, 포스텔러(매출 100억)와 동일한 업종 구조입니다."

**Q: "AI 규제가 강화되고 있는데?"**
> "풀림은 진단·치료를 표방하지 않는 '코칭·자기결정 지원 도구'로, 디지털의료제품법 대상이 아닙니다. AI 기본법 투명성 의무는 서비스 설계에 이미 반영했고, 위기 감지 시 109(자살예방 상담전화) 안내 + LLM 즉시 중단하는 RED 프로토콜을 탑재했습니다."

**Q: "개인정보 해외로 나가는 거 아니야?"**
> "해외 LLM API 사용 시 민감정보 국외이전 동의를 별도로 받으며, 직접 식별자는 서버에서 제거 후 전송합니다. 장기적으로 한국인 의사결정 데이터가 축적되면 국내 sLLM 파인튜닝으로 전환하는 로드맵이 있습니다."
