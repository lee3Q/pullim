**결론: 재분류 시장(Re-segmented Market) — 니치 전략**

| 유형 | 해당 여부 | 판단 근거 |

## 2. 경쟁 우위 분석

### 2-1. 한국 경쟁 현황 매핑

| | 마인드카페 | 트로스트 | 상담냥 | ChatGPT | **풀림** |
|---|---|---|---|---|---|
| **진입 방식** | 감정 토로 | 감정 기록 | 캐릭터 대화 | 자유 질문 | 고민 입력 |
| **AI 역할** | 초기 케어→상담사 연결 | 감정 스캐너/일기 | 조언 제시 | 장단점 나열 | **Socratic 질문→구조화** |
| **산출물** | 없음 | 마음정리보고서(감정) | 없음 | 텍스트 대화 | **의사결정 정리 문서** |
| **후속 추적** | 없음 | 없음 | 없음 | 없음 | **추적 알림+패턴 분석** |

| **MAU** | 7.9만 | 8.3만 | 8천 | - | 0 (미출시) |

**핵심 발견**: "Socratic 질문 → 의사결정 정리 문서" 서비스는 한국에 없다.

### 2-2. 경쟁 우위 요소 (5 Forces + 독자 분석)

| 우위 요소 | 강도 | 방어 가능성 | 설명 |
|-----------|------|-------------|------|
| **Socratic 질문 파이프라인** | 🟢 강함 | 🟡 중기 | 4축 라우팅(가역성/정보충분도/감정관여도/시간압박) IP. 단, 복제 가능 |
| **의사결정 정리 문서** | 🟢 강함 | 🟢 장기 | "상담 후 뭐가 달라졌는지 모르겠다" 해결. 경쟁사에 없는 가치 |
| **의사결정 히스토리 Moat** | 🟡 잠재 | 🟢 장기 | 시간 경과 → 전환 비용 증가 → 데이터 플라이휠 |
| **창업자 실사용 1년** | 🟢 강함 | 🔴 단기 | N=1이나 도메인 인사이트 풍부. 시간 우위는 감소 |
| **멘탈케어 시장 빈자리** | 🟢 강함 | 🔴 단기 | 선점 기회. 빠른 실행이 관건 |

### 2-3. 글로벌 성공/실패 패턴에서 도출한 교훈

**성공 공통 패턴** (BetterUp, Noom, Wysa):
1. B2B 수익 모델 확보 (80%+ 매출)
2. 인간 + AI 하이브리드 (순수 AI only 리스크)
3. 측정 가능한 결과물 (체중, 결정 문서 등)

**실패 공통 패턴** (Woebot, Pi, Character.AI):
1. 규제 정면 돌파 (FDA/의료기기)
2. 수익 모델 부재 (B2C only + 무료 의존)
3. 낮은 ARPU ($1.14 = 지속 불가)

**풀림 시사점**: 의사결정 정리 문서 = 측정 가능한 결과물 ✅, 웰니스 포지셔닝 = 규제 회피 ✅, B2B EAP 병행 = 수익 안정화 ✅

| **Revenue** | 유료 전환율 | > 5% |
| **Referral** | 정리문서 공유 → 신규 유입 | Viral K > 0.3 |

**One Metric That Matters (OMTM)**:
- **초기**: 세션 완료율 (시작 → 정리문서 생성) — 가치 전달의 직접 증거
- **성장기**: 7일 재사용률 — 지속 가치의 증거

### 4-5. PLG (Product-Led Growth) 플라이휠

```
고민 입력 (진입)
    ↓
Socratic 질문 체험 (Activation)
    ↓
정리 문서 생성 (WOW 모먼트 / Time to Value < 15분)
    ↓
문서 공유 (바이럴 루프) → 새 사용자 유입
    ↓
히스토리 축적 → 개인화 → 프리미엄 전환
    ↓
패턴 분석 → 전환 비용 상승 = Moat
```

### 4-6. 데이터 플라이휠 (장기 해자)

```
사용자 세션 → 의사결정 히스토리 축적
    ↓
익명화 집합 분석 → "한국인 의사결정 패턴 DB"
    ↓
패턴 기반 개인화 질문 → 사용자 만족도 향상
    ↓
만족도 → 재사용 → 더 많은 데이터 → 더 나은 개인화 (선순환)
```

### 4-7. 정부 지원금 활용 로드맵

| 시기 | 지원사업 | 규모 | 적합도 |
|------|---------|------|--------|
| 현재 | 창업동아리 (대학) | 250만원 | ✅ 진행 중 |
| Pre-seed | 예비창업패키지 (중기부) | 최대 1억원 | ★★★★★ |
| Pre-seed | AI 바우처 (과기부) | 최대 3억원 | ★★★★☆ |
| Seed | 초기창업패키지 (중기부) | 최대 1억원 | ★★★★★ |
| Seed~A | TIPS (중기부) | 최대 5억+R&D 매칭 | ★★★★★ |

## 5. AI 창업팀 조직 설계 시사점

### 5-1. 이 분석이 팀 빌딩에 주는 시사점

| 분석 결과 | 팀 설계 함의 |
|-----------|-------------|
| 멘탈케어 포지셔닝 확정 | → **도메인 전문가(심리학/의사결정) 에이전트 필수** |
| Socratic 파이프라인이 핵심 차별화 | → **프롬프트 엔지니어를 CTO와 분리** |
| Customer Discovery가 최대 병목 | → **PM/전략 에이전트의 고객 리서치 역량 중요** |
| B2C+B2B 하이브리드 수익 모델 | → 마케팅 에이전트는 MVP 출시 직전 소집 |
| 규제 리스크 존재 | → 도메인 전문가에게 안전/윤리 기준 관리 위임 |

### 5-2. 권장 초기 팀 구성 (5명 균형 모델)

```
대표 (이상규) — 비전/방향/최종 승인
    ├── CTO — MVP 개발, 기술 아키텍처
    ├── 프롬프트/AI 엔지니어 — Socratic 파이프라인, LLM 최적화
    ├── PM/전략가 — 고객 리서치, 로드맵, 경쟁 분석
    └── 도메인 전문가 — 심리학/의사결정 이론, 안전 기준
```

### 5-3. 의사결정 체계 (RAPID + Advice Process 하이브리드)

| 결정 유형 | 권한 | 프로세스 |
|-----------|------|----------|
| 전략적 (피벗, 포지셔닝) | 대표 전결 | 팀 분석 → 제안 → 대표 결정 |
| 전술적 (기능 우선순위, 채널) | 팀 제안 → 대표 승인 | 회의 토론 → 제안서 → 승인/반려 |
| 운영적 (일정, 리서치 범위) | 팀 자율 → 보고 | 관련자 의견 수렴 → 자체 결정 |
| 실행적 (구체적 방법, 도구) | 팀 자율 | 보고 불필요 |

## 6. 결론: 즉시 실행 액션 아이템

### 최우선 (이번 주)
1. ☐ **Customer Discovery 시작**: Mom Test 기반 인터뷰 스크립트 확정 → 15명 목표 인터뷰 시작

3. ☐ **AI 창업팀 에이전트 소집**: CTO + 프롬프트/AI + PM/전략 + 도메인 전문가 (4 에이전트)

### 단기 (2주 내)
4. ☐ **Smoke Test**: 랜딩페이지 제작 → 전환율 측정
5. ☐ **창업동아리 신청서 작성**: 사회적 명분 3가지 + 초기 트랙션 포함
6. ☐ **핵심 가설 #1 검증**: "AI에게 중요한 고민을 말할 의향"

### 중기 (1개월 내)
7. ☐ **MVP 개발 시작**: Next.js + Claude API 기반 웹앱
8. ☐ **Value Hypothesis 검증**: Concierge MVP 결과 → Go/No-Go 결정
9. ☐ **마케팅 에이전트 소집 여부 결정**: MVP 출시 2주 전 기준
