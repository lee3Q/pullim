# 텍스트 선택지 게임 UI 리서치

> 조사일: 2026-03-20 | 목적: 풀림 UI를 "게임성 UI"로 전환할 때 참고할 레퍼런스

---

## 1. 장르 개요: 인터랙티브 픽션 / 선택지 게임

텍스트 + 최소한의 일러스트 + 선택지로 진행하는 게임 장르.
**핵심은 "메신저가 아니라 게임"이라는 프레이밍**.

시장 규모:
- Choices: Stories You Play — 누적 매출 $544M, 다운로드 1억+
- Episode — 인터랙티브 스토리 장르 1위
- 인터랙티브 스토리 게임 전체 US Q1 2025 상위권 유지

## 2. 주요 레퍼런스 앱

### Tier 1: 풀림에 직접 참고할 만한 것

| 앱 | UI 특징 | 풀림에 가져갈 요소 |
|----|---------|-------------------|
| **Lifeline** | 문자 메시지 형식이지만 "조난자와 교신" 서사 → 메신저가 아닌 "통신 장비" 느낌. 선택지 2개만 제시, 실시간 대기 메카닉 | 서사적 프레이밍으로 같은 텍스트도 게임으로 느끼게 만드는 법 |
| **Reigns** | 카드 스와이프 UI. 왼쪽/오른쪽으로 예/아니오 결정. 상단에 4개 지표(교회/국민/군대/재정) | **선택이 지표에 영향을 미치는 시각적 피드백** → 풀림의 "결정력/감정해상도" 지표 |
| **80 Days** | 아르데코 스타일 일러스트 + 지도 UI + 텍스트 선택지. 여행 서사. | **테마별 아트 디렉션**의 모범 사례. 텍스트 페이싱 디자인 |
| **Sorcery!** | 일러스트 지도 위에서 경로 선택 → 텍스트 어드벤처 진행 | **시각적 진행감** (지도/경로) + 텍스트 선택지 조합 |
| **A Dark Room** | 극단적 미니멀. 버튼 1개로 시작 → 점진적 UI 확장 | **전략실** 테마에 적합. 미니멀에서 복잡으로 성장하는 UI |

## 3. UI 패턴 분석: 연애앱 vs 게임 UI

| 요소 | AI 연애앱 | 텍스트 선택지 게임 | 풀림 방향 |
|------|----------|-------------------|----------|
| **텍스트 표시** | 메신저 말풍선 (좌/우 정렬) | 스크롤 텍스트 박스 / 카드 / 페이지 | 테마별 텍스트 박스 (말풍선 X) |
| **입력 방식** | 자유 텍스트 입력 (키보드) | 선택지 버튼 (2-4개) | 선택지 기본 + 자유 입력 보조 |
| **캐릭터 표현** | 실사/반실사 아바타 | 미니멀 일러스트 / 아이콘 / 없음 | 동물/마스코트 일러스트 |
| **진행 피드백** | 호감도/관계 레벨 | 스탯 변화 / 지도 이동 / 챕터 진행 | 자기성장 지표 + 챕터 진행 |
| **배경** | 채팅방 배경 | 세계관 일러스트 / 분위기 컬러 | 테마별 세계관 배경 |
| **사운드** | 메시지 알림음 | BGM + 효과음 | 테마별 앰비언트 사운드 |
| **시간 흐름** | 실시간 대화 | 턴 기반 / 챕터 기반 | 세션 기반 (시작-진행-마무리) |

## 4. 텍스트 게임 UI 설계 원칙

### 4-1. 선택지 설계
- **2-4개가 최적** — 너무 많으면 "선택의 역설"로 오히려 선택 못함
- **선택지마다 결과가 달라야** 의미 있음 (= "의미 있는 선택")
- 선택 후 **즉각적 피드백** 필요 (지표 변화, 텍스트 반응, 시각 효과)

### 4-2. 텍스트 페이싱
- 한 번에 전부 보여주지 않고 **점진적 노출** (글자 하나씩, 단락별)
- 읽는 속도에 맞춘 **자연스러운 딜레이**
- 중요 선택 전 **정지(pause)** → 긴장감 조성

### 4-3. 시각적 진행감
- 챕터/단계 표시 (어디까지 왔는지)
- 지도, 경로, 트리 등 **공간적 메타포**
- 스탯/지표 변화의 **시각적 피드백** (Reigns의 4지표 바)

### 4-4. 세계관 일체감
- UI 자체가 세계관의 일부 (80 Days의 아르데코, A Dark Room의 미니멀)
- **폰트, 색상, 텍스트 박스 모양**이 테마를 전달
- 같은 기능이라도 테마마다 완전히 다른 비주얼

## 5. 앱별 UI 상세 비교표 (Perplexity)

| 게임 | 텍스트 표시 | 선택 인터랙션 | 캐릭터 | 진행 피드백 | 자유입력 |
|------|-----------|-------------|--------|-----------|---------|
| Lifeline | SMS 스트림 + 실시간 대기 | 2지선다 버튼 | 텍스트만 | 실시간 지연 자체가 피드백 | X |
| Reigns | 카드 1장 + 짧은 텍스트 | 좌/우 스와이프 | 단순 아이콘 | 4 스탯 아이콘 (0이나 100→게임오버) | X |
| 80 Days | 텍스트 패널 + 3D 지구본 | 버튼 + 지도 노선 탭 | 최소 일러스트 | 시간/돈/지도 | X |
| Sorcery! | 스크롤 "슬립" (종이 조각 느낌) | 텍스트 선택지 버튼 | Spirit Guide 동물 아이콘 | 스탯 6종 + 지도 동시 | X |
| A Dark Room | 텍스트 로그 + 박스 (4색만) | 텍스트 액션 버튼 | 없음 | 자원 수치/건물 상태 | X |
| Choices | 비주얼 노벨 하단 대화창 | 대사 버튼 (+프리미엄) | 커스터마이즈 아바타 | 책/챕터/통계 | X |
| Episode | 만화 말풍선 | 대사/행동 메뉴 | 고도 커스터마이즈 | 에피소드/키 시스템 | X |
| Magium | 소설식 스크롤 | 텍스트 선택지 | 텍스트만 | 능력치 직접 선택 | X |
| Florence | 코믹 패널/이미지 | 퍼즐/제스처 | 만화체 | 챕터/시계 연출 | X |
| AI Dungeon | 콘솔형 로그 + 테마 시스템 | Do/Say/Story 버튼 + 자유입력 | 텍스트만 | Undo/Story Cards | O (핵심) |

### 공통 패턴
1. 텍스트 중심 + 하단/주변 선택지 (읽기→결정→읽기 루프)
2. 2-4개 선택지로 결정 피로 최소화
3. 지도/스탯/챕터 등 "어디쯤인가" 보여주는 메타 UI
4. 순수 텍스트 ↔ 비주얼 노벨 양극화
5. 시간 연출 적극 활용 (Lifeline 실시간 대기, 80 Days 시간 제한)

## 6. 게임 프레이밍 vs 메신저 UI: 학술 근거 (Gemini Deep Research)

### 핵심 논제: "참여-효능-윤리 트릴레마"
맹목적 참여 유도 → 임상 효능 저해 + 윤리적 위험. 게이미피케이션이 해결책.

### 멘탈헬스 앱의 게임적 인터랙션 사례

| 앱 | 전략 | 풀림 시사점 |
|----|------|------------|
| **Woebot** (Stanford) | 자유입력 의도적 제한 → 선택지 버튼 중심. 인지 부하 감소 + LLM 환각 차단 | 선택지 기반이 치료적으로도 우월 |
| **Wysa** | 펭귄 마스코트 → 불쾌한 골짜기 회피 + 안전한 공간 | 동물 캐릭터의 학술적 근거 |
| **SuperBetter** | 심리 문제 → "퀘스트/악당/파워업"으로 외재화 | 고민을 게임 메카닉으로 번역하는 모범 사례 |
| **Happify** | 긍정심리학 활동을 게임 트랙으로 구조화 | 진행 시스템 설계 참고 |

### 메신저 UI vs 게임 UI: 심리학적 비교

| 비교 항목 | 메신저 UI | 게임 UI |
|----------|----------|---------|
| **인지 처리** | System 1 (즉각/반사적) | System 2 (심사숙고/메타인지) |
| **관계 인식** | 인간-인간 대화 모방 → 사회적 실재감 극대화 | 이중 인식: 감정은 느끼되 가상임을 앎 |
| **심리적 거리** | 1인칭 → 자아 취약성 노출 | 3인칭 대리 → 치료적 거리두기 |
| **윤리적 위험** | 의인화 → 과의존 → 유사사회적 애착 | "마법의 원" → 현실/가상 경계 확립 |
| **치료적 적합성** | 긴급 감정 토로/위기 공감 | CBT 인지 재구성, 문제해결, 회복탄력성 |

### 텍스트 어드벤처 UI가 치료에 맞는 3가지 이유

1. **느린 사고 유도 (System 2)**
   - 메신저: 감정을 쏟아냄 → 텍스트 어드벤처: 읽고 → 시각화 → 판단 → 선택
   - 메타인지 활성화, 충동적 감정 표출 대신 객관적 분석

2. **치료적 거리두기 (Narrative Distancing)**
   - 1인칭 직접 타이핑 → 트라우마 날것 대면 → 압도
   - 3인칭/허구 캐릭터 → 자기 문제를 투사 → 안전하게 탐색

3. **선택-결과의 비가역성 (Chain Analysis)**
   - 메신저: 주제 돌리기/회피 쉬움
   - 게임: 선택 필수 → 결과 즉각 반영 → CBT "행동-결과 분석" 자연 융합
   - 예: 불안 회피 선택 → 게임 내 "몬스터" 강해짐

### 결론 (Gemini)
> "게임 프레이밍은 단순한 오락이 아니라, 사용자의 감정 전이와 현실 도피를 막기 위한 **필수적 임상적/윤리적 가드레일**이다."

## 7. 풀림 테마별 게임 UI 방향 (제안)

### 모험가의길 (Adventure)
- **레퍼런스**: Sorcery! + 80 Days
- 경로/지도 위에서 선택지 진행
- 판타지 일러스트 + 따뜻한 톤
- 동물 가이드 캐릭터가 내레이션
- "여정" 메타포 → 고민이 모험의 갈림길

### 전략실 (Strategy)
- **레퍼런스**: Reigns + A Dark Room
- 카드/패널 기반 선택 UI
- 미니멀/다크 톤 + 데이터 시각화
- 지표 변화가 핵심 피드백
- "전략 회의" 메타포 → 고민이 전략적 의사결정

### 달빛정원 (Garden)
- **레퍼런스**: Florence + 동물의 숲
- 부드러운 일러스트 + 파스텔 톤
- 동물 캐릭터가 정원에서 대화
- 감정을 "식물 성장"으로 시각화
- "정원 가꾸기" 메타포 → 감정 돌봄이 정원 돌봄
