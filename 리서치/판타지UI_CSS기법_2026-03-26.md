# 판타지 UI CSS 기법 리서치 (3자 합성)

**날짜**: 2026-03-26
**소스**: Claude 자체 + Perplexity + Gemini Deep Research

## 합성 결론

### 폰트
- **본문**: Gowun Batang (따뜻하고 섬세, 정렬 안정적)
- **제목/UI**: Noto Serif KR (장엄, 버튼 내 수직 정렬 보정 필요: leading-none + pt)
- Next.js next/font/google로 로드, CSS 변수로 주입

### 색상 팔레트
| 역할 | Hex | 비고 |
|------|-----|------|
| 배경 | #05060b ~ #12101a | 현재 유지 가능 |
| 카드 표면 | #1a1612 | 미세 갈색 (가죽 느낌) |
| 텍스트 | #C0A788 (양피지) | 순백 금지 |
| 금색 프레임 | #C0A374 (바랜 금) | 테두리 |
| 금색 발광 | #F1E1C5 (빛나는 금) | hover, 강조 |
| 금색 진 | #b8860b | 보더 |

### 카드/패널 CSS
```css
/* 다크 양피지 카드 */
background: linear-gradient(145deg, #1a1612, #0d0b08);
border: 1.5px solid #C0A374;
box-shadow:
  inset 0 0 30px rgba(0,0,0,0.4),
  inset 0 1px 0 rgba(241,225,197,0.15),
  0 8px 24px rgba(0,0,0,0.9);
```

### 버튼 CSS (medieval leather)
```css
background: linear-gradient(145deg, #4b2b1a, #2a140c);
border: 1px solid #b8860b;
color: #f3e3c4;
box-shadow:
  0 2px 0 #1a0b06,
  0 3px 8px rgba(0,0,0,0.8),
  inset 0 1px 0 rgba(255,255,255,0.1);
text-shadow: 0 1px 0 #1a0b06;
```
