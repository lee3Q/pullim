# PRD: /같이읽기 스킬 — 책 모드 추가

> 작성일: 2026-03-18

## 배경

책을 혼자 읽는 것은 몰입감이 없으면 부담스럽고 지루하다. 모르는 단어나 이해 안 되는 순간 책을 덮게 된다. 이런 순간을 더 쉽고 즐겁게 만들기 위해, 기존 `/같이읽기` 스킬에 **책 모드**를 추가한다.

## 목표

기존 웹 아티클 모드(URL 기반)는 유지하면서, 책 제목을 입력하면 자유 대화형 독서 보조 모드로 진입하는 기능을 추가한다.

## 모드 구분

| 입력 | 모드 | 동작 |
|------|------|------|
| URL | 웹 아티클 모드 (기존) | 의미 단위 분절 → 이해 확인 → 다음 |
| 텍스트 (책 제목) | **책 모드 (신규)** | 자유 대화형 독서 보조 |

## 책 모드 세션 흐름

### 1. 진입
- `/같이읽기 죄와벌` 입력
- 기존 배경자료 파일이 있으면 자동 로드

### 2. 배경 자료 (선택)
- AI: "이 책에 대한 배경 자료가 있으면 붙여넣어 주세요. 없으면 '건너뛰기'를 입력해 주세요."
- 제공하면 임시 디렉토리에 저장 → 다음 세션에서 자동 로드
- 건너뛰면 AI 자체 지식으로 대화

### 3. 자유 대화 루프
- 사용자가 문장 + 요청을 입력
- **"설명해줘"** → 단어/개념을 비유와 함께 쉽게 풀어 설명
- **"논의하자"** → 소크라틱 질문으로 독자의 생각을 끌어내는 대화

### 4. 세션 종료

| 명령 | 동작 |
|------|------|
| **"끝"** | 인사이트 자동 추출 → 적용 포인트 논의 → 저장 |
| **"완독"** | 인사이트 자동 추출 → 적용 포인트 논의 → 저장 → 배경자료 삭제 |

## 인사이트 저장

- **위치**: `~/study/main/창업/사전/독서_인사이트_로그.md`
- **형식**: 기존 `형_인사이트_로그.md` 형식 동일
- 모든 책의 인사이트가 하나의 파일에 누적
- 적용 포인트는 AI가 자동 결정하지 않고, **사용자와 논의하여 합의** 후 기록

```
## YYYY-MM-DD

**출처**: {책 제목 - 저자}

**오늘 물어본 것들**:
- {개념}: {한 줄 설명}

**인사이트**:
- {핵심 인사이트}

**적용 포인트**:
- {사용자와 논의하여 합의된 적용 방안}

**적용 여부**: 미적용
```

## 배경 자료 저장

- **위치**: 임시 디렉토리 (`~/.claude/tmp/같이읽기/{책제목}/context.md`)
- 같은 책 제목으로 재진입 시 자동 로드
- "완독" 명령 시 삭제
