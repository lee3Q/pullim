# 검증위원 하네스 (극악 채점표 생성 + 정답지 검증)
> 목적: 실제 심사위원보다 빡센 채점표 생성 → 정답지 채점 → 수정 → 100점 확정
> PPT는 변경 불가. 발표 말 + Q&A 답변으로만 커버.
> 모든 검증위원 = Opus

---

## Phase A: 극악 채점표 작성

### 소환 프롬프트

```
너는 대학 창업동아리 심사위원 3인단이다.
- 교수 1: 경영학과, 스타트업 회계/수익 모델 전문. 숫자 하나 잘못되면 바로 감점.
- 교수 2: 컴퓨터공학과, AI/LLM 기술 이해 높음. "AI가 다 해준다" 식 주장에 가장 냉소적.
- 심사위원 3: 초기 VC 심사역. 팀 구성, 실행력, 시장 검증에 집중. "혼자서 가능?" 이 첫 질문.

이 3명의 관점을 통합하여, 아래 PPT 기반 7분 발표에 대한 **채점표**를 만들어라.

[PPT 대본]
{대본_v2_전문}

[현재 정답지]
{정답지_전문}

---

채점표 작성 기준:

1. **슬라이드별 채점 항목** (슬1~슬22 각각)
   - 핵심 메시지 전달 (10점): 이 슬라이드에서 반드시 전달해야 할 1문장
   - 근거/수치 정확도 (10점): 출처 있는 수치를 정확하게 말하는가
   - PPT 오류 변호 (10점): PPT에 잘못된 내용이 있으면 — 어떻게 변호해야 하는지. 오류 없으면 "해당 없음, 10점"
   - 심사위원 설득력 (10점): 이 설명을 들은 3인이 납득하는가
   - 예상 질문 대비 (10점): 이 슬라이드에서 나올 질문에 답할 수 있는가
   - 슬라이드 소계: 50점

2. **Q&A 채점 항목** (별도)
   - 각 Q&A별 10점 × 예상 질문 수
   - 기준: 정확성 4 + 논리 3 + 솔직함 3

3. **전체 발표 채점 항목** (크로스슬라이드)
   - 일관성 (20점): 전체 스토리가 하나의 흐름인가. 슬라이드 간 모순 없는가
   - 과잉 확신 제어 (20점): "검증 완료/반드시/즉시" 등 금지 표현 없는가
   - N=2 솔직 인정 (10점): 데이터 부족을 인정하면서 질로 보완하는가
   - ChatGPT 차별화 (10점): 범용 AI와의 차이를 선제적으로 설명하는가
   - 해자 재정의 (10점): 코드가 아닌 운영 노하우+데이터 축적으로 설명하는가
   - 전체 소계: 70점

4. **감점 항목** (이것만으로 탈락 가능)
   - 출처 없는 수치를 단정 (-20)
   - 검증 데이터 N=2를 N>>2처럼 포장 (-20)
   - 안전 설계 질문에 구체적 답변 불가 (-15)
   - Bus factor=1 질문 회피 (-15)
   - "AI가 만들어준 PPT" 의심에 내용 설명 불가 (-30, 탈락)

---

출력 형식:
1. 슬라이드별 채점표 (슬1~슬22, 각각 5개 항목 + "이 슬라이드에서 나올 질문 TOP 2")
2. Q&A 채점표 (질문별)
3. 전체 발표 채점표 (5개 항목)
4. 감점 항목 리스트
5. **PPT 오류 목록**: PPT 자체에서 발견한 오류/모순 + 각각의 최적 변호법

채점표에는 "기대 답변 예시"를 넣지 마라 — 그건 정답지의 역할이다. 채점표는 순수 기준만.
```

---

## Phase B: 채점 (현행 정답지 → 채점표 기준 채점)

### 소환 프롬프트

```
너는 Phase A에서 만든 채점표의 채점관이다. 아래 정답지를 채점표 기준으로 채점해라.

[채점표]
{Phase_A_채점표}

[정답지]
{정답지_전문}

---

채점 규칙:
1. 슬라이드별로 5개 항목 각각 채점 + 감점 사유 (없으면 생략)
2. Q&A별 채점
3. 전체 발표 5개 항목 채점
4. 감점 항목 해당 여부 체크
5. **총점 산출**: 슬라이드 평균 + Q&A 평균 + 전체 발표 점수 (가중 합산)

출력 형식:
| 슬라이드 | 핵심메시지 | 근거정확 | PPT변호 | 설득력 | 질문대비 | 소계 | 감점사유 |
슬라이드별 한 줄 + 감점 사유

하단에:
- Q&A 채점 테이블
- 전체 발표 채점 테이블
- 총점
- **수정 필요 슬라이드 리스트** (소계 40점 미만 = 빨강, 40~45 = 주황)
```

---

## Phase C: 채점표 보완

Phase B 채점 중 발견한 것:
- 채점표에 없었지만 감점해야 할 항목
- 채점표 기준이 모호해서 채점이 어려웠던 항목

→ 채점표에 추가/수정하여 **v2 채점표** 확정.

---

## Phase D: 정답지 재수정 (병렬 4팀)

### 소환 프롬프트 (4팀 병렬)

```
너는 발표 코치다. 아래 채점표 기준으로 정답지를 100점으로 만들어라.

[극악 채점표 v2]
{Phase_C_채점표}

[현행 정답지 — 담당 슬라이드]
{해당_슬라이드_정답지}

[PPT 대본 — 담당 슬라이드]
{해당_슬라이드_대본}

---

수정 규칙:
1. 채점표 각 항목에서 만점을 받을 수 있도록 정답지를 수정
2. PPT 오류가 있는 슬라이드: "변호법" 섹션을 정답지에 추가
3. 과잉 확신 표현은 전부 톤다운
4. 수치는 출처와 함께 — 출처 없으면 "추정값임을 밝히며" 형태로
5. 예상 질문 답변은 채점표의 "이 슬라이드에서 나올 질문 TOP 2"를 반드시 커버
6. 자연스럽게 말할 수 있는 표현으로 — 논문 말투 금지

출력: 수정된 정답지 (해당 슬라이드 파트만, 기존 형식 유지)
```

### 4팀 배정
- A팀: 슬1~6 (도입~파이프라인)
- B팀: 슬7~12 (산출물~고객검증)
- C팀: 슬13~18 (유닛이코~비전)
- D팀: 슬19~22 + Q&A (기술~팀소개 + 전체 Q&A)

---

## Phase E: 자가검증

Phase D 결과물을 다시 Phase B 프롬프트로 채점.
목표: 전 슬라이드 소계 45점 이상 + 감점 항목 0건 + 총점 90점 이상.
미달 시 해당 슬라이드만 Phase D 재실행.

---

## 실행 순서 요약

```
Phase A (Opus 1명) → 극악 채점표 v1
   ↓
Phase B (Opus 1명) → 현행 정답지 채점
   ↓
Phase C (자동) → 채점표 v2 확정
   ↓
Phase D (Sonnet 4팀 병렬) → 정답지 재수정
   ↓
Phase E (Opus 1명) → 자가검증 → 90점 이상이면 완료
   ↓ (미달 시)
Phase D 재실행 (해당 슬라이드만)
```
