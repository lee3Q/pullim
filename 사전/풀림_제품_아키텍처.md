# 풀림 제품 아키텍처

```yaml
업데이트_주기: 변경 시마다
마지막_업데이트: 2026-03-11
트리거_조건: "PRD 변경, 팀 결정 변경, 기능 추가/제거"
불확실성_항목: ["좌뇌/우뇌 모드 분리 시 UI 차별화 정도", "광고 타이밍 최적점"]
```

## 핵심 가설

**풀림 = 인지 처리 플랫폼**
입력 온도(감정 vs 상황)만 다르고 처리 구조는 동일.

- 우뇌모드: 감정적 고민 → 구조화 (현재 풀림 핵심)
- 좌뇌모드: 상황/업무 혼돈 → 우선순위 + 주의점 + 파훼법
- 두 모드 = 같은 앱의 다른 진입점, 별개 제품 아님

반박: 감정처리와 논리처리는 신경학적으로 다른 경로 → UI가 달라야 할 수 있음
미해결: 두 모드의 공통 코어가 무엇인가 (현재: "구조화 출력"이라고만 정의됨)

## 마케팅 포지셔닝

**버전 A (기존)**: "당신의 뇌를 쉬어주는 곳" + 뇌건강 뉴스레터
**버전 B (권장)**: "자기인식 속도 향상" — 어제의 나보다 오늘의 나가 더 명확하게 생각했는가

> B가 리텐션에 유리. 체중계처럼 매일 올라가는 구조.

공식 카피: "이야기를 듣고, 같이 나아갑니다."
내부 원칙: "Evoke, don't prescribe."

---

## 수익화 모델

- 기본: 무료 + 광고
- 광고 방식: 연속 재생, 사전 고지, 울먹이는 캐릭터로 반감 최소화
- 타이머 10분 → 미리 보기 옵션
- 게임화: 출석 + todo 완료 시 모드 사용권 추가 부여
- 프리미엄: 월 구독으로 광고 제거

리스크: 접근성 높이면 세션 비용 증가 → 광고 수익으로 커버 가능한지 검증 필요

## 온보딩 설계 (초안)

불쾌 프로파일 추출 질문:
- "평소 어떤 대화가 에너지를 빼앗나요?"
- "어떤 말을 들으면 대화를 끊고 싶어지나요?"

→ 응답 패턴 규칙으로 변환 → 개인화 하네스 구성
