## 슬라이드 4: 5단계 파이프라인 수정 (기존 "3명의 AI 전문가가 토론하는 구조" 슬라이드)

**현재 문제**: 3단계만 표현됨 (이야기 듣기 / 3인 병렬 분석 / AI 상호 토론), 전문가 선택 없음, 착지 단계 없음

**수정 지시:**

제목 교체:
- 기존: "3명의 AI 전문가가 토론하는 구조"
- 변경: "5단계 파이프라인 — 고민이 입력되면 결론이 정리된다"

3카드 구조 → 5단계 화살표 플로우로 교체:

```
① 고민 입력
    ↓
② 이야기 듣기
   Socratic 질문으로 진짜 고민 파악
    ↓
③ AI 3명 병렬 분석 (추천 또는 직접 선택)
   현실주의자 · 공감자 · 역발상가
    ↓
④ AI 토론
   선택된 관점 vs 반론 → 종합 인사이트
    ↓
⑤ 의사결정 정리 문서 자동 생성
   "첫 걸음" + 첫 행동 1개
```

**레이아웃 지시:** 수평 또는 수직 화살표 5단계. 각 단계 박스 = 둥근 사각형 radius 8px. ③번에 "(추천 또는 직접 선택)" 명시. ⑤번에 "자동 생성" 강조. 브랜드 컬러 Primary.

**제목:** 기술 아키텍처 — "프롬프트가 아니라 파이프라인"

**아키텍처 플로우 텍스트 (다이어그램으로 제작):**
```
[사용자]  "이직해야 할까?"
   ↓
[프론트엔드]  Next.js 15 + PWA
   ↓
[AI 엔진]
   |---> [라우터] Haiku 4.5 — 4축 자동 분류
   |       가역성 / 정보충분성 / 감정개입 / 시간압박
   |
   |---> [구체화 엔진] Sonnet 4.6
   |       이야기 듣기 → 진짜 고민 파악
   |
   |---> [멀티 AI 토론] Opus x3
   |       3명 병렬 분석 → 토론 → 종합
   ↓
[맥락 축적 엔진]
   이전 세션 기억 / 패턴 분석
   ↓
[산출물]  다각도 분석 리포트 + 의사결정 정리 문서(첫 걸음)
   ↓
[저장]  Supabase RLS (암호화, 본인만 접근)
```

**기술 선택 근거 표:**
| 선택 | 이유 |
|------|------|
| Haiku + Sonnet + Opus 3계층 | 라우팅=저비용, 대화=고품질, 토론=최고품질 |
| Claude Opus x3 토론 | 멀티 AI 토론 품질 최상위 |
| Next.js + PWA | 앱스토어 심사 없이 모바일 앱 경험 |
| Supabase RLS | 사용자 데이터 완전 격리 |

**세션당 비용 분해 (1줄 강조 박스):**
> Haiku(라우팅 ~2원) + Sonnet(대화 ~150원) + Opus x3(토론 ~391원) = **세션당 543원**
