## 검증 축 (7개)

### 축 1. 서비스 차별화 강조도
- [ ] "타로의 의식성 + AI의 실질성" 공식이 양식맞춤에서 몇 번, 어디에 등장하는가
- [ ] 경쟁사 비교표에서 풀림의 차별 지점이 명확히 드러나는가 (단순 나열 vs 차별 강조)
- [ ] "전 세계에 이 조합은 없다" 주장이 근거와 함께 적절히 배치되어 있는가
- [ ] 3개 구조적 장벽("왜 아무도 안 했나") 논리가 설득력 있는가
- [ ] ChatGPT/타로/마인드카페 각각과의 차이가 한 문장으로 요약 가능한 수준인가
- [ ] 이종 모델 오케스트레이션이 "기술 자랑"이 아닌 "사용자 가치"로 설명되어 있는가

### 축 2. 출처 신뢰도 (가장 중요)
- [ ] 모든 수치/통계에 출처가 명시되어 있는가 (양식맞춤 기준)
- [ ] 가이드북의 출처가 실제 접근 가능한 자료인가 (URL/보고서명 검증)
- [ ] "The Economist 2018" — 8년 전 자료. 현재 유효성 설명이 있는가
- [ ] "한국리서치 AI 심리상담 인식조사 2025.4" — 실존 보고서인가, 조사 방법론은
- [ ] "잡코리아×원픽 2024.10" — 실존 조사인가, 표본 크기 719명의 대표성
- [ ] "NIA·과기부 2024" — 정확한 보고서명이 있는가
- [ ] "MentalAgora (arXiv 2407.02736)" — 실존 논문인가, 저자/학회 권위
- [ ] "MedARC" — 정확한 출처가 있는가, 논문인가 기관인가
- [ ] "AIUA" — 공식 학술 용어인가, 자체 조어인가
- [ ] 출처의 권위 분포: 정부/학술/언론/자체분석 비율은 적정한가
- [ ] "Gemini Deep Research 분석 결론" — AI 분석을 출처로 쓸 수 있는가, 보강 필요한가
- [ ] 글로벌 시장 수치 출처 (Grand View Research, Mordor Intelligence) — 유료 리포트 접근 없이 인용 가능한가
- [ ] "Co-Star 2,100만 DL" — 출처 확인
- [ ] "점신 1,900만 DL / 979억" — 매일경제 2025 어떤 기사인가

### 축 3. 최근 발전 사항 반영 여부
- [ ] 글로벌화: v5 양식맞춤에 글로벌 확장 문단이 있는가, 근거 데이터가 포함되어 있는가
- [ ] 게임 UI: 텍스트 선택지 게임 UI 전환이 v5에 반영되어 있는가 (메신저→게임 전환)
- [ ] 파이프라인 개선: 이종 모델 검증 + 리서치 에이전트가 적절히 설명되어 있는가
- [ ] 재화 개념: 구슬/불씨/달빛/크레딧 재화 체계가 설명되어 있는가
- [ ] 서비스 내용: 9단계 파이프라인이 최신 설계와 일치하는가
- [ ] 고민 라우팅: Quick/Talk/Deep 분류 체계가 반영되어 있는가 (또는 반영 불필요 판단)
- [ ] 모델 저비용화: Gemini Flash-Lite 무료 티어 등 최신 비용 구조가 반영되어 있는가

### 축 4. 수치 정합성
- [ ] "세션당 250원" vs "구슬당 65원" — 양식맞춤 내 혼재 여부
- [ ] BEP 13명 계산: 85,000 ÷ 6,650 = 12.78 → "약 13명" OK인가
- [ ] 변동비 3,250원 = 100재화 × 65원 — Standard가 주 50재화(월 ~200재화)인데 100재화로 계산한 이유
- [ ] 마진율 67% 계산: (9,900 - 3,250) / 9,900 = 67.2% OK
- [ ] SOM 3,100만 원 = 200명 × 12,900원 × 12 = 30,960,000원 → "약 3,100만 원" OK
- [ ] TAM 2,000억: 979억 + 100억 + 93억 + 기타 = 합산이 2,000억에 도달하는가
- [ ] "유료 50명 이상 목표" (3단계) vs "유료 100명 목표" (4단계) — 양식맞춤 내 일관성
- [ ] 협약기간 내 100명 vs 200명 — 어디서 어떤 수치를 쓰고 있는가

### 축 5. 양식맞춤 ↔ 가이드북 일관성
- [ ] 양식맞춤의 모든 수치가 가이드북에서 근거를 찾을 수 있는가
- [ ] 가이드북에는 있지만 양식맞춤에 누락된 핵심 내용이 있는가
- [ ] 심사위원 Q&A(가이드북)가 양식맞춤에서 발생할 수 있는 질문을 모두 커버하는가

### 축 6. 표현/톤 적절성
- [ ] 예비창업자 수준에 맞는 현실적 톤인가 (과장 vs 솔직 밸런스)
- [ ] "전 세계에 없다" 류의 강한 주장에 반드시 근거가 붙어있는가
- [ ] 자기 과시적 표현이 있는가 ("혁신적", "획기적" 등)
- [ ] 약점 인정이 적절히 포함되어 있는가 (해자 약함, 매출 없음, 1인 한계)
