[첨부1] 사업계획서 요약
=====================================

[창업아이템 개요]

국내 디지털 운세/멘탈케어 시장의 확인된 매출을 합산하면 약 1,200억 원이 넘는다(점신 979억, 포스텔러 100억, 마인드카페 93억). 이 시장에서 "타로의 재미"와 "AI의 데이터 분석"을 동시에 제공하는 서비스는 12개 경쟁사를 비교한 결과 찾지 못했다. 풀림은 이 빈 자리를 노린다.

풀림은 AI 기반 의사결정 코칭 플랫폼이다. 사용자가 10개 구슬 중 3개를 고르면 Claude, GPT, Gemini 3개 AI가 각각 독립 분석한 뒤 교차 토론한다. 프롬프트를 쓸 줄 몰라도 구슬을 고르면 끝이고, 세션이 끝나면 리스크, 보상, 성향을 정리한 결론 문서와 첫 행동이 남는다.

3개 테마 세계관: 모험가(현자, 모닥불, RPG), 전략실(비서, 야경, 프로), 달빛정원(친구, 꽃밭, 힐링). PWA 웹앱, pullim.vercel.app 배포 완료. 가격은 무료(주 10재화), Standard 월 9,900원(주 50재화), Pro 월 19,900원(주 120재화). 무료도 유료와 동일 품질의 풀 파이프라인이고, 횟수로만 차등한다.

재화당 원가 약 65원. 풀 세션 원가 약 250원(보수적). Standard 기준 마진율 67%. BEP 유료 약 13명.


[창업아이템 현황 및 구체화 방안]

현황: 웹앱 프로토타입 배포 완료(pullim.vercel.app). 핵심 기능 6개 구현: 고민 복잡도별 자동 라우팅, 선택지 탭 방식 질문, Claude/GPT/Gemini 3모델 독립 분석+교차 토론, 결론 문서 생성, 2계층 위기 감지 시스템(Tier A 즉시 중단/Tier B 안전 가드), 테마별 게임화 UI. 3개 테마 동등 구현. 백엔드 API 6개(경청/리서치/분석/검증/토론/결론) 완성. 데모 모드 탑재.

미완성: Supabase 인증/DB 연동, 결제 시스템, 외부 베타 테스트. 사업자등록 2026년 4월 예정.

협약기간 산출물: Supabase 인증/히스토리 연동, Stripe 또는 토스 결제 시스템, 이용약관/개인정보처리방침 완비, 클로즈드 베타 20~30명, 유료 구독 런칭, 유료 100명 목표.

역량 활용: 대표 1인이 Claude Code + Cursor Pro로 기획~풀스택 개발 수행. AI 멀티모델 실사용 1년 경험이 파이프라인 설계의 기반. 법률/회계는 ICC 멘토링 활용.

차별점: 프롬프트 불필요(구슬 선택), 이종 3모델 분석으로 편향 감소, 세션 후 결론 문서 산출. 12개 경쟁사 5축 비교 결과 이 조합을 제공하는 서비스를 찾지 못했다. 포스텔러 심층 1회 3,000~20,000원 = 풀림 1달. O2O 상담 1회 5~15만 원 = 풀림 2.5~7.5달.

=====================================
1. 문제 인식 (Problem)
=====================================

수치로 보면 분명하다. 통계청 2025년 2월 기준, "쉬었음"이라고 답한 15~29세 청년이 역대 최고 50.4만 명이다. 일자리 밖 2030세대는 158만 명. 잡코리아와 원픽이 2024년 10월 직장인 719명을 조사한 결과 73%가 이직 고민 중이면서도 결정을 유보하고 있었다. 이들에게 부족한 것은 정보가 아니라 정보를 정리해줄 도구다.

돈은 이미 움직이고 있다. 국내 점술 시장 약 4조 원(The Economist 2018). 점신 앱 1,900만 다운로드, 매출 979억 원(매일경제 2025). 마인드카페 누적 400만 회원, 매출 93억 원(한경 2025). 글로벌 점성술/타로 앱 시장 약 40억 달러(2024). 불확실한 상황에서 "정리된 이야기"를 듣고 싶은 욕구는 숫자로 검증됐다.

그런데 기존 서비스에는 구조적 빈 자리가 있다. ChatGPT는 프롬프트를 잘 짜야 쓸 수 있고, 1개 모델이라 편향에 갇힌다. AI 상담의 핵심 불만은 효과 의심 55%, 공감 부족 52%(한국리서치 AI 심리상담 인식조사, 2025.4). 타로/점 앱은 재미 요소는 강하나 데이터 분석이 없고 행동 변화로 이어지지 않는다. 전문 심리 상담은 1회 5~15만 원이라 진입 비용이 높다. AI 상담 이용 의향 40%에 비해 실제 이용은 11%다(한국리서치 2025.4). 수요와 공급 사이의 간극이 크다.

풀림은 이 간극을 겨냥한다. 구슬을 고르는 의식적 경험(타로의 재미) 아래에, Claude/GPT/Gemini 3개 모델의 독립 분석(AI의 실질)을 배치했다. 세션이 끝나면 결론 문서와 구체적 행동이 남는다.


=====================================
2. 실현 가능성 (Solution)
=====================================

핵심 코드는 이미 완성되어 동작 중이다. pullim.vercel.app에서 확인할 수 있다. 구현 완료 항목: 핵심 기능 6개, 백엔드 API 6개, 3개 테마 동등 수준 구현, 데모 모드.

구현 완료 기능: 고민 복잡도별 자동 경로 분기, 선택지 탭 방식 질문(프롬프트 불필요), Claude/GPT/Gemini 3모델 독립 분석과 교차 토론, 결론 문서(상황 요약, 선택지, 핵심 갈림길, 첫 행동), 2계층 위기 감지(Tier A 즉시 중단 + 전문기관 안내, Tier B 안전 가드), 테마별 게임화 UI(모험가는 두루마리, 전략실은 카드, 달빛정원은 편지)

미구현: Supabase 인증/세션 히스토리, 결제 시스템(Stripe/토스), 이용약관/개인정보처리방침. 사업자등록 2026년 4월.

남은 개발은 인프라와 법적 서류다. 핵심인 AI 파이프라인과 프론트엔드 UI가 동작하고 있으므로 기술 리스크는 낮다.

기술적 차별점: 이종 모델 오케스트레이션. 단일 모델은 자기 편향을 벗어나지 못한다. 풀림은 3개 모델이 같은 고민을 독립 분석한 뒤, 상대 분석을 보고 반론한다. 모델 간 의견 불일치 지점이 사용자의 실제 갈림길이 된다. 이 구조는 멀티 에이전트 토론 아키텍처(MentalAgora, arXiv 2407.02736, NYU)에서 학술적으로 검증된 방법을 참고했다.

10개 구슬: 금화(재무), 나침반(진로), 거울(인지편향), 저울(법적), 모닥불(가치관), 타인(관계), 심연(심리), 전략(경영), 뒤집기(리프레이밍), 몸(건강). 사용자에게는 구슬 고르는 의식이고, 내부적으로는 분석 렌즈 선택이다.

개발은 대표 1인이 Claude Code(Opus/Sonnet/Haiku) + Cursor Pro로 수행한다. 비전공자이지만 AI 개발 도구를 활용하여 웹앱을 독립 구현, 배포했다.

=====================================
3. 성장전략 (Scale-up)
=====================================

경쟁 구도: 주요 4개 카테고리와 비교한다. ChatGPT 같은 범용 AI(프롬프트 장벽, 단일 모델 편향), 점신 같은 타로/운세 앱(재미 있으나 분석 없음, 건당 3,000~20,000원), 마인드카페 같은 상담 플랫폼(1회 5~15만 원, 산출물 없음), Co-Star 같은 일일 운세 앱(의사결정 도구 아님). 풀림은 프롬프트 없이 구슬 선택, 3모델 분석, 결론 문서 산출이라는 조합으로 이 중 어디에도 속하지 않는 위치에 있다.

시장 규모: TAM 약 1,200억 원 이상(국내 디지털 운세/멘탈케어 확인 매출). 글로벌 AI 멘탈헬스 시장 2025년 약 15~20억 달러에서 2030년 80~100억 달러 전망(Grand View Research, Mordor Intelligence 등, CAGR 약 30%). 글로벌 점성술/타로 앱 시장 2024년 약 40억 달러. SOM: 유료 200명, 연 약 3,100만 원(Standard 70% + Pro 30% 믹스).

시장 진입: 1~3개월 에브리타임/인스타 릴스/한성대 커뮤니티(비용 0원). 4~6개월 SEO 블로그/유튜브 숏폼(비용 0원). 7개월 이후 바이럴 카드/대학 제휴(0~30만 원/월). 세션 종료 시 도트 아트 공유 카드 자동 생성이 바이럴 엔진이다.

유료 200명 도달 퍼널(정식 출시 후 약 6~9개월): 노출 50,000명 > 방문 5,000명(10%) > 가입 1,000명(20%) > 유료 200명(20%). 보수적 전환율 5% 적용 시에도 50명이고, BEP(13명)을 넘는다.

Unit Economics 상세: 재화당 원가 약 65원(API 호출 비용, MVP 기준). 풀 세션(리서치 1 + 구슬 3 + 토론 1 = 5재화) 원가 약 250원(보수적 산출). Standard(월 9,900원) 기준 변동비 약 3,250원(주 50재화 중 실소비 약 50재화/월, 주간 소멸 정책 감안). 마진율 67%. 고정비 월 약 85,000원(Vercel, 도메인, API 기본료). BEP = 85,000 / (9,900 - 3,250) = 약 13명.

리텐션 전략: Quick Mode(일상 결정 30초 정리, 1재화), 공유 카드(바이럴), 캐릭터 리마인드 푸시, 위클리 체크인(지난주 결정 실행 추적), 월간 패턴 리포트(Pro).

투자유치: ICC IR데모데이 참여(27.01~02), BEP 달성 후 시드 라운드. B2B 확장(대학 진로상담센터, 기업 EAP).

글로벌: 텍스트 선택지 UI로 언어 의존도가 낮다. 다국어 응답은 LLM 시스템 프롬프트 수정으로 가능하여 번역 비용 없음. 국내 PMF 확인 후 영어권 진입.

리스크: 외부 유료 전환 데이터가 아직 없다. 클로즈드 베타에서 전환율을 확인하는 것이 첫 번째 과제다.

사회적 가치 - 환경: AI SaaS, 물리적 폐기물 없음. 서버리스 인프라.
사회적 가치 - 사회: O2O 상담 1회 5~15만 원 대비 풀림 월 9,900원으로 의사결정 코칭 접근성 확대. 2계층 위기 감지(AI 즉시 중단 + 109 안내). 전문 심리상담을 대체하지 않고 보완. AI 기본법(2026.1) 투명성 의무 준수.
사회적 가치 - 지배구조: 의사결정 기록 투명 경영. 사용자 자율성 존중이 제품 철학.

법률/규제: 정보서비스업 사업자등록 예정(포스텔러 선례). "상담"이 아닌 "코칭" 표현(심리상담사법 대비). 민감정보 별도 동의, 해외 API 전송 동의. 론칭 전 변호사 검토 예정.
