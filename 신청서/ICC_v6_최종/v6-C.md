[첨부1] 사업계획서 요약
=====================================

[창업아이템 개요]

중요한 결정 앞에서 머리가 멈추는 경험은 대부분의 사람이 해봤을 것이다. ChatGPT에 물어보면 답은 나오지만 그 답을 믿어야 할지 모르겠고, 타로를 보면 재미는 있지만 끝나면 남는 게 없다. 풀림은 이 둘 사이의 빈 자리를 채운다.

풀림은 AI 기반 의사결정 코칭 플랫폼이다. 이직, 진로, 연애 같은 고민을 입력하면 10개 구슬 중 3개를 고르고, Claude, GPT, Gemini 3개 AI가 각각 독립 분석한 뒤 서로 토론한다. 세션이 끝나면 리스크, 보상, 성향을 정리한 결론 문서와 "내일 할 첫 행동"이 남는다. 프롬프트를 쓸 줄 몰라도 구슬을 고르면 끝이다.

3개 세계관이 있다. 모험가(현자, 모닥불, RPG 감성), 전략실(비서, 야경, 프로 감성), 달빛정원(친구, 꽃밭, 힐링 감성). 같은 분석 파이프라인 위에 다른 분위기를 입혔다. PWA 웹앱으로 pullim.vercel.app에서 써볼 수 있다.

가격: 무료(주 10재화) / Standard 월 9,900원(주 50재화) / Pro 월 19,900원(주 120재화). 무료도 유료와 동일한 풀 파이프라인이고 횟수만 다르다.


[창업아이템 현황 및 구체화 방안]

현황: 웹앱 프로토타입을 pullim.vercel.app에 배포했다. 핵심 기능 6개가 동작한다. 고민 복잡도별 자동 라우팅, 선택지 탭 방식 질문, 3개 이종 모델(Claude/GPT/Gemini) 독립 분석과 교차 토론, 결론 문서 생성, 2계층 위기 감지(AI 즉시 중단 + 전문기관 안내), 테마별 게임화 UI. 3개 테마와 백엔드 API 6개가 모두 완성되어 있다.

아직 안 된 것: 사용자 인증과 세션 기록(Supabase 연동), 결제 시스템, 외부 사용자 베타 테스트. 사업자등록은 2026년 4월 예정.

협약기간 산출물: 인증과 결제를 붙여 정식 서비스를 출시한다. 클로즈드 베타 20~30명으로 검증하고, 유료 구독을 시작하여 협약기간 내 100명을 목표로 한다.

역량 활용: 대표 1인이 Claude Code + Cursor Pro로 기획부터 개발까지 수행. AI 실사용 1년 경험이 파이프라인 설계의 기반. 법률/회계는 ICC 멘토링으로 보완.


[목표시장 및 사업화 추진 전략]

비즈니스 모델: 재화 점진적 소모. 입장/경청은 무료이고 리서치 1재화, 구슬 분석 1재화씩, 토론 1재화. 사용자가 매 단계를 통제한다.

고객 확보: 에브리타임, 인스타 릴스, 한성대 커뮤니티에서 비용 0원으로 시작. 세션 종료 시 도트 아트 공유 카드 자동 생성.

차별점: 기존 도구의 한계를 정리하면 이렇다. ChatGPT는 프롬프트 장벽이 높고 편향에 갇힌다. 타로 앱은 재미있지만 분석이 없다. 상담은 비싸다. 풀림은 구슬 선택(재미, 진입장벽 제거) + 이종 모델 분석(편향 감소) + 결론 문서(산출물)로 세 문제를 동시에 해결한다.


[창업공간 활용계획]

대표 1명 풀타임 상주. 개인실에서 AI 도구를 음성으로 활용하며 개발한다. 공유실은 대면 테스트, 외주 미팅, 멘토링에 쓴다.

=====================================
1. 문제 인식 (Problem)
=====================================

문제: 현대인은 정보 과잉 속에서 결정을 못 한다. 통계청 2025년 2월, "쉬었음" 청년(15~29세) 역대 최고 50.4만 명. 일자리 밖 2030세대 158만 명. 잡코리아/원픽 2024.10 조사에서 직장인 719명 중 73%가 이직 고민 중인데 결정을 유보하고 있었다. 능력이 아니라 결정이 문제다.

수요는 검증됐다: 사람들은 "혼란의 정리"에 이미 돈을 쓰고 있다. 국내 점술 시장 약 4조 원(The Economist 2018). 점신 앱 1,900만 다운로드, 매출 979억 원(매일경제 2025). 마인드카페 누적 400만 회원, 매출 93억 원(한경 2025). AI 상담 이용 의향 40%지만 실제 이용 11%(한국리서치 2025.4). 수요와 공급 사이에 큰 간극이 있다.

기존 해법이 실패하는 이유:

ChatGPT 같은 범용 AI: 빈 화면에 프롬프트를 잘 써야 답이 나온다. AI에 익숙하지 않으면 쓸 수 없다. 1개 모델이라 편향에 갇리고, "이 답이 맞나?" 확인할 방법이 없다. AI 상담 핵심 불만은 효과 의심 55%, 공감 부족 52%다(한국리서치 2025.4).

타로/점 앱: 재미있고 접근성이 좋다. 카드를 고르는 순간 집중이 되고 해석을 듣다 보면 생각이 정리되는 느낌이 있다. 하지만 데이터 기반 분석은 없고, "조심하세요" "좋은 기운이 옵니다" 수준에서 끝난다. 행동 변화로 이어지지 않는다.

전문 상담: 효과는 있지만 1회 5~15만 원이라 접근성이 낮다. 세션 후 정리된 문서가 남지 않는 경우가 많다.

풀림의 해법: 프롬프트 대신 구슬을 고르게 해서 진입장벽을 없앴다. Claude, GPT, Gemini 3개 모델이 따로 분석하고 서로 토론하게 해서 편향을 줄였다. 세션이 끝나면 결론 문서와 구체적 첫 행동이 남게 했다. 구슬을 고르는 과정이 집중을 만들고, 뒤에서는 AI가 데이터 기반 분석을 수행한다.


=====================================
2. 실현 가능성 (Solution)
=====================================

기존 개발 방식의 문제: 의사결정 코칭 서비스를 만들려면 프론트엔드, 백엔드, 멀티 AI 연동, 안전 시스템, 세계관 디자인이 동시에 필요하다. 전통적으로는 최소 2~3명 팀이 수개월 걸릴 작업이다.

풀림의 접근: Claude Code라는 AI 개발 도구를 활용하면 비전공자 1인이 풀스택 개발을 할 수 있다. 실제로 이 방법으로 핵심 기능 6개, 백엔드 API 6개, 3개 테마를 구현하고 pullim.vercel.app에 배포했다.

현재 동작하는 기능: (1) 고민 복잡도를 판단하여 경로를 자동 분기하는 라우팅 (2) 프롬프트 없이 선택지를 탭하는 질문 방식 (3) Claude/GPT/Gemini가 각각 독립 분석 후 교차 토론 (4) 결론 문서 생성(상황 요약, 선택지, 핵심 갈림길, 첫 행동) (5) 위기 감지 2계층 시스템(Tier A: 자살/자해 키워드에 AI 즉시 중단 + 전문기관 109/1577-0199/1588-9191 안내, Tier B: 절망/무력감에 안전 가드 추가) (6) 3개 테마별 게임화 UI(모험가 두루마리/전략실 카드/달빛정원 편지). 데모 모드도 있어서 API 키 없이 서비스 흐름을 확인할 수 있다.

남은 과제: Supabase 인증/세션 기록, 결제 시스템(Stripe 또는 토스), 이용약관/개인정보처리방침, 사업자등록(26년 4월). 핵심인 AI 파이프라인은 이미 작동하므로 남은 것은 인프라와 법적 서류다.

기술적 차별점: 이종 모델 오케스트레이션. 기존 문제는 단일 AI 모델이 자기 편향을 알지 못한다는 것이다. 풀림의 해법은 Claude, GPT, Gemini를 같은 고민에 독립 배치하고 서로 반론하게 하는 것이다. 모델 간 의견 불일치가 사용자의 진짜 갈림길을 드러낸다. 이 구조는 MentalAgora(arXiv 2407.02736, NYU)에서 학술적으로 효과가 확인된 멀티 에이전트 토론 방법을 참고했다.

10개 구슬: 금화(재무), 나침반(진로), 거울(인지편향), 저울(법적), 모닥불(가치관), 타인(관계), 심연(심리), 전략(경영), 뒤집기(리프레이밍), 몸(건강). 사용자에게는 구슬 의식이고, 시스템에서는 분석 렌즈 선택이다.

=====================================
3. 성장전략 (Scale-up)
=====================================

경쟁사 분석: 기존 서비스들은 각각 문제가 있다.

ChatGPT(범용 AI): 프롬프트를 잘 짜야 쓸 수 있고, 모델 하나라 편향에 갇힌다. 풀림과 비교하면 진입장벽이 높고 산출물이 대화 형태로만 남는다.

점신, 포스텔러(타로/운세): 재미있고 접근성이 좋지만 데이터 분석은 없다. 건당 3,000~20,000원. 세션 후 행동 변화로 연결되지 않는다.

마인드카페(상담 플랫폼): 1회 5~15만 원. 세션 후 정리 문서가 없는 경우가 많다.

Co-Star(일일 운세): 매일 보는 루틴이지 의사결정 도구는 아니다.

풀림의 위치: 프롬프트 불필요(구슬 선택), 이종 3모델 분석, 결론 문서 산출이라는 조합은 12개 경쟁사를 비교한 결과 찾지 못했다.

시장 규모: TAM 약 1,200억 원 이상(점신 979억 + 포스텔러 100억 + 마인드카페 93억, 확인 매출 합산). 글로벌 AI 멘탈헬스 시장 2030년 80~100억 달러 전망(Grand View Research, Mordor Intelligence 등). SOM: 유료 200명, 연 약 3,100만 원.

시장 진입: 문제는 "어떻게 첫 사용자를 데려오는가"다. 풀림의 접근: 1~3개월차 비용 0원으로 에브리타임, 인스타 릴스, 한성대 커뮤니티에서 시작한다. 4~6개월차 SEO 블로그와 유튜브 숏폼 추가. 7개월 이후 바이럴 카드와 대학 제휴로 확장. 세션 종료 시 도트 아트 카드가 자동 생성되어 카카오톡이나 인스타로 공유할 수 있다.

유료 200명 도달(정식 출시 후 6~9개월): 노출 50,000명 > 방문 5,000명(10%) > 가입 1,000명(20%) > 유료 200명(20%). 보수적 전환율 5% 시 50명. BEP는 13명이므로 달성 가능하다.

비즈니스 모델과 Unit Economics: 재화 점진적 소모 + 구독. 재화당 원가 약 65원, 풀 세션 약 250원(보수적). Standard(9,900원/월) 기준 마진율 67%. 고정비 월 85,000원. BEP 유료 약 13명.

투자유치: ICC IR데모데이(27.01~02) 참여. BEP 달성 후 시드 라운드. B2B 확장(대학 진로상담센터, 기업 EAP).

글로벌 확장: 텍스트 선택지 UI라서 언어 의존도가 낮다. 다국어 응답은 LLM 시스템 프롬프트 수정으로 가능, 번역 비용 없음. 국내 PMF 검증 후 영어권.

리스크: 외부 사용자 유료 전환 데이터가 아직 없다. 클로즈드 베타에서 전환율 가설을 확인하는 것이 최우선 과제다.

사회적 가치 - 환경: AI SaaS로 물리적 폐기물 없음. 서버리스 인프라로 에너지 효율적.
사회적 가치 - 사회: 전문 상담 1회 5~15만 원 대비 풀림 월 9,900원. 접근성을 넓힌다. 위기 감지 시 AI 즉시 중단, 109 안내. 전문 심리상담을 대체하지 않고 보완한다. AI 기본법(2026.1) 투명성 의무 준수.
사회적 가치 - 지배구조: 의사결정 기록 투명 경영. 사용자 자율성 존중.

법률/규제: 정보서비스업 사업자등록 예정(포스텔러 선례). "상담" 대신 "코칭"으로 심리상담사법 리스크 회피. 민감정보 별도 동의, 해외 API 전송 동의. 론칭 전 변호사 검토 예정.

4. 팀 구성 (Team)
=====================================

문제: 의사결정 코칭 서비스를 만들려면 기획, 개발, AI 연동, 법적 판단이 동시에 필요하다. 초기 스타트업이 이걸 다 채용하면 PMF 검증 전에 자금이 소진된다.

풀림의 접근: 1인이 다 한다. 한성대 기업경영트랙에서 BM 설계와 재무 계획을 배웠고, 법&정책트랙에서 AI 규제와 개인정보보호를 다뤘다. Claude Code와 Cursor Pro라는 AI 개발 도구로 비전공자임에도 웹앱을 독립 개발하여 pullim.vercel.app에 배포했다.

AI 역량: 1년간 Claude, GPT, Gemini를 병렬로 쓰면서 각 모델의 강점과 편향을 익혔다. 이 실사용 경험이 이종 모델 파이프라인 설계의 기반이다. AI를 "사용하는" 수준이 아니라 "오케스트레이션하는" 수준에 있다.
