[창업아이템 개요]

나는 1년 넘게 Claude, GPT, Gemini를 나란히 열어놓고 인생의 결정을 정리해왔다. 모델 하나만 쓰면 그 모델의 시각에 갇혔고, 타로를 보면 재미는 있는데 끝나면 남는 게 없었다. 세 모델의 답을 비교하면 비로소 "확실한 부분"과 "내가 직접 판단해야 할 부분"이 나뉘었다. 이 경험을 서비스로 만든 것이 풀림이다. 풀림은 이직, 진로, 연애 같은 인생의 선택 앞에서 생각을 정리해주는 AI 의사결정 코칭 플랫폼이다. 사용자가 10개 구슬 중 3개를 고르면 Claude, GPT, Gemini가 각각 독립 분석하고 서로 토론한다. 세션이 끝나면 리스크, 보상, 성향을 정리한 결론 문서와 구체적인 첫 행동이 남는다. ChatGPT처럼 프롬프트를 잘 써야 하는 게 아니라, 구슬을 고르면 끝이다. 구슬을 고르는 과정이 타로처럼 재미있고, 뒤에서는 3개 AI가 데이터 기반 분석을 돌린다. 세계관은 3개다. 모험가(현자, 모닥불, RPG 감성), 전략실(비서, 야경, 프로 감성), 달빛정원(친구, 꽃밭, 힐링 감성). 같은 분석 파이프라인 위에 서로 다른 분위기를 입혔다. PWA 웹앱으로 pullim.vercel.app에서 바로 써볼 수 있다. 가격은 무료(주 10재화), Standard 월 9,900원(주 50재화), Pro 월 19,900원(주 120재화). 무료도 유료와 동일한 풀 파이프라인 품질이고, 횟수만 다르다.


[창업아이템 현황 및 구체화 방안]

지금까지 만든 것: 웹앱을 pullim.vercel.app에 배포했다. 핵심 기능 6개가 전부 동작한다. 고민 복잡도에 따라 자동으로 경로를 분기하는 라우팅, 프롬프트 대신 선택지를 탭하는 질문 방식, Claude/GPT/Gemini 3개 모델의 독립 분석과 교차 토론, 상황 요약과 선택지와 첫 행동을 담은 결론 문서, 위기 키워드 감지 시 AI를 즉시 중단하고 자살예방상담전화 109를 안내하는 안전 시스템, 구슬 선택 애니메이션과 테마별 세계관의 게임화 UI까지 모두 구현했다. 3개 테마와 백엔드 API 6개(경청, 리서치, 분석, 검증, 토론, 결론)도 완성되어 있다. 아직 안 된 것: 사용자 인증과 세션 기록 저장(Supabase 연동), 결제 시스템, 외부 사용자 대상 본격 베타 테스트. 사업자등록은 2026년 4월 예정이다. 협약기간 산출물: 인증과 결제 시스템을 붙여 정식 서비스를 출시한다. 클로즈드 베타 20~30명으로 실사용 데이터를 모으고 대면 인터뷰로 제품을 개선한다. 유료 구독을 시작하여 협약기간 내 유료 100명을 목표로 한다. 역량 활용: Claude Code와 Cursor Pro로 기획부터 개발까지 혼자 수행한다. AI를 1년간 실생활 의사결정에 쓴 경험이 파이프라인 설계의 기반이다. 법률과 회계는 ICC 멘토링 프로그램으로 보완한다.


[목표시장 및 사업화 추진 전략]

비즈니스 모델: 재화를 점진적으로 소모하는 방식이다. 입장과 경청은 무료, 리서치에 1재화, 구슬 분석에 1재화씩, 토론에 1재화가 든다. 사용자가 매 단계마다 계속 여부를 결정한다. 무료도 유료와 같은 품질이고, 횟수만 다르다. 고객 확보: 초기에는 비용 0원으로 에브리타임, 인스타 릴스, 한성대 커뮤니티에서 시작한다. 세션이 끝나면 구슬 3개와 핵심 갈림길을 도트 아트 카드로 만들어 카카오톡이나 인스타에 공유할 수 있다. 차별점: 타로 앱은 접근성이 좋지만 분석이 없고, ChatGPT는 분석은 되지만 프롬프트를 잘 써야 쓸 수 있다. 풀림은 구슬 선택이라는 쉬운 시작점에 이종 모델 분석을 얹었다. 12개 경쟁 서비스를 5개 축으로 비교했지만, 이 조합을 단일 서비스에서 제공하는 곳은 없었다.

[1. 문제 인식]

통계청이 2025년 2월에 발표한 숫자에서 나는 내 또래를 봤다. "쉬었음"이라고 답한 15~29세 청년이 역대 최고 50.4만 명. 일자리 밖 2030세대는 158만 명이다(통계청 2025.2). 잡코리아와 원픽이 직장인 719명을 조사했더니 73%가 이직을 고민하면서도 결정을 미루고 있었다(잡코리아x원픽 2024.10). 능력이 없어서가 아니라 선택을 못 해서 멈춰 있다.
나도 그랬다. 1년 전, 진로 앞에서 머리가 아팠다. ChatGPT에 물어보니 그럴듯한 답이 나왔는데, 그게 맞는 건지 확인할 길이 없었다. 타로를 보러 갔더니 재미는 있었다. 카드를 고르는 순간 집중이 되고, 해석을 듣는 동안 생각이 정리되는 느낌이었다. 문제는 끝나고 나면 남는 게 없다는 것이었다. 구체적인 데이터나 행동 계획 없이 "조심하세요" 같은 말만 남았다.
이 시장은 이미 돈이 된다. 국내 점술 시장은 약 4조 원 규모이고(The Economist 2018), 점신 앱 하나가 1,900만 다운로드에 매출 979억 원이다(매일경제 2025). 마인드카페는 누적 400만 회원에 매출 93억 원(한경 2025). 불확실한 상황에서 "정리된 이야기"를 듣고 싶은 욕구가 있고, 사람들은 거기에 돈을 쓴다.
그런데 기존 도구에는 빈 자리가 있다. ChatGPT에서 좋은 답을 얻으려면 프롬프트를 잘 짜야 하는데, 그걸 할 줄 아는 사람이 얼마나 될까. 게다가 모델이 하나라서 편향에 갇린다. 한국리서치가 2025년 4월에 조사한 결과, AI 상담의 핵심 불만은 "효과 의심" 55%와 "공감 부족" 52%였다. 타로나 점 앱은 접근성은 좋은데 끝나면 "조심하세요" 말고 남는 게 없다. 전문 상담은 1회에 5~15만 원이라 선뜻 가기 어렵다. AI 상담 이용 의향은 40%인데 실제 이용은 11%다(한국리서치 2025.4). 원하는 사람은 많은데 쓸 만한 서비스가 없는 상태다.
그래서 풀림을 만들었다. 타로처럼 구슬을 고르면 집중이 되고, 뒤에서 3개 AI가 각각 분석한 뒤 서로 반론한다. 끝나면 결론 문서와 "내일 할 첫 행동"이 남는다.


[2. 실현 가능성]

이미 만들어서 돌리고 있다. pullim.vercel.app에 접속하면 3개 테마 중 하나를 골라 세션을 시작할 수 있다. 고민을 입력하면 AI가 경청하고, 구슬을 고르면 Claude, GPT, Gemini가 각각 분석하고, 서로 토론하고, 결론을 내린다. 체험용 데모 모드도 있어서 API 키 없이도 서비스 흐름을 확인할 수 있다.
나는 비전공자다. 컴퓨터공학을 배운 적이 없다. Claude Code라는 AI 개발 도구를 사용하면 "이런 기능이 필요하다"고 설명했을 때 코드가 나온다. 이 방식으로 핵심 기능 6개와 백엔드 API 6개를 구현했고, 3개 테마를 동등한 수준으로 완성했다.
현재 동작하는 것: 고민 복잡도별 자동 경로 분기, 선택지 탭 방식 질문(프롬프트 불필요), 3개 이종 모델 독립 분석과 교차 토론, 결론 문서(상황 요약/선택지/두려움/첫 행동), 위기 감지 시 AI 즉시 중단과 전문기관 안내(109/1577-0199/1588-9191). 위기 감지는 2계층이다. Tier A(자살, 자해 등)에서는 AI가 즉시 멈추고, Tier B(절망, 무력감)에서는 안전 가드가 추가된다. 게임화 UI는 테마별로 다른 스타일(모험가는 두루마리, 전략실은 카드, 달빛정원은 편지)로 구현했다.
남은 개발: 사용자 인증과 세션 기록(Supabase), 결제(Stripe 또는 토스), 이용약관과 개인정보처리방침, 사업자등록(26년 4월). AI 파이프라인이라는 핵심은 이미 동작하고, 남은 것은 인프라와 법적 서류다. 기술적으로 큰 리스크는 없다고 판단한다.
기술적으로 가장 다른 점은 이종 모델 오케스트레이션이다. 1년간 AI를 쓰면서 느낀 건, 같은 질문을 해도 Claude와 GPT와 Gemini가 다른 답을 낸다는 것이었다. 이 차이가 중요하다고 생각했다. 풀림은 세 모델이 같은 고민을 따로 분석하고, 서로의 결과를 보고 반론하게 했다. 의견이 갈리는 지점이 사용자가 실제로 고민해야 할 부분이다. 이 구조는 멀티 에이전트 토론 아키텍처(MentalAgora, arXiv 2407.02736, NYU)의 설계를 참고했다.
구슬은 10개다. 돈 문제라면 금화, 커리어라면 나침반, 자기 편향을 들여다보고 싶으면 거울을 고른다. 관계 고민에는 타인, 심리적으로 깊이 파고 싶으면 심연이 있다. 사용자는 구슬을 고르는 것이고, 시스템은 분석 렌즈를 세팅한다.

[3. 성장전략]

경쟁사를 분석했다. 주요 경쟁 카테고리는 4개다. ChatGPT 같은 범용 AI는 프롬프트를 잘 짜야 쓸 수 있고 모델 하나의 시각에 갇린다. 점신 같은 타로/운세 앱은 재미는 있지만 데이터 기반 분석이 없다. 마인드카페 같은 상담 플랫폼은 1회 5~15만 원이라 접근성이 낮다. Co-Star 같은 운세 앱은 매일 보는 루틴이지 의사결정 도구가 아니다.
풀림이 다른 이유: 프롬프트 없이 구슬을 고르면 되기 때문에 AI를 모르는 사람도 쓸 수 있다. 3개 모델이 따로 분석하고 서로 토론해서 한 모델의 편향에 갇히지 않는다. 세션이 끝나면 결론 문서가 남는다. 12개 경쟁 서비스를 비교한 결과, 이 조합을 단일 서비스에서 제공하는 곳을 찾지 못했다.
시장 진입 전략: 초기 3개월은 비용 0원으로 에브리타임, 인스타 릴스, 한성대 커뮤니티에서 시작한다. 4~6개월째 SEO 블로그와 유튜브 숏폼을 추가한다. 7개월 이후에는 바이럴 공유 카드와 대학 제휴로 확장한다. 세션이 끝나면 도트 아트 카드가 자동 생성되어 카카오톡이나 인스타 스토리에 공유할 수 있다. 직접 써본 사람이 공유하는 것이 가장 효과적인 채널이라고 생각한다.
비즈니스 모델: 재화 점진적 소모 + 구독. 재화당 원가 약 65원(API 호출 비용, MVP 기준). 풀 세션은 5재화(리서치 1 + 구슬 3 + 토론 1)이고 최대 원가 325원이나, 모든 사용자가 5재화를 전부 소모하지는 않으므로 평균 소비 기준 약 250원으로 산출했다. Standard(월 9,900원) 기준 변동비 약 3,250원/월(실소비 약 50재화/월 기준), 마진율 67%. 고정비 월 약 85,000원(서버, 도메인, API 기본료). BEP = 85,000 / (9,900 - 3,250) = 유료 약 13명.
시장 규모: 국내 디지털 운세/멘탈케어 시장 확인 매출 약 1,200억 원 이상(점신 979억(매일경제 2025), 포스텔러 100억(한경 2025), 마인드카페 93억(한경 2025)). 글로벌 AI 멘탈헬스 시장은 2025년 약 15~20억 달러에서 2030년 80~100억 달러 성장 전망이다(Grand View Research, Mordor Intelligence 등). 글로벌 점성술/타로 앱 시장도 2024년 약 40억 달러에서 급성장 중이다.
목표: 정식 출시(26.10) 후 6~9개월에 유료 200명 도달, 연 약 3,100만 원(Standard 70% + Pro 30% 믹스). 노출 50,000명에서 방문 5,000명(10%), 가입 1,000명(20%), 유료 200명(20%). 보수적 전환율 5%로 잡아도 50명이고, BEP(13명)는 넘는다.
투자유치: ICC IR데모데이 참여로 초기 투자 기회를 잡는다. BEP 달성 이후 시드 라운드를 준비한다. B2B는 대학 진로상담센터와 기업 EAP로 확장 가능하다.
글로벌 확장: 텍스트 선택지 기반 UI라서 언어 의존도가 낮다. 다국어 응답은 AI API 시스템 프롬프트 수정으로 가능하여 별도 번역 비용이 없다. 국내 PMF 검증 후 영어권 진입이 목표다.
아직 외부 사용자의 유료 전환 데이터가 없다. "재미있어서 돌아온다"는 내 경험이지 시장 검증은 아니다. 클로즈드 베타 20~30명에서 이 가설을 확인하는 것이 가장 먼저 할 일이다.
사회적 가치: 서버 위에서 돌아가는 앱이라 물리적 폐기물이 없다. 전문 상담 1회에 5~15만 원인 것에 비해 풀림은 월 9,900원이고, 위기 감지 시 AI가 즉시 멈추고 전문기관(109)을 안내한다. 의사결정 기록을 남기는 투명 경영 체계를 운용하고, AI 기본법(2026.1) 투명성 의무를 준수할 예정이다.
법률/규제: 정보서비스업으로 사업자등록 예정(포스텔러 선례). "상담"이 아닌 "코칭"으로 표현하여 심리상담사법 리스크를 회피했다. 민감정보 별도 동의, 해외 API 전송 동의. 론칭 전 변호사 검토 예정.

[4. 팀 구성]

나는 한성대학교에서 기업경영트랙과 법&정책트랙을 동시에 밟고 있다. 경영 수업에서 BM 설계와 재무 계획을 배웠고, 법정책 수업에서 AI 규제와 개인정보보호를 다뤘다. 두 트랙이 풀림의 사업 기획과 법적 설계에 그대로 쓰이고 있다.
기술력은 교과서가 아니라 실전에서 왔다. 1년간 Claude, GPT, Gemini를 매일 병렬로 쓰면서 각 모델의 강점과 편향을 몸으로 익혔다. 이 경험이 이종 모델 파이프라인 설계의 기반이다. Claude Code와 Cursor Pro를 활용하여 비전공자임에도 웹앱을 독립 개발하고 배포했다. pullim.vercel.app에서 확인할 수 있다.
