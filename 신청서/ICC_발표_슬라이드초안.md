## 슬라이드 2 — 문제 + 기존 앱 한계 (~1분 20초)

막막한 순간, 어디로 가세요?
- 오프라인 상담: 비싸고 · 예약 대기 · "그 정도 고민인가?" 부담
- AI 챗봇: 맥락 놓침 · 동의만 · 새로운 시각 없음 · 게임화 없어 일하는 느낌 · 수정 답답 · 대화 길면 앞 내용 잊음
- 기존 멘탈케어 앱: 문제를 정리해서 소명해야 함 · 콘텐츠/유료 유도 위주 · 게임형은 도피

실제 리뷰 (구글 플레이):
- "똑같은 질문밖에 할줄 모르고, 결국 검색창처럼 쓰게 됨"
- "앵무새처럼 답변하고, 분석해주길 바랐는데 그러질 않음"
- "그냥 잘 들어줄 뿐이라면 돈을 지불해야할 가치가 무언가요?"

**핵심:** "진짜 막막할 때, 자기 문제를 정리해서 말하는 건 매우 어렵다. 아무도 해결 안 하고 있었다."

## 슬라이드 3 — 풀림이 해주는 것 (한눈에) (~40초)

기존 앱이 못 주는 것을 풀림이 해결합니다.

1. 에너지 적응형 사다리 — 힘들면 내려가고, 괜찮으면 올라감
2. 이종모델 분석 — 여러 AI가 독립 분석, 편향에 갇히지 않음
3. 이종모델 내면사고 — AI 파악을 요약 공개, 잘못되면 바로 피드백
4. 이종모델 리서치 — 여러 관점에서 조사, 결정 재료 제공
5. 5개 테마 세계관 — 게임형 몰입 + 실제 고민 연결

**핵심:** "선택하기 어려워? 다 해줄게. 따라오기만 하면 돼. 아니면 네가 이끌어도 돼."

## 슬라이드 4 — 사다리 상세 (~1분 10초)

사다리 — 사용자 에너지 적응형 시스템

Lv4: 직접 입력 (괜찮을 때)
Lv3: 선택지 고르기
Lv2: 감각으로 고르기
Lv1: 이거 좋아? (힘들 때)
+ 리서치/분석이 각 단계를 보조

근거: 멘탈헬스 앱 사용자 82%가 1~2일 안에 이탈 — 빈 입력창이 원인 (JMIR 2023)

**핵심:** "어려우면 내려가고, 괜찮으면 올라간다. 끝까지 포기하지 않으면서 강요하지 않는다."
**시뮬:** "하기 싫어? 내일 하자. 이것도 못하겠어? 이거 해보자. 모르겠어? 리서치 줄게."

## 슬라이드 5 — 이종모델 + 내면사고 + 리서치 (~50초)

왜 AI를 여러 개 쓰는가

- 분석: 여러 AI 독립 분석 → 의견 갈리는 지점 = 사용자가 고민해야 할 부분
- 내면사고: AI 파악을 한두 문장으로 요약 → 클릭해서 확인 → 잘못되면 바로 피드백
- 리서치: 여러 관점에서 조사 · 비교 → 결정 재료 제공

근거: MentalAgora (arXiv 2407.02736, NYU) — 이종모델이 단일 모델보다 품질 우수

**핵심:** "모델 하나면 편향에 갇힌다."

## 슬라이드 6 — 테마 세계관 (~30초)

5개 테마:
- 모험가의 숲 (도전) / 전략가의 방 (문제해결) / 달빛정원 (힐링) / 천문대 (탐색) / 종말 (자극)

테마마다 다른 이미지 · BGM · 말투 · 추측도 · 공감도 제공
원하는 곳에 찾아가는 자유로운 경험, 선택이 부담스러울 경우 자동 매칭 기능 존재

**핵심:** 테마 5개 이름을 한 번은 말한다.

| 질문 | 답변 |
|------|------|
| 실제 사용자 반응? | 20명 UI 테스트, 피드백 5건 외 긍정적. 익명 피드백 3건 포함. |
| 수익 모델? | 3티어 구독 (무료/심화/프리미엄). 기존 가격(9,900/19,900) 참고. BEP 유료 ~13명. |
| ChatGPT랑 뭐가 달라? | UX 레이어. 사다리+테마+내면사고. 일반인이 스스로 만들어 쓰기 어려움. |
| 상담 앱이랑? | 인간 연결 안 함. 상담=치유, 풀림=의사결정. 코칭 도구. |
| 사용자 확보? | 에브리타임. 심리테스트 결과 공유. 마케팅 0원. |
| 서류랑 달라진 거? | 13개 앱 체험 후 전면 재설계. 사전 확인함. 실행력 증빙. |
| 비용 구조? | 모델 테스트 후 산출. 세션 유형별 다름. 관리 가능 수준. |
| 이종모델 근거? | MentalAgora (NYU, arXiv 2407.02736). |
| 시장 진짜 있어? | 아무도 시도를 안 한 것. 기존 앱 불만 리뷰가 반복됨. 확신의 근거: 나, 주변, 소비자 불만. |
| 1인인데 확장? | 기획개발배포 혼자 완료. 빠른 판단+반영이 강점. 성장 시 팀 확장. |
| 리텐션 어떻게? | 약속 기능(if/then) 예정 + 내면사고 피드백 루프 + 테마 확장 |
| 사다리 근거? | 멘탈헬스 앱 82% 이탈(JMIR 2023). 빈 입력창 = 이탈 원인. 선택지>자유텍스트(Nguyen 2022). |
| 테마 뭔 차이? | 이미지/BGM/말투/추측도/공감도가 다름. 기능은 동일. |
