### "핵심 기능: 사용자가 10개 수정구슬 중 3개를 고르면 Claude/GPT/Gemini 3개 AI 모델이 각각 독립 분석"

왜 "10개 수정구슬 중 3개"인가:
- 타로의 메이저 아르카나 22장 → 너무 많음. 사용자가 3개를 고르기에 10개가 적정 (인지 부하 vs 선택의 다양성 밸런스).
- 구슬 선택이 "분석 렌즈를 직접 고르는" 행위로서, 사용자에게 주체성을 부여하고 타로의 "카드 뽑기" 의식을 재현하되 내부는 분석 렌즈.
- 출처: 끝판왕 파이프라인 설계 문서

왜 "이종 3개 모델"인가:
- 같은 모델 3개(v2) = 자문자답. 다른 모델 3개 = 진짜 불일치.
- 모델마다 학습 데이터, 아키텍처, 편향이 다르기 때문에 불일치 지점이 실제로 존재함. 이 불일치가 고민의 핵심 갈림길.
- 학술 근거: MentalAgora (arXiv 2407.02736) — 멀티 에이전트 토론이 단일 모델보다 우수.

심사위원 예상 질문: "Claude/GPT/Gemini를 다 붙이면 비용이 너무 비싸지지 않나?"
답변 가이드: "API 가격이 급락했습니다. Gemini 2.5 Flash는 하루 1,500회 무료입니다. GPT 4.1 mini 기준 세션당 약 30원. 풀 파이프라인 보수적으로 잡아도 세션당 250원이고, 이것이 사업계획서에 쓴 수치입니다. 3자 교차검증(Claude+GLM-5+GPT)이 수렴한 수치입니다."

### "9단계 파이프라인"

각 단계의 존재 이유:

1단계 고민 입력 + 자동 라우팅: 모든 고민이 같은 깊이가 아님. "점심 뭐 먹지"와 "이직할까"는 다른 파이프라인이 필요. Haiku가 복잡도(가역성/중요도/긴급성/감정관여도)를 판단해서 Quick Mode 또는 풀 파이프라인으로 자동 분기.

2단계 리서치: 감정이 아니라 데이터 기반 분석이 차별점. "느낌"이 아니라 "사실" 위에서 판단. Tavily API 실시간 검색 설계. 경쟁사(타로, 마인드카페) 모두 리서치 기능 없음.

3단계 팩트체크: 리서치 결과의 신뢰성 확보. LLM 환각(hallucination) 방지. MedARC 프레임워크: LLM 상호 비판이 환각을 방지한다는 학술 검증.

4단계 구슬 선택: 사용자에게 "분석 관점을 직접 고르는" 주체성 부여. 프론트엔드는 리추얼, 백엔드는 추론.

5단계 이종 모델 병렬 분석: 같은 모델 3개 = 인위적 차이. 다른 모델 3개 = 진짜 불일치. MentalAgora (arXiv 2407.02736) 학술 검증.

6단계 교차 토론: 자기합리화 방지. 모델 A의 분석을 모델 B가 반박. 진짜 약점 노출. MentalAgora + MedARC 프레임워크.

7단계 최종 검증: Judge 모델이 전체 논리 흐름의 모순/비약 체크. Haiku를 Judge로 쓰는 이유: 저비용 + 빠른 응답 + 검증에 충분한 성능.

8단계 결론: "신중히 하세요" 같은 빈말이 아닌 리스크/보상/확률/성향을 담은 구조화된 산출물. 경쟁사 분석 결과: ChatGPT="신중히", 타로="이렇게 될 것", 마인드카페="힘드시겠어요" → 모두 행동으로 이어지지 않음.

9단계 행동 약속: "뭘 해볼 건가?" → 구체적 행동 + 기한 → 푸시 리마인드. 경쟁제품 5축 분석에서 "행동 연결" 축 최고 평가는 풀림과 BetterUp만.

### 3테마 세계관 테이블

왜 3테마인가:
- 게임의 "스킨" = 프리미엄. 같은 파이프라인이지만 다른 분위기. 달빛정원/전략실을 프로 티어 전용으로 잠금 → 업그레이드 동기.
- 모험가를 먼저 구현한 이유: RPG 감성이 가장 독특하고 차별화 강함. 도트 아트 + 모닥불 + 현자 = 기억에 남는 첫인상.
- 전략실: "현실 전문가 브리핑" 톤. 게임 감성이 싫은 사용자를 위한 진지한 모드.
- 달빛정원: 파스텔, 힐링 감성. 연애/감성적 고민에 최적.
- 출처: .state/decisions/2026-03-19_끝판왕_컨셉확정.md

심사위원 예상 질문: "왜 여러 테마가 필요한가?"
답변 가이드: "같은 파이프라인인데 테마가 세 개인 이유는 두 가지입니다. 첫째, 사용자 취향 차이입니다. RPG 감성을 싫어하는 사람이 전략실을 선택합니다. 둘째, 수익화 수단입니다. 달빛정원과 전략실은 Pro 티어 전용으로 잠겨 있어 업그레이드 동기가 됩니다."

- 이것이 타로 앱(건당 결제)과의 차별점. 먼저 경험하게 하고 설득하는 모델.

### Unit Economics: "재화당 원가 약 65원, 풀 세션 약 250원(보수적), 월 마진율 67%, BEP 유료 약 13명"

비용 수치 3단계 (혼동 주의):

65원: 재화 1개당 MVP 원가. 재화 모델 설명 시 사용.
120원: 가중 평균 세션 비용. 가벼운 고민(60%) × 50원 + 중간(25%) × 150원 + 무거운(15%) × 250원 = 약 120원. 실제 운영 원가 추정 시 사용.
250원: 풀 파이프라인 1회 보수적 원가. 사업계획서 공식 수치 (worst case).

250원 구성: 시스템 프롬프트 토큰 + reasoning tokens + 재시도 + 이종 모델 3개 호출.
검증: 3자 교차검증 완료 (Claude + GLM-5 + GPT-5.4). 이론 최소 160원 / 현실 200원 / 보수적 250원.
출처: .state/projects/ICC_지원.md 비용 수치 항목. API 가격표 기준: Anthropic/OpenAI/Google API 공식 가격 (2026-03).

BEP 계산:
- 고정비: 월 약 85,000원 (Vercel Pro 20,000원 + 도메인 2,000원 + Tavily Pro 50,000원 + 기타 13,000원)
- 순이익/인: 9,900원(월구독) - 3,250원(월 변동비) = 6,650원
- BEP = 85,000 ÷ 6,650 ≈ 13명

심사위원 예상 질문: "65원이랑 250원이랑 왜 다른가?"
답변 가이드: "65원은 재화 1개 단위 원가입니다. 250원은 풀 파이프라인, 즉 이종 모델 3개 + 리서치 + Judge 검증까지 1회 전체 원가입니다. 가벼운 고민은 재화 1~2개(65~130원), 풀 분석은 4~6재화(250원)입니다. 사업계획서에는 최악의 시나리오인 250원을 적용했습니다."

### TAM/SAM/SOM

- 산출 방식: 바텀업. 점신 979억(매일경제 2025) + 포스텔러 약 100억(한경 2025) + 마인드카페 93억(한경 2025) + 기타 디지털 자기계발/운세 합산.
- TAM을 "한국 점술 시장 4.6조(The Economist 2018)"로 잡지 않고 실제 디지털 결제가 일어나는 영역만 계산한 이유: 현실성. 4.6조는 오프라인 포함 전체 시장이므로 과장으로 보일 수 있음.

- 생성형 AI 이용률 33%(NIA·과기부 2024) + 2030세대 약 1,570만 명 중 디지털 결제 활성 유저 → 50~100만 명 추정.
- 출처: NIA·과기부 2024 보고서

SOM 200명, 연 약 3,100만 원:
- 계산: 200명 × 월 평균 약 12,900원 (Standard 70% + Pro 30% 믹스) × 12개월 = 약 3,100만 원.

## 2. 실현 가능성 (Solution)

### 개발 현황 및 계획

"v1 프로토타입 배포 완료, v2 핵심 기능 5개 + 끝판왕 프론트엔드 UI 구현 완료, 끝판왕 설계 12건 완성":
- v1: pullim.vercel.app 배포 완료
- v2: 5개 핵심 기능 구현
- 끝판왕: 설계 12건 완성 + 프론트엔드 UI (백엔드 API 연결 진행 중)
- 증거: pullim.vercel.app 라이브 데모 + 소스 코드

구현 완료 기능 6개 — 각각의 근거:

1. 자동 라우팅: Haiku가 복잡도(가역성/중요도/긴급성/감정관여도) 판단. 코드에 구현됨.
2. 선택형 Socratic 질문: 프롬프트 타이핑 대신 선택지 탭. Socratic AI는 EU TITAN 프로젝트, Khanmigo 등 글로벌 트렌드.
3. 3관점 병렬 분석 및 토론: 현재(v2)는 같은 모델(Claude)이 3관점 수행. 끝판왕에서 이종 모델로 교체 예정.
4. 의사결정 정리 문서: 세션 완료 시 자동 생성.
5. 3층 위기 감지(RED 프로토콜): 위기 키워드 감지 → AI 즉시 중단 → 자살예방상담전화 109 안내. 방통위 가이드라인(2025.2) 준수.
6. 끝판왕 프론트엔드 UI: 모험가 모드 세션 페이지, 구슬 선택 애니메이션, 데이터 카드, 결론 뷰.

개발 예정 기능 4개 — 협약기간 내 구현:
- 이종 모델 오케스트레이션: 이종 모델 API 연결 = 백엔드 작업 2~3주. 이미 설계 완료 상태.
- 리서치 에이전트: Tavily API로 실시간 웹 검색 + 팩트체크.
- 비동기 처리: 파이프라인 돌려놓고 나중에 확인.
- Supabase 연동: 인증, 세션 히스토리, 개인화 패턴 분석.

심사위원 예상 질문: "이종 모델이 아직 연결 안 됐다며?"
답변 가이드: "현재 상태를 솔직히 말씀드리면 v2는 Claude 단독, 끝판왕 UI는 구현 완료이고 백엔드 API 연결이 진행 중입니다. 이종 모델 API 연결은 기술적으로 2~3주 작업입니다. 핵심은 기술 자체가 아니라 실행력입니다. 2주 만에 5개 핵심 기능을 구현·배포하고 2일 만에 설계 12건을 완성한 속도면 협약 시작 직후 구현 완료 가능합니다."

### 핵심 기술 차별화 — 이종 모델 오케스트레이션

v2 vs 끝판왕 비교:

v2 구조: Claude × 3 (같은 모델, 다른 프롬프트). 불일치가 인위적. 같은 모델 자문자답. Judge 없음.
끝판왕 구조: Claude + GPT + Gemini (다른 모델, 같은 프롬프트). 불일치가 진짜 (모델 고유 편향에서 나온 차이). 모델 간 교차 반론 (자기합리화 방지). Judge 모델 독립 검증.

이것이 풀림의 핵심 기술 차별화. 라운드 로빈 배정: 구슬 A=Claude, 구슬 B=GPT, 구슬 C=Gemini → 다음 세션에서는 배정 순환 → 모델-구슬 고착 방지.

10개 수정구슬 각각의 분석 렌즈:
- 금화 = 재무 분석
- 나침반 = 진로/커리어
- 거울 = 행동경제학/인지 편향
- 저울 = 법적/구조적
- 모닥불 = 가치관/동기
- 타인 = 관계
- 심연 = 심리 패턴
- 전략 = 경영/전략
- 뒤집기 = 철학적 리프레이밍
- 몸 = 생활/건강

### 200명 도달 퍼널

전환율 수치의 근거와 공격성 인정:

노출 → 방문 10%:
- 고관여 키워드("이직 고민" 등) 기준. 일반 광고 CTR 1~3%보다 높지만, SEO/커뮤니티는 관심 있는 사람만 유입되므로 10%가 현실적.

방문 → 가입 20%:
- 무료 세션 3회 + 세계관 경험(모닥불+현자)이 강력한 후크. SaaS 평균 가입 전환율 5~15% 대비 공격적이지만 무료 가치가 높음.

가입 → 유료 20%:
- 세계관 몰입 + 이종 모델 차별화 + 만원 이하 심리 가격. 공격적 가정임을 솔직히 인정.
- 안전장치: 5%에서도 BEP(13명) 달성.

심사위원이 "20% 전환율이 너무 낙관적이지 않은가?"라고 물을 때:
답변 가이드: "공격적 가정임을 인정합니다. 중요한 건 5% 전환에서도 BEP가 달성된다는 점입니다. 50명이면 13명 BEP를 충분히 넘습니다. 20% 목표를 잡은 이유는 무료로 동일한 품질을 제공하고, 만원 이하 심리 가격에서 전환 장벽이 낮기 때문입니다. 하지만 현실 데이터가 나오면 즉시 수정합니다."

### 매출 외 성과

각 성과의 의미:

"v1 웹앱 프로토타입 독립 개발 및 배포 완료 (pullim.vercel.app)":
- 라이브 데모가 존재한다 = "아이디어"가 아닌 "개발" 단계. 심사위원이 직접 써볼 수 있음.

"외부 테스터 2명 탐색적 테스트 완료 (v1 기준)":
- 혼자 개발한 게 아니라 실제 사용자 반응을 확인했다는 의미.

"테스트 세션 3회 완료 (v1 x 2, v2 x 1)":
- 테스트 세션 기록은 ./테스트/ 디렉토리에 있음.

"끝판왕 설계 문서 12건 + 프론트엔드 UI 구현 완료":
- 12건의 내용: 파이프라인, 이종모델, 캐릭터 3종, UI 2종, 기술스펙, 수익모델, 마케팅, 경쟁분석, 법률, 로드맵, 브레인스톰.
- 예비창업자라 매출이 없음 → "이만큼 구체적으로 준비했다"를 설계 문서로 증명.

"2주 만에 v1~v2 구현 + 2일 만에 끝판왕 설계 12건 — 실행력의 직접적 증거":
- 이 한 줄이 팀 구성 섹션의 "1인 가능한가" 질문에 대한 가장 직접적인 답변.

## [심사위원 예상 Q&A] 종합 가이드

### Q1: "ChatGPT랑 뭐가 다른가?"

논리구조:
1. 진입 장벽: ChatGPT = 프롬프트 필요. 풀림 = 구슬 3개 고르기.
2. 분석 구조: 1개 모델 확인편향 vs 3개 이종 모델 독립 분석.
3. 불일치의 가치: "모델이 동의하지 않는 지점이 당신 고민의 핵심 갈림길".
4. 접근성: AI를 모르는 사람도 사용 가능.
5. 세계관: ChatGPT는 차가운 채팅창. 풀림은 모닥불 앞 경험.

### Q2: "이종 모델이 아직 연결 안 됐다며?"

논리구조:
1. 현재 상태 솔직히 인정: v2 기능 5개 + 끝판왕 프론트엔드 UI.
2. 기술적 근거: 이종 모델 API 연결 = 백엔드 작업 2~3주. 설계는 완료.
3. 프레이밍 전환: 중요한 건 기술이 아니라 실행력. 2주 만에 5개 기능, 2일 만에 설계 12건.

### Q3: "타로 프레이밍이 법적으로 문제 아닌가?"

논리구조:
1. "점술 서비스가 아닙니다" — 명확한 선 긋기.
2. 타로 메타포 = UX의 일부. 내부 = 이종 AI 데이터 기반 분석.
3. 업종 선례: 포스텔러(매출 100억) = 정보서비스업.
4. 대표 법정책 전공 → 설계 단계부터 법적 그린존.

### Q4: "Pi가 실패하고 Woebot도 접었는데 왜 성공한다고 보나?"

논리구조:
1. 실패 원인 분석: Pi/Woebot = 감정적 공감만 → 돈 안 됨.
2. 풀림의 차별: 의식적 경험 + 실질적 산출물(리스크/보상 + 행동 약속).
3. 지불 가치가 다름: 공감 vs 구조화된 행동 연결.
4. B2B 확장 로드맵 보유.

### Q5: "200명 어떻게 모으나?"

논리구조:
1. 첫 후크: 무료 세션의 세계관 경험.
2. 바이럴: 세션 공유 카드 자동 생성 → SNS.
3. 리텐션: 캐릭터 리마인드 + 위클리 체크인.
4. 안전장치: 5% 전환에서도 BEP(13명) 달성.

### Q6: "1인이 가능한가?"

논리구조:
1. 린 스타트업 원칙: PMF 전 팀 확대 = 방향 없이 조율 비용만 증가.
2. 실행력 증거: 2주 만에 5개 기능, 2일 만에 설계 12건.
3. 보완 계획: 디자인 외주(ICC 지원금), 마케팅(MRR)으로 순차 확보.
4. AI 도구: Claude Code + Cursor Pro = 1인 풀스택 개발 가능.

### Q7: "AI 규제 강화되는데 어떻게 대응하나?"

논리구조:
1. 포지셔닝: 진단/치료 표방 안 함 → 디지털의료제품법 대상 아님.
2. AI 기본법: 투명성 의무 이미 설계 반영.
3. 위기 대응: RED 프로토콜 + 109 안내.
4. 대표 자격: 법&정책 트랙 전공.

### Q8: "해자가 약하지 않나?"

논리구조:
1. Day 1 솔직 인정: "약합니다".
2. 선점 효과: "모닥불+구슬+이종 모델" 조합을 먼저 설계한 것 자체.
3. 시간 강화: 6개월 → 개인화 데이터. 12개월 → 행동 데이터셋.
4. 데이터 해자: "한국인 의사결정 행동 데이터셋 = 풀림만 보유하게 됨".
