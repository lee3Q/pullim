[창업아이템 개요]

용도: AI 기반 의사결정 코칭 플랫폼. 이직, 진로, 연애 등 인생의 중요한 선택 앞에서 혼란을 구조화하고, 스스로 답을 찾도록 돕는 서비스.

핵심 기능: 사용자가 10개 수정구슬 중 3개를 고르면, Claude/GPT/Gemini 3개 AI 모델이 각각 독립 분석. 9단계 파이프라인(고민 입력 - 리서치 - 팩트체크 - 구슬 선택 - 이종 모델 병렬 분석 - 교차 토론 - 최종 검증 - 결론 - 행동 약속)을 거쳐 리스크/보상/확률/성향을 담은 결론 문서와 구체적 행동 약속이 산출물로 남는다.

고객 혜택: ChatGPT는 프롬프트를 잘 써야 하지만, 풀림은 구슬을 고르면 끝이다. AI를 모르는 사람도 사용 가능. 타로의 재미(모닥불, 구슬, 현자)와 AI의 실질(이종 모델 분석, 팩트체크)을 동시에 경험할 수 있다.

3테마 세계관 (같은 파이프라인, 다른 분위기):

| 테마 | 캐릭터 | 세계관 | 비주얼 |
|------|--------|--------|--------|
| 모험가 | 현자 | 오두막과 모닥불 | 도트 아트, RPG 감성 |
| 전략실 | 비서 | 도시 야경과 전략실 | 미니멀, 프로 감성 |
| 달빛정원 | 친구 | 달빛과 꽃밭 | 파스텔, 힐링 감성 |

사양: Next.js 15 + React 19 + TypeScript 웹앱(PWA). Claude API + GPT API + Gemini API 이종 모델 파이프라인. Supabase 인증/DB. Vercel 서버리스 배포.

=====================================
1. 문제 인식 (Problem) - 창업 아이템의 필요성
=====================================

○ 시장 현황

현대인은 정보 과잉 속에서 의사결정 피로에 시달리고 있고, "혼란의 정리"를 원하지만 기존 도구는 재미가 없거나 실질이 없다.

- 통계청 2025.2, "쉬었음" 청년(15~29세) 역대 최고 50.4만명. 일자리 밖 2030세대 158만명 — 진로 결정의 마비
- 잡코리아x원픽 2024.10, 직장인 719명 중 73%가 이직 고민 중 — 결정 못 하고 있는 상태
- AI가 답을 주면 오히려 불안해지는 'AI 유발 불확실성 불안(AIUA)' 현상 보고

"혼란의 정리"에 돈을 쓰고 있다 — 수요는 이미 검증됨:
- 국내 점술 시장 약 4조 원 (The Economist 2018, $3.7B), 점신 앱 1,900만 DL/매출 979억 (매일경제 2025)
- 마인드카페 누적 400만 회원, 매출 93억 (한경 2025)
- 글로벌 점성술/타로 앱 시장 약 50억 달러 (연 20% 이상 성장)
- AI 상담 이용 의향 40% vs 실제 이용 11% — 수요는 있으나 기존 서비스가 못 잡고 있음 (한국리서치 AI 심리상담 인식조사, 2025.4)

○ 기존 해결 방식의 문제점

| 기존 방식 | 핵심 문제 | 근거 |
|---------|---------|------|
| ChatGPT | 빈 화면에 프롬프트 필요. 1개 모델의 확인편향. 재미 없음. | AIUA 개념 |
| 마인드카페/트로스트 | AI 상담 핵심 불만: 효과 의심 55%, 공감 부족 52%. 1회 5~15만 원. 세션 후 산출물 없음. | 한국리서치 AI 심리상담 인식조사, 2025.4 |
| 타로/사주 앱 | 재미는 있지만 비합리적 프레임. 데이터 기반 분석 없음. 행동 변화 없음. | 점신 979억/포스텔러 100억의 시장 규모가 수요 증명 |
| Co-Star | 매일 운세 보는 일일 루틴이지 의사결정 도구 아님. | Co-Star 2,100만 DL |
| 지인/커뮤니티 | 본인 경험 투영, 정보 과잉, 혼란 가중 | |

○ 풀림이 해결하는 핵심 문제

사람들은 "정답"이 아니라 "혼란의 정리"를 원한다. 그리고 그 과정이 재미있어야 돌아온다.

- 타로 시장 약 4조 원이 증명한다: 불확실성 속에서 "정리된 내러티브"를 듣고 싶은 욕구는 강력하고, 돈이 된다. 하지만 타로에는 실질이 없고, AI 도구에는 재미가 없다.
- 풀림은 타로의 의식성(모닥불, 구슬, 현자라는 의식적 경험)과 AI의 실질성(이종 모델 분석, 리서치, 팩트체크)을 결합한다. 구슬을 고르는 의식 아래에 3개 AI 모델의 독립 분석이 있고, 세션이 끝나면 리스크/보상/확률/성향을 담은 결론 문서와 구체적 행동 약속이 남는다.


=====================================
2. 실현 가능성 (Solution) - 창업 아이템의 개발 계획
=====================================

○ 개발 현황 및 계획

현재 상태: v1 프로토타입 배포 완료 (pullim.vercel.app). v2 핵심 기능 5개 + 끝판왕 프론트엔드 UI 구현 완료 (총 6개). 끝판왕 설계 12건 완성 (백엔드 API 연결 진행 중).

구현 완료 기능 (6개) — 라이브 데모 가동 중:
- 자동 라우팅: 고민의 복잡도를 AI가 판단하여 Quick Mode 또는 풀 파이프라인 자동 분기
- 선택형 Socratic 질문: 프롬프트 타이핑이 아닌 선택지 탭으로 진행
- 3관점 병렬 분석 및 토론: 독립 분석 후 교차 토론, 불일치 지점이 고민의 핵심 갈림길
- 의사결정 정리 문서: 상황 요약 + 선택지 + 진짜 두려움 + 첫 행동 1개
- 3층 위기 감지(RED 프로토콜): 위기 키워드 감지 시 AI 즉시 중단, 자살예방상담전화 109 안내
- 끝판왕 프론트엔드 UI: 모험가 모드 세션 페이지, 구슬 선택 애니메이션, 데이터 카드, 결론 뷰

개발 예정 기능 (5개) — 협약기간 내 구현:
- 이종 모델 오케스트레이션: 구슬 3개 = Claude + GPT + Gemini가 각각 독립 분석
- 리서치 에이전트: Tavily API로 실시간 웹 검색, 통계/사례/전문가 견해 수집
- Judge 검증: Haiku 모델이 리서치 결과와 분석 논리를 독립 팩트체크
- 비동기 처리: 파이프라인 돌려놓고 나중에 확인
- Supabase 연동: 인증, 세션 히스토리, 개인화 패턴 분석

○ 핵심 기술 차별화 — 이종 모델 오케스트레이션

기존 v2는 같은 모델(Claude)이 3명의 전문가를 연기했다. 끝판왕은 3개 다른 모델이 각각 독립 분석한다.

| 구분 | v2 (기존) | 끝판왕 |
|------|---------|--------|
| 분석 주체 | Claude x 3 (같은 모델, 다른 프롬프트) | Claude + GPT + Gemini (다른 모델, 같은 프롬프트) |
| 불일치 | 인위적 (같은 모델이 만든 차이) | 진짜 (모델 고유 편향에서 나온 차이) |
| 토론 | 같은 모델 자문자답 | 모델 간 교차 반론 (자기합리화 방지) |
| 검증 | 없음 | Judge 모델 독립 검증 |

10개 수정구슬 시스템 — 사용자에게는 "구슬을 고르는 의식", 내부적으로는 분석 렌즈:
- 금화(재무 분석), 나침반(진로/커리어), 거울(행동경제학/인지 편향), 저울(법적/구조적), 모닥불(가치관/동기), 타인(관계), 심연(심리 패턴), 전략(경영/전략), 뒤집기(철학적 리프레이밍), 몸(생활/건강)

○ 왜 지금 가능한가

- 2024~2026 LLM API 가격 급락: Gemini 2.5 Flash 무료 티어 제공, GPT 4.1 mini 입력 $0.40/출력 $1.60(백만 토큰당)
- 멀티 에이전트 토론 아키텍처(MentalAgora, MedARC)가 학술적으로 검증됨 (arXiv 2407.02736)
- Socratic AI가 글로벌 트렌드: EU TITAN 프로젝트, 칸아카데미 Khanmigo 등
- 2주 만에 v1~v2 구현, 2일 만에 끝판왕 설계 12건 — 이종 모델 연동은 2~3주 내 가능

3. 성장전략 (Scale-up) - 사업화 추진 전략
=====================================

○ 경쟁사 분석 및 차별성

Gemini Deep Research 분석 결론: 타로의 재미와 AI의 실질적 코칭이 완벽한 시너지를 내며 주류 시장을 장악한 단일 하이브리드 서비스는 2026년 현재 전 세계에 존재하지 않는다.

주요 경쟁사 비교 (12개 경쟁사 분석 중 대표 4개):

| 구분 | ChatGPT | 타로/점신 | 마인드카페 | 풀림 |
|------|---------|---------|----------|------|
| 진입 방식 | 프롬프트를 잘 짜야 함 | 질문 선택 + 결제 | 상담사 예약 | 구슬 고르면 AI가 알아서 |
| 분석 | 1개 모델 (확인편향) | 운명 프레임 | 1명 상담사 | 이종 3모델 독립 분석 |
| 리서치 | 사용자가 직접 | 없음 | 없음 | 자동 웹 검색 + 팩트체크 |
| 산출물 | 대화로 끝남 | 운세 결과 | 감정 기록 | 리스크/보상/확률/성향 + 행동 약속 |
| 가격 | 무료~27,000원 | 건당 3,000~20,000원 | 1회 5~15만 원 | 월 9,900원 |

왜 아무도 안 했나 — 3개 구조적 장벽과 풀림의 돌파:
- 윤리적 리스크: 타로의 무작위성으로 인생 조언하면 책임 문제 발생. 풀림의 답: 구슬은 분석 렌즈의 메타포이고, 뒤에는 이종 모델의 진짜 데이터 분석이 있다.
- 기술적 딜레마: 추론 AI와 비과학적 점술의 아키텍처 모순. 풀림의 답: 프론트엔드는 리추얼, 백엔드는 추론.
- 문화적 장벽: 서구 AI는 하이퍼 합리주의. 풀림의 답: 한국은 운세 WTP 약 4조 시장으로, 문화적으로 가장 적합한 테스트베드.

○ 비즈니스 모델 (수익화)

재화 점진적 소모 + 광고/구독 이중 모델:
- Free(무료): 오퍼월 미션/설문 참여로 재화 획득 + 주 10재화. 품질 동일.
- Standard(9,900원/월): 광고 없음 + 주 50재화 + 히스토리 + Quick Mode
- Pro(19,900원/월): 주 120재화 + 3테마 전체 + 월간 패턴 리포트

점진적 소모: 입장과 듣기는 무료. 리서치(+1재화), 수정구슬 분석(+1재화씩), 토론(+1재화), 결론(무료). 사용자가 매 순간 통제권을 가진다.
품질 차등 없음: 무료도 유료와 동일한 이종 모델 풀 파이프라인. "와, 이게 무료?" 경험이 전환 동기.
가격 앵커링: 포스텔러 심층 사주 1회(3,000~20,000원) = 풀림 1달. O2O 상담 1회(5~15만 원) > 풀림 2.5~7.5달.

Unit Economics: 재화당 약 65원(MVP 원가), 풀 세션 약 250원(보수적). Standard 기준 월 매출 9,900원 중 변동비 약 3,250원(100재화 x 65원/재화, API 비용 기준) = 월 마진율 67%(Standard 기준 보수적 산출), 고정비 약 85,000원/월(Vercel+도메인+Tavily) 기준 BEP 유료 약 13명.

○ 목표시장 진입 전략

풀림은 기능을 마케팅하지 않는다. 경험을 마케팅한다.

| 뿌리 | 4~6개월 | SEO 블로그 + 유튜브 숏폼 + 타로/MBTI 커뮤니티 | 0원 |
