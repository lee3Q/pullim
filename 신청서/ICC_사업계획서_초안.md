## [첨부1] 사업계획서 요약 (페이지 2)

### 창업아이템 개요

**풀림(Pullim)은 AI가 답을 주지 않고, 구조화된 질문으로 사용자가 스스로 명확해지는 의사결정 정리 도구입니다.**

고민을 입력하면 5단계 파이프라인이 작동합니다:
1. 고민 입력 → 2. Socratic 질문으로 진짜 고민 파악 → 3. AI 3명이 각기 다른 관점(현실주의자·공감자·역발상가)으로 병렬 분석 → 4. 선택된 관점과 반론이 토론 → 5. 의사결정 정리 문서 "첫 걸음" 자동 생성

**핵심 기능**: 고민 유형 자동 분류(라우팅), Socratic 질문, 3관점 병렬 분석+토론, 의사결정 정리 문서 생성
**고객 혜택**: "상담받고 뭐가 달라졌는지 모르겠다"는 기존 앱의 한계를 해결. 세션이 끝나면 상황 요약, 선택지 A/B/C, 진짜 두려움, 첫 행동 1개가 문서로 남음.
**가격**: 월 7,500원 (무료 체험 월 1회 포함)

### 창업아이템 현황 및 구체화 방안

**현황**:
- v1 프로토타입 구축 완료 (22개 소스 파일, 1,642줄, Next.js + Supabase + Claude API)
- pullim.vercel.app 데모 배포 완료
- v1 테스트 2회, v2 테스트 1회 완료. 고객 인터뷰 2건 (WTP 월 1~3만원 확인)
- v2 멀티 에이전트 파이프라인 통합 중 (3월 내 마무리)

**협약기간 내 최종 산출물**:
- 정식 MVP 웹앱 (pullim.vercel.app)
- 베타 테스트 20명 완료 + 피드백 반영

- 의사결정 정리 문서 50건 이상 누적

**역량 활용 계획**:

## 1. 문제 인식 (Problem) — 창업 아이템의 필요성 (페이지 3)

### 시장 현황

**사람들은 중요한 결정 앞에서 고통받고 있고, 기존 도구는 이를 해결하지 못합니다.**

진로·이직 영역:
- 통계청 2025년 2월, "쉬었음" 청년(15~29세) **역대 최고 50.4만명**. 실업자·취업준비자까지 포함한 일자리 밖 2030세대는 **158만명**
- 잡코리아×원픽 2024.10, 직장인 719명 설문: **73%가 이직 고민 중**

멘탈케어 수요:
- 건강보험심사평가원 기준, 우울증 환자 **110만명 이상**, 상당수 미치료
- 20대 우울증 **5년간 127% 증가** (건보심평원 2017→2021)
- 보건복지부 청년마음건강바우처: 청년 **1.5만 한정** (수요 대비 부족)

AI 수용 기반:
- NIA·과기부 2024, 생성형 AI 이용률 **33%**, 1년 만에 약 2배 성장
- 이미 AI를 쓰는 층이 우리 타겟. "더 나은 AI 경험"에 대한 수요 존재

### 기존 해결 방식의 문제점

| 기존 방식 | 문제 |
|---------|------|
| 지인 상담 | "잘 생각해봐" — 본인 경험 투영, 구조적 분석 불가 |
| ChatGPT | 장단점 나열 → "신중히 하세요"로 끝. 사용자가 질문을 잘 해야 좋은 답이 나옴 |
| 마인드카페·트로스트 | "상담받고 뭐가 달라졌는지 모르겠다" — 세션 후 산출물 없음 |
| 커뮤니티(에타, 블라인드) | 정보 과잉, 신뢰도 낮음, 혼란 가중 |

### 풀림이 해결하는 핵심 문제

**좋은 의사결정 방법은 이미 존재합니다. 문제는 일반인이 "어떤 상황에 어떤 방법을 쓸지" 모른다는 것입니다.**

풀림은 이 라우팅을 AI가 대신하고, 답 대신 구조화된 질문을 던져 사용자가 스스로 명확해지게 합니다. 세션이 끝나면 반드시 의사결정 정리 문서가 남습니다.

## 2. 실현 가능성 (Solution) — 창업 아이템의 개발 계획 (페이지 4)

### 개발 계획

**아이디어 → 제품 구체화 경로**:

v1 프로토타입은 이미 구축 완료 (pullim.vercel.app). 협약기간 내에는 v2 멀티 에이전트 파이프라인 안정화 → 베타 테스트 → 정식 MVP → 유료 전환까지 달성합니다.

**기술 스택**: Next.js 15 + React 19 + TypeScript + Tailwind CSS 4 + Supabase(RLS 데이터 격리) + Claude API(Haiku/Sonnet/Opus 3계층) + Zustand(상태관리)

**핵심 차별화 기능**:
1. **자동 라우팅**: 고민의 가역성/중요도/긴급성/감정관여도를 AI가 판단 → 맞는 분석 프로토콜 자동 선택
2. **Socratic 질문**: 정보 수집이 아닌 전제를 의심하는 질문. "이직하고 싶다" → "이직이 현재 문제를 해결한다는 확신은 어디서 왔나요?"
3. **3관점 병렬 분석+토론**: 현실주의자·공감자·역발상가가 각각 독립 분석 후 교차 토론. 고민 유형에 따라 전문가 페르소나가 바뀜 (의사의 역발상 ≠ 철학자의 역발상)
4. **의사결정 정리 문서 "첫 걸음"**: 상황 요약 + 선택지 A/B/C + 대화에서 발견한 진짜 두려움 + 오늘 바로 할 수 있는 첫 행동 1개

**왜 이게 지금 가능한가**:
- 2024~2025 Claude API 가격 하락으로 멀티 에이전트 세션당 543원 실현 (마진율 71%)
- 생성AI 이용률 33% → AI 코칭 서비스 수용 기반이 형성된 시점
