## 4. 차별화 강화 전략 (탈락 사유 보완)

이전 탈락 사유: **"시장 차별화가 없음"**

### 보완 방향

기존 PPT에서 차별화를 이미 다루고 있으나 **"구조적 차별화"가 아닌 "기능 나열"로 보였을 가능성**이 높다. ICC 사업계획서에서는:

1. **경쟁사 3개를 구체적으로 비교** (마인드카페, 트로스트, ChatGPT)
   - 각각의 한계를 1줄로
   - 풀림이 해결하는 방식을 1줄로

2. **"왜 이게 지금 가능한가"** 시점 논리 추가
   - 2024~2025 Claude API 가격 하락으로 멀티 에이전트 비용 현실화
   - 생성AI 이용률 33% → AI 코칭 수용 기반 형성

3. **산출물 차별화** 강조
   - 기존 앱: 대화로 끝남 → 풀림: 의사결정 정리 문서 "첫 걸음" 자동 생성
   - 이것이 "상담받고 뭐가 달라졌는지 모르겠다"는 기존 불만 해결

- 공유실: 베타 테스터 대면 인터뷰, 멘토링 세션 활용
