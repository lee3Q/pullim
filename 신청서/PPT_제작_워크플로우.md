## 단계 0: Google Slides 테마 세팅 (15분)

Gemini가 생성하는 슬라이드에 자동 적용되도록, 먼저 마스터 테마를 세팅한다.

### 순서
1. Google Slides에서 빈 프레젠테이션 생성
2. **슬라이드 > 테마 편집** (마스터 슬라이드 열기)
3. 아래 설정 적용:

| 요소 | 설정값 |
|------|--------|
| 배경색 | `#F7F4F0` (오프 화이트) |
| 제목 폰트 | Noto Sans KR Bold, 28pt, `#2A7D8C` |
| 본문 폰트 | Noto Sans KR Regular, 14pt, `#2D2D2D` |
| 강조색 | `#E8856C` (웜 코럴) |

> **Pretendard는 Google Slides에서 직접 지원 안 됨.** Noto Sans KR이 가장 가까운 무료 대안이고, Google Slides에 기본 탑재돼 있다. 최종 PPTX 내보내기 후 로컬에서 Pretendard로 일괄 교체하거나, Noto Sans KR 그대로 가도 품질 차이 거의 없다.

4. 마스터 슬라이드 레이아웃 3종 만들기:
   - **타입 A** (제목 + 2열 텍스트): 슬라이드 2, 3, 7, 18용
   - **타입 B** (제목 + 3열 카드): 슬라이드 8, 10용
   - **타입 D** (제목 + 플로우 영역 + 하단 테이블): 슬라이드 9, 11, 17, 20, 22용
5. 마스터 편집 닫기

## 단계 1: Gamma 초안 생성 (20분)

Gamma는 최종본이 아니라 **레이아웃 감 잡기 + Gemini 프롬프트 작성 참고용**이다.

### 순서
1. gamma.app 접속 → "Paste in your content"
2. 콘텐츠 명세서(디자이너_콘텐츠_명세서.md)의 **E섹션 전체**(슬라이드 1~23 상세)를 통째로 붙여넣기
3. 테마: "Minimal" 또는 "Startup" 계열 선택
4. 생성된 결과에서 **괜찮은 레이아웃**만 메모 (특히 표, 퍼널, Before/After 배치)
5. 참고가 끝나면 Gamma는 닫아도 됨

> Gamma의 강점: 텍스트를 넣으면 AI가 자동으로 레이아웃을 잡아준다. 다이어그램까지 자동 생성해주므로 "이런 식으로 배치하면 되겠구나" 감 잡기에 최적.

## 단계 2: Gemini로 슬라이드 일괄 생성 (40분)

### Gemini 프롬프트 전략

Google Slides의 Gemini는 **한 번에 전체 프레젠테이션을 생성**하는 것보다, **4~5장씩 나눠서 생성**하는 게 품질이 높다. 아래처럼 블록별로 나눠서 프롬프트를 던진다.

### 프롬프트 1: 표지 + 창업 계기 (슬라이드 1~3)

```
아래 내용으로 슬라이드 3장을 만들어줘.

[디자인 규칙]
- 배경: #F7F4F0 (오프 화이트)
- 제목: Noto Sans KR Bold, 28pt, #2A7D8C
- 본문: Noto Sans KR Regular, 14pt, #2D2D2D
- 강조 숫자: 40pt 이상, Bold, #E8856C
- 카드/박스 배경: #E3EEF0, 모서리 둥글게

[슬라이드 1: 표지]
- 중앙 정렬
- 제목: "풀림 (Pullim)" — 크게
- 서브타이틀: "꼬인 고민이 풀리다" — 작게
- 하단: "답을 찾게 하는 AI. 결론은 같이 해나갑니다."
- 소속: 한성대학교

[슬라이드 2: 창업의 계기]
- 3단 구성 (가로 3열 카드)
- 카드 1 "창업 아이디어 발상의 계기": 76.5%의 직장인이 이직을 고민하지만, 대부분 "잘 생각해봐"로 끝난다. 나도 그랬다. 1년간 AI로 진로, 연애, 휴학 등 모든 중요한 결정을 해봤다. 답을 주는 AI는 쓸모없었다. 맞는 질문을 던지는 AI가 결정을 만들었다.
- 카드 2 "구체화 과정 1": 삼수 실패에 고통받던 시절, 구원받고 싶었다. AI와 대화하며 막연함이 사라졌고, 고통의 반추가 아니라 흥미로운 분석이 가능해졌다. 의사결정이 삶을 바꿨다.
- 카드 3 "구체화 과정 2": 엄마에게 AI를 알려줬다. 세상 모든 사람이 고민을 구조화하고 좋은 선택을 하길 바란다. 한국에 "맞는 질문 → 정리 문서" 서비스가 없어서 풀림을 시작했다.

[슬라이드 3: 제거됨 — 소셜벤처 데이터는 슬라이드 5(시장 분석)에 통합]
- 양식 #3 슬롯은 빈 슬라이드 또는 생략 처리
```

### 프롬프트 2: 아이템 + 시장 + 경쟁사 (슬라이드 4~6)

```
아래 내용으로 슬라이드 3장을 만들어줘.

[디자인 규칙]
- 배경: #F7F4F0
- 제목: Noto Sans KR Bold, 28pt, #2A7D8C
- 본문: Noto Sans KR Regular, 14pt, #2D2D2D
- Before 영역: 배경 #F0F0F0, 텍스트 #6B7280, 부정 결과 #C45B4A
- After 영역: 배경 #E3EEF0, 텍스트 #2D2D2D, 긍정 결과 #2A7D8C
- 표 헤더: #2A7D8C 배경 + 흰색 텍스트

[슬라이드 4: Before/After — "고민을 입력하면, 생각이 정리된다"]
- 좌우 50:50 분할
- 좌측 "BEFORE: 기존 방식" (회색 톤):
  이직 → 장단점 나열 → 여전히 모르겠다
  연인 → "대화를 해보세요" → 결국 혼자 끙끙
  휴학 → 취업률 통계 → 정보만 늘고 결정은 안 됨
- 우측 "AFTER: 풀림" (브랜드 컬러):
  이직 → "지금 제일 힘든 게 뭐야?" → 진짜 고민 발견 + 정리 문서
  연인 → "제일 서운했던 순간이 언제였어?" → 감정 정리 + 내 기준 발견
  휴학 → "1년 뒤에 어디 있고 싶어?" → 선택지 정리 + 첫 행동 1개
- 하단에 3단계 플로우: [고민 입력] → [AI 질문 대화] → [첫 걸음 (정리 문서)]
- 최하단: "답을 주는 AI가 아니라, 네 안에 있는 답을 찾게 해주는 AI"

[슬라이드 5: 시장 분석 — TAM/SAM/SOM]
- 깔때기(피라미드) 시각화
- TAM: 한국 멘탈케어+의사결정 시장 약 1.5조원 (디지털 상담/심리 앱/EAP 1.2조 + 코칭/컨설팅 디지털 전환 3,000억).
- SAM: 한국 20-30대 멘탈케어 앱 사용 의향자 약 130만명 × 월 7,500원 × 12개월 = 약 1,170억원.
- SOM: 멘탈케어 앱 MAU 16만명. 초기 목표 유료 1,000명 × 월 7,500원 = 연 9,000만원.
- 각 단계 숫자를 크게 강조

[슬라이드 6: 경쟁사 분석]
- 상단: 5열 비교표 (마인드카페, 트로스트, 상담냥, ChatGPT, 풀림)
  행: 핵심 접근, AI 역할, 세션 산출물, 감정→행동 연결, 후속 추적, 위기 안전, 가격, 포지셔닝
- 풀림 열은 #2A7D8C 배경으로 강조
- 하단: 2x2 포지셔닝 맵
  X축: 감정 케어 ←→ 의사결정 구조화
  Y축: AI 보조 ←→ AI 주도
  풀림은 우상(빈 영역)에 위치, #E8856C로 강조
- 경쟁 해자(Moat) 1줄: "세션 축적 → 맥락 연속성 → 전환 비용 (설계 완료, v2 적용)"
```

- 하단 결론: "초기 타겟: 20-30대 진로/이직 고민자 약 50만+" — 굵게, #2A7D8C

[슬라이드 9: 비즈니스 모델]
- 상단 카피: "답을 찾게 하는 AI. 결론은 같이 해나갑니다."
- 중앙: 세로 플로우 다이어그램 (무료 체험 월1회 풀 Sonnet → WOW 모먼트 → 2번째 고민에서 유료 전환 → 결심 캐시백 월1회 2,500원 → 잠금 효과: 맥락 연속성→전환 비용)
- 각 단계를 박스로, 화살표로 연결
- 우측: 가격표 3장 카드 (Tier 0 무료 월1회 풀 Sonnet, Tier 1 월 7,500원, 결심 캐시백 월1회 -2,500원)
- 하단: MRR 성장 테이블 3행 (7월 4~8만, 12월 113만, 12개월 후 750만)

### 프롬프트 4: 안전설계 + 역산퍼널 + 정리문서 샘플 (슬라이드 10~12)

```
아래 내용으로 슬라이드 3장을 만들어줘.

[디자인 규칙]
- 배경: #F7F4F0
- 제목: Noto Sans KR Bold, 28pt, #2A7D8C
- 본문: Noto Sans KR Regular, 14pt, #2D2D2D
- 카드 배경: #E3EEF0

[슬라이드 10: 안전 설계 — "AI가 잘못된 답을 줄 수 없는 구조"]
- 가로 3분할 카드
- 카드 1 "구조적 안전" (배경 #E3EEF0, 방패 아이콘):
  "풀림의 AI는 답을 주지 않는다. 질문만 한다."
  X "이직하세요" / O "이직을 고민하게 된 계기가 뭐야?"
  + "지금 결정하지 않는다"가 항상 정식 선택지
- 카드 2 "GREEN/YELLOW/RED 3층 안전" (배경 #FDF0E8, 손잡기 아이콘):
  GREEN: 일반 대화, 파이프라인 정상 진행
  YELLOW: 절망/무가치감 → 대화 유지 + 감정 수용 (인사이트 금지)
  RED: 구체적 위기 → 탐색 중단 + 전문기관 안내 (1393, 1577-0199)
  에스컬레이션 단방향 (RED→YELLOW 복귀 없음)
- 카드 3 "업계 교훈" (배경 #F0F0F0, 문서 아이콘):
  Woebot $123.5M → 폐쇄 (FDA 실패)
  Yara AI → 자진 폐쇄
  풀림 대응: 전문 상담 보완 웰니스 도구 + 3층 안전 구조 + 답 안 줌 + 안전 모니터링(MVP 수동→스케일 자동화)

[슬라이드 11: 역산 퍼널 — "작게 시작해서 검증한다"]
- 메인 깔때기: 6개월 보수적 시나리오 (크게, 중앙)
  ① 인지 5,000명 (커뮤니티 + 지인) — 가장 넓음, 연한 틸
  ② 설치 500명 (전환 10%) — 틸
  ③ 무료 체험 150명 (전환 30%) — 딥 틸
  ④ 유료 8명 (전환 5%) — #E8856C로 강조. "8명이라도 돈을 내면, 그게 검증이다."
- 서브: 12개월 낙관 시나리오 (우측 또는 하단, 작게)
  노출 200,000 → 설치 20,000 → 체험 6,000 → 유료 1,000명, MRR 750만원
- 하단 핵심: "돈을 내는 이유는 'AI가 좋아서'가 아니다. '내 결론이 1페이지로 정리됐다'는 산출물 때문이다. 8명이라도 돈을 내면, 그게 검증이다."

[슬라이드 12: 정리 문서(첫 걸음) 샘플 — "세션이 끝나면 남는 것"]
- 좌측 60%: 이직 고민 정리 문서 전문 (A4 문서 느낌 카드, 얇은 테두리+그림자)
  오늘의 고민: 이직 / 지금 상황 / 선택지 정리(A,B,C) / 대화에서 발견한 것 / 첫 행동
- 우측 40%: 연애/휴학 발췌 카드 2장 세로 배치
  연애: "진짜 질문은 '상대'인지 '나의 기대'인지" → 첫 행동
  휴학: "진짜 질문은 '졸업 후 뭘 하고 싶은지 모른다는 불안'" → 첫 행동
- 하단 1줄: "정리된 결과는 당신의 생각입니다. AI는 질문했을 뿐."
```

## 부록: Gemini 활용 추가 팁

### Gemini가 잘하는 것
- 텍스트 → 슬라이드 레이아웃 자동 배치
- 표 자동 생성
- 글머리 기호 정리
- 색상 팔레트 지정 시 적용

### Gemini가 못하는 것 (수동 필수)
- 정밀한 다이어그램 (퍼널, 플로우차트, 아키텍처)
- 2x2 매트릭스에 정확한 위치에 요소 배치
- Before/After 좌우 분할의 색상 대비
- 여러 표를 한 슬라이드에 적절히 배치

### Gemini 프롬프트 팁
1. **디자인 규칙을 매 프롬프트 상단에 반복** — Gemini는 이전 프롬프트 컨텍스트를 유지하지 않음
2. **한 번에 3~4장씩** — 7장 이상이면 뒤쪽 슬라이드 품질 떨어짐
3. **색상은 헥스코드로** — "파란색"이 아니라 "#2A7D8C"
4. **레이아웃 지시를 구체적으로** — "3열 카드", "좌우 50:50 분할", "세로 플로우"
5. **생성 후 바로 수정** — 한 블록 생성 → 서식 수정 → 다음 블록. 전부 생성 후 수정하면 나중에 뭐가 뭔지 헷갈림.
