## [첨부1] 사업계획서 요약 (페이지 2)

### 창업아이템 개요

**풀림(Pullim)은 프롬프트 없이, 선택만으로 돌아가는 AI 의사결정 구조화 도구입니다.**

점심 메뉴부터 이직 결정까지 — 고민을 입력하면 AI가 자동으로 복잡도를 판단하고, 맞는 파이프라인을 태웁니다:

1. **고민 입력 + 자동 라우팅** — 단순 결정(식사, 일정)은 빠른 정리, 복잡 결정(진로, 관계)은 풀 파이프라인으로 자동 분기
2. **Socratic 질문** — AI가 답을 주지 않고, 전제를 흔드는 질문을 던짐. 사용자는 선택지를 탭하며 진행
3. **리서치 에이전트** — 결정에 필요한 정보를 자동 수집·정리 (급여 비교, 시장 동향, 후기 등)
4. **3관점 병렬 분석 + 토론** — 현실주의자·공감자·역발상가가 독립 분석 후 교차 토론
5. **검증 에이전트** — 분석 결과의 논리적 허점·편향을 교차 검증
6. **의사결정 정리 문서 "첫 걸음"** — 상황 요약 + 선택지 + 진짜 두려움 + 오늘 할 수 있는 첫 행동 1개

**사용자는 중간에 언제든 개입하여 선호와 의사를 입력할 수 있고, 비동기로 작동합니다.**
퇴근길 지하철에서 고민을 입력하고 선택지 몇 개 탭 → 폰 주머니에 넣음 → 집에 와서 확인하면 분석 완료.

**핵심**: ChatGPT는 빈 화면에 프롬프트를 잘 써야 합니다. 풀림은 질문에 답하기만 하면 됩니다. AI를 처음 쓰는 사람도 사용 가능합니다.

**가격**: 월 7,500원 (무료 체험 월 1회 포함)

**왜 타로에 돈을 쓰면서 AI 상담에는 안 쓸까?**
사주·타로 시장(4.6조 원)이 번창하는 이유는 예측의 정확성이 아니라, 혼란스러운 상황을 "정리된 내러티브"로 바꿔주는 심리적 안도감 때문입니다 [출처: 벤처스퀘어·매경 분석]. 풀림은 같은 욕구를 합리적 방법(소크라테스 질문 + 다관점 분석)으로 충족합니다. 타로 1회 비용(3,000~20,000원) = 풀림 1달(7,500원 무제한).

**경쟁력(보유역량)**: 기존 AI 상담앱의 핵심 불만은 "패턴화된 공감, 효과 의심"(사용자 55%)입니다 [출처: 2024 국민정신건강조사]. 풀림은 공감이 아닌 구조화로 이 "공감의 함정(Empathy Trap)"을 우회합니다. 멀티 에이전트 토론 아키텍처는 MentalAgora(arXiv 2407.02736) 등 2025~2026년 학술 최전선의 기술이며, Socratic AI는 EU TITAN 프로젝트, 칸아카데미 Khanmigo 등 글로벌 트렌드의 정점입니다.

## 1. 문제 인식 (Problem) — 창업 아이템의 필요성 (페이지 3)

### 시장 현황

**현대인은 정보 과잉 속에서 의사결정 피로에 시달리고 있고, 기존 도구는 이를 해결하지 못합니다.**

의사결정 피로의 보편성:
- 통계청 2025.2, "쉬었음" 청년(15~29세) **역대 최고 50.4만명**. 일자리 밖 2030세대 **158만명** — 진로 결정의 마비
- 잡코리아×원픽 2024.10, 직장인 719명 중 **73%가 이직 고민 중** — 결정 못하고 있는 상태
- AI가 답을 주면 오히려 불안해지는 **'AI 유발 불확실성 불안(AIUA)'** 현상 보고 [출처: LinkedIn/학술 분석 종합] — 선택지가 많아질수록 결정이 더 어려워짐

기존 도구에 돈은 쓰고 있음:
- 국내 점술 시장 **약 4.6조 원** [출처: The Economist 2018 추산], 점신 앱 **1,900만 다운로드/매출 979억** [출처: 매일경제 2025]
- 마인드카페 **누적 300만 회원, 매출 93억** [출처: 한경 2025, 사람인 재무정보]
- AI 상담 이용 의향 **40%** vs 실제 이용 **11%** [출처: 2024 국민정신건강조사] — 수요는 있으나 기존 서비스가 못 잡고 있음

AI 수용 기반:
- NIA·과기부 2024, 생성형 AI 이용률 **33%**, 1년 만에 약 2배 성장

### 기존 해결 방식의 문제점

| 기존 방식 | 문제 | 근거 |
|---------|------|------|
| ChatGPT | "답을 너무 쉽게 줘서 오히려 생각이 둔해진다." 프롬프트를 잘 짜야 좋은 답이 나옴. | AIUA 개념, ChatGPT를 "거울치료 도구"로만 사용하는 2030 패턴 [한경 2024.12] |
| 마인드카페·트로스트 | "패턴화된 말", "효과 의심 55%", "공감 부족 52%". 세션 후 산출물 없음. 1회 5~15만 원 고비용. | 2024 국민정신건강조사, 앱스토어 리뷰 종합 |
| 타로·사주 | 비합리적 프레임. 일시적 안도감은 주지만 실질적 행동 변화 없음. | 심리학 분석: "인지적 부하의 아웃소싱" — 결정의 짐을 운명에 전가 |
| 지인·커뮤니티 | 본인 경험 투영, 정보 과잉, 신뢰도 낮음, 혼란 가중 | |

### 풀림이 해결하는 핵심 문제

**사람들은 "정답"이 아니라 "혼란의 정리"를 원합니다.**

타로 시장 4.6조 원이 증명하는 것: 불확실성 속에서 "정리된 내러티브"를 듣고 싶은 욕구는 강력하고, 돈이 됩니다. 풀림은 이 욕구를 **합리적 방법**으로 충족합니다 — 운명이 아닌 소크라테스 질문으로, AI가 답을 주는 대신 사용자가 스스로 명확해지게.

세션이 끝나면 반드시 **의사결정 정리 문서 "첫 걸음"**이 남습니다. 이것이 타로와 기존 AI 상담 모두에 없는, 풀림만의 산출물입니다.

## 2. 실현 가능성 (Solution) — 창업 아이템의 개발 계획 (페이지 4)

### 개발 계획

**현재 상태**: v1 웹앱 프로토타입 구축·배포 완료 (pullim.vercel.app). v2 멀티 에이전트 파이프라인 통합 중.

**기술 스택**: Next.js 16 + React 19 + TypeScript + Tailwind CSS 4 + Supabase(RLS 데이터 격리) + Claude API + Gemini API + Zustand(상태관리)

**핵심 차별화 기능**:

1. **자동 라우팅**: 고민의 복잡도(가역성/중요도/긴급성/감정관여도)를 AI가 판단 → 단순 결정은 빠른 정리, 복잡 결정은 풀 파이프라인으로 자동 분기
2. **선택형 Socratic 질문**: 프롬프트 타이핑이 아닌 선택지 탭으로 진행. "이직이 현재 문제를 해결한다는 확신은 어디서 왔나요?" → [A: 커리어 성장이 막혀서 / B: 조직문화가 안 맞아서 / C: 사실 확신은 없어요 / 직접 입력]
3. **리서치 에이전트**: 결정에 필요한 정보를 자동 수집·정리. 급여 비교, 업계 동향, 유사 경험담 등.
4. **3관점 병렬 분석 + 토론**: 현실주의자·공감자·역발상가가 각각 독립 분석 후 교차 토론. 고민 유형에 따라 전문가 페르소나가 동적으로 바뀜.
5. **검증 에이전트**: 분석 결과의 논리적 허점·인지 편향을 교차 검증. 단일 AI의 환각(Hallucination) 방지.
6. **비동기 처리**: 파이프라인을 돌려놓고, 사용자는 중간에 개입하거나 나중에 결과 확인. 퇴근길에 시작 → 집에서 완성본 확인.
7. **의사결정 정리 문서 "첫 걸음"**: 상황 요약 + 선택지 A/B/C + 대화에서 발견한 진짜 두려움 + 오늘 바로 할 수 있는 첫 행동 1개
8. **3층 위기 감지(RED 프로토콜)**: 위기 키워드 감지 시 AI 즉시 중단 → 자살예방상담전화 1393 안내. 방통위 생성형 AI 이용자 보호 가이드라인(2025.2) 준수.

**왜 이게 지금 가능한가**:
- 2024~2025 LLM API 가격 하락으로 멀티 에이전트 세션당 543원 실현
- 멀티 에이전트 토론 아키텍처(MentalAgora, MedARC)가 2025~2026년 학술적으로 검증됨 [출처: arXiv 2407.02736]
- 생성형 AI 이용률 33% → AI 기반 서비스 수용 기반 형성

**LLM은 교체 가능한 인프라**: 현재 Claude API + Gemini API를 사용하나, GPT, 중국산 sLLM 등 더 저렴하고 효율적인 모델이 등장하면 즉시 교체 가능한 모듈형 아키텍처. 축적된 의사결정 대화 데이터로 특화 sLLM 파인튜닝 로드맵도 보유.

### 심사위원 예상 Q&A (시장분석 출처 포함)

**Q1: "ChatGPT랑 뭐가 다른데?"**
> "ChatGPT는 빈 화면에 프롬프트를 잘 써야 합니다. 풀림은 질문에 답하기만 하면 됩니다. AI를 처음 쓰는 사람도 쓸 수 있는 UX가 차이입니다. 그리고 ChatGPT는 1개 관점으로 답을 주지만, 풀림은 3개 관점이 토론하고, 리서치와 검증까지 자동으로 돌아갑니다. 결과물이 대화가 아니라 '의사결정 정리 문서'로 남습니다."

**Q2: "답을 안 주는 서비스에 누가 돈을 내?"**
> "타로·사주 시장이 4.6조 원입니다. 사람들은 '정답'이 아니라 '혼란의 정리'에 돈을 냅니다. 풀림은 타로 1회 비용(3,000~20,000원)으로 1달 무제한 사용 가능합니다. 세션 후 자동 생성되는 '첫 걸음' 의사결정 정리 문서가 지불 가치입니다."

**Q3: "희랩이랑 겹치지 않나?"**
> "희랩은 그림으로 심리 상태를 '측정'합니다(CV 기반, B2B). 풀림은 대화로 의사결정을 '구조화'합니다(LLM 기반, B2C). 기술·타겟·산출물이 모두 다릅니다. 오히려 둘이 합쳐지면 '진단→치료→결정'이라는 멘탈케어 밸류체인이 완성됩니다."

**Q4: "Pi가 실패하고 Woebot도 중단됐는데?"**
> "Pi는 '감정적 동반자 챗봇', Woebot은 '디지털 치료제'로 의료 규제+높은 운영비에 노출됐습니다. 풀림은 의료기기가 아닌 '의사결정 생산성 도구'입니다. 노션이 메모장을 대체하듯, 풀림은 혼란스러운 사고를 구조화하는 유틸리티입니다."

**Q5: "API 종속 아닌가?"**
> "LLM은 교체 가능한 인프라입니다. Claude→GPT→Gemini→향후 경량 sLLM까지, 더 저렴하고 효율적인 모델이 나오면 즉시 교체할 수 있는 모듈형 아키텍처입니다. 풀림의 해자는 특정 모델이 아니라, 어떤 질문이 전제를 흔드는지, 어느 시점에 관점 선택을 넣어야 사용자가 능동 참여하는지에 대한 파이프라인 설계 노하우입니다."

**Q6: "AI 규제는?"**
> "풀림은 진단·치료를 표방하지 않는 '의사결정 보조 도구'로, 디지털의료제품법(2025.1 시행) 대상이 아닙니다. 다만 방통위 생성형 AI 이용자 보호 가이드라인(2025.2)에 따라, 위기 키워드 감지 시 AI 즉시 중단 + 전문기관(1393) 안내하는 RED 프로토콜을 설계에 반영했습니다."
