## [첨부1] 사업계획서 요약 (페이지 2)

### 창업아이템 개요

**풀림(Pullim)은 프롬프트 없이, 선택만으로 돌아가는 AI 의사결정 구조화 도구입니다.**

점심 메뉴부터 이직 결정까지 — 고민을 입력하면 AI가 자동으로 복잡도를 판단하고, 맞는 파이프라인을 태웁니다:

1. **고민 입력 + 자동 라우팅** — 단순 결정(식사, 일정)은 빠른 정리, 복잡 결정(진로, 관계)은 풀 파이프라인으로 자동 분기
2. **Socratic 질문** — AI가 답을 주지 않고, 전제를 흔드는 질문을 던짐. 사용자는 선택지를 탭하며 진행
3. **3관점 병렬 분석 + 토론** — 현실주의자·공감자·역발상가가 독립 분석 후 교차 토론
4. **의사결정 정리 문서 "첫 걸음"** — 상황 요약 + 선택지 + 진짜 두려움 + 오늘 할 수 있는 첫 행동 1개
5. **3층 위기 감지(RED 프로토콜)** — 위기 키워드 감지 시 AI 즉시 중단 → 109 안내

**구현 완료 (5개)**:
- 자동 라우팅 (복잡도 판단 → 파이프라인 자동 분기)
- Socratic 질문 (선택형 인터페이스)
- 3관점 병렬 분석 + 교차 토론
- 의사결정 정리 문서 "첫 걸음" 자동 생성
- 3층 위기 감지 RED 프로토콜

**개발 예정 (4개)** — v3 로드맵:
- 리서치 에이전트 (결정에 필요한 정보 자동 수집)
- 검증 에이전트 (논리적 허점·편향 교차 검증)
- 비동기 처리 (파이프라인 돌려놓고 나중에 확인)
- Supabase 인증·데이터 연동 (히스토리·개인화)

**사용자는 중간에 언제든 개입하여 선호와 의사를 입력할 수 있습니다.**
퇴근길 지하철에서 고민을 입력하고 선택지 몇 개 탭 → 폰 주머니에 넣음 → 집에 와서 확인하면 분석 완료.

**핵심**: ChatGPT는 빈 화면에 프롬프트를 잘 써야 합니다. 풀림은 질문에 답하기만 하면 됩니다. AI를 처음 쓰는 사람도 사용 가능합니다.

**가격**: 무료(월 1세션) / 스탠다드 월 7,500원(8세션) / 프로 월 14,900원(20세션+)

**왜 타로에 돈을 쓰면서 AI 상담에는 안 쓸까?**
사주·타로 시장(4.6조 원)이 번창하는 이유는 예측의 정확성이 아니라, 혼란스러운 상황을 "정리된 내러티브"로 바꿔주는 심리적 안도감 때문입니다 [출처: Gemini Deep Research, 벤처스퀘어·매경 분석]. 풀림은 같은 욕구를 합리적 방법(소크라테스 질문 + 다관점 분석)으로 충족합니다. 포스텔러 심층 사주 1회(3,000~20,000원) = 풀림 1달(7,500원, 8세션).

**경쟁력(보유역량)**: 기존 AI 상담앱의 핵심 불만은 "패턴화된 공감, 효과 의심"(사용자 55%)입니다 [출처: 2024 국민정신건강조사]. 풀림은 공감이 아닌 구조화로 이 "공감의 함정(Empathy Trap)"을 우회합니다. 멀티 에이전트 토론 아키텍처는 MentalAgora(arXiv 2407.02736) 등 2025~2026년 학술 최전선의 기술이며, Socratic AI는 EU TITAN 프로젝트, 칸아카데미 Khanmigo 등 글로벌 트렌드의 정점입니다.

### 리텐션 전략 — "의사결정 저널"

단발성 사용을 막고 구독을 유지하게 만드는 습관 루프:

| 주기 | 기능 | 설명 |
|------|------|------|
| 수시 | **Quick Mode** | 점심·일정 등 일상 결정 30초 정리. 비용 ~10~30원. 무제한. "풀림 열기"의 진입 장벽을 낮춤 |
| 주간 | **위클리 체크인** | 지난주 결정의 실행 여부 추적. "이직 서류 넣기로 했는데, 실행했나요?" → 탭 한 번으로 기록 |
| 월간 | **패턴 리포트** | "당신은 3개월간 15번의 결정을 내렸습니다. 가장 자주 고민하는 영역: 진로(60%). 결정-실행 전환율: 73%." |
| 분기 | **마일스톤** | 결정력 성장 시각화. "첫 10개 결정 완료" 뱃지 등 |

**핵심 논리**: 의사결정은 1회성 이벤트가 아니라 연속된 과정. "이직을 결정"한 뒤에도 "어느 회사?", "언제?", "어떻게 말하지?" 등 후속 결정이 이어짐. 의사결정 저널은 이 연속성을 포착하여 자연스러운 재방문 동기를 만듦.

### 창업공간 활용계획

- **상주인원**: 대표 이상규 1명 (풀타임 상주)
- **개인실 — 왜 독립 공간이 필수인가**:
  1. **STT 기반 개발**: 풀림의 핵심 작업은 멀티 에이전트 파이프라인의 프롬프트 설계. 복잡한 맥락을 키보드로 타이핑하는 것보다 STT(음성→텍스트)로 구술하는 것이 3~4배 빠르며, AI 도구(Claude Code)와의 협업도 음성 기반이 효율적. 이를 위해 소음 없는 독립 공간이 필수.
  2. **콘텐츠 촬영 공간**: 링크드인 채널 현재 운영 중이며, 유튜브·인스타그램 채널 개설 예정. 제품 데모 영상, 의사결정 사례 콘텐츠 등 마케팅 영상 촬영에 상시 활용.

## 1. 문제 인식 (Problem) — 창업 아이템의 필요성 (페이지 3)

### 시장 현황

**현대인은 정보 과잉 속에서 의사결정 피로에 시달리고 있고, 기존 도구는 이를 해결하지 못합니다.**

의사결정 피로의 보편성:
- 통계청 2025.2, "쉬었음" 청년(15~29세) **역대 최고 50.4만명**. 일자리 밖 2030세대 **158만명** — 진로 결정의 마비
- 잡코리아×원픽 2024.10, 직장인 719명 중 **73%가 이직 고민 중** — 결정 못하고 있는 상태
- AI가 답을 주면 오히려 불안해지는 **'AI 유발 불확실성 불안(AIUA)'** 현상 보고 [출처: LinkedIn/학술 분석 종합] — 선택지가 많아질수록 결정이 더 어려워짐

기존 도구에 돈은 쓰고 있음:
- 국내 점술 시장 **약 4.6조 원** [출처: The Economist 2018 추산], 점신 앱 **1,900만 다운로드/매출 979억** [출처: 매일경제 2025]
- 마인드카페 **누적 300만 회원, 매출 93억** [출처: 한경 2025, 사람인 재무정보]
- AI 상담 이용 의향 **40%** vs 실제 이용 **11%** [출처: 2024 국민정신건강조사] — 수요는 있으나 기존 서비스가 못 잡고 있음

AI 수용 기반:
- NIA·과기부 2024, 생성형 AI 이용률 **33%**, 1년 만에 약 2배 성장

### 기존 해결 방식의 문제점

| 기존 방식 | 문제 | 근거 |
|---------|------|------|
| ChatGPT | "답을 너무 쉽게 줘서 오히려 생각이 둔해진다." 프롬프트를 잘 짜야 좋은 답이 나옴. | AIUA 개념, ChatGPT를 "거울치료 도구"로만 사용하는 2030 패턴 [한경 2024.12] |
| 마인드카페·트로스트 | "패턴화된 말", "효과 의심 55%", "공감 부족 52%". 세션 후 산출물 없음. 1회 5~15만 원 고비용. | 2024 국민정신건강조사, 앱스토어 리뷰 종합 |
| 타로·사주 | 비합리적 프레임. 일시적 안도감은 주지만 실질적 행동 변화 없음. | 심리학 분석: "인지적 부하의 아웃소싱" — 결정의 짐을 운명에 전가 |
| 지인·커뮤니티 | 본인 경험 투영, 정보 과잉, 신뢰도 낮음, 혼란 가중 | |

### 풀림이 해결하는 핵심 문제

**사람들은 "정답"이 아니라 "혼란의 정리"를 원합니다.**

타로 시장 4.6조 원이 증명하는 것: 불확실성 속에서 "정리된 내러티브"를 듣고 싶은 욕구는 강력하고, 돈이 됩니다. 풀림은 이 욕구를 **합리적 방법**으로 충족합니다 — 운명이 아닌 소크라테스 질문으로, AI가 답을 주는 대신 사용자가 스스로 명확해지게.

세션이 끝나면 반드시 **의사결정 정리 문서 "첫 걸음"**이 남습니다. 이것이 타로와 기존 AI 상담 모두에 없는, 풀림만의 산출물입니다.

## 2. 실현 가능성 (Solution) — 창업 아이템의 개발 계획 (페이지 4)

### 개발 계획

**현재 상태**: v1 웹앱 프로토타입 구축·배포 완료 (pullim.vercel.app). v2 핵심 파이프라인 5개 기능 구현 완료.

**기술 스택**: Next.js 16 + React 19 + TypeScript + Tailwind CSS 4 + Claude API + Zustand(상태관리)
> Supabase(인증·DB·RLS 격리)는 v3 로드맵. 현재는 로컬 상태 기반.

**구현 완료 기능 (5개)** — 라이브 데모 가동 중:

1. **자동 라우팅**: 고민의 복잡도(가역성/중요도/긴급성/감정관여도)를 AI가 판단 → 단순 결정은 Quick Mode, 복잡 결정은 풀 파이프라인으로 자동 분기
2. **선택형 Socratic 질문**: 프롬프트 타이핑이 아닌 선택지 탭으로 진행. "이직이 현재 문제를 해결한다는 확신은 어디서 왔나요?" → [A: 커리어 성장이 막혀서 / B: 조직문화가 안 맞아서 / C: 사실 확신은 없어요 / 직접 입력]
3. **3관점 병렬 분석 + 토론**: 현실주의자·공감자·역발상가가 각각 독립 분석 후 교차 토론. 고민 유형에 따라 전문가 페르소나가 동적으로 바뀜.
4. **의사결정 정리 문서 "첫 걸음"**: 상황 요약 + 선택지 A/B/C + 대화에서 발견한 진짜 두려움 + 오늘 바로 할 수 있는 첫 행동 1개
5. **3층 위기 감지(RED 프로토콜)**: 위기 키워드 감지 시 AI 즉시 중단 → 자살예방상담전화 109 안내. 방통위 생성형 AI 이용자 보호 가이드라인(2025.2) 준수.

**개발 예정 기능 (4개)** — 협약기간 내 구현:

6. **리서치 에이전트**: 결정에 필요한 정보를 자동 수집·정리. 급여 비교, 업계 동향, 유사 경험담 등.
7. **검증 에이전트**: 분석 결과의 논리적 허점·인지 편향을 교차 검증. 단일 AI의 환각(Hallucination) 방지.
8. **비동기 처리**: 파이프라인을 돌려놓고, 사용자는 중간에 개입하거나 나중에 결과 확인. 퇴근길에 시작 → 집에서 완성본 확인.
9. **Supabase 연동**: 사용자 인증, 세션 히스토리, RLS 기반 데이터 격리, 개인화 패턴 분석 기반.

> 솔직하게: 2주 만에 5개 핵심 기능을 구현·배포한 것 자체가 실행력 증거입니다. 나머지 4개는 협약기간 10개월 안에 충분히 구현 가능합니다.

**왜 이게 지금 가능한가**:
- 2024~2025 LLM API 가격 하락: Sonnet 기준 세션당 **~300원** 실현 [출처: Anthropic API 가격표]
- 멀티 에이전트 토론 아키텍처(MentalAgora, MedARC)가 2025~2026년 학술적으로 검증됨 [출처: arXiv 2407.02736]
- 생성형 AI 이용률 33% → AI 기반 서비스 수용 기반 형성

**LLM은 교체 가능한 인프라**: 현재 Claude API를 사용하나, GPT, 중국산 sLLM 등 더 저렴하고 효율적인 모델이 등장하면 즉시 교체 가능한 모듈형 아키텍처. 축적된 의사결정 대화 데이터로 특화 sLLM 파인튜닝 로드맵도 보유.

- 엑시트 시나리오: 특화 의사결정 도구는 교육·HR·헬스케어 플랫폼의 부가 서비스로 M&A 수요 존재 (Pi→Microsoft 6.5억 달러 사례 참고)

### 사회적 가치

**환경**: AI SaaS 특성상 물리적 폐기물 최소. 서버리스(Vercel) + 클라우드 DB(Supabase)로 에너지 효율적 인프라.

**사회**:
- 의사결정 접근성 확대: O2O 상담 1회 5~20만 원 vs 풀림 월 7,500원 8세션 → 비용 장벽 해소
- 위기 감지 시 전문기관(자살예방상담전화 109) 즉시 연결 → 방통위 생성형 AI 가이드라인(2025.2) 준수
- 풀림은 전문 심리상담을 대체하지 않음. 의사결정 구조화 도구로 포지셔닝하여 기존 상담 인프라와 공존. 비의료행위 영역.

**지배구조**:
- 모든 의사결정을 문서로 기록하는 투명 경영 (Decision Record 시스템 자체가 제품의 원천)
- AI 윤리: "AI는 답을 주지 않는다" 원칙 — 사용자 자율성 존중이 제품 철학

### 심사위원 예상 Q&A (4라운드 합의 기반)

**Q1: "ChatGPT랑 뭐가 다른데?"**
> "ChatGPT는 빈 화면에 프롬프트를 잘 써야 합니다. 풀림은 선택만으로 5단계 파이프라인이 자동으로 돌아갑니다. AI를 모르는 사람도 사용 가능합니다. ChatGPT는 1개 관점으로 답을 주지만, 풀림은 3개 관점이 토론하고 결과물이 대화가 아니라 '의사결정 정리 문서'로 남습니다."

**Q2: "리서치 에이전트가 아직 없다며?"**
> "현재 라이브는 5개 핵심 기능입니다. 리서치·검증 에이전트는 v3 로드맵으로 협약기간 내 구현 예정입니다. 중요한 건, 2주 만에 5개 기능을 만든 것 자체가 실행력 증거입니다. 나머지 4개는 10개월이면 충분합니다."

**Q3: "희랩이랑 겹치지 않나?"**
> "희랩은 그림으로 심리 상태를 '측정'합니다(CV 기반, B2B). 풀림은 대화로 의사결정을 '구조화'합니다(LLM 기반, B2C). 기술·타겟·산출물이 모두 다릅니다. 오히려 둘이 합쳐지면 '진단→치료→결정'이라는 멘탈케어 밸류체인이 완성됩니다."

**Q4: "Pi가 실패하고 Woebot도 중단됐는데?"**
> "Pi는 '감정적 동반자 챗봇', Woebot은 '디지털 치료제'로 의료 규제+높은 운영비에 노출됐습니다. 풀림은 의료기기가 아닌 '의사결정 생산성 도구'입니다. 노션이 메모장을 대체하듯, 풀림은 혼란스러운 사고를 구조화하는 유틸리티입니다."

**Q5: "1,000명은 비현실적 아닌가?" → (수정됨)**
> "솔직히 200명이 현실 목표입니다. 노출 50,000 → 방문 5,000 → 가입 1,000 → 유료 200. 전환율은 베타에서 검증합니다. 보수적으로 5% 전환해도 50명이고, BEP(15명)는 달성합니다."

**Q6: "왜 계속 쓰지? 한 번 쓰고 끝 아닌가?"**
> "의사결정은 1회성이 아닙니다. 이직을 결정한 뒤에도 '어느 회사?', '언제?', '어떻게 말하지?' 후속 결정이 이어집니다. 위클리 체크인으로 실행을 추적하고, 마이크로 세션으로 일상 결정을 처리하고, 월간 패턴 리포트로 자기 성장을 시각화합니다. 이것이 습관 루프입니다."

**Q7: "해자가 약하지 않나?"**
> "Day 1 해자는 약합니다, 인정합니다. ChatGPT 프롬프트로 비슷한 걸 만들 수 있습니다. 하지만 시간이 갈수록 강화되는 구조입니다. 프롬프트 품질 → 개인화 패턴 데이터(6개월) → 한국인 의사결정 행동 데이터셋(12개월). 이 데이터는 풀림만 가지게 됩니다."

**Q8: "AI 규제는?"**
> "풀림은 진단·치료를 표방하지 않는 '의사결정 보조 도구'로, 디지털의료제품법(2025.1 시행) 대상이 아닙니다. 다만 방통위 생성형 AI 이용자 보호 가이드라인(2025.2)에 따라, 위기 키워드 감지 시 AI 즉시 중단 + 전문기관(109) 안내하는 RED 프로토콜을 이미 구현했습니다."
