## [첨부1] 사업계획서 요약 (페이지 2)

### 창업아이템 개요

**풀림(Pullim)은 "삶의 안식처"입니다. 지친 사람이 모닥불 앞에 앉아, 수정구슬로 자기 고민을 들여다보고, 현자의 질문에 스스로 답을 찾는 경험.**

타로 카페에 가는 이유는 "미래 예측"이 아니라 "혼란의 정리"입니다. 풀림은 이 욕구를 합리적 방법으로 충족합니다 — 운명이 아닌 이종 AI 3개 모델이 현실을 보여주고, 선택은 사용자가 합니다.

**9단계 파이프라인**:
1. **고민 입력 + 자동 라우팅** — AI가 복잡도를 판단하여 파이프라인 자동 분기
2. **리서치** — 실시간 웹 검색으로 데이터 수집 (통계, 사례, 전문가 견해)
3. **팩트체크** — Judge 모델이 리서치 결과 검증 (사용자에게 비노출)
4. **구슬 선택** — 10개 수정구슬 중 3개 선택 ("어떤 눈으로 세상을 보고 싶은가?")
5. **이종 모델 병렬 분석** — Claude + GPT + Gemini가 각각 독립 분석 → 진짜 불일치 추출
6. **교차 토론** — 구슬 간 반론-수용 2라운드 (모델 교차 수행으로 자기합리화 방지)
7. **최종 검증** — Judge 모델이 전체 논리 흐름 검증
8. **결론** — 상황 요약 + 선택지(리스크/보상) + 핵심 갈림길 + 사용자 성향
9. **행동 약속** — "뭘 해볼 건가?" → 선택 → 기한 → **"기다리고 있겠네"**

**3테마 세계관** (같은 파이프라인, 다른 분위기):

| 테마 | 캐릭터 | 세계관 | 비주얼 |
|------|--------|--------|--------|
| 🧙 모험가 | 현자 | 오두막 + 모닥불 | 도트 아트, RPG 감성 |
| 💼 전략실 | 비서 | 도시 야경 + 전략실 | 미니멀, 프로 감성 |
| 🌿 달빛정원 | 친구 | 달빛 + 꽃밭 | 파스텔, 힐링 감성 |

**10개 수정구슬 시스템** — 사용자에게는 "구슬을 고르는 의식", 내부적으로는 분석 렌즈:

| 구슬 | 이름 | 보이는 것 | 내부 분석 프레임 |
|------|------|----------|---------------|

**구현 완료**:
- 자동 라우팅 (복잡도 판단 → 파이프라인 자동 분기)
- Socratic 질문 (선택형 인터페이스)
- 3관점 병렬 분석 + 교차 토론
- 의사결정 정리 문서 자동 생성
- 3층 위기 감지 RED 프로토콜 (109 안내)
- **끝판왕 프론트엔드 UI** (모험가 모드 — 모닥불 배경, 구슬 선택, 9단계 파이프라인 화면 흐름)

**개발 예정** (끝판왕 파이프라인):
- 이종 모델 오케스트레이션 (Claude + GPT + Gemini 독립 분석)
- 리서치 에이전트 (Tavily API 실시간 검색 → 데이터 카드)
- Judge 검증 (Haiku 독립 팩트체크)
- 비동기 처리 + Supabase 인증·데이터 연동

**핵심**: ChatGPT는 빈 화면에 프롬프트를 잘 써야 합니다. 풀림은 구슬을 고르면 3개 AI가 알아서 분석합니다. AI를 모르는 사람도 사용 가능합니다.

### 목표시장 및 사업화 추진 전략

**비즈니스 모델 — 재화 + 광고+구독 이중 모델**:

**수정구슬**(10개)은 분석 관점을 고르는 것이고, **재화**(모험가 테마에서 "불씨"🔥)는 파이프라인 단계를 여는 소모 단위입니다. 수정구슬은 사라지지 않고, 재화만 소모됩니다.

세션 시작 전에 비용을 정하지 않고, **진행하면서 단계마다 재화를 소모할지 사용자가 선택**. 가벼운 고민은 1~2재화, 무거운 고민은 4~6재화로 자연스럽게 분기.

| 티어 | 가격 | 재화 (주간) | 파이프라인 |
|------|------|-----------|----------|
| Free (무료) | 0원/월 | 주 10재화 + 미션으로 추가 획득 | **풀 (품질 동일)** |
| **Standard** | **9,900원/월** | 주 50재화 + Quick Mode + 히스토리 | **풀 (이종 모델 3개)** |
| **Pro** | **19,900원/월** | 주 120재화 + 3테마 + 100% 이월 + 패턴 리포트 | **풀 (품질 동일)** |

- **점진적 소모**: 입장+듣기는 무료 → 리서치(+1재화) → 수정구슬 분석(+1재화씩) → 토론(+1재화) → 결론(무료). 사용자가 매 순간 통제권을 가짐.
- **품질 차등 없음**: 무료도 유료와 동일한 이종 모델 풀 파이프라인. 사용 횟수(재화)로만 차등 → "와, 이게 무료?" 경험이 전환 동기.
- **Quick Mode**: 일상적 결정(점심·일정)을 30초 내 정리. 재화 1개. "풀림 열기"의 진입 장벽을 낮춤.
- **미션 → 재화**: 오퍼월 미션/설문 참여로 재화 획득 (일 3건, 주 9건 상한). 세션 중 광고 삽입 절대 금지. [출처: 무료티어_설계 §3, Tapjoy·Pollfish eCPM 리서치]

## 1. 문제 인식 (Problem) — 창업 아이템의 필요성 (페이지 3)

### 시장 현황

**현대인은 정보 과잉 속에서 의사결정 피로에 시달리고 있고, "혼란의 정리"를 원하지만 기존 도구는 재미가 없거나 실질이 없습니다.**

의사결정 피로의 보편성:
- 통계청 2025.2, "쉬었음" 청년(15~29세) **역대 최고 50.4만명**. 일자리 밖 2030세대 **158만명** — 진로 결정의 마비
- 잡코리아×원픽 2024.10, 직장인 719명 중 **73%가 이직 고민 중** — 결정 못 하고 있는 상태
- AI가 답을 주면 오히려 불안해지는 **'AI 유발 불확실성 불안(AIUA)'** 현상 보고 [출처: LinkedIn/학술 분석 종합]

**"혼란의 정리"에 돈을 쓰고 있다** — 수요는 이미 검증됨:
- 국내 점술 시장 **약 4.6조 원** [출처: The Economist 2018 추산], 점신 앱 **1,900만 DL/매출 979억** [출처: 매일경제 2025]
- 마인드카페 **누적 300만 회원, 매출 93억** [출처: 한경 2025]
- 글로벌 점성술/타로 앱 시장 **~$50억** (연 20%+ 성장) [출처: Gemini Deep Research]
- AI 상담 이용 의향 **40%** vs 실제 이용 **11%** — 수요는 있으나 기존 서비스가 못 잡고 있음 [출처: 2024 국민정신건강조사]

### 기존 해결 방식의 문제점

| 기존 방식 | 핵심 문제 | 근거 |
|---------|---------|------|
| **ChatGPT** | 빈 화면 + 프롬프트 필요. 1개 모델의 확인편향. 재미 없음. | AIUA 개념, "답을 너무 쉽게 줘서 생각이 둔해진다" |
| **마인드카페·트로스트** | AI 상담의 핵심 불만: 효과 의심 55%, 공감 부족 52% — **"공감의 함정(Empathy Trap)"**. 1회 5~15만 원. 세션 후 산출물 없음. | 2024 국민정신건강조사, Gemini Deep Research |
| **타로·사주 앱** | 재미는 있지만 비합리적 프레임. 데이터 기반 분석 없음. 행동 변화 없음. | 점신 979억·포스텔러 100억의 시장 규모가 수요 증명 |
| **Co-Star** | 매일 운세 보는 일일 루틴이지 의사결정 도구 아님. 공격적 푸시 알림 → 정신건강 우려 비판. | Co-Star 2,100만 DL, 미국 월 매출 ~$21만 [출처: Perplexity 실시간 검색] |
| **지인·커뮤니티** | 본인 경험 투영, 정보 과잉, 혼란 가중 | |

### 풀림이 해결하는 핵심 문제

**사람들은 "정답"이 아니라 "혼란의 정리"를 원합니다. 그리고 그 과정이 재미있어야 돌아옵니다.**

타로 시장 4.6조 원이 증명합니다: 불확실성 속에서 "정리된 내러티브"를 듣고 싶은 욕구는 강력하고, 돈이 됩니다. 하지만 타로에는 실질이 없고, AI 도구에는 재미가 없습니다.

풀림은 **타로의 의식성(모닥불, 구슬, 현자라는 의식적 경험)과 AI의 실질성(이종 모델 분석, 리서치, 팩트체크)을 결합**합니다. 구슬을 고르는 의식 아래에 3개 AI 모델의 독립 분석이 있고, 세션이 끝나면 **리스크/보상/확률/성향을 담은 결론 문서 + 구체적 행동 약속**이 남습니다. 이것이 타로와 ChatGPT 모두에 없는, 풀림만의 조합입니다.

## 2. 실현 가능성 (Solution) — 창업 아이템의 개발 계획 (페이지 4)

### 개발 계획

**현재 상태**: v1 프로토타입 배포 완료 (pullim.vercel.app). v2 핵심 파이프라인 5개 기능 구현 완료. **끝판왕 설계 12건 + 프론트엔드 UI 구현 완료** (백엔드 API 연결 진행 중).

**기술 스택**: Next.js 15 + React 19 + TypeScript + Tailwind CSS 4 + Zustand + Claude API (Sonnet 4.6) + **GPT API (GPT-5.4) + Gemini API (3.1 Pro) + Tavily API**
> LLM은 교체 가능한 인프라. 모듈형 프로바이더 아키텍처로 어떤 모델이든 플러그인 방식으로 교체 가능.

**구현 완료 기능 (6개)** — 라이브 데모 가동 중:

1. **자동 라우팅**: 고민의 복잡도(가역성/중요도/긴급성/감정관여도)를 Haiku가 판단 → Quick Mode or 풀 파이프라인 자동 분기
2. **선택형 Socratic 질문**: 프롬프트 타이핑이 아닌 선택지 탭으로 진행. 전제를 흔드는 질문.
3. **3관점 병렬 분석 + 토론**: 독립 분석 후 교차 토론 → 불일치 지점 = 사용자 고민의 핵심 갈림길
4. **의사결정 정리 문서**: 상황 요약 + 선택지 + 진짜 두려움 + 첫 행동 1개
5. **3층 위기 감지(RED 프로토콜)**: 위기 키워드 감지 시 AI 즉시 중단 → 자살예방상담전화 109 안내. 방통위 생성형 AI 이용자 보호 가이드라인(2025.2) 준수.
6. **끝판왕 프론트엔드 UI**: 모험가 모드 세션 페이지 (모닥불 배경, 9단계 파이프라인 화면 흐름, 구슬 선택 애니메이션, 데이터 카드, 결론 뷰)

**개발 예정 기능 (4개)** — 협약기간 내 구현:

7. **이종 모델 오케스트레이션**: 구슬 3개 = Claude + GPT + Gemini가 각각 독립 분석. 같은 프롬프트, 다른 모델 → 진짜 불일치. 라운드 로빈 배정으로 모델-구슬 고착 방지.
8. **리서치 에이전트**: Tavily API로 실시간 웹 검색 → 통계/사례/전문가 견해 → Sonnet이 구조화 → Judge가 팩트체크.
9. **비동기 처리**: 파이프라인 돌려놓고 나중에 확인. 퇴근길에 시작 → 집에서 결과 확인.
10. **Supabase 연동**: 인증, 세션 히스토리, RLS 기반 데이터 격리, 개인화 패턴 분석.

> 솔직하게: 2주 만에 5개 핵심 기능을 구현·배포하고, 2일 만에 끝판왕 설계 12건을 완성한 것 자체가 실행력 증거입니다. 이종 모델 연동은 API 키 설정 + 프로바이더 코드 작성으로 2~3주 내 가능합니다.

**왜 이게 지금 가능한가**:
- 2024~2026 LLM API 가격 급락: Gemini 2.5 Flash **무료** 1,500회/일, GPT 4.1 mini 세션당 **~30원**
- 멀티 에이전트 토론 아키텍처(MentalAgora, MedARC)가 학술적으로 검증됨 [출처: arXiv 2407.02736]
- Socratic AI가 글로벌 트렌드: EU TITAN 프로젝트, 칸아카데미 Khanmigo 등에서 "답을 주지 않는 AI"가 교육·코칭의 정점으로 부상 [출처: Gemini Deep Research]
- 이종 모델 불일치(Inter-model disagreement)가 단일 모델 자문자답보다 **진짜 관점 다양성** 제공

### 이종 모델 오케스트레이션 — 핵심 기술 차별화

기존 v2는 같은 모델(Claude Sonnet)이 3명의 전문가를 연기했습니다. 끝판왕은 **3개 다른 모델이 각각 독립 분석**합니다.

| | v2 (기존) | 끝판왕 |
|---|---------|--------|
| 분석 주체 | Claude × 3 (같은 모델, 다른 프롬프트) | **Claude + GPT + Gemini** (다른 모델, 같은 프롬프트) |
| 관점 | "전문가 역할극" | **"수정구슬 = 분석 렌즈"** (관점 자체가 주체) |
| 불일치 | 인위적 (같은 모델이 만든 차이) | **진짜** (모델 고유 편향에서 나온 차이) |
| 토론 | 같은 모델 자문자답 | **모델 간 교차 반론** (자기합리화 방지) |
| 검증 | 없음 | **Judge 모델 독립 검증** |

**폴백 전략**: 모델 1개 실패 → 나머지 2개로 진행 ("구슬 하나가 흐려졌군..." 연출). 모델 2개 실패 → 단일 모델 3관점 분석 (v2 호환 모드). 모델 전부 실패 → 리서치 데이터 기반 정리만 제공.

## 3. 성장전략 (Scale-up) — 사업화 추진 전략 (페이지 5)

### 비즈니스 모델 (수익화)

- **광고+구독 이중 모델**:
  - Free(무료): 오퍼월 미션/설문 참여로 재화 획득 + 주 10재화. 품질 동일.
  - Standard(9,900원): 광고 없음 + 주 50재화 + 히스토리 + Quick Mode
  - Pro(19,900원): 주 120재화 + 3테마 전체 + 100% 이월 + 월간 패턴 리포트
- **가격 앵커링**: 포스텔러 심층 사주 1회(3,000~20,000원) = 풀림 여정 1달. O2O 상담 1회(5~15만 원) > 풀림 현자 **2.5~7.5달**. 타로 카페 1회(2~5만 원) > 풀림 여정 **2~5달**.
- **Unit Economics**: 재화당 ~65원 (MVP 원가, 교차검증 수렴), 풀 세션 ~240원, BEP 유료 약 13명 [출처: 재화_원가_분석, BEP_재계산]
- **12개월 목표**: 유료 200명, 연 매출 ~3,100만 원

### 목표시장 진입 전략

풀림은 기능을 마케팅하지 않습니다. **경험을 마케팅합니다.** 모닥불 앞에 앉아 수정구슬로 세상을 들여다보는 의식(ritual) — 이것이 콘텐츠이자 제품이자 마케팅입니다.

| Phase | 시기 | 채널 | 비용 |
|-------|------|------|------|
| 씨앗 | 1~3개월 | 에브리타임 + 링크드인 + 인스타 릴스 + **한성대 커뮤니티** | 0원 |
| 뿌리 | 4~6개월 | SEO 블로그 + 유튜브 숏폼 + 타로/MBTI 커뮤니티 + 인플루언서 시딩 | 0원 |
| 가지 | 7~12개월 | **바이럴 공유 카드** + 리퍼럴 + 대학 제휴 + (선택) 유료 광고 | 0~30만 원/월 |

**바이럴 엔진 — 세션 공유 카드**:
- 세션 종료 시 도트 아트 스타일 카드 자동 생성 (구슬 3개 + 핵심 갈림길 + 시그니처 문구)
- 카카오톡/인스타 스토리/X 공유 → "이게 뭐야?" → 풀림 유입
- 마케팅 비용 0원의 유기적 성장 채널

**"늦은 밤 전환" 시나리오**:
1. 밤 11시, 혼자. 내일 출근이 두렵다.
2. "풀림" 접속 → 무료 세션 → 현자와 대화 → "이거... 진짜 도움이 되네"
3. 세션 끝 → "이종 모델 풀 분석을 받고 싶으신가요?" → 9,900원
4. **만원 이하 = 실제로 도움을 받은 순간, 자연스럽게 구독으로 이어진다**

### 심사위원 예상 Q&A

**Q1: "ChatGPT랑 뭐가 다른데?"**
> "ChatGPT는 빈 화면에 프롬프트를 잘 써야 합니다. 풀림은 구슬을 3개 고르면 끝입니다. Claude, GPT, Gemini 3개 모델이 각각 독립 분석하고, 불일치 지점이 고민의 핵심 갈림길입니다. AI를 모르는 사람도 사용 가능합니다."

**Q2: "이종 모델이 아직 연결 안 됐다며?"**
> "현재 라이브는 v2 기능 5개 + 끝판왕 프론트엔드 UI입니다. 이종 모델 API 연결은 백엔드 작업으로 2~3주면 가능합니다. 중요한 건, 2주 만에 5개 기능을 만들고, 2일 만에 설계 12건을 완성한 실행력입니다."

**Q3: "타로 프레이밍이 법적으로 문제 아닌가?"**
> "풀림은 점술 서비스가 아닙니다. 타로 메타포는 UX의 일부이며, 내부는 이종 AI 모델의 데이터 기반 분석입니다. 사업자등록도 정보서비스업으로 진행하며, 포스텔러(매출 100억)와 동일한 업종 구조입니다."

**Q4: "Pi가 실패하고 Woebot도 접었는데?"**
> "Pi/Woebot은 '감정적 공감'만 팔았습니다. 돈 안 됩니다. 풀림은 '의식적 경험 + 실질적 산출물(리스크/보상 분석 + 행동 약속)'입니다. 지불 가치가 다릅니다. 또한 초기부터 B2B(대학 진로상담센터) 확장 로드맵을 보유하고 있습니다."

**Q5: "200명 어떻게 모으나?"**
> "무료 세션의 세계관 경험(모닥불+현자+구슬)이 첫 후크입니다. 세션 완료 시 자동 생성되는 공유 카드가 바이럴 엔진이고, 캐릭터가 약속 날짜에 '기다리고 있겠네'라고 리마인드하는 것이 리텐션입니다. 5% 전환에서도 BEP(13명)는 달성합니다."

**Q6: "1인 가능?"**
> "PMF 검증 전에 팀을 키우면 방향도 없이 조율 비용만 증가합니다. 2주 만에 5개 기능을 만든 것이 1인 실행력의 증거입니다. 디자인 외주는 ICC 지원금, 마케팅은 MRR로 순차 확보합니다."

**Q7: "AI 규제 강화되는데?"**
> "풀림은 진단·치료를 표방하지 않는 '코칭 도구'로, 디지털의료제품법 대상이 아닙니다. AI 기본법 투명성 의무는 설계에 이미 반영했고, 위기 감지 시 109 안내 + LLM 즉시 중단하는 RED 프로토콜을 탑재했습니다. 대표가 법&정책 트랙 전공입니다."

**Q8: "해자가 약하지 않나?"**
> "Day 1 해자는 약합니다. 인정합니다. 하지만 '모닥불 + 구슬 + 이종 모델'이라는 조합을 처음부터 설계한 것이 선점 효과입니다. 그리고 6개월 후 개인화 데이터, 12개월 후 한국인 의사결정 행동 데이터셋 — 이건 풀림만 가지게 됩니다."
