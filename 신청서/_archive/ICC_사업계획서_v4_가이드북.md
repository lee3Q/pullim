## [페이지 2] 사업계획서 요약

### "풀림(Pullim)은 '삶의 안식처'입니다. 지친 사람이 모닥불 앞에 앉아, 수정구슬로 자기 고민을 들여다보고, 현자의 질문에 스스로 답을 찾는 경험."

**왜 "안식처"인가?**
- 논리: 사람들이 타로에 가는 이유 = "미래 예측"이 아니라 "혼란의 정리". Gemini가 이것을 "인지적 부하의 아웃소싱(Cognitive Offloading)"이라고 분석.
- 출처: 리서치/시장분석_Gemini_2026-03-19.md — "사주에 돈 쓰는 이유 = 정확성이 아닌 결정의 짐을 덜어주는 안도감"
- 출처: 리서치/시장분석_교차분석_최종_2026-03-19.md §1-3

**왜 "모닥불 + 수정구슬 + 현자"인가?**
- 타로 카페의 경험을 디지털로 옮기되, 비합리성은 제거. 모닥불=공간, 구슬=카드 뽑기(분석 렌즈 선택), 현자=해석자.
- 출처: .state/decisions/2026-03-19_끝판왕_컨셉확정.md, handoff 15에서 대표와 논의 확인 ("기능이 아니라 경험의 프레임이 타로")

### "타로 카페에 가는 이유는 '미래 예측'이 아니라 '혼란의 정리'입니다."

**출처와 근거**:
- Gemini Deep Research: 20~30대가 타로를 "힐링 콘텐츠·엔터테인먼트"로 소비. 맹신X. "정리된 내러티브" 욕구.
- Perplexity: 점신 1,900만 DL/979억 매출이 수요 증명.
- 3/3 소스 일치: 리서치/시장분석_교차분석_최종_2026-03-19.md §1-3
- 논리: 4.6조 원 시장이 존재한다는 것 자체가 "혼란의 정리"에 돈을 쓴다는 증거.

### 9단계 파이프라인 설명

**각 단계의 근거**:

| 단계 | 왜 필요한가 | 출처 |
|------|-----------|------|
| 1. 고민 입력 + 자동 라우팅 | 모든 고민이 같은 깊이가 아님. "점심 뭐 먹지"와 "이직할까"는 다른 파이프라인 필요 | 자체 설계 판단 |
| 2. 리서치 | 감정이 아니라 데이터 기반 분석이 차별점. "느낌"이 아니라 "사실" 위에서 판단 | Tavily API 실시간 검색 설계. 경쟁사 분석에서 타로/마인드카페 모두 리서치 기능 없음 확인 |
| 3. 팩트체크 | 리서치 결과의 신뢰성 확보. 환각(hallucination) 방지 | MedARC 프레임워크: LLM 상호 비판 → 환각 방지 (학술 검증) |
| 4. 구슬 선택 | 사용자에게 "분석 관점을 직접 고르는" 주체성 부여. 타로의 "카드 뽑기" 의식을 재현하되 내부는 분석 렌즈 | 끝판왕 컨셉 — "프론트엔드는 리추얼, 백엔드는 추론" |
| 5. 이종 모델 병렬 분석 | 같은 모델 3개 = 인위적 차이. 다른 모델 3개 = 진짜 불일치. 이 불일치가 고민의 핵심 갈림길 | MentalAgora (arXiv 2407.02736): 멀티 에이전트 토론이 단일 모델보다 우수. 시장분석 교차분석 §1-2 |
| 6. 교차 토론 | 자기합리화 방지. 모델 A가 쓴 분석을 모델 B가 반박 → 진짜 약점 노출 | MentalAgora + MedARC 프레임워크 |
| 7. 최종 검증 | Judge 모델이 전체 논리 흐름의 모순/비약 체크 | Haiku를 Judge로 쓰는 이유: 저비용 + 빠른 응답 + 검증에 충분한 성능 |
| 8. 결론 | "신중히 하세요" 같은 빈말이 아닌, 리스크/보상/확률/성향을 담은 구조화된 산출물 | 경쟁사 분석: ChatGPT="신중히", 타로="이렇게 될 것", 마인드카페="힘드시겠어요" → 모두 행동으로 이어지지 않음 |
| 9. 행동 약속 | "뭘 해볼 건가?" → 구체적 행동 + 기한 → 푸시 리마인드. 세션이 행동으로 연결되는 유일한 서비스 | 경쟁제품 5축 분석에서 "행동 연결" 축 ★★★은 풀림과 BetterUp만 |

### 3테마 세계관 테이블

**왜 3테마인가?**
- 논리: 게임의 "스킨" = 프리미엄. 같은 파이프라인이지만 다른 분위기 → 달빛정원/전략실을 프로 티어 전용으로 잠금 → 업그레이드 동기.
- 모험가를 먼저 구현한 이유: RPG 감성이 가장 독특하고 차별화 강함. 도트 아트 + 모닥불 + 현자 = 기억에 남는 첫인상.
- 전략실은 "현실 전문가 브리핑" 톤: 게임 감성이 싫은 사용자를 위한 진지한 모드. 전문가 이름이 표시됨.
- 출처: .state/decisions/2026-03-19_끝판왕_컨셉확정.md

### 10개 수정구슬 시스템

**왜 10개인가?**
- 타로의 메이저 아르카나 22장 → 너무 많음. 사용자가 3개를 고르기에 10개가 적정 (인지 부하 vs 선택의 다양성 밸런스).
- 각 구슬은 실제 분석 프레임워크에 대응:
  - 금화 = 재무 분석, 나침반 = 커리어, 거울 = 행동경제학(인지 편향), 저울 = 법적 분석, 모닥불 = 가치관, 타인 = 관계, 심연 = 심리 패턴, 전략 = 경영, 뒤집기 = 철학적 리프레이밍, 몸 = 생활 건강
- 논리: "구슬을 고르는 행위"가 사용자에게는 의식(ritual)이지만, 내부적으로는 분석 렌즈를 선택하는 것.
- 출처: 끝판왕 파이프라인 설계 문서

### "ChatGPT는 빈 화면에 프롬프트를 잘 써야 합니다. 풀림은 구슬을 고르면 3개 AI가 알아서 분석합니다."

**논리구조**:
- ChatGPT의 진입 장벽: "프롬프트 엔지니어링"을 알아야 좋은 결과를 얻음. AI 리터러시가 없는 사람에게는 빈 화면이 공포.
- 풀림의 해결: 구슬 3개 탭 → 끝. "어떤 눈으로 세상을 보고 싶은가?"만 선택하면 AI가 알아서 분석.
- 출처: 경쟁제품 끝판왕분석 (리서치/경쟁제품_끝판왕분석_2026-03-20.md) — ChatGPT 진입방식 "프롬프트를 잘 짜야 함"

### 가격 테이블: Free(0원) / Standard(9,900원) / Pro(19,900원)

**가격 결정 근거**:
- v3에서 7,500원/14,900원 → v4에서 9,900원/19,900원으로 인상
- 인상 이유 4가지:
  1. 이종 모델(3개 AI) 도입으로 원가 증가
  2. "만원 이하" 심리적 가격대 (9,900원은 "만원 미만"으로 인식)
  3. 앵커링: 타로 1회(2~5만 원), O2O 상담 1회(5~15만 원) 대비 압도적 가성비
  4. 넷플릭스 Standard(13,500원) 대비 낮음
- 출처: B트랙 수익모델 심화설계 (B2), 시장분석 교차분석 §1-4
- "품질 차등 없음": 무료도 유료와 동일한 이종 모델 풀 파이프라인. 차이는 재화(사용 횟수)만. → "와, 이게 무료?" 경험이 전환 동기.

## [페이지 2 계속] 목표시장 및 사업화 추진 전략

### Unit Economics — "세션당 변동원가: ~250원 (보수적)"

**비용 수치 3단계 (혼동 주의)**:

| 수치 | 의미 | 사용 맥락 |
|------|------|----------|
| **~65원** | 재화 1개당 MVP 원가 | 재화 모델 설명 시 |
| **~120원** | 가중 평균 세션 비용 (가벼운 60% + 중간 25% + 무거운 15%) | 실제 운영 원가 추정 시 |
| **~250원** | 풀 파이프라인 1회 보수적 원가 | 사업계획서 공식 수치 (worst case) |

**수치의 출처와 검증 과정**:
- 3자 교차검증 완료: Claude + GLM-5 + GPT-5.4
- 비용 범위: 이론 최소 160원 / 현실 200원 / 보수적 250원
- 사업계획서에는 보수적 수치(250원) 적용 → 심사위원에게 "낙관적 수치가 아님"을 보여주는 전략
- 250원 구성: 시스템 프롬프트 토큰 + reasoning tokens + 재시도 + 이종 모델 3개 호출
- 출처: .state/projects/ICC_지원.md 비용 수치 항목, 재화_원가_분석 §4-5
- API 가격표 기준: Anthropic/OpenAI/Google API 공식 가격 (2026-03)

**심사위원이 "250원이랑 65원이랑 왜 다르냐?"고 물으면**:
> "65원은 재화 1개 단위 원가, 250원은 풀 파이프라인(이종 모델 3개 + 리서치 + Judge) 1회 원가입니다. 가벼운 고민은 재화 1~2개(65~130원), 풀 분석은 4~6재화(250원)입니다. 사업계획서에는 최악의 시나리오인 250원을 적용했습니다."

### "가중 평균 세션 비용: ~120원"

**논리**: 모든 사용자가 풀 파이프라인을 돌리지 않음. 가벼운 고민(60%) × 50원 + 중간(25%) × 150원 + 무거운(15%) × 250원 = ~120원. 실제 과금 기준인 재화당 원가는 ~65원.

### "BEP: 유료 약 13명"

**계산**:
- 고정비: 월 ~85,000원 (Vercel Pro 20,000 + 도메인 ~2,000 + Tavily Pro 50,000 + 기타 ~13,000)
- 순이익/인: 9,900원(월구독) - ~3,250원(월 변동비) = ~6,650원
- BEP = 85,000 ÷ 6,650 ≈ 13명
- 출처: BEP_재계산 §4, 재화_원가_분석 §5

### TAM ~2,000억 원

**산출 근거**:
- 점신 979억 매출 (매일경제 2025)
- 포스텔러 ~100억 매출 (추정, 한경 2025)
- 마인드카페 93억 매출 (한경 2025)
- 기타 디지털 자기계발/운세 서비스 합산
- **바텀업 방식**: 개별 서비스 매출 합산. TAM을 "한국 점술 시장 4.6조"로 잡지 않고, 실제 디지털 결제가 일어나는 영역만 계산 → 현실적.
- 출처: 매일경제 2025, 한경 2025, 사람인 재무정보

### 12개 경쟁사 5축 분석 테이블

**5축 정의와 출처**:
- 의식성(Ritual): 모닥불·구슬·캐릭터 같은 의식적 경험
- 실질성(Substance): 데이터/분석 기반 실질적 도움
- 게임성(Fun): 재미, "다시 해보고 싶다"
- 다관점(Multi-view): 여러 각도로 보는가
- 행동(Action): 세션 후 구체적 행동 연결
- 출처: 리서치/경쟁제품_끝판왕분석_2026-03-20.md §1

**왜 풀림 실질성이 ★★☆인가?**
- 솔직한 평가: 이종 모델 분석+리서치가 설계되어 있으나 MVP 단계라 실사용자 검증 미완료. 정식 출시 후 ★★★ 가능.
- 이것을 솔직히 쓴 이유: 심사위원이 "자기 평가가 객관적인가"를 봄. 모든 축 만점은 오히려 신뢰 하락.

### 3개 구조적 장벽과 돌파

**장벽 1: 윤리적 리스크**
- 문제: 타로의 무작위성으로 인생 조언 → 책임 문제
- 풀림의 답: 구슬 = 분석 렌즈의 메타포. 뒤에는 이종 모델의 진짜 데이터 분석.
- 논리: "타로처럼 보이지만 타로가 아니다"가 핵심. 프론트엔드만 리추얼, 백엔드는 추론.

**장벽 2: 기술적 딜레마**
- 문제: 추론 AI + 비과학적 점술 = 아키텍처 모순
- 풀림의 답: UI 레이어(세계관)와 분석 레이어(AI 파이프라인)의 명확한 분리.

**장벽 3: 문화적 장벽**
- 문제: 서구 AI = 하이퍼-합리주의 → 영적 요소 배척
- 풀림의 답: 한국 = 운세 WTP 4.6조 원 시장. 점신 1,900만 다운로드. 문화적으로 가장 적합한 테스트베드.
- 출처: The Economist 2018 추산, 매일경제 2025

### 200명 도달 퍼널

| 단계 | 전환율 | 근거 |
|------|--------|------|
| 노출 → 방문: 10% | 고관여 키워드("이직 고민" 등) 기준. 일반 광고 CTR 1~3%보다 높지만, SEO/커뮤니티는 관심 있는 사람만 유입 |
| 방문 → 가입: 20% | 무료 세션 3회 + 세계관 경험(모닥불+현자)이 강력한 후크. SaaS 평균 가입 전환율 5~15% 대비 공격적이지만, 무료 가치가 높음 |
| 가입 → 유료: 20% | 세계관 몰입 + 이종 모델 차별화 + 만원 이하 심리 가격. **⚠️ 공격적 가정**. 5%에서도 BEP 달성 |

**왜 20% 전환율이 공격적인지 솔직히 밝혔나?**
- 심사위원은 과장된 숫자를 싫어함. "솔직하게" 라벨을 달면 오히려 신뢰 상승.
- 5% 시나리오(50명)에서도 BEP(13명) 달성이라는 안전장치를 보여줌.

**출처**: LinkedIn/학술 분석 종합 (시장분석 교차분석 최종)

### "국내 점술 시장 약 4.6조 원"

### 구현 완료 6개 기능 리스트

**각 기능의 증거**:

2. 선택형 Socratic 질문: 프롬프트 타이핑 대신 선택지 탭. 코드에 구현됨.

4. 의사결정 정리 문서: 세션 완료 시 자동 생성.
5. RED 프로토콜: 위기 키워드 감지 → AI 중단 → 109 안내. 방통위 가이드라인(2025.2) 준수.
6. 끝판왕 프론트엔드 UI: 모험가 모드 세션 페이지, 구슬 선택 등 구현 완료.
- 증거: pullim.vercel.app 라이브 데모 + 소스 코드 (pullim/ 디렉토리)

### 이종 모델 오케스트레이션 비교 테이블 (v2 vs 끝판왕)

**핵심 논리**: "같은 모델 3개 = 자문자답. 다른 모델 3개 = 진짜 불일치."
- v2: Claude × 3, 같은 모델이 다른 프롬프트 → 인위적 차이
- 끝판왕: Claude + GPT + Gemini, 다른 모델이 같은 프롬프트 → 모델 고유 편향에서 나온 진짜 차이
- 이것이 풀림의 핵심 기술 차별화.
- 라운드 로빈 배정: 구슬 A=Claude, 구슬 B=GPT, 구슬 C=Gemini → 다음 세션에서는 배정 순환 → 모델-구슬 고착 방지.

### 폴백 전략

**왜 이걸 썼나?**
- 심사위원이 "모델 하나 장애 나면 어떡해?"라고 물을 것에 대비.
- 3단계 폴백: 1개 실패→2개로 진행 / 2개 실패→v2 호환 모드 / 전부 실패→리서치 데이터만 제공.
- "구슬 하나가 흐려졌군..." 연출: 기술적 장애를 세계관 내에서 자연스럽게 처리.

### 사업추진 일정 (협약기간 내)

**일정의 논리**:
- v3에서 v4로 바꾸면서 일정을 뒤로 밀었음 ("베타 5월"→"베타 7월", "정식 7월"→"정식 10월")
- 이유: 이종 모델 파이프라인 구현 + 법적 기반(이용약관/개인정보처리방침) 완비에 시간 필요.
- 심사위원에게: "빨리 하겠다"보다 "제대로 하겠다"가 더 신뢰.

## [페이지 5] 성장전략 (Scale-up)

### "풀림은 기능을 마케팅하지 않습니다. 경험을 마케팅합니다."

**논리**:
- 기능 마케팅: "이종 AI 3개 모델 분석" → 일반인이 이해 불가
- 경험 마케팅: "모닥불 앞에 앉아 수정구슬로 세상을 들여다보세요" → 호기심 유발
- 타로 시장이 증명: 사람들은 "분석 기법"이 아니라 "경험"에 돈을 씀.

### 마케팅 채널 (씨앗 → 뿌리 → 가지)

**왜 0원부터 시작하나?**
- BEP 13명이면 유료 광고 없이도 달성 가능한 규모.
- 에브리타임: 한성대생 접근. "이직 고민" "진로 고민" 키워드로 자연스럽게 유입.
- 바이럴 공유 카드: 세션 종료 시 도트 아트 카드 자동 생성 → SNS 공유 → 유기적 성장. 마케팅 비용 0원.

### "늦은 밤 전환" 시나리오

**왜 이 시나리오를 썼나?**
- 타로 카페 방문 시간 = 주로 저녁~밤. 감성적 의사결정이 일어나는 시간대.
- "만원 이하 = 실제로 도움을 받은 순간, 자연스럽게 구독" → 가격 저항이 낮은 순간을 포착.

### 해자(Moat) 테이블 — Day 1 / 6개월 / 12개월+

**왜 "Day 1 해자는 약합니다"라고 솔직히 썼나?**
- 심사위원이 "경쟁자가 복제하면?" 질문할 것. "강합니다"라고 하면 신뢰 하락.
- 솔직한 인정 + 시간 경과에 따른 강화 구조 = 더 설득력 있음.
- Day 1: 프롬프트 + 세계관 → 복제 가능하지만 시행착오 비용이 진입 장벽
- 6개월: 개인화 데이터 축적 → 복제 불가
- 12개월: 한국인 의사결정 행동 데이터셋 → 풀림만 보유. sLLM 파인튜닝 원료.

### B2B 확장 방향

**왜 B2B를 언급했나?**
- ICC 심사에서 "확장성"을 봄. B2C만으로는 스케일 제한.
- 선례: 마인드카페(EAP 250개 기업, 93억), 트로스트(넛지헬스케어 인수) → B2B로 수익 다각화 성공.
- 풀림의 B2B 경로: 대학 진로상담센터 → 기업 EAP. 한성대 ICC 입주 시 교내 PoC 우선.

**왜 법률 섹션이 있나?**
- 대부분의 사업계획서에 법률 대응이 없음 → 차별화.
- 대표가 법&정책 트랙 전공 → 이것이 강점이라는 걸 보여주는 섹션.

## [심사위원 예상 Q&A] 가이드

### Q1: "ChatGPT랑 뭐가 다른데?"

**답변의 논리구조**:
1. 진입 장벽 차이: ChatGPT = 프롬프트 필요 vs 풀림 = 구슬 3개 고르기
2. 분석 구조 차이: 1개 모델 확인편향 vs 3개 이종 모델 독립 분석
3. 불일치 = 가치: "모델이 동의하지 않는 지점이 당신 고민의 핵심 갈림길"
4. 접근성: AI를 모르는 사람도 사용 가능

### Q2: "이종 모델이 아직 연결 안 됐다며?"

**답변의 논리구조**:
1. 현재 상태 솔직히 인정: v2 기능 5개 + 끝판왕 프론트엔드 UI
2. 기술적 근거: 이종 모델 API 연결 = 백엔드 작업 2~3주
3. 프레이밍 전환: "중요한 건 기술이 아니라 실행력. 2주 만에 5개 기능, 2일 만에 설계 12건."

### Q3: "타로 프레이밍이 법적으로 문제 아닌가?"

**답변의 논리구조**:
1. "점술 서비스가 아닙니다" — 명확한 선 긋기
2. 타로 메타포 = UX의 일부. 내부 = 이종 AI 데이터 기반 분석.
3. 업종 선례: 포스텔러(매출 100억) = 정보서비스업
4. 대표 법정책 전공 → 설계 단계부터 법적 그린존

### Q4: "Pi가 실패하고 Woebot도 접었는데?"

**답변의 논리구조**:
1. 실패 원인 분석: Pi/Woebot = '감정적 공감'만 → 돈 안 됨
2. 풀림의 차별: 의식적 경험 + 실질적 산출물(리스크/보상 + 행동 약속)
3. 지불 가치가 다름: 공감 vs 구조화된 행동 연결
4. B2B 확장 로드맵 보유: 대학 진로상담센터

### Q5: "200명 어떻게 모으나?"

**답변의 논리구조**:
1. 첫 후크: 무료 세션의 세계관 경험
2. 바이럴: 세션 공유 카드 자동 생성 → SNS → 유입
3. 리텐션: 캐릭터 리마인드 "기다리고 있겠네" (약속 날짜 푸시)
4. 안전장치: 5% 전환에서도 BEP(13명) 달성

### Q6: "1인 가능?"

**답변의 논리구조**:
1. 린 스타트업 원칙: PMF 전 팀 확대 = 방향 없이 조율 비용만 증가
2. 실행력 증거: 2주 만에 5개 기능
3. 보완 계획: 디자인 외주(ICC 지원금), 마케팅(MRR)으로 순차 확보
4. AI 도구가 팀을 대체: Claude Code + Cursor Pro = 1인 풀스택 개발 가능

### Q7: "AI 규제 강화되는데?"

**답변의 논리구조**:
1. 포지셔닝: 진단/치료 X → 디지털의료제품법 대상 아님
2. AI 기본법: 투명성 의무 이미 설계 반영
3. 위기 대응: RED 프로토콜 + 109 안내
4. 대표 자격: 법&정책 트랙 전공

### Q8: "해자가 약하지 않나?"

**답변의 논리구조**:
1. Day 1 솔직 인정: "약합니다"
2. 선점 효과: "모닥불+구슬+이종 모델" 조합을 먼저 설계한 것 자체
3. 시간 강화: 6개월→개인화 데이터, 12개월→행동 데이터셋
4. 데이터 해자: "한국인 의사결정 행동 데이터셋 = 풀림만 보유하게 됨"
