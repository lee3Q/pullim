## 슬라이드 13: Unit Economics

### 핵심 주장
변동비 기준 세션당 흑자 구조이며, 고정비 포함 BEP는 유료 약 40명이다.

### 발표 대본 (5분 압축판)

비용 구조입니다. 세션당 변동 원가 약 543원. Haiku 2원, Sonnet 150원, Opus 3명 391원 — Anthropic 공식 API 단가 기준 추정값입니다.

월 구독 7,500원, 월 4세션 기준 마진율 71%.

**PPT에 '유료 1명부터 즉시 흑자'라고 적었는데, 정확히는 변동비 기준입니다. 고정비 포함 BEP는 유료 약 40명입니다.**

초기 인프라는 Vercel·Supabase 무료 티어로 고정비를 최소화합니다.

### 암기 팩트
- 세션당 원가: 543원 (Haiku 2 + Sonnet 150 + Opus 3명 391) — **추정값**
- 월 구독 7,500원 / 월 4세션 / 마진율 71%
- **"유료 1명부터 즉시 흑자" = 변동비 기준. 고정비 포함 BEP = 유료 약 40명** (PPT 변호 필수)
- BEP 40명 근거: Claude Max 등 고정비 ÷ 세션당 마진 역산
- 수치는 추정값, 베타 후 실측 업데이트

### 예상 질문 + 답변

Q: "유료 1명부터 즉시 흑자라고 하셨는데, 개발 도구 비용은요?"
A: "PPT 표현이 부정확했습니다. 변동비 기준입니다. Claude Max 같은 고정비를 포함하면 BEP는 유료 약 40명이고, 초기 목표 구간인 3개월 내에 달성 가능합니다."

Q: "543원은 검증됐나요?"
A: "Anthropic 공식 API 단가 기준 추정치입니다. 40턴 가정으로 계층별 비용을 합산했고, 5월 베타에서 실제 API 로그로 검증합니다."

Q: "월 4세션 가정 근거는?"
A: "고민은 이벤트 기반이라 주 1회 수준이 자연스럽다고 봤습니다. 빈도가 낮으면 마진이 더 높아지는 구조입니다. 베타에서 실사용 빈도를 측정합니다."

## 슬라이드 14: 핵심 성과지표

### 핵심 주장
동아리 기간은 검증 중심, 이후 6개월은 수익 목표. 1,000명 도달 경로가 단계적으로 설계돼 있다.

### 발표 대본 (5분 압축판)

동아리 기간 KPI입니다.

3월: Socratic 수동 테스트 5명. 모집은 대표 주변 네트워크와 대학 커뮤니티 게시판으로 접근합니다.
5월: 웹앱 배포, 베타 20명.
7월: 의사결정 정리 문서 50건 누적.

**이 50건이 왜 중요하냐면, '누가 왜 돈을 내는가'를 보여주는 패턴 데이터가 되기 때문입니다.**

동아리 후 6개월: 유료 1,000명, MRR 750만원.

**경로는 이렇습니다. 베타 20명에서 핵심 패턴 추출 → 커뮤니티 직접 접근으로 100명 → SEO 인지 확장 → 1,000명. 단번에 50배 점프가 아니라 단계별 검증입니다.**

### 암기 팩트
- 3월: 5명 (주변 네트워크 + 대학 커뮤니티 게시판) / 5월: 베타 20명 / 7월: 문서 50건
- 문서 50건 = 무료+베타 포함, **패턴 분석용 데이터**
- 동아리 후: 유료 1,000명 / MRR 750만원
- **경로**: 20명 패턴 → 커뮤니티 100명 → SEO → 1,000명 (MAU 16만명의 0.6%)
- 3월 5명 모집 채널을 구체적으로 말할 수 있어야 함

### 예상 질문 + 답변

Q: "베타 20명에서 유료 1,000명으로 50배 점프하는 경로가 보이지 않습니다."
A: "단번에 가는 게 아닙니다. 20명 → 50건 문서 → 전환율 높은 고민 유형 발견 → 커뮤니티 직접 접근 100명 → SEO 인지 20만 → 퍼널 통해 1,000명입니다. 각 단계에서 숫자가 안 나오면 그 자리에서 전략을 수정합니다."

Q: "MRR 750만원, 3개월 내 BEP가 현실적인가요?"
A: "마진율 71% 구조에서 BEP 도달 속도는 빠릅니다. 5월 베타 전환율이 나오면 이 수치를 업데이트합니다. 목표라기보다 검증 기준입니다."

Q: "3월 5명은 어떻게 모으나요?"
A: "대표 주변 네트워크와 한성대·인근 대학 커뮤니티 게시판에서 직접 접근합니다. 타겟은 진로·이직 고민이 있는 20대입니다."

## 슬라이드 15: 진행 과정

### 핵심 주장
솔루션 검증 진행 중이다. 프로토타입 구축은 완료했고, 내부 테스트 단계다.

### 발표 대본 (5분 압축판)

현재 위치입니다.

**문제 검증에서 초기 시그널을 확인했습니다.** 2건 인터뷰 모두에서 '문제가 있다', '기존 방식 불만족', '돈을 낼 의향 있다' 세 가지 신호가 나왔습니다. 2건으로 완료라고 하지 않습니다. 3월 5건으로 패턴을 굳히는 중입니다.

솔루션 검증 진행 중입니다. v1 테스트 2회, v2 테스트 1회 완료.

**프로토타입은 구축 완료했고 현재 내부 테스트 단계입니다. API 키 세팅과 v2 멀티 에이전트 통합이 남아 있어서, 외부 공개 전 안정화를 먼저 마무리합니다.**

### 암기 팩트
- **"검증 완료" 표현 절대 금지 → "초기 시그널 확인, 패턴 굳히는 중"**
- 1단계: 문제 검증 — 초기 시그널 확인 (2건, 3월 5건 목표)
- 2단계: 솔루션 검증 — 진행 중 (v1 2회, v2 1회)
- **프로토타입 구축 완료, 내부 테스트 단계** (pullim.vercel.app 직접 시연 유도 금지)
- "지금 바로 확인하세요" 표현 금지 → "프로토타입 구축 완료, 안정화 후 공개"
- v2 피드백: "구성 자체가 좋다" + WTP 1~3만원

### 예상 질문 + 답변

Q: "문제 검증이 '완료'라고 하셨는데 2건으로 완료가 가능한가요?"
A: "PPT 표현이 과했습니다. 정확하게는 초기 시그널을 확인한 단계입니다. 3월 5건으로 패턴 일관성을 확인하고, 5월 베타 20명에서 통계적 유의미성을 확보합니다."

Q: "v1과 v2의 차이는 무엇인가요?"
A: "v1은 단일 AI Socratic 대화입니다. 대표 본인이 1년간 써오면서 단일 관점의 한계를 느꼈고, v2에서 3명 AI 병렬 분석+토론 구조로 전환했습니다. 사용자 불만에서 나온 구조 변경입니다."

Q: "지금 직접 써볼 수 있나요?"
A: "프로토타입은 구축 완료했습니다. 현재 API 세팅과 v2 통합 안정화 단계여서, 안정화 후 공개합니다. v1 기준 데모는 보여드릴 수 있습니다."

## 슬라이드 16: 마케팅 전략

### 핵심 주장
퍼널을 역산했다. 보수적 8명은 "왜 돈을 냈는지"를 인터뷰할 대상이다. 12개월 퍼널은 단계적 검증 구조다.

### 발표 대본 (5분 압축판)

마케팅 퍼널입니다.

6개월 보수적 시나리오: 노출 5,000명, 방문 10%, 체험 완료 30%, 유료 전환 5% — **전환율은 가정치입니다** — 를 적용하면 유료 8명.

**8명이라도 돈을 내면 검증입니다.** 그 8명이 왜 결제했는지 인터뷰합니다. 그게 1,000명으로 가는 메시지를 만드는 단서입니다.

12개월 목표: 방문 2만명 → 무료 체험 6천명 → 유료 1,000명.

채널은 에브리타임 같은 대학생 커뮤니티에서 진로·관계 고민 게시판에 직접 접근하고, 멘탈케어 키워드 SEO로 인지를 확장합니다.

**바이럴에 대해 솔직히 말하면, 정리 문서 링크 공유 기능은 설계돼 있지만 실제로 퍼질지는 가설입니다. 베타에서 확인합니다.**

### 암기 팩트
- 보수적: 노출 5,000 → 유료 8명 (**전환율 5%는 가정치**)
- 12개월: 방문 2만 → 무료 6천 → 유료 1,000명 (4단계 퍼널)
- 채널: 에브리타임 등 대학생 커뮤니티 진로·관계 게시판(초기) + SEO(확장)
- **8명 = 목표 아님. "왜 결제했나" 인터뷰가 진짜 목적**
- 바이럴 = 가설, 베타에서 검증
- 커뮤니티 접근법: 진로·관계 고민 게시판에서 풀림 체험 초대 (구체적 채널+메시지 준비)

### 예상 질문 + 답변

Q: "8명에서 1,000명으로 가는 논리적 연결이 없습니다."
A: "8명 단계의 목표는 '왜 결제했는가' 인터뷰입니다. 그 패턴으로 메시지를 날카롭게 만들고, 커뮤니티 100명 → SEO 확장 → 1,000명 순으로 단계를 밟습니다. 각 단계에서 숫자가 안 나오면 전략을 수정합니다."

Q: "유료 전환율 5% 근거는?"
A: "가정치입니다. 프리미엄 앱 벤치마크 2~8% 범위 내 보수적 수치를 적용했습니다. 5월 베타에서 실측합니다."

Q: "바이럴 루프가 작동한다는 근거는?"
A: "현재 없습니다. 정리 문서 링크 공유 구조와, 2030 고민 커뮤니티에서 경험 공유가 활발하다는 관찰 기반 가설입니다. 베타에서 측정하고, 안 되면 가설을 버립니다."

## 슬라이드 17: 개발 로드맵

### 핵심 주장
3~7월, 각 단계가 검증 포인트로 설계됐다. 4월 맥락 축적 엔진이 잠금 효과의 시작점이다.

### 발표 대본 (5분 압축판)

개발 로드맵입니다.

3월: v2 파이프라인 구축. 진행 중입니다.
4월: 맥락 축적 엔진, UI/UX 최적화.
5월: 베타 출시, 테스터 20명.
6~7월: 피드백 반영, 정식 MVP, 유료 전환 검증.

**4월 맥락 축적 엔진은 MVP 수준으로 범위를 제한합니다. 세션 히스토리 저장과 키워드 기반 패턴 추출입니다. 3회차부터 개인화가 시작되고, 이게 비즈니스 모델에서 말한 잠금 효과의 시작점입니다. 정교한 개인화는 데이터가 쌓이면서 단계적으로 고도화합니다.**

### 암기 팩트
- 3월: v2 파이프라인 (진행 중) / 4월: 맥락 축적 엔진 + UI/UX / 5월: 베타 20명 / 7월: 정식 MVP
- **맥락 축적 엔진 4월 범위**: 세션 히스토리 저장 + 키워드 패턴 추출 (MVP 수준)
- 맥락 축적 엔진 = 잠금 효과의 시작점
- 1인 개발 일정 방어: 이미 22파일 1,642줄 구현 실적

### 예상 질문 + 답변

Q: "맥락 축적 엔진이 4월 한 달 안에 가능한가요?"
A: "범위를 명확히 제한했습니다. 세션 데이터 저장과 키워드 기반 패턴 추출입니다. 정교한 개인화는 이후 단계입니다."

Q: "1인 개발인데 이 일정이 현실적인가요?"
A: "이미 22개 파일 1,642줄을 혼자 구현했습니다. 각 단계의 범위를 기능 중심으로 좁게 잡아서 관리합니다. 안 되면 일정을 조정하지, 품질을 낮추지 않습니다."

## 슬라이드 18: 창업회사의 비전

### 핵심 주장
풀림이 만들려는 세상 — 누구나 자기 고민을 스스로 정리할 수 있는 세상. 전체 발표를 한 줄로 회수한다.

### 발표 대본 (5분 압축판)

미션입니다.
"혼자 끙끙대는 고민을, 함께 나아가는 첫 걸음으로 바꾼다."

비전.
"누구나 자기 고민을 스스로 정리할 수 있는 세상."

**'함께'는 AI가 결정을 내린다는 뜻이 아닙니다. 결론은 항상 사용자의 것입니다. AI는 옆에서 구조를 잡아줄 뿐입니다.**

**한 줄로 정리합니다. 고민을 입력하면, 파이프라인이 이끌고, 첫 걸음이 남습니다. 그게 풀림입니다.**

*(잠깐 멈춤)*

"이야기를 듣고, 같이 나아갑니다."

### 암기 팩트
- 미션: "혼자 끙끙대는 고민을, 함께 나아가는 첫 걸음으로 바꾼다."
- 비전: "누구나 자기 고민을 스스로 정리할 수 있는 세상."
- **PPT 오탈자 "스스로" → 대본에서 "스스로"로 교정** (채점표 감점 회피)
- 공식 카피: "이야기를 듣고, 같이 나아갑니다."
- **전체 회수 문장 필수**: "고민 입력 → 파이프라인 → 첫 걸음. 그게 풀림."
- "함께" = AI가 결정 아님, 결론은 사용자 것 (선제 변호)

### 예상 질문 + 답변

Q: "비전이 추상적입니다. 구체적으로 어떤 상태가 비전 달성인가요?"
A: "1,000명이 매달 자기 고민을 정리하는 상태입니다. 그 중 한 명이 '풀림 덕분에 이직 결정을 했다'고 말하는 순간이 비전의 시작점입니다."

Q: "'함께 나아간다'는 표현이 AI가 결정을 내린다는 뜻인가요?"
A: "아닙니다. 풀림의 원칙이 'AI는 질문만, 결론은 사용자가'입니다. 함께는 AI가 옆에서 구조를 잡아준다는 의미입니다."
