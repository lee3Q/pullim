## 1번. 창업 아이디어 (문제 / 차별점 / 고객 변화)

### 소재

**문제 정의 — 수치 근거 (ICC 출처)**
- 158만 명: 일자리 밖 2030세대 (통계청 2025.2)
- 73%: 직장인 중 이직 고민 중인 비율 (잡코리아x원픽 2024.10)
- 4.6조 원: 한국 점술 시장 (The Economist 2018) — "혼란의 정리"에 돈 쓰는 수요 검증
- 55%: AI 상담 핵심 불만 "효과 의심" (한국리서치 2025.4)
- AI 상담 이용 의향 40% vs 실제 이용 11% — 수요는 있으나 기존 서비스가 못 잡는 중

**문제 본질**
- "결정 못 하는 게 아니라 기댈 데가 없는 것"
- 파악 없이 이끄는 것이 진짜 문제. 기존 AI 상담앱은 사용자를 모른 채 조언함
- "재미 있으면 실질 없고, 실질 있으면 재미 없다" — 그 사이에 답이 있다

**솔루션 — 풀림**
- Socratic AI: 답을 주지 않고 질문으로 스스로 명확화
- 양방향 사다리 (5단계): 감각→감정→패턴→통찰→행동
- 3테마 세계관 (모험가/달빛정원/전략실): 같은 고민도 접근 방식이 다름
- 고민 없어도 진입 가능 ("심심해", "궁금해" 경로)
- 12개 캐릭터 유형 파악 → 심리테스트형 바이럴 루프

**차별점 (경쟁사 대비)**
- ChatGPT: 빈 화면에 프롬프트 필요, 1모델 확인편향, 재미 없음
- 타로/점신: 재미 있지만 비합리적, 행동 변화 없음
- 마인드카페: 1회 5~15만 원, 세션 후 산출물 없음
- Woebot/Wysa: CBT 기반, 문화권마다 재설계 필요, "답을 주는" 모델
- **풀림**: 스토리형 장면 선택 → 12캐릭터 유형 파악 → 양방향 사다리 세션
- 이면사고 공개 모드: AI가 나를 어떻게 파악하는지 투명하게 보여줌 (기존 서비스에 없음)
- 치트 버튼: 사용자가 AI 판단을 교정 → 교정이 데이터가 됨
- **글로벌 확장성**: Socratic 질문은 문화 무관 — CBT/명상과 달리 국경을 넘는다

**고객 변화**
- Before: "뭐가 문제인지도 모르겠어" → After: "아 이게 핵심이었구나" (스스로 도달)
- 테스트 체감 (대표 본인, 14턴): "이정도면 지금 팔아도 되겠는데"

### 뼈대 (500자)
```
고민이 있을 때 기댈 데가 없다. 상담은 무겁고 AI 챗봇은 모른 채 답을 준다.
4.6조 점술 시장이 증명한다 — 사람들은 정답이 아니라 혼란이 정리되는 경험에 돈을 낸다.
그런데 재미 있으면 실질이 없고, 실질 있으면 재미가 없다.

스토리형 장면 선택으로 사용자를 먼저 파악하고, 5단계 양방향 사다리로 감각→통찰까지 단계적으로 깊어진다. 3가지 세계관이 같은 고민을 다른 방식으로 접근한다.
AI가 나를 어떻게 보는지 투명하게 공개하고, 틀리면 사용자가 교정한다. 그 교정이 다시 데이터가 된다.
Socratic 질문은 문화 무관하다 — 이 구조는 국경을 넘는다.
"뭐가 문제인지도 모르겠어"에서 스스로 핵심을 찾는 경험.

## 2번. 글로벌 경쟁력 (시장 / 경쟁 우위 / 진입 전략)

### 소재

**글로벌 시장 수치 (ICC 출처, CC 단위 수정 반영)**
- 글로벌 AI 멘탈헬스 시장 (직접 진입): 2025년 ~$1.5~2B → 2030년 $8~10B (CAGR ~30%, Grand View Research/Mordor Intelligence)
- 글로벌 점성술/타로 앱 시장 (대체 수요): 2024년 ~$4B → 2033년 ~$30B (CAGR ~25%)
- 이 두 시장의 교차점 = 풀림. "스토리형 경험 + AI Socratic 코칭" 결합 서비스는 전 세계 전례 없음
- 한국 TAM 1,200억+ (점신 979억 + 포스텔러 100억 + 마인드카페 93억, 보수적)

**경쟁 우위 (왜 글로벌)**
- Socratic 접근 = 문화 무관. CBT/명상 기반 앱은 문화권마다 재설계 필요, 질문 기반은 보편적
- 텍스트 선택지 기반 게임 UI = 언어 의존도 낮음 → i18n 진입비용 최소
- 다국어 응답 = LLM API 시스템 프롬프트 수정으로 대응, 별도 번역 비용 없음
- 심리테스트형 바이럴: 파악→유형결과→공유→친구유입 루프
- 12개 경쟁사 5축 비교 분석: Woebot(CBT), Wysa(CBT+명상), Replika(감정 동반자), Pi — 모두 "답을 주는" 모델
- Gemini Deep Research 결론: "타로의 재미와 AI 실질이 결합된 서비스는 전 세계에 아직 없다"

**진입 전략**
- Phase 1: 한국어 MVP + 피드백 루프 (지금 — 피드백 수집 시작됨)
- Phase 2: 영어 버전 + Product Hunt / Reddit 론칭
- Phase 3: 두어스 MARU SF 거점으로 영어권 유저 검증
- Born Global 논거: 1인 + AI 에이전트 24시간 개발, 물리적 팀 불필요

### 뼈대 (500자)
```
글로벌 AI 멘탈헬스 시장 ~$2B, 2030년 $10B 전망(CAGR 30%).
점성술/타로 앱 시장 ~$4B — "혼란의 정리"에 돈을 쓰는 수요가 이미 검증됐다.
이 두 시장의 교차점에 풀림이 있다. 스토리형 경험 + AI Socratic 코칭의 결합은 전 세계에 전례가 없다.

풀림의 Socratic 접근은 문화 무관하다. Woebot/Wysa 같은 CBT 앱은 문화권마다 재설계가 필요하지만 질문은 어디서나 통한다. 선택지 기반 UI라 언어 의존도가 낮고, 다국어 전환은 프롬프트 수정만으로 가능하다.

한국어 MVP로 검증 중이다. 심리테스트형 바이럴(파악→유형결과→공유→친구유입)로 사용자를 모으고 있고, 영어 전환 비용은 최소다. 1인 + AI 에이전트 24시간 개발 사이클이 물리적 팀 없이 Born Global을 가능하게 한다.

## 4번. 어려웠던 시도 (동기 / 실행 / 결과 / 변화)

### 소재

**ICC 사업계획서 경험 — 구체 수치 (ICC 자료에서 확인)**
- 동기: 풀림을 세상에 내놓는 첫 공식 기회 (ICC = 한성대 창업 인큐베이팅)
- 실행:
  - 사업계획서 v5까지 작성 (5번 리비전)
  - HWP 양식 맞춤 재배치까지 수행
  - 발표대본 v2.1 (교차검증 반영, 대사량 32% 삭감)
  - 12개 경쟁사 5축 비교 분석, Q&A 10개 대비
  - AI(Claude, GPT)에게 완성본을 맡겼으나 데이터는 맞되 맥락(배치/톤)을 못 잡음
- 결과: 번아웃. v5까지 갈수록 AI 산출물과 내 의도 사이 괴리가 커짐
- 후속: ICC 후 외부 지원(공모전) 없이 가는 쪽으로 전환 선호

**이후 변화 — AI 활용 방식 근본 전환**
- Before: AI = 대필자 (완성본 맡기기)
- After: AI = 팀원, 나 = 오케스트레이터 (지시+검증)
- 구체적 변화:
  - 멀티모델 교차검증 도입 (단일 모델 맹신 X)
  - .state 상태관리 시스템 구축 (AI에게 맥락 넘기는 구조)
  - "내가 직접 쓰고 AI는 소재만" 원칙 확립
  - 밤 배치 자동화 (28태스크 병렬) — 번아웃 이후 구축한 시스템
- **전환 후 결과**: 방식을 바꾼 뒤 1주일 만에 스토리형 세션 재설계→배포→피드백 수집 완료. 2시간 내 버그→수정→재배포 사이클 확립.
- 이 경험이 풀림 철학에도 반영: "AI는 답을 주지 않고, 질문으로 돕는다"

## 5번. 참여 이유 (왜 나 / 왜 두어스 / 목표 지표)

### 소재

**왜 지금, 왜 나**
- 3학년 1학기 = 군필 기준 만 나이 적격 (만 19~29세, 군복무 가산)

- Unit Economics 검증 완료: 재화당 65원, BEP 유료 13명, 마진율 67%

**왜 두어스**
- 7개월 인큐베이팅 = 풀림 영어판 개발 + 검증에 딱 맞는 기간

- 선배 창업가 멘토링(채널톡 김재홍 등) = GTM/고객검증 노하우 (1인 창업자에게 가장 부족)

- 60명 소수정예 + 전담 코치 주간 밀착 = ICC와 차원이 다른 밀착도
- 데모데이: 상위 4팀 → 정주영 대회 결선 (총 상금 7,000만원)

**달성 목표 (지표)**
- 7개월 내 영어권 유저 100명 확보
- 글로벌 PMF 시그널: retention D7 > 30%, 세션 완주율 > 60%
- 한국어 유저 1,000명 (심리테스트 바이럴 루프)
- BEP 달성 (유료 13명)

**개인 동기**
- "절대 버리지 않는 친구" — 풀림의 출발점
- 창업자가 자기 제품으로 실제 감정 처리까지 한 경험 (14턴 테스트)
- 철학적 근거까지 자기주도로 연결 (로저스/비고츠키/릴케/노자)
