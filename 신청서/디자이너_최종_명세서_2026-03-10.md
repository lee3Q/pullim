## A. 프로젝트 개요

풀림(Pullim)은 AI 기반 고민 정리 서비스다. 사용자가 고민을 입력하면, 3명의 전문가 AI가 각자 다른 각도로 분석하고 토론한다. 세션이 끝나면 다각도 분석 리포트 + "의사결정 정리 문서(첫 걸음)"가 자동 생성된다.

**핵심 포지셔닝**: 인간 상담은 공감하다 감성적으로 흐른다. AI 상담은 구조적으로 냉철하게 정리한다. 풀림은 감정→구조화→결정→추적까지.
**타겟**: 20-30대 진로/이직/관계 고민자
**단계**: Customer Discovery (MVP 출시 전)

## B. 브랜드 가이드

| 항목 | 값 |
|------|-----|
| 서비스명 | 풀림 (Pullim) |
| 의미 | "꼬인 고민이 풀리다" + "마음의 풀림" |
| **공식 카피** | **"답을 찾게 하는 AI. 감정은 듣고, 결론은 정리한다."** |
| 톤 | 구조적이되 따뜻함. 공감하되 감성에 휩쓸리지 않는다. |
| 산출물 이름 | "첫 걸음" (공식: "의사결정 정리 문서(첫 걸음)") |
| 엔진 이름 | "구체화 엔진" (내부 코드: ClarifyEngine) |

### 비주얼 방향
- 권장: 따뜻한 톤 + 신뢰감 + 구조적 명료함 (멘탈케어 앱 느낌 + 테크 깔끔함)
- Before/After 구분: Before=회색/어두운 톤, After=브랜드 컬러/밝은 톤
- 톤 키워드: "옆에 앉은 똑똑한 친구" — 3D/그라데이션 금지, 라인 아이콘 + 카드형 미니멀

### 3. 레이아웃 원칙: "카드형 미니멀"

- 풀 텍스트 슬라이드 금지. 모든 정보를 카드/박스/블록으로 묶는다.
- 여백 상하좌우 최소 40px. 한 슬라이드 = 1 메시지.
- 그리드: 2분할(50:50), 3분할(33:33:33), 비대칭(60:40)만 사용.
- 카드/박스 모서리: 둥근 사각형 radius 8px 통일.
- 표 스타일: 헤더 Primary 배경 + 흰 텍스트, 행 교대 `#E3EEF0`.

**슬라이드 유형별 레이아웃**:

| 유형 | 해당 슬라이드 | 구조 |
|------|-------------|------|
| 타입 A: 스토리/계기 | 2, 7, 18 | 좌 60% 텍스트 + 우 40% 아이콘, 또는 3열 카드 균등 |
| 타입 B: 데이터/수치 | 5, 8, 14, 15 | 핵심 숫자 40~56pt 크게, 3열 카드 |

### 6. 제작 도구

|------|------|

| 초안 레이아웃 잡기 | Gamma (콘텐츠 붙여넣기 → AI 자동 레이아웃) |

**실행 순서**:
1. Gamma에 명세서 텍스트 붙여넣어 레이아웃 초안 생성 (30분)
2. 한성대 양식 PPTX를 Canva에 임포트 (5분)
3. Gamma 초안 참고하며 Canva에서 디자인 적용 (3~4시간)
4. 슬라이드 22 아키텍처만 Whimsical에서 별도 제작 → PNG 삽입
5. PPTX 내보내기 → 최종 확인

**통일감 체크리스트**:
- [ ] 전 슬라이드 배경: `#F7F4F0` 통일
- [ ] 제목: 좌측 상단 동일 좌표, Pretendard Bold 28pt `#2A7D8C`
- [ ] 본문: Pretendard Regular 14pt `#2D2D2D`
- [ ] 아이콘: 라인 2px, Primary 또는 차콜 단색
- [ ] 카드 모서리: radius 8px 통일
- [ ] 표: 헤더 Primary 배경 + 흰 텍스트, 행 교대 `#E3EEF0`
- [ ] 그라데이션 배경 금지, 3D 아이콘 금지, 애니메이션 금지 (제출용)

**심사위원 시선 관리**: 슬라이드당 10~15초. 제목(2초) → 핵심 비주얼(5초) → 숫자(3초). 표가 6행 넘으면 읽지 않는다.

## C. 표현 규칙 (전 슬라이드 적용)

### 금지 표현
| 표현 | 이유 | 대체 |
|------|------|------|
| "풀림이 ~해드립니다/해줍니다" | 서비스가 주어 + 결과 보장 | "~하게 됩니다/~할 수 있습니다" |
| "코칭 엔진" | 폐기된 용어 | "구체화 엔진" |
| "정리 편지" | 유서 연상 위험 | "정리 문서" 또는 "첫 걸음" |
| "AI 코치 / AI 상담사" | 마케팅 문구 사용 금지 | "AI 생각 정리 도우미" |
| "고민을 해결해줍니다" | 치료적 표현 | "생각이 정리되는 경험" |
| "결론은 같이 해나갑니다" | **폐기된 카피** | "감정은 듣고, 결론은 정리한다" |
| "결심 캐시백" | **폐지된 BM** | 언급 없음 |
| "냉철한 AI" | 취약 사용자 경시로 읽힐 수 있음 | "감정에 휩쓸리지 않는 구조적 분석" |

### 허용 표현
- "감정은 듣고, 결론은 정리한다"
- "구조적으로 정리된 결론"
- "공감하되 결론까지 도달하는 AI"
- "여러 관점의 AI가 토론하고 정리한다"

### 슬라이드 2: 창업의 계기 (양식 #2)

**제목**: 창업의 계기

**창업 아이디어 발상의 계기**
AI 에이전트 팀 토론 시스템을 직접 설계하고, 다양한 관점의 AI 에이전트 6명이 동시에 토론하는 방식으로 진로 변경, 창업 포지셔닝, 학습 방식 등 실제 의사결정을 수행했다. 한 AI에게 묻는 것과 여러 관점의 AI가 토론하는 것은 완전히 달랐다. "같은 고민인데 왜 이렇게 다른 결론이 나오지?"에서 이 경험이 제품이 됐다.

**창업 아이디어 구체화 과정 1**
ChatGPT/Claude에 "이직해야 할까요?"라고 물으면 장단점만 나열하고 끝난다. 하지만 여러 관점의 AI가 각자 다른 각도로 분석하고 서로 토론하면, 내가 미처 생각하지 못한 관점이 충돌하면서 진짜 답이 나온다. 이 경험을 누구나 쓸 수 있는 서비스로 만들기로 했다.

**창업 아이디어 구체화 과정 2**
한국에 "다양한 관점의 AI 분석 + 토론 → 의사결정 정리 문서" 서비스가 없다는 걸 확인했다. 기존 멘탈케어 앱(마인드카페, 트로스트)은 감정 케어에 집중하지만, "상담받고 나서 뭐가 달라졌는지 모르겠다"는 공통 불만이 있었다. 여러 관점의 AI 토론과 의사결정 구조화를 결합하면 이 빈 자리를 채울 수 있다고 판단했다.

**레이아웃**: 3단 구성 (계기→구체화1→구체화2). 양식 원본 레이아웃 유지.

### 슬라이드 4: 아이템 설명 — Before/After (양식 #4)

**제목**: 고민을 입력하면, 생각이 정리된다

**레이아웃**: 좌우 분할. 좌=Before(회색/어두운 톤), 우=After(브랜드 컬러/밝은 톤)

**[Before: 기존 방식]**

| 고민 | 기존 AI의 반응 | 결과 |
|------|-------------|------|
| "이직해야 할까요?" | 장단점 나열 + "신중히 생각해보세요" | 여전히 모르겠다 |
| "연인이랑 헤어져야 하나" | "대화를 해보세요" + 일반론 | 결국 혼자 끙끙 |
| "휴학할까 졸업할까" | 취업률 통계 + "본인이 판단해야" | 정보만 늘고 결정은 안 됨 |

**[After: 풀림]**

| 고민 | 풀림의 첫 반응 | 결과 |
|------|-------------|------|
| "이직해야 할까요?" | "지금 제일 힘든 게 뭐야?" | 진짜 고민 발견 + 정리 문서 |
| "연인이랑 헤어져야 하나" | "제일 서운했던 순간이 언제였어?" | 감정 정리 + 내 기준 발견 |
| "휴학할까 졸업할까" | "1년 뒤에 어디 있고 싶어?" | 선택지 정리 + 첫 행동 1개 |

**5단계 파이프라인** (슬라이드 하단, 화살표 아이콘 5개):
```
① 고민 입력
    ↓
② 이야기 듣기 (Socratic 질문으로 진짜 고민 파악)
    ↓
③ AI 3명 병렬 분석 (현실주의자 · 공감자 · 역발상가 — 추천 또는 직접 선택)
    ↓
④ AI 토론 (선택된 관점 vs 반론 → 종합 인사이트)
    ↓
⑤ 의사결정 정리 문서 + 첫 행동
```

**한 줄 요약** (최하단):
> 답을 주는 AI가 아니라, **네 안에 있는 답을 찾게 해주는 AI**

**디자인 노트**:
- Before 표: "결과" 열은 빨간/회색 (부정적)
- After 표: "결과" 열은 브랜드 컬러 (긍정적)
- 정리 문서 A4 축소판 이미지를 우측 하단에 삽입 (슬라이드 12에 전문)
- 심사위원 시선: 제목(2초) → Before/After 표(5초) → 파이프라인(3초)

### 슬라이드 20: 비전 (양식 #20)

**제목**: 창업회사의 비전

**VISION**:
> "감정 정리하러 왔는데, 결정까지 됐다"
> — 다양한 관점의 AI가 토론하고, 멘탈케어와 의사결정을 하나로 연결하는 서비스

**Value 1: 다양한 관점의 AI 분석**
한 AI에게 물으면 한 가지 답이 나온다. 풀림은 3가지 관점의 AI가 동시에 분석한다. 내가 미처 생각하지 못한 각도를 보여준다.

**Value 2: AI 토론으로 검증된 결론**
나만의 생각이 아니라, 여러 관점이 충돌하고 종합된 결론. AI끼리 반론하고 검증한 결과물이다.

**Value 3: 구조화된 산출물**
세션이 끝나면 의사결정 정리 문서 "첫 걸음"이 남는다. "상담받고 뭐가 달라졌는지 모르겠다"를 해결한다.

**Value 4: 축적 학습**
의사결정 히스토리가 쌓이면 "당신은 관계 결정에서 항상 회피하는 패턴이 있다"를 알려준다.

**Value 5: 접근성 + 안전**
심리상담 1회 5~20만원 vs 풀림 월 7,500원. 24시간, 대기 없이. 전문 치료를 대체하지 않으며 위기 시 즉시 전문기관 연결.

**레이아웃**: 중앙 VISION + 5방향 Value 카드.

