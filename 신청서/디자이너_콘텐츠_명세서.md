## A. 프로젝트 개요

풀림(Pullim)은 AI 기반 생각 정리 서비스다. 사용자가 고민을 입력하면, AI가 맞춤 질문을 던져 생각을 정리하고, 세션이 끝나면 "의사결정 정리 문서(첫 걸음)"가 자동 생성된다.

**핵심 포지셔닝**: 기존 멘탈케어 앱은 감정에서 끝남. 풀림은 감정→구조화→결정→추적까지.
**타겟**: 20-30대 진로/이직/관계 고민자
**단계**: Customer Discovery (MVP 출시 전)

### 슬라이드 2: 창업의 계기 (양식 #2)

**제목**: 창업의 계기

**창업 아이디어 발상의 계기**
76.5%의 직장인이 이직을 고민하지만, 대부분 "잘 생각해봐"로 끝난다.
나도 그랬다. 1년간 AI로 진로, 연애, 휴학 등 모든 중요한 결정을 해봤다.
답을 주는 AI는 쓸모없었다. 맞는 질문을 던지는 AI가 결정을 만들었다.

**창업 아이디어 구체화 과정 1**
삼수 실패에 고통받던 시절, 구원받고 싶었다. AI와 대화하며 막연함이 사라졌고, 고통의 반추가 아니라 흥미로운 분석이 가능해졌다. 의사결정이 삶을 바꿨다.

**창업 아이디어 구체화 과정 2**
엄마에게 AI를 알려줬다. 세상 모든 사람이 고민을 구조화하고 좋은 선택을 하길 바란다. 한국에 "맞는 질문 → 정리 문서" 서비스가 없어서 풀림을 시작했다.

**레이아웃**: 3단 구성 (계기→구체화1→구체화2). 양식 원본 레이아웃 유지.

### 슬라이드 4: 아이템 설명 — Before/After (양식 #4)

**제목**: 고민을 입력하면, 생각이 정리된다

**레이아웃**: 좌우 분할. 좌=Before(회색/어두운 톤), 우=After(브랜드 컬러/밝은 톤)

**[Before: 기존 방식]**

| 고민 | 기존 AI의 반응 | 결과 |
|------|-------------|------|
| "이직해야 할까요?" | 장단점 나열 + "신중히 생각해보세요" | 여전히 모르겠다 |
| "연인이랑 헤어져야 하나" | "대화를 해보세요" + 일반론 | 결국 혼자 끙끙 |
| "휴학할까 졸업할까" | 취업률 통계 + "본인이 판단해야" | 정보만 늘고 결정은 안 됨 |

**[After: 풀림]**

| 고민 | 풀림의 첫 반응 | 결과 |
|------|-------------|------|
| "이직해야 할까요?" | "지금 제일 힘든 게 뭐야?" | 진짜 고민 발견 + 정리 문서 |
| "연인이랑 헤어져야 하나" | "제일 서운했던 순간이 언제였어?" | 감정 정리 + 내 기준 발견 |
| "휴학할까 졸업할까" | "1년 뒤에 어디 있고 싶어?" | 선택지 정리 + 첫 행동 1개 |

**발췌 인용** (After 쪽 하단, 작은 폰트, 이탤릭):
> "처음엔 '이직할까 말까'로 시작했는데, 진짜 질문은
> '지금 회사에서 내가 원하는 걸 시도해봤는가'였어요."
> — 풀림 정리 문서 중

**3단계 플로우** (슬라이드 하단, 화살표 아이콘 3개):
```
[고민 입력]  →  [AI 질문 대화]  →  [첫 걸음 (정리 문서)]
 자유 텍스트      맞춤 질문으로       문제/선택지/결정/
 한 줄이면 충분    생각 정리           첫 행동까지 1장
                 네 속도에 맞춰
```

**한 줄 요약** (최하단):
> 답을 주는 AI가 아니라, **네 안에 있는 답을 찾게 해주는 AI**

**디자인 노트**:
- Before 표: "결과" 열은 빨간/회색 (부정적)
- After 표: "결과" 열은 브랜드 컬러 (긍정적)
- 정리 문서 A4 축소판 이미지를 우측 하단에 삽입 (슬라이드 12에 전문)
- 심사위원 시선: 제목(2초) → Before/After 표(5초) → 발췌(3초) → 플로우(2초)

### 슬라이드 5: 시장 분석 (양식 #5)

**제목**: 시장 분석

**전체 시장 (TAM) — 한국 멘탈케어 + 의사결정 시장**
- 한국 디지털 헬스케어 시장: 약 33조원(2024), 연평균 8.5% 성장
- 이 중 멘탈케어/심리 웰니스 영역: 약 1.2조원 (디지털 상담, 심리 앱, EAP 포함)
- 의사결정 지원 도구(코칭/컨설팅 디지털 전환): 약 3,000억원
- **TAM 합산: 약 1.5조원**
- 출처: Statista, 한국보건산업진흥원, 건강보험심사평가원

**유효 시장 (SAM) — 한국 20-30대 멘탈케어 수요**
- 한국 20-30대 인구 약 1,300만명
- 이직 고민 직장인 76.5%, "쉬었음" 청년 50.4만명(역대 최고)
- 우울증 환자 110.7만명 중 치료율 28.2% (80만명 방치)
- 심리상담 1회 비용 5~20만원 → 전문 상담 보완 저비용 웰니스 도구 수요 존재
- 20-30대 중 멘탈케어 앱 사용 의향자 약 130만명 (인구 10% 추정)
- **SAM: 130만명 × 월 7,500원 × 12개월 = 약 1,170억원**

**서비스 초기 핵심 시장 (SOM)**
- 한국 멘탈케어 앱 MAU 합산 약 16만명 (마인드카페 7.9만 + 트로스트 8.3만)
- 초기 목표: 유료 사용자 1,000명 × 월 7,500원 = 월 750만원 (연 9,000만원)
- **이 16만명은 이미 "앱으로 고민을 풀어보겠다"는 행동을 하는 사람들이다. 풀림은 이들의 공통 불만("뭐가 달라졌는지 모르겠다")을 해결한다.**

**접근성 + 정부 연계** (소셜벤처 데이터 통합)
- 심리상담 1회 5~20만원, 예약 대기 2~4주 — 접근 자체가 막혀 있는 구조적 불평등
- 심리상담 바우처: 청년 1.5만명 한정, 연 8회 (수요 대비 턱없이 부족)
- 풀림 = **전문 상담 보완 웰니스 도구** (상담 대체가 아닌 보완재)
- 월 7,500원 vs 상담 1회 5~20만원 → 접근성 27배 차이
- 정부 연계: 과기부 AI 심리케어 지원사업 240억원(2027까지), 중기부 AI 예산 7,992억원

출처: 통계청, 건보심평원, 보건복지부, 캐치설문, AI타임스

**레이아웃**: TAM > SAM > SOM 깔때기(피라미드) 시각화. 숫자 강조. 접근성 데이터는 SOM 하단에 박스로 배치.

### 슬라이드 6: 경쟁사 분석 (양식 #6)

**제목**: 경쟁사 분석

**비교표 — 2카테고리 분리: 멘탈케어 AI vs 의사결정 AI**

**카테고리 1: 멘탈케어 AI** (감정 케어 중심)

| 분류 | 마인드카페 | 트로스트 | 상담냥 |
|------|-----------|---------|--------|
| 핵심 접근 | 감정 토로→상담사 연결 | 감정 기록/일기 | 캐릭터 대화→조언 |
| AI 역할 | 초기 케어(인간 의존) | 감정 스캐너(기록) | 조언자(답 제시) |
| 세션 산출물 | 없음 | 감정 보고서 | 없음 |
| 감정→행동 | X (감정에서 끝) | X (감정만) | X (조언만) |
| 위기 안전 | 상담사 연결 | 불명확 | 불명확 |
| 가격 | 월 12,900원+상담비 | 월 5,900원 | 무료+광고 |

**카테고리 2: 의사결정 AI** (구조화 중심)

| 분류 | ChatGPT | 풀림(우리) |
|------|---------|----------|
| 핵심 접근 | 장단점 나열→일반론 | 질문→구조화 |
| AI 역할 | 정보 제공(답 제시) | 질문자(답 안 줌) |
| 세션 산출물 | 없음 | 의사결정 정리 문서(첫 걸음) |
| 감정→행동 | X (정보만) | O (감정→구조화→결정→추적) |
| 후속 추적 | 없음 | 1주/1개월 추적 알림 |
| 위기 안전 | 없음 | GREEN/YELLOW/RED 3층 안전 구조 |
| 가격 | 무료/월 $20 | 무료(월1회)+월7,500원 |

**핵심**: 멘탈케어 AI는 감정에서 끝나고, 범용 AI는 정보만 준다. **풀림만이 감정→구조화→결정→추적까지 연결한다.**

**포지셔닝 맵** (2×2 매트릭스)
- X축: 감정 케어 ←→ 의사결정 구조화
- Y축: AI 보조 ←→ AI 주도
- 마인드카페: 좌하 (감정+인간)
- 트로스트/상담냥: 좌상 (감정+AI보조)
- ChatGPT: 우상 근처 (AI주도, 구조화 약함)
- **풀림: 우상 (의사결정 구조화+AI 주도) — 빈 영역**

**핵심 차별점** (하단):
> 기존 앱 사용자 공통 불만: "상담받고 나서 뭐가 달라졌는지 모르겠다"
> 풀림의 답: 세션 끝에 의사결정 정리 문서(첫 걸음)가 나온다. 감정→구조화→결정→추적까지.

**경쟁 해자(Moat)**: 세션 축적 → 맥락 연속성 → 전환 비용 (설계 완료, v2 적용)

**레이아웃**: 상단 비교표 + 하단 포지셔닝 맵 2×2. 풀림 위치 강조.

```
자살예방상담전화 1393 / 정신건강위기상담전화 1577-0199
```

```
   |  → 이전 결정 기억 / 진전 인식 / 후속 문제 연결
   |  → "돌아오면 알아보는" 연속적 관계
   |
   v
[산출물]  의사결정 정리 문서(첫 걸음) 자동 생성
   |  문제 / 맥락 / 선택지 / 평가 / 리스크 / 결정 / 첫 행동
   v
[저장] Supabase (암호화, 본인만 접근)
```

**핵심 기술 선택 근거** (하단 표):

| 선택 | 이유 |
|------|------|
| Next.js + PWA | 앱스토어 심사 없이 모바일 앱 경험 |
| Claude API 기반 | 맥락 파악 성능 최상위 — "이 사람이 뭘 고민하는지" 정확히 이해 |
| 이중 모델 (Haiku + Sonnet) | 라우팅=저비용, 대화=고품질 — 비용 60% 절감 |
| 데이터 파일 기반 맥락 관리 | 요약 압축 아닌 원본 보존 — 연속적 유대감의 기반 |
| Supabase RLS | 사용자 데이터 완전 격리 |
| Vercel Edge | 자동 스케일링, 배포 5분 이내 |

**레이아웃**: 플로우 다이어그램을 시각적으로 깔끔하게 정리. 기술 선택 표는 하단.
