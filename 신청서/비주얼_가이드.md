## 2. 타이포그래피

### 추천 폰트 (무료, 상업 사용 가능)

| 용도 | 폰트 | 대안 | 비고 |
|------|------|------|------|
| **제목** | **Pretendard Bold / ExtraBold** | Noto Sans KR Bold | 깔끔하고 현대적. SaaS/스타트업 피치덱 표준. Google Fonts 무료. |
| **본문** | **Pretendard Regular / Medium** | Noto Sans KR Regular | 가독성 최우선. 제목과 같은 패밀리로 통일감. |
| **강조 숫자** | **Pretendard Bold** 또는 **Inter Bold** | - | 통계/지표 숫자를 크게 쓸 때 |
| **인용/카피** | **KoPub바탕체 Light** | 나눔명조 Light | 감성 카피("답을 찾게 하는 AI")에만 사용. 1~2곳. |

### 크기 가이드

| 요소 | 크기 | 스타일 |
|------|------|--------|
| 슬라이드 제목 | 28~32pt | Bold, Primary 컬러 |
| 서브 제목/섹션 | 20~24pt | SemiBold, 차콜 |
| 본문 | 14~16pt | Regular, 차콜 |
| 캡션/출처 | 10~12pt | Regular, 쿨 그레이 |
| 강조 숫자 | 40~56pt | ExtraBold, Primary 또는 Coral |
| 카피/인용 | 18~22pt | KoPub바탕체 Light, 이탤릭 효과 |

### 규칙

- 폰트 2종만 사용 (Pretendard + KoPub바탕체). 3종 이상 쓰면 산만해진다.
- 제목은 2줄 이하. 3줄 넘어가면 문장을 줄여라.
- 본문은 한 슬라이드에 6줄 이하 (심사위원은 읽지 않는다. 핵심만).

## 3. 레이아웃 스타일

### 기본 원칙: "카드형 미니멀"

- 풀 텍스트 슬라이드 금지. 모든 정보를 카드/박스/블록으로 묶는다.
- 여백을 충분히 둔다 (상하좌우 최소 40px).
- 한 슬라이드 = 1 메시지. 두 가지를 말하려면 두 장으로 나눈다.
- 그리드: 12컬럼 기준. 2분할(50:50), 3분할(33:33:33), 비대칭(60:40)만 사용.

### 슬라이드 유형별 레이아웃

#### 타입 A: 스토리/계기 슬라이드 (2, 3, 7, 18)
```
┌─────────────────────────────────┐
│  [제목]                          │
│                                  │
│  ┌──────────┐  ┌──────────┐     │
│  │ 텍스트    │  │ 텍스트    │     │
│  │ 블록 1    │  │ 블록 2    │     │
│  └──────────┘  └──────────┘     │
│                                  │
│  하단 인용/한 줄 요약             │
└─────────────────────────────────┘
```
- 좌측 60% 텍스트 + 우측 40% 일러스트/아이콘
- 또는 양식이 3단 요구 시: 3열 카드 균등 배치

#### 타입 B: 데이터/수치 슬라이드 (5, 8, 14, 15)
```
┌─────────────────────────────────┐
│  [제목]                          │
│                                  │
│  ┌────┐  ┌────┐  ┌────┐        │
│  │ 56pt│  │ 56pt│  │ 56pt│       │
│  │숫자 │  │숫자 │  │숫자 │       │
│  │설명 │  │설명 │  │설명 │       │
│  └────┘  └────┘  └────┘        │
│                                  │
│  하단 차트 또는 출처              │
└─────────────────────────────────┘
```
- 핵심 숫자를 40~56pt로 크게
- 아래에 14pt 설명 1줄
- 3열 카드로 숫자 3개까지. 4개 이상이면 테이블.

#### 타입 C: 비교/분석 슬라이드 (4, 6)
```
┌──────────┬──────────┐
│ Before   │ After    │
│ (회색)    │ (브랜드)  │
│          │          │
│ 표/리스트 │ 표/리스트 │
│          │          │
└──────────┴──────────┘
   하단: 3단계 플로우 화살표
```
- 좌우 50:50 분할. 배경색으로 영역 구분.
- 경쟁사 분석: 상단 비교표 + 하단 2x2 매트릭스

#### 타입 D: 프로세스/플로우 슬라이드 (9, 11, 17, 20, 22)
```
┌─────────────────────────────────┐
│  [제목]                          │
│                                  │
│  ○ ──→ ○ ──→ ○ ──→ ○           │
│  단계1   단계2   단계3   단계4    │
│                                  │
│  하단 테이블                      │
└─────────────────────────────────┘
```
- 수평 플로우: 화살표로 연결된 원형/사각형 노드
- 수직 퍼널: 위에서 아래로 좁아지는 사다리꼴

#### 타입 E: 테이블 중심 슬라이드 (14, 21, 23)
- 표 헤더: Primary 컬러 배경 + 흰 텍스트
- 행 교대: 흰색 / 미스트 블루(`#E3EEF0`)
- 합계/강조 행: Primary 컬러 텍스트 + Bold

## 4. 핵심 슬라이드 비주얼 제안

### 슬라이드 4: Before/After

**구조**: 좌우 50:50 분할

```
┌───────────────────┬───────────────────┐
│   BEFORE           │   AFTER            │
│   bg: #F0F0F0      │   bg: #E3EEF0      │
│                    │                    │
│   😶 (회색 아이콘)  │   💡 (코럴 아이콘)  │
│                    │                    │
│   "이직해야 할까?"   │   "이직해야 할까?"   │
│   → 장단점 나열      │   → "지금 제일 힘든  │
│   → "신중히 생각해"   │     게 뭐야?"       │
│   → 여전히 모르겠다   │   → 진짜 고민 발견   │
│                    │   → 정리 문서        │
│   ✕ 결과 없음       │   ✓ 첫 걸음         │
│                    │                    │
│   색: 회색+적색      │   색: 브랜드 틸+코럴  │
└───────────────────┴───────────────────┘
     ┌─────┐    ┌─────┐    ┌─────┐
     │고민  │ →  │AI   │ →  │첫   │
     │입력  │    │질문  │    │걸음 │
     └─────┘    └─────┘    └─────┘
```

- Before/After 각각 표가 아니라 **카드 3장**(고민 3개)을 세로로 쌓는 방식도 좋다
- 가운데에 세로 점선 or 번개 모양 구분선
- 하단 3단계 플로우는 둥근 사각형 + 화살표
- A4 정리 문서 축소판: After 쪽 우하단에 45도 기울여 그림자 넣어 배치

## 5. 아이콘/일러스트 방향

### 스타일: 라인 아이콘 (Outlined, 2px stroke)

- 플랫도 괜찮지만, 라인 아이콘이 "깔끔 + 따뜻함" 톤에 가장 맞다
- 3D는 과하다. 이 PPT의 톤은 "옆에 앉은 친구"지 "테크 대기업"이 아니다
- 컬러: Primary 틸(`#2A7D8C`) 단색 또는 차콜(`#2D2D2D`) 단색. 2컬러 이하.

### 추천 아이콘 세트 (무료)

| **Phosphor Icons** | phosphoricons.com | 라인/볼드/필 전환 가능. 무료. PPT 친화적. 가장 추천. |

### 왜 Canva인가

1. **양식 PPTX를 그대로 임포트**할 수 있다. 한성대 양식 위에 디자인을 얹는 방식이므로 이게 핵심.
2. 한국어 폰트 Pretendard를 직접 업로드할 수 있다 (Pro 기능).
3. 다이어그램(퍼널, 플로우, 2x2 매트릭스) 템플릿이 풍부하다.
4. Canva AI 이미지 생성으로 페르소나 일러스트도 해결 가능.

### 보완 도구

| 용도 | 도구 | 이유 |
|------|------|------|
| 아키텍처 다이어그램 (슬라이드 20) | **Whimsical** 또는 **Excalidraw** | 플로우차트 전문. 무료. PNG 내보내기 → Canva 삽입 |
| 퍼널 다이어그램 (슬라이드 11) | **Canva 내장** 또는 **FigJam** | Canva "Funnel" 템플릿이면 충분 |
| 빠른 초안 | **Gamma** | "내용 붙여넣기 → AI가 레이아웃 자동 생성"으로 초안 잡기. 최종본은 Canva에서 다듬기. |

### 실행 순서 (권장)

```
1. Gamma에 콘텐츠 명세서 텍스트를 붙여넣어 초안 자동 생성 (30분)
   → 레이아웃 감 잡기 용도. 이게 최종본이 아님.

2. 한성대 양식 PPTX를 Canva에 임포트 (5분)

3. Gamma 초안을 참고하면서, Canva에서 양식 위에 디자인 (3~4시간)
   → 이 비주얼 가이드의 컬러/폰트/레이아웃 적용
   → 다이어그램은 Canva 내장 템플릿 활용

4. 슬라이드 20 아키텍처만 Whimsical/Excalidraw에서 별도 제작 → PNG 삽입

5. PPTX로 내보내기 → 최종 확인
```

## 7. 추가 팁

### 심사위원 시선 관리

- 심사위원은 슬라이드당 10~15초를 본다. 제목(2초) → 핵심 비주얼(5초) → 숫자(3초).
- 모든 슬라이드에 "이 슬라이드의 핵심 1문장"을 제목 바로 아래에 넣어라.
- 표가 6행 넘어가면 읽지 않는다. 핵심 3~4행만 남기고 나머지는 부록으로.

### 통일감 체크리스트

- [ ] 모든 슬라이드 배경: `#F7F4F0` (오프 화이트) 통일
- [ ] 제목 위치: 좌측 상단, 동일 좌표
- [ ] 제목 폰트/크기/색: Pretendard Bold 28pt `#2A7D8C`
- [ ] 본문 폰트/크기/색: Pretendard Regular 14pt `#2D2D2D`
- [ ] 아이콘 스타일: 라인 2px, 단색, 동일 세트
- [ ] 카드/박스 모서리: 둥근 사각형 radius 8px 통일
- [ ] 표 스타일: 헤더 Primary 배경 + 흰 텍스트, 행 교대색 통일
