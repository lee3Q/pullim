## 핵심 인사이트 (본인 경험 기반)

### 왜 이걸 만들고 싶은가
- 내가 AI에서 제일 도움 받는 건 의사결정이다
- 인생의 방향성이나 중요한 결정할 때 AI의 가치가 가장 크다
- 여러 방면으로 사고하고, 정보 제공받고, 자신의 의견도 정리해봐야 하는데 — 이걸 AI로 하는 건 일반인 기준에선 어렵다
- 그래서 이 과정을 클릭 몇 번으로 할 수 있는 앱/웹앱을 만들고 싶다

### 핵심 설계 철학
- 의사결정 체계는 "무조건적인 게 없다" — 상황에 맞는 옵션이 있어야 한다
- 일반인에게 다양한 의사결정 프로세스를 옵션으로 제공 + 직접 세팅도 가능하게
- 돈보다 효용을 느낀 지점을 공유하고 싶음. 오픈소스도 고려. 남이 기여하면 더 좋아짐

### 내가 실제로 써본 의사결정 방식들
1. **에이전트 팀 토론** — 6인 전문가 + 천재3 + 비판1 구성으로 영어 학습 결정 (2026-03-05)
2. **Known/Unknown 4분면** — Clarify 스킬로 전략 맹점 탐색
3. **Clarify (모호→구체)** — Vague한 요구사항을 반복 질문으로 구체화
4. **밤 회의** — 하루 리뷰 + 내일 동선 생성 (일상 의사결정 자동화)
5. **CLAUDE.md 자기비판 범위 제한** — 에이전트 토론에서 분석이 행동을 대체하는 문제 발견 → 해결

### 발견한 문제점
- "분석이 행동을 대체한다" — 자기비판 프롬프트가 의사결정 자체를 무력화할 수 있음
- 에이전트 팀 토론이 강력하지만, 일반인이 프롬프트 세팅하기 어려움
- 상황별로 다른 프레임워크가 필요한데, 어떤 상황에 뭘 쓸지 아는 것 자체가 어려움
