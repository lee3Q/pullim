# AI 의사결정 도우미 — 창업 아이디어 구체화
> 2026-03-06 | 에이전트 분석 결과 종합
> 용도: 창업동아리 신청서 기초 자료 (마감 3/11)

---

## 1. 문제 정의

사람들은 중요한 결정(진로, 연애, 이직, 독립 등) 앞에서 고통받는다.
- 막연한 불안 — 뭘 모르는지도 모르는 상태
- 혼자 반추 — 같은 걱정을 돌려막기
- 정보 과잉 — 검색할수록 혼란

AI 챗봇(ChatGPT 등)이 있지만, "아무한테나 물어보기"와 "구조화된 의사결정 도우미"는 다르다.

## 2. 해결책 컨셉

**"고민을 고통이 아니라 흥미로운 분석으로 바꿔주는 AI 의사결정 도우미"**

핵심 메커니즘: ouroboros의 Socratic interview를 일반인용으로 재해석
- AI가 답을 주는 게 아니라 **구조화된 질문**을 던짐
- 사용자가 답하면서 스스로 명확해짐
- 세션 끝에 **의사결정 정리 문서** 자동 생성

사용 흐름:
```
고민 입력 → 구조화된 질문 5~7개 → 응답 → 의사결정 정리 문서 출력
         (명확도 점수 시각화)
```

## 3. ChatGPT와의 차별점

| ChatGPT 자유 대화 | AI 의사결정 도우미 |
|---|---|
| 사용자가 질문해야 함 | AI가 질문을 던짐 (Socratic) |
| 답변 위주 | 정리 위주 (사용자가 결론 도달) |
| 산발적 | 의사결정 프레임워크 내장 (MECE 등) |
| 결과물 없음 | 의사결정 정리 문서 자동 생성 |
| 후속 없음 | 1주 후 "그 결정 어떻게 됐어?" 추적 |

## 4. 타겟 사용자 3그룹

1. **진로/이직 고민자** (20~30대) — "이 회사 다녀야 하나, 이직해야 하나"
2. **관계 갈등 당사자** — "헤어져야 하나, 계속 만나야 하나"
3. **생활 결정자** (전연령) — "독립해야 하나, 대학원 가야 하나"

MVP 추천: **진로/이직 고민에 특화** (도메인 하나만)

## 5. MVP 정의

**가장 작은 단위:**
- 웹 챗봇 (Claude Artifacts + 배포)
- 진로/이직 특화 5개 구조화 질문
- 세션 끝에 의사결정 정리 1페이지 출력
- 비개발자(이상규)가 Claude로 만들 수 있는 범위

## 6. 수익 모델 (간단히)

- 무료 체험 3회 → 월 구독 (5,000~10,000원)
- 시제품 제작비: 창업동아리 지원금 활용
- LLM API 비용: 세션당 약 500~2,000원 (Claude API)

## 7. 이상규만의 강점

**1년간 AI로 모든 중요한 의사결정을 해온 실 사용자.**
- 진로 변경, 독립, 연애 갈등, 휴학을 AI와 함께 해결한 구체적 사례 보유
- 비개발자이기 때문에 일반인의 어려움을 직접 안다
- 형(Q00)이 ouroboros 개발자 — 기술 자문 가능

3. **"AI한테 고민 말할 의향"**: 주변인에게 "AI한테 진로 고민 상담할 의향 있어?" 물어보기.

## 주의사항

- AI가 "A를 하라"는 답을 주지 않는다. 질문과 정리만.
- 법적 면책: "정보 정리 도구이며 전문 상담을 대체하지 않습니다"
- 위기 상황(자살/자해) 감지 시 전문 상담 안내 연결
- ouroboros MIT 라이센스 — 형과 사전 소통 권장
