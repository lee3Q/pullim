## 검증 원칙 4가지 (절대 기준)

### 원칙 1: 할루시네이션 0%
PPT에 나오는 모든 수치는 인터넷 단순 검색으로 즉시 확인 가능해야 한다.
아래 **수치 검증 목록**을 WebSearch로 하나씩 검증하라.
- 검증 성공 → 출처 명시 그대로 사용
- 검증 실패 또는 수치 불일치 → 발표 대본에 변호 문구 삽입 ("추정치", "방향성 수치" 등)
- 검증 불가 → 반드시 "인터넷 검색 확인 어려움, 내부 추정치" 표시

### 원칙 2: PPT 변호는 반드시 대본 본문에
채점표 섹션5의 PPT 오류 10개가 **대본 본문에서 선제 변호**되어야 한다.
Q&A에만 있으면 감점 (-10점). 대본 본문에서 먼저 말해야 만점.

### 원칙 3: 발표 전반 연결성
- 슬라이드 1~22까지 수치/주장 모순 없어야 함
- "의사결정 정리 도구" 정체성이 처음부터 끝까지 관통
- 앞에서 한 말과 뒤에서 한 말이 달라지면 안 됨

### 원칙 4: 논리 오류 없음
- 억지스러운 비약 없음
- 보수적 가정은 "보수적 가정임"을 명시
- 모든 논리가 자연스럽게 이어져야 함
