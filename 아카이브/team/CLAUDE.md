# 풀림 (Pullim) 창업팀 — 운영 가이드

## 이 폴더는
AI 의사결정 도우미 "풀림" 창업팀의 운영 허브.
기존 개인 시스템(전황판/세션_맥락/밤 회의)과 **완전 독립**. 참조 가능하나 종속 금지.

## 팀 구조
- **대표 (이상규)**: 아이디어 오리지네이터, 최종 승인권자. 전문성보다 방향 설정.
- **코어 팀**: CTO(한재원), AI(서윤하), PM(박도현), Domain(최서영), COO(정하린)
- **에이전트 프롬프트**: agents/ 폴더 참조

## 운영 원칙

### 의사결정
1. 어떤 팀원이든 proposals/에 제안 가능
2. 일일 회의에서 Consent 라운드 (치명적 반대 여부)
3. 대표가 최종 승인/반려
4. 결과는 decisions/에 기록

### 자율성 수준
- **L2 (실행+보고)**: 일상 업무 — 각자 판단 후 보고
- **L1 (추천→승인)**: 로드맵/비용/인원/프로세스 변경 — 대표 승인 필요
- **L0 (보고만)**: 안전/피벗/팀 구조 변경 — 보고 후 대표 지시 대기

### 회의
- 일일 스탠드업: 15분, COO 진행
- 형식: 어제 완료 → 오늘 계획 → 블로커 → 안건
- 대표: 실시간 참여 or 보고서 검토 (선택)

## 폴더 구조
```
team/
├── CLAUDE.md          ← 이 파일
├── team_state.yaml    ← 팀원별 상태 (COO 관리)
├── dashboard.md       ← 대시보드 (COO 관리)
├── sprint_backlog.md  ← Sprint 백로그
├── agents/            ← 에이전트 프롬프트
├── meetings/          ← 일일 회의록
├── proposals/         ← 팀원 제안서
└── decisions/         ← 결정 로그
```
