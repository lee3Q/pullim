## 결정 근거

### Phase 1 리서치 요약
- **창업 방법론**: Lean Startup (Build-Measure-Learn), Customer Development (4단계), 스테이지 프레임워크 적용
- **조직 설계**: Two-Pizza Team, Centaur Model (인간+AI 협업), 자율성 수준 차등 (L0/L1/L2)
- **컨설팅 분석**: 시장 TAM $1.5B→$25.1B (CAGR 32%), 멘탈케어+의사결정 하이브리드 포지셔닝, Socratic 방법론 차별화

### 팀 구성 선택 근거 (방안 B 변형: 4+1)
- **Why 4, not 3**: CTO/PM/Prompt는 기본이나, 심리학·안전이 핵심인 도메인에서 Domain Expert 없이 시작하면 안전 리스크
- **Why 4, not 5+**: Pre-seed 단계에서 마케팅(CMO)은 MVP 전 불필요. 커뮤니케이션 채널 6개로 관리 가능
- **Why COO 추가**: AI 에이전트 팀의 문맥 유지·회의 운영·문서화는 전담자 필요. 없으면 대표가 직접 해야 함

### 미커버 영역 임시 방안
| 미커버 영역 | 임시 커버 | 소집 트리거 |
|------------|----------|------------|
| 마케팅 | PM 겸임 | MVP 출시 2주 전 |
| 디자인/UX | CTO + 외부 템플릿 | 디자인 피드백 3건+ |
| 재무 | 대표 직접 | 투자/지원금 신청 |
| 법률 | 외부 자문 | 법적 이슈 발생 |

## 팀원 의견 (Consent 라운드)

### Phase 1에서 도출된 합의
- **CTO 관점**: 기술 스택 확정됨 (Next.js 15, Supabase, Vercel, Claude API). 즉시 개발 가능
- **Prompt/AI 관점**: Socratic 파이프라인 7단계 설계 필요. 도메인 전문가 협업 필수
- **PM 관점**: PRD v1 존재. MVP 범위 축소 필요 (RICE 우선순위). 사용자 인터뷰 3건 완료, 추가 필요
- **Domain Expert 관점**: 위기 감지 안전장치 v1 필수. 심리학적 근거 없는 질문 설계 불가
- **COO 관점**: 운영 체계 준비 완료. 회의 프로토콜, 제안 워크플로우, 문서 구조 즉시 가동 가능

### 치명적 반대: 없음
