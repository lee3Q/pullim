## 프로젝트 개요

**멘탈케어 + 의사결정 하이브리드 웹앱**
- 카테고리: 멘탈케어/심리 웰니스
- 차별화: Socratic 질문 -> 의사결정 정리 문서
- 메시지: "감정 정리하러 왔는데, 결정까지 됐다"

## 기술 설계 확정

### 스택
| 레이어 | 기술 | 이유 |
|--------|------|------|
| Frontend | Next.js 15 (App Router) | SSR + PWA, React 생태계 |
| Backend/DB | Supabase (Postgres + Auth + Storage) | 빠른 구축, Row Level Security |
| 배포 | Vercel | Next.js 최적화, 자동 배포 |
| LLM (메인) | Claude Sonnet 4.6 | 품질 우선. Socratic 질문에 강함 |
| LLM (라우팅) | Claude Haiku 4.5 | 저비용 분류/라우팅 |
| PWA | next-pwa | 모바일 앱 경험 |

### 인증
- 기본: 익명 사용 (로컬 저장소)
- 선택: Google/Kakao 소셜 로그인 -> 클라우드 동기화
- 이유: 민감한 고민은 저장하기 싫을 수 있음. 써보면서 자연스럽게 저장 유도

### MVP 범위
- 7단계 파이프라인 전체 (CLARIFY -> CONTEXT -> OPTIONS -> EVALUATE -> STRESS TEST -> DECIDE -> COMMIT)
- 6개 모델 전체 (A: 다중관점토론, B: 빠른판단, C: 불확실성탐색, D: 갈등해소, E: 자원배분, F: 반복자동화)
- 자동 라우팅 (4축: 가역성/정보충분성/감정개입/시간압박)
- 의사결정 정리 문서 (앱 내 웹 페이지, 공유 링크)

### UI/디자인
- 방향: 추후 결정 (Perplexity 스타일 미니멀 vs 멘탈케어 따뜻함)
- 브랜드명: 추후 결정

## 사용 흐름 (Full Pipeline)

```
[사용자] 고민 입력 (자유 텍스트)
    |
[Haiku] 자동 라우팅 (4축 분류 -> 6개 모델 중 선택)
    |    -> "이 고민은 감정이 많이 얽혀 있네요. 찬반 분석 + 감정 정리로 갈게요."
    |
[Sonnet] Stage 1. CLARIFY -- 모호함 제거
    |    -> "표면적으로는 이직 고민이지만, 진짜 질문은 뭘까요?"
    |
[Sonnet] Stage 2. CONTEXT -- 맥락 수집
    |    -> "지금 재정 상황은? 가족이 의존하고 있나요?"
    |
[Sonnet] Stage 3. OPTIONS -- 선택지 생성
    |    -> "보이는 선택지 외에, 이런 것도 가능해요..."
    |
[Sonnet] Stage 4. EVALUATE -- 다기준 평가
    |    -> "당신에게 가장 중요한 기준 3가지는?"
    |
[Sonnet] Stage 5. STRESS TEST -- 편향 감지 + Pre-mortem
    |    -> "이 선택이 실패한다면, 가장 가능성 높은 이유는?"
    |
[Sonnet] Stage 6. DECIDE -- 결정 지원
    |    -> 종합 정리 + 추천 (결정은 사용자가)
    |
[Sonnet] Stage 7. COMMIT -- 실행 계약
    |    -> "첫 행동 1개: ___. 1주 후 리뷰."
    |
[출력] 의사결정 정리 문서 (웹 페이지)
    |    -> 문제/맥락/선택지/평가/리스크/결정/근거/첫행동
    |
[추적] 1주/1개월 후 알림: "그 결정 어떻게 됐어?"
```
