## 의사결정 프로세스

### 1단계: 초기 인터뷰 (Ouroboros)
- 사용자 비전: "어떤 고민이든 넣으면 뭘부터 해야 할지 정리해주는 AI"
- 핵심 갈등: 진로 특화 vs 범용
- 사용자 인사이트: "진로만이 아니라 모든 부분에서 도움을 받았다"

### 2단계: 전문가 에이전트 1차 투표 (5명)
| 에이전트 | 추천 | 핵심 논거 |
|----------|------|-----------|
| 마케팅 | A(진로)+D(갈림길) | SEO 최강, 브랜드는 범용 |
| 심사위원 | B(대학생 코치) | 심사 42/50, "내가 첫 고객" |
| UX 전략가 | D(결정장애) | 리텐션+바이럴 최강 |
| 시장 분석가 | C(멘탈케어) | 돈 도는 시장, B2B EAP |
| 비판자 | A(덜 위험) | 히스토리가 유일한 해자 |

-> 의견 분산. 추가 리서치 필요 판단.

### 3단계: 리서치 (에이전트 3명 + Perplexity 3건)
핵심 발견:
1. AI 의사결정 순수 카테고리 돈 번 사례 = 전 세계 0건
2. 멘탈케어 앱 다운로드 용의도 1위
3. 정부 예산 240억이 AI 심리케어로 가고 있음
4. 한국에 Socratic -> 정리 문서 서비스 없음 (빈 자리 확인)

### 4단계: 전문가 에이전트 2차 투표
| 에이전트 | 1차 | 2차 | 변경 이유 |
|----------|-----|-----|-----------|
| 마케팅 | A+D | **C** | 진로는 앱 전환율이 멘탈케어보다 낮다 |
| 심사위원 | B | **C** | AI 의사결정 돈 번 사례 0건 = 시장 부재 가능성 |
| UX 전략가 | D | **A** | "결정장애" 다운로드 용의도 중간 |
| 시장 분석가 | C | **C** | 유지. 정부 돈이 여기로 감 |
| 비판자 | A | **C** | A의 리스크가 낮은 게 아니라 보상 천장이 낮은 것 |

**결과: C가 4:1로 압승.**

## 검토한 포지셔닝 옵션 (탈락 사유 포함)

### A) 진로/이직 고민 AI -- 탈락
- 장점: SEO 강함, 타겟 명확
- 탈락 사유: 레드오션(사람인/잡코리아), 앱 다운로드 용의도가 멘탈케어보다 낮음, 리텐션 구조 불가(연 1-2회 이벤트)

### B) 대학생 AI 의사결정 코치 -- 탈락
- 장점: 창동 심사 최적화, "내가 첫 고객" 스토리
- 탈락 사유: AI 의사결정 순수 카테고리 글로벌 수익화 사례 0건, 대학생 WTP 최저, "빈 자리 = 수요 부재" 가능성

### C) 멘탈케어 + 의사결정 하이브리드 -- 채택
- 장점: 돈 도는 시장(93억), 정부 예산(240억), 앱 다운로드 의도 1위, Socratic+정리문서 차별화
- 약점: Woebot 폐쇄 사례(규제 리스크), 한국 MAU 천장 10만대
- 대응: 의료기기 아닌 웰니스로 포지셔닝, 의사결정 정리 문서가 차별화 무기

### D) "결정장애/갈림길 AI" -- 탈락
- 장점: 바이럴 가능성, MZ 공감
- 탈락 사유: 앱 다운로드 용의도 중간(밈으로 소비하고 끝), 제품 카테고리로는 약함

## 확정된 포지셔닝 상세

| 항목 | 내용 |
|------|------|
| **카테고리** | 멘탈케어/심리 웰니스 앱 |
| **핵심 메시지** | "감정 정리하러 왔는데, 결정까지 됐다" |
| **차별화** | Socratic 질문 -> 의사결정 정리 문서 (한국 유일) |
| **진입 키워드** | 심리상담 앱, 멘탈케어 앱, 고민 상담 앱 |
| **타겟** | 20-30대, 멘탈케어 니즈 (진로/관계/생활) |
| **수익화** | B2C 구독 + B2B EAP + 정부 그랜트 |
| **해자** | 의사결정 히스토리 축적 -> 패턴 분석 |

| | 마인드카페 | 트로스트 | 우리 |
