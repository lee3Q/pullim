> 날짜: 2026-03-20
> 상태: **교차검증 1차 완료** (GLM-5)
> 기반: 비용구조_구슬재화_확정.md (3자 교차검증 완료), 수익모델_심화설계.md
> 변경 이유: per-session → per-interaction(구슬) 재화 모델 전환. 기존 BEP 11명(세션 단위) 무효.
> 교차검증: GLM-5 검증 완료. 계산 정확, 결제 수수료 누락 지적 → 반영. 분석 구슬 과소추정 가능성 있으나 풀세션 250원 총액이 앵커이므로 BEP에 미미한 영향.

## 전제 조건

### 검증된 수치 (3자 교차검증 완료)
- 풀 파이프라인(5구슬) 세션 비용: **~250원** (보수적)
- 모델: Claude Sonnet 4.6 + GPT-5.4 + Gemini 3.1 Pro (모두 최상위)
- 이론 최소 ~160원, 현실 중간 ~200원, 보수적 ~250원

### 구슬 재화 모델 (확정)
- 입장+듣기: 무료 / 리서치: +1구슬 / 분석: +1구슬씩 / 토론: +1구슬 / Judge+결론: 무료
- 가벼운 고민 1-2구슬, 무거운 고민 4-6구슬
- 라우팅 AI가 추천, 사용자가 최종 선택

### 구독 구조 (확정)
- 여정(유료): 9,900원/월, 주 50구슬 (월 ~200구슬)
- 현자(프로): 19,900원/월, 주 120구슬 (월 ~480구슬)
- 모험(무료): 주 10구슬 (월 ~40구슬), 광고 4회 = +1구슬
- 품질 차등 없음 -- 사용 횟수로만 차등

## 2. 구슬 원가 분석

### 2-1. 세션 기본 오버헤드 (구슬 1개 이상 사용 시 발생)

구슬을 1개라도 사용하면 Judge+결론이 자동 실행되어 아래 비용 발생:

| 결론 정리 | Sonnet | ~21원 | 분석 후 자동 |
| 시스템 버퍼 | - | ~9원 | reasoning tokens, 재시도 |
| **소계** | | **~70원** | |

> 기본 대화만(0구슬) 시에는 입장 비용 ~15원만 발생.

### 2-2. 구슬별 변동비

| 구슬 유형 | 내용 | 비용 | 비고 |
|----------|------|------|------|
| 리서치 | Tavily 3-5회 + Sonnet 요약/검증 | ~54원 | 검증 단계 포함 |
| 분석 | 이종 모델 1개 독립 분석 | ~21원 | Claude/GPT/Gemini 중 1개 |
| 토론 | 불일치 추출 + 합성 (Sonnet) | ~62원 | 불일치 시에만 제안 |

> 가중 평균은 실사용 구슬 유형 비율 추정치. 실측 필요.

### 2-3. 세션 유형별 총비용

|----------|------|------|---------|--------------|

## 7. 핵심 인사이트

### 구슬 모델의 경제적 특성

1. **BEP는 유사** (10-17명) -- 구슬 모델 자체는 BEP에 큰 영향 없음
2. **수익성 하락 주범은 무료 티어** -- 40구슬/월은 기존 3세션/월 대비 3배 이상 관대
3. **깊은 세션이 경제적** -- 구슬당 실효원가: 1구슬=91원 vs 5구슬=50원
4. **현자 티어가 수익의 핵심** -- 유료 30%가 가중평균 순이익의 ~50% 기여
5. **세션 횟수 증가 = 변동비 증가** -- 기존 5세션→구슬 모델 30세션, 변동비 3배

### 조정 레버 (우선순위순)

| 레버 | 효과 | 난이도 | 추천 |
|------|------|--------|------|
| 무료 구슬 감축 (10→5/주) | 순이익률 15→33%, 전환율BEP 17→8% | 낮음 | 강력 추천 |
