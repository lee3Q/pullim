## 리스크 & 대응

| 리스크 | 확률 | 대응 |
|--------|------|------|
| ICC 서류/발표 탈락 | 중 | 창업동아리 2차 지원 or 직접 창업. 로드맵은 ICC 없이도 실행 가능 |
| 이종 모델 API 비용 초과 | 낮 | Judge를 Haiku로 고정, 토큰 예산 상한. Gemini 무료 티어 활용 |
| 유료 전환율 5% 미달 | 중 | 5%에서도 BEP(11명) 달성 가능. UX 개선에 집중 |
| 1인 개발 병목 | 높 | Phase 2까지는 핵심 기능만 집중. 디자인 외주는 ICC 지원금 활용 |
| 법률/규제 변경 | 낮 | 초기부터 그린존 설계. "코칭 도구" 포지셔닝 유지 |
| 카카오/네이버 AI 진출 | 중 | 범용 AI 비서 ≠ 의식적 의사결정 경험. 닫힌 생태계에서 감성 안식처는 못 만듦 |
