## 2. 현재 구조 → 변경 범위

### 안 바꾸는 것 (유지)
- 7단계 파이프라인 (ENTER→LISTEN→RESEARCH→CRYSTAL→DEBATE→CONCLUDE→COMPLETE)
- Zustand 세션 스토어 구조
- 6개 API 호출 로직 (Listen, Research, Analyze, Debate, Judge, Conclude)

- Theme 시스템 (getTheme() → colors, labels, assets)
- 위기 감지 (CrisisAlert)
- 구슬/렌즈/봉오리 시스템 (CrystalSelector)

## 3. 테마별 게임 UI 설계

### 3-1. 모험가의길 (Adventure)

**레퍼런스**: Sorcery! + 80 Days
**메타포**: 고민 = 모험의 갈림길, 선택 = 경로 탐색

| 요소 | 현재 | 변경 |
|------|------|------|
| 텍스트 표시 | 채팅 말풍선 | 양피지 텍스트 박스 (Sorcery! "슬립" 스타일) |
| 캐릭터 | 🧙 이모지 + sage.webp | 동물 현자 (부엉이/여우 등) 일러스트 |
| 선택지 | rpg-button 그리드 | 갈림길 표지판 스타일 (2-3개) |
| 진행 피드백 | 점 5개 | 여정 경로 지도 (현재 위치 표시) |
| 배경 | particles 애니메이션 | 판타지 숲/동굴/산 일러스트 (스테이지별 변경) |
| 입력 | 키보드 자유입력 | 선택지 기본, "직접 말하기" 접힌 상태 |
| 톤 | 따뜻한 주황 | 유지, 판타지 톤 강화 |

**씬 흐름 예시:**
```
[ENTER] 숲 입구 배경 + 부엉이 현자 등장
  "여행자여, 어떤 갈림길에 서 있는가?"

[LISTEN] 숲 속 오솔길 배경
  선택지: "일 고민" / "관계 고민" / "직접 말하기"
  → 추가 질문도 선택지 위주

[RESEARCH] 마법 도서관 배경
  팩트 카드 → "마법 두루마리" 스타일

[CRYSTAL_SELECT] 수정동굴 배경
  "세 개의 수정구슬이 빛나고 있다. 어떤 관점으로 들여다볼까?"

[CONCLUDE] 산꼭대기 배경
  "여행자의 길이 밝아졌다." + 결론 카드
```

### 3-2. 전략실 (Strategy)

**레퍼런스**: Reigns + A Dark Room
**메타포**: 고민 = 전략적 의사결정, 선택 = 보고서 검토

| 요소 | 현재 | 변경 |
|------|------|------|
| 텍스트 표시 | 채팅 말풍선 | 미니멀 카드/패널 (다크 톤) |
| 캐릭터 | 🏙️ 이모지 + strategy-avatar.webp | 고양이 비서 (차분한 일러스트) |
| 선택지 | rpg-button 그리드 | 카드 탭 or 좌우 스와이프 (Reigns 스타일) |
| 진행 피드백 | 점 5개 | 상단 지표 바 (분석 진행도) |
| 배경 | 미니멀 파티클 | 다크 모드 오피스/보드룸 |
| 입력 | 키보드 자유입력 | 선택지 기본, "메모 추가" 접힌 상태 |
| 톤 | 차가운 파랑 | 유지, 더 미니멀하게 |

**씬 흐름 예시:**
```
[ENTER] 다크 보드룸 + 고양이 비서 등장
  "오늘의 안건을 보고해 주세요."

[LISTEN] 브리핑 화면
  선택지: "커리어" / "재무" / "의사결정" / "직접 입력"

[RESEARCH] 데이터 대시보드 스타일
  팩트 카드 → 리포트 카드

[CRYSTAL_SELECT] 전문가 패널 선택
  "세 명의 전문가 관점을 선택하세요"

[CONCLUDE] 요약 보고서 스타일
  핵심 1-2-3 + 액션 아이템
```

### 3-3. 달빛정원 (Garden)

**레퍼런스**: Florence + 동물의 숲
**메타포**: 감정 = 식물, 돌봄 = 정원 가꾸기

| 요소 | 현재 | 변경 |
|------|------|------|
| 텍스트 표시 | 채팅 말풍선 | 부드러운 둥근 텍스트 박스 (편지/일기 느낌) |
| 캐릭터 | 🌿 이모지 + garden-avatar.webp | 토끼/다람쥐 친구 (동물의 숲 톤) |
| 선택지 | rpg-button 그리드 | 꽃잎/나뭇잎 모양 버튼 |
| 진행 피드백 | 점 5개 | 정원 성장 시각화 (씨앗→새싹→꽃) |
| 배경 | 보라 파티클 | 파스텔 정원 일러스트 (시간대별 변화) |
| 입력 | 키보드 자유입력 | 선택지 기본, "마음 적기" 접힌 상태 |
| 톤 | 부드러운 보라 | 파스텔 + 따뜻한 톤 |

**씬 흐름 예시:**
```
[ENTER] 밤 정원 + 토끼 친구 등장
  "달빛이 좋은 밤이야. 무슨 생각 하고 있어?"

[LISTEN] 벤치에 앉은 장면
  선택지: "마음이 무거워" / "결정이 어려워" / "직접 말하기"

[RESEARCH] 도서관 정원 코너
  팩트 카드 → 꽃 카드 (각 꽃에 정보)

[CRYSTAL_SELECT] 정원 온실
  "세 개의 꽃봉오리 중 어떤 걸 피워볼까?"

[CONCLUDE] 만개한 정원
  "네 정원에 새로운 꽃이 피었어." + 인사이트 카드
```

## 4. 공통 UI 원칙

### 4-1. 텍스트 표시
- **말풍선 완전 제거** → 테마별 텍스트 박스
- 텍스트 점진적 노출 (글자 단위 타이핑, 현재보다 느리게)
- 중요 선택 전 짧은 pause
- AI 응답은 단락별로 나눠서 표시 (한 번에 안 보여줌)

### 4-2. 선택지 인터랙션
- **기본은 선택지** (2-4개), 자유 입력은 "접힌 상태"로 보조
- 선택 후 즉각적 시각 피드백 (색상 변화, 작은 애니메이션)
- LISTEN 단계에서만 자유 입력 비중 높임 (고민 듣는 단계이므로)
- 나머지 단계는 선택지 위주 (구조화된 사고 유도)

### 4-3. 캐릭터
- **AI 인간 이미지 완전 제거**
- 동물 마스코트 일러스트 (SVG or 고해상도 PNG)
- 감정 표현은 간단한 표정 변화 (2-3종: 기본/생각 중/반응)
- 텍스트 박스 옆에 작게 배치 (현재 72px → 48px 정도)

### 4-4. 진행 시각화
- 현재 5점 인디케이터 → 테마별 메타포
- 모험가: 여정 경로 지도
- 전략실: 분석 진행 바
- 달빛정원: 정원 성장 (씨앗→꽃)

### 4-5. 씬 전환
- 현재: 타임라인 스크롤 (채팅 로그처럼 쌓임)
- 변경: **스테이지별 배경/분위기 전환** (페이드 or 슬라이드)
- 이전 대화는 "기록" 탭으로 이동 (메인 화면은 현재 씬만)

## 5. 구현 우선순위

### Phase 1: 공통 기반 (1-2일)
1. `CharacterDialogue.tsx` → `GameDialogue.tsx` 리팩토링
   - 말풍선 제거, 테마별 텍스트 박스 렌더링
2. `ChatInput.tsx` → `GameInput.tsx` 리팩토링
   - 선택지 우선 모드 + 접힌 자유입력
3. `SelectionButtons.tsx` → 테마별 선택지 스타일
4. Theme 시스템에 `uiStyle` 속성 추가 (게임 UI 설정)

### Phase 2: 달빛정원 먼저 (2-3일)
- **이유**: 20대 여성 피드백이 달빛정원 + 동물의 숲 스타일을 직접 언급
- 토끼/다람쥐 캐릭터 에셋 제작/조달
- 파스텔 정원 배경
- 꽃 모양 선택지 버튼
- 정원 성장 진행 시각화

### Phase 3: 모험가의길 (2-3일)
- 부엉이/여우 현자 에셋
- 양피지 텍스트 박스 + 갈림길 선택지
- 여정 경로 지도
- 판타지 배경 세트

### Phase 4: 전략실 (1-2일)
- 고양이 비서 에셋
- 미니멀 카드/패널 UI (현재 RPG 스타일에서 변경)
- 데이터 시각화 스타일 진행 바
- 다크 모드 강화

### Phase 5: 통합 검증 (1일)
- 3개 테마 교차 검증
- "연애앱 느낌 나는가?" 테스트
- 데모 피드백 기준 재확인

## 7. 기술 변경 사항

### 새로운 컴포넌트
```
components/game/
├── GameDialogue.tsx      # 테마별 텍스트 박스 (CharacterDialogue 대체)
├── GameInput.tsx          # 선택지 우선 입력 (ChatInput 대체)
├── GameChoices.tsx        # 테마별 선택지 (SelectionButtons 대체)
├── SceneBackground.tsx    # 스테이지별 배경 전환 (ThemedBackground 확장)
├── ProgressVisual.tsx     # 테마별 진행 시각화 (StageIndicator 대체)
└── CharacterAvatar.tsx    # 동물 마스코트 (avatarSrc 교체)
```

### Theme 타입 확장
```typescript
interface Theme {
  // 기존 유지...

  // 추가
  gameUI: {
    dialogueStyle: "parchment" | "card" | "letter";
    choiceStyle: "signpost" | "swipe" | "petal";
    progressStyle: "journey-map" | "progress-bar" | "garden-grow";
    inputLabel: "직접 말하기" | "메모 추가" | "마음 적기";
  };

  scenes: {
    enter: string;    // 배경 이미지/그래디언트
    listen: string;
    research: string;
    crystal: string;
    conclude: string;
  };
}
```

### page.tsx 변경
- 타임라인 스크롤 → 현재 씬 중심 렌더링
- 이전 대화 → 사이드 패널 or 접힌 기록
- 렌더링 로직 650~790 라인 리팩토링

## 8. 리스크 & 미결 사항

| 항목 | 상태 | 비고 |
|------|------|------|
| 동물 캐릭터 구체적 동물 선정 | 미결 | 대표 결정 필요 |
| 자유입력 비중 (LISTEN 단계) | 미결 | 너무 제한하면 고민 표현 어려움 |
| 에셋 품질 (AI 생성 vs 디자이너) | 미결 | MVP는 AI 생성, 추후 교체 |
| 모바일 반응형 | 고려 필요 | 게임 UI가 작은 화면에서 잘 보이는지 |
| 기존 사용자 데이터 | 호환 | 세션 스토어 구조 변경 없음 |
