# 고민 라우팅 시스템 기획

## 문제
현재 풀림은 **모든 고민에 동일한 13단계 파이프라인**을 적용한다.
- "서브웨이 vs 피자" → LISTEN → RESEARCH → VERIFY → DISCUSS → CRYSTAL → DEBATE → CONCLUDE
- 사용자 이탈 원인: 간단한 질문에 불필요한 무거운 프로세스
- 비용 낭비: Quick 고민에도 리서치+이종모델 분석 실행

## 핵심 아이디어
**고민의 수준/성격을 자동 감지 → 적절한 파이프라인으로 라우팅**
- 테마(모험가/전략실/달빛정원) = UI 분위기만 담당
- 파이프라인 깊이 = 고민 수준이 결정

---

## 1. 고민 분류 체계 (3단계)

### Quick (간단한 비교/선택)
- 예: "서브웨이 vs 피자", "빨간색 vs 파란색 신발", "오늘 뭐 먹지"
- 특징: 되돌릴 수 있음, 정보 충분, 감정 개입 낮음, 시간 압박 높음
- 파이프라인: LISTEN(1~2턴) → 바로 CONCLUDE
- 모델: Gemini Flash-Lite (무료) 또는 Gemini Flash

### Talk (대화/상담형)
- 예: "요즘 번아웃인 것 같아", "친구랑 사이가 좀...", "뭔가 답답해"
- 특징: 감정 표현 중심, 답보다 대화 자체가 목적, 정보보다 공감
- 파이프라인: LISTEN(자유 대화) → 사용자 요청 시에만 분석 진행
- 모델: Claude Sonnet (한국어 공감 품질 필수)

### Deep (복잡한 의사결정)
- 예: "이직 vs 현직", "창업할까", "이혼을 고민 중"
- 특징: 되돌리기 어려움, 정보 부족, 감정 깊음, 장기 영향
- 파이프라인: 현재 풀 파이프라인 (LISTEN → RESEARCH → CRYSTAL → DEBATE → CONCLUDE)
- 모델: Claude Sonnet + Gemini Pro + Perplexity Sonar (현행)

---

## 2. 라우팅 판단 기준

### 자동 분류 (LISTEN 1~2턴)
기존 `RoutingScores` 구조를 활용:

| 지표 | Quick | Talk | Deep |
|------|-------|------|------|
| reversibility (되돌림 가능성) | 높음 (≥7) | 중간 | 낮음 (≤4) |
| info_sufficiency (정보 충분도) | 높음 (≥7) | 중간 | 낮음 (≤4) |
| emotional_involvement (감정 개입) | 낮음 (≤3) | 높음 (≥6) | 높음 (≥6) |
| time_pressure (시간 압박) | 높음 (≥7) | 낮음 | 다양 |

**분류 로직:**
```
if (reversibility ≥ 7 && info_sufficiency ≥ 7 && emotional_involvement ≤ 3):
  → Quick
elif (emotional_involvement ≥ 6 && info_sufficiency ≥ 5):
  → Talk (감정은 높지만 정보는 충분 = 대화 필요)
else:
  → Deep (기본값 — 판단 불가 시 Deep으로)
```

### 사용자 명시 전환
- "좀 더 깊게 봐줘" / "분석해줘" → Talk → Deep 업그레이드
- "가볍게 얘기하자" / "그냥 대화하고 싶어" → Deep → Talk 다운그레이드
- "빨리 결정하고 싶어" → Talk/Deep → Quick 다운그레이드

### 오분류 자동 보정
- Quick으로 라우팅됐는데 사용자가 3턴 이상 대화 → Talk로 업그레이드
- Talk으로 라우팅됐는데 사용자가 "분석해줘", "비교해줘" 키워드 → Deep 제안
- Deep으로 라우팅됐는데 사용자가 1턴 만에 "A로 할래" → Quick으로 빠르게 마무리

## 3. 레벨별 파이프라인

### Quick 파이프라인
```
ENTER → LISTEN(1~2턴, 라우팅 판단) → QUICK_RESOLVE → COMPLETE
```
- QUICK_RESOLVE: "A와 B 중에서 [기준]이 중요하다면 [A/B]가 나을 것 같아. 가볍게 정리하면..."
- 리서치/구슬/토론 전부 스킵
- 구슬 소모: 0개 (또는 1개)
- 예상 소요: 30초~1분

### Talk 파이프라인
```
ENTER → LISTEN(자유 대화, 턴 제한 없음) → [사용자 요청 시] CRYSTAL_ANALYZE → CONCLUDE
```
- LISTEN이 메인 — 소크라틱 질문으로 자유 대화
- 사용자가 원할 때만 분석("좀 정리해줘", "구슬 써볼래")
- 리서치 스킵 (사용자 요청 시에만)
- 구슬 소모: 0~3개 (선택적)
- 예상 소요: 5~15분

### Deep 파이프라인
```
ENTER → LISTEN → RESEARCH → VERIFY → DISCUSS_1 → CRYSTAL_SELECT → CRYSTAL_ANALYZE → DISCUSS_2 → DEBATE → DISCUSS_3 → JUDGE → CONCLUDE → COMPLETE
```
- 현행 유지
- 구슬 소모: 3~5개
- 예상 소요: 15~30분

## 4. 모델 매핑 (저비용화 연계)

| 레벨 | 라우팅 판단 | 대화 | 분석 | 리서치 |
|------|-----------|------|------|--------|
| **Quick** | Gemini Flash-Lite (무료) | Gemini Flash (무료) | 없음 | 없음 |
| **Talk** | Gemini Flash-Lite (무료) | Claude Sonnet 4.6 | Claude Sonnet 4.6 (선택적) | 없음 |
| **Deep** | Gemini Flash-Lite (무료) | Claude Sonnet 4.6 | Gemini Pro + Claude Sonnet | Perplexity Sonar |

### 예상 비용 (세션당)

| 레벨 | 예상 비율 | input 토큰 | output 토큰 | 세션당 비용 |
|------|----------|-----------|------------|-----------|
| Quick | 30% | 500 | 300 | ~$0.0003 (무료) |
| Talk | 40% | 3,000 | 1,500 | ~$0.032 |
| Deep | 30% | 5,000 | 3,000 | ~$0.060 |

**월 1만 세션 기준: ~$92/월** (현재 $243 대비 62% 절감)

## 5. UI 반영

### 공통
- 테마 UI(모험가/전략실/달빛정원)는 유지 — 분위기만
- 캐릭터 페르소나(현자/비서/친구)도 레벨 무관하게 유지

### Quick 전용
- 진행 단계 표시 없음 (또는 최소화)
- 구슬 선택 없음
- "빠른 정리" 느낌의 간결한 UI

### Talk 전용
- 진행 단계: "듣기" 하나만 표시
- 하단에 "더 깊게 볼래?" 버튼 (Deep 업그레이드 유도)
- 구슬은 사용자가 원할 때만 등장

### Deep 전용
- 현행 5단계 표시 (입장 → 듣기 → 리서치 → 구슬 → 결론)
- 변경 없음

---

## 6. 위기 안전

- 위기 감지(GREEN/YELLOW/RED)는 **레벨 무관하게 항상 작동**
- Quick/Talk에서도 RED 감지 시 즉시 전문기관 안내
- 레벨 라우팅보다 위기 감지가 항상 우선
