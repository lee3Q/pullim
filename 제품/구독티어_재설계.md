## 1. 설계 원칙

1. **적자 안 나면서 최대한 많이 주기** — 마진 최적화 X, BEP 안전 확보 후 최대 제공
2. **품질 차등 없음** — 무료도 이종 모델 풀 파이프라인. 차등은 양+부가기능으로만
3. **주간 배분** — 심리상담의 주 단위 리듬. 매주 리셋 = 재방문 동기
4. **"1구슬 = 1단계"** — 투명한 가격 구조

## 2. 구슬 경제학

### 2-1. 구슬당 비용

| 구슬 유형 | 파이프라인 단계 | 비용 |
|----------|--------------|------|
| 리서치 | Tavily 검색 + Sonnet 요약 | ~25원 |
| 분석 1모델 | 이종 모델 독립 분석 | ~18원 |
| 추가 분석 2 | 추가 모델 | ~17원 |
| 추가 분석 3 | 추가 모델 | ~14원 |
| 토론 | 모델 간 교차 비평 2R | ~38원 |

무료 단계: 입장+듣기(0원), Judge+결론(0원) — 세션 시작/끝은 항상 무료.

### 2-2. 구슬 가중평균 단가 (교차검증 반영)

| 세션 무게 | 비율 | 평균 구슬 | 총비용 | 구슬당 비용 |
|----------|------|---------|-------|-----------|
| 가벼운 (1~2구슬) | 40% | 1.5 | ~32원 | ~21원 |
| 중간 (3~4구슬) | 40% | 3.5 | ~80원 | ~23원 |
| 무거운 (5~6구슬) | 20% | 5.5 | ~112원 | ~20원 |

**가중평균: ~22원/구슬** (실제)
**운영 기준: 30원/구슬** (위험 버퍼 +36% 포함)

> 교차검증 결과: Claude 초안 30원, GLM-5 지적 14.5원, 실측 재계산 ~22원.
> 30원은 과대추정이나 **안전 방향 오류** — 마진 계산에는 보수적 30원 유지.
> 실제 마진은 아래 시나리오보다 더 좋을 것.

### 2-3. per-session → per-interaction 환산

| 기존 (per-session) | 세션수 | × 평균 3구슬 | = 구슬 환산 |
|-------------------|-------|------------|-----------|
| 여정 월 8세션 | 8 | ×3 | 24구슬/월 |
| 현자 월 20세션 | 20 | ×3 | 60구슬/월 |

→ 구슬 모델에서는 이보다 **훨씬 넉넉하게** 제공 (아래 참조)

## 3. 티어 설계

### 3-1. 구슬 배분

| 티어 | 가격 | 주간 구슬 | 월 환산 | 세션수/주(평균3구슬) | 일 상한 |
|------|------|---------|---------|-------------------|--------|
| **모험** (무료) | 0원 | 10 | ~40 | 3~5 | 6 |
| **여정** (스탠다드) | 9,900원 | 50 | ~200 | 8~16 | 15 |
| **현자** (프로) | 19,900원 | **120** | ~480 | 17~40 | 35 |

#### 현자 주 80 → 120 변경 (교차검증 반영)

기존 설계: 여정 50 / 현자 80 (1.6배) → 초안 100 (2.0배) → **최종 120 (2.4배)**

- 100구슬일 때: 구슬당 199원 = 여정(198원)과 동일 → **업그레이드 유인 약함** (GLM-5 지적)
- 120구슬: 구슬당 166원 vs 여정 198원 → **구슬 효율 16% 우위** + 프리미엄 기능
- "2배 가격으로 2.4배 구슬 + 테마+리포트" = 명확한 가치 제안
- 마진 안전성 확인 완료 (5장 참조)

#### 무료 광고 구슬

- 광고 4회 시청 = 1구슬 (기존 유지)
- 일 광고 상한: 8회 (= 최대 2구슬/일)
- 주 최대: 10(기본) + 14(광고) = **24구슬**

### 3-2. 가격

| 가격 | 판단 | 근거 |
|------|------|------|
| 9,900원 | **유지** | 만원 이하 심리 가격대. 넷플릭스(13,500원) 이하. 충동 구독 마지노선. |
| 19,900원 | **유지** | 2만원 이하. 타로 카페 1회(2-5만원) 이하. O2O 상담 1회 미만. |

### 3-3. 티어 차등 요소

| 요소 | 모험 | 여정 | 현자 |
|------|------|------|------|
| 주간 구슬 | 10 | 50 | 120 |
| 구슬당 실효가격 | - | 198원 | **166원** |
| 파이프라인 | 풀 (이종 모델) | 풀 (이종 모델) | 풀 (이종 모델) |
| 광고 | 세션 전 리워드 | 없음 | 없음 |
| 테마 | 모험가만 | 모험가만 | **3테마 전체** |
| 히스토리 | 최근 3세션 | 전체 | 전체 |
| 패턴 리포트 | - | - | **월간 제공** |
| 구슬 이월 | 없음 | 50% (최대 25) | 100% (최대 60) |
| 우선 응답 | - | - | O |
| Quick Mode | 1구슬/건 | **첫 1회/일 무료** + 1구슬 | **첫 1회/일 무료** + 1구슬 |

> **핵심**: 파이프라인 품질 전 티어 동일. 차등은 양+부가기능으로만.
> 수익모델_심화설계의 "현자=Opus Judge"는 폐기 → 품질 차등 없음 원칙 우선.

## 4. 이월/소멸 정책

### 4-1. 규칙

| 티어 | 이월 비율 | 이월 상한 | 소멸 시점 |
|------|---------|---------|---------|
| 모험 | 0% (소멸) | - | 매주 월요일 00:00 |
| 여정 | 미사용분의 50% | 25구슬 | 다음 주 배분 시 (1주만 유지) |
| 현자 | 미사용분의 100% | 60구슬 | 다음 주 배분 시 (1주만 유지) |

### 4-2. 예시

여정:
- 이번 주 20구슬 미사용 → 다음 주: 50 + 10(=20×50%) = **60구슬**
- 이번 주 40구슬 미사용 → 다음 주: 50 + 20(=40×50%) = **70구슬**
- 최대 보유: 50 + 25(상한) = **75구슬/주**

현자:
- 이번 주 30구슬 미사용 → 다음 주: 120 + 30 = **150구슬**
- 이번 주 80구슬 미사용 → 다음 주: 120 + 60(상한) = **180구슬**
- 최대 보유: 120 + 60(상한) = **180구슬/주**

### 4-3. 설계 근거

- **완전 소멸 안 하는 이유**: "돈 냈는데 못 썼다" = 해지 1순위 감정
- **완전 이월 안 하는 이유**: 누적 폭탄 → 특정 주 과대 사용 → 비용 스파이크
- **1주 한정**: 이월 구슬은 다음 주에만 유효. 2주 연속 미사용 → 소멸
- **현자 우대(100% 이월)**: 프리미엄 가치. "바쁜 주에도 구슬이 기다려준다"
- **일 상한 병행** (GLM-5 제안 반영): 이월 폭발 방지. 여정 15/현자 35구슬/일

## 5. Unit Economics (교차검증 반영)

### 5-1. 사용률 시나리오 (교차검증 반영)

GLM-5 지적: 60%는 낙관. 웰니스앱 산업 평균 25-35%.

| 단계 | 사용률 | 근거 |
|------|-------|------|
| 초기 (1~6개월) | 35% | 산업 평균 수준, 사용 습관 형성 전 |
| 성장 (6~12개월) | 50% | 리텐션 확보 사용자 중심 |
| 성숙 (12개월+) | 60% | 코어 유저 정착 |

아래 마진 계산은 **보수적 구슬단가 30원** 기준 (실제 ~22원이므로 안전 마진 있음).

### 5-2. 여정 (9,900원, 주 50, 월 ~200구슬)

| 시나리오 | 사용률 | 구슬단가 | 월 비용 | 마진 |
|---------|-------|---------|--------|------|
| 초기 | 35% | 30원 | 2,100원 | **79%** |
| 성장 | 50% | 30원 | 3,000원 | **70%** |
| 성숙 | 60% | 30원 | 3,600원 | **64%** |
| 극단 | 100% | 40원 | 8,000원 | **19%** |

### 5-3. 현자 (19,900원, 주 120, 월 ~480구슬)

| 시나리오 | 사용률 | 구슬단가 | 월 비용 | 마진 |
|---------|-------|---------|--------|------|
| 초기 | 35% | 30원 | 5,040원 | **75%** |
| 성장 | 50% | 30원 | 7,200원 | **64%** |
| 성숙 | 60% | 30원 | 8,640원 | **57%** |
| 극단 | 100% | 40원 | 19,200원 | **4%** |

> **적자 체크**:
> - 여정: 100% × 40원 = 8,000원 < 9,900원 → 적자 없음 ✓
> - 현자: 100% × 40원 = 19,200원 < 19,900원 → 적자 없음 ✓ (마진 얇음)
> - 현자 실제(22원): 100% × 22원 = 10,560원 → 마진 47% ✓
>
> 극단 시나리오(100% 사용, 40원)는 "모든 사용자가 매주 120구슬 전부 쓰면서 전부 무거운 세션" = 현실에서 불가능.

### 5-4. BEP

| 항목 | 초기(35%) | 성장(50%) | 성숙(60%) |
|------|----------|----------|----------|
| 고정비/월 | 85,000원 | 85,000원 | 85,000원 |
| 여정 순이익/인 | 7,800원 | 6,900원 | 6,300원 |
| BEP (여정 only) | **11명** | **13명** | **14명** |
| 혼합 BEP (7:3) | **9명** | **10명** | **11명** |

> 사용률 낮을수록 BEP 유리. 모든 시나리오에서 15명 미만.

### 5-5. 무료 티어 손익

- 월 사용: ~40구슬 × 35% = 14구슬 × 22원(실제) = **308원 비용**
- 광고 수익: ~5세션 × ~35원 = **175원**
- **순 손실: ~133원/무료 사용자**

전환율별 손익 (여정 순이익 6,300원 기준):
- 20% 전환: 5명 × -133원 + 1명 × +6,300원 = **+5,635원** ✓
- 10% 전환: 10명 × -133원 + 1명 × +6,300원 = **+4,970원** ✓
- 손익분기 전환율: **~2%** (매우 안전)

## 6. 여정 → 현자 업그레이드 동기

추가 비용 10,000원으로 얻는 것:

| 추가 가치 | 환산 |
|----------|------|
| 구슬 +280/월 (50→120/주) | 2.4배 구슬 (구슬당 166원 vs 198원) |
| 3테마 전체 | "같은 고민, 다른 세계관" 경험 |
| 100% 이월 (vs 50%) | 바쁜 주에도 손해 없음 |
| 이월 상한 60 (vs 25) | 더 넉넉한 버퍼 |
| 월간 패턴 리포트 | 자기 이해 인사이트 |
| 우선 응답 | 피크 타임 대기 없음 |

구슬 효율: 여정 198원/구슬 → 현자 166원/구슬 (**16% 할인**)
→ "더 많이 쓸수록 이득" + 프리미엄 기능 = 명확한 업그레이드 가치

## 7. Quick Mode (교차검증 반영)

기존: 유료 티어 무제한 (30-50원/건) → 비용 예측 불가
변경: **1구슬/건 + 유료 티어 첫 1회/일 무료**

| 항목 | 내용 |
|------|------|
| 기본 | Quick Mode 1회 = 1구슬 |
| 유료 혜택 | 여정/현자: 하루 첫 Quick 1회 무료 |
| 무료 티어 | Quick도 구슬 소모 (동일) |
| 근거 | 진입장벽 완화 (GLM-5 제안) + 비용 통제 |

> "매일 가볍게 한 번"은 무료, 더 쓰면 구슬 소모. 일상적 사용 습관 형성 유도.
