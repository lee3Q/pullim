# 풀림 끝판왕 파이프라인 설계 — "삶의 안식처"

> 날짜: 2026-03-19 심야
> 상태: 핵심 컨셉 확정
> 이전 버전과의 관계: v1(상담도구) → v2(의사결정도구) → **끝판왕(삶의 안식처)**

---

## 이건 도구가 아니다

의사결정 "도구"가 아니라 **삶의 안식처**.
지친 모험가가 모닥불 앞에 앉아 현자와 이야기하는 경험.
타로의 의식성 + AI의 실질성 = **합리적 타로의 완성형**.

---

## 핵심 철학

1. AI가 답을 주지 않는다
2. 현실을 보여주고, 선택지와 리스크/보상을 제시한다
3. 선택은 끝이 아니라 시작이다 — "다음에 뭘 해올 건가?"
4. **재미가 있어야 한다** — 의식(ritual), 캐릭터, 구슬, 모닥불
5. "자네는 이미 답을 알고 있지 않은가?" — 주체는 사용자

---

## 수정구슬 시스템 (관점 선택)

"전문가를 선택하세요" ❌
"어떤 눈으로 세상을 보고 싶은가?" ✅

내부적으로는 분석 렌즈. 사용자에게는 **구슬을 고르는 의식**.

| 구슬 | 이름 | 보이는 것 | 내부 분석 프레임 |
|------|------|----------|---------------|
| 💰 | 금화의 구슬 | 돈의 흐름이 보입니다 | 재무 분석 (비용, 수익, 기회비용) |
| 🧭 | 나침반의 구슬 | 3년 뒤의 갈림길이 보입니다 | 진로/커리어 분석 (강점×시장, 분기점) |
| 🎯 | 거울의 구슬 | 자네가 왜 망설이는지 보입니다 | 행동경제학 (인지 편향, 손실 회피, 현상유지) |
| ⚖️ | 저울의 구슬 | 권리와 의무가 보입니다 | 법적/구조적 분석 |
| 🔥 | 모닥불의 구슬 | 가슴이 뛰는 쪽이 보입니다 | 가치관/동기 분석 (내적 동기, 에너지) |
| 🪞 | 타인의 구슬 | 상대방의 눈으로 보입니다 | 관계 분석 (상대 입장, 역학) |
| 🧠 | 심연의 구슬 | 감정 아래 숨은 패턴이 보입니다 | 심리 패턴 (반복되는 선택, 회피 패턴) |
| 📊 | 전략의 구슬 | 판의 구조가 보입니다 | 경영/전략 분석 (리스크, 포지셔닝) |
| 🤔 | 뒤집기의 구슬 | 질문 자체가 바뀝니다 | 철학적 리프레이밍 (전제 의심) |
| 🏃 | 몸의 구슬 | 몸이 보내는 신호가 보입니다 | 생활/건강 연결 (스트레스, 수면, 에너지) |

사용자가 3개를 고름. 각 구슬 = 이종 모델이 독립 분석.
**"나는 금화, 나침반, 거울의 구슬로 세상을 봤다"** — 이게 기억에 남음.

---

## 캐릭터 시스템 (세계관 개인화)

첫 세션에서 선택. 이후 모든 세션에 적용.

| 캐릭터 | 세계관 | 톤 | 비주얼 |
|--------|--------|-----|--------|
| 🧙 현자 | 모험가가 현자의 오두막을 방문 | 고어체, 무게감 | 도트 아트, 모닥불, 두루마리 |
| 💼 비서 | 개인 전략실에서 브리핑 | 깔끔, 프로 | 미니멀 화이트, 카드 UI |
| 🔥 코치 | 트레이닝 세션 | 직설, 에너지 | 다크 모드, 네온 |
| 🌙 친구 | 카페에서 수다 | 편안, 반말 | 파스텔, 둥근 UI |

분석 내용은 동일. 전달 방식만 다름.

## 파이프라인 (9단계) — 현자 버전 예시

```
[도트 모닥불이 타고 있음. 앰비언트 BGM]

🧙 "모험가여, 오늘은 무슨 바람이 불어 찾아왔는가?"

[고민 입력] "이 사업에 목숨 걸어도 될까요?"
```

### 1. 리서치
```
🧙 "흥미로운 질문이군. 잠시 두루마리를 펼쳐보겠네..."

[애니메이션: 현자가 두루마리를 펼치는 도트 연출]
[내부: Tavily/Perplexity API로 실시간 검색]
[수집: 1인 AI SaaS 성공률, B2C 구독 생존율, 유사 서비스 매출...]
```

### 2. 검증
```
[내부: 다른 모델이 리서치 결과 팩트체크]
[사용자에게는 보이지 않음 — 현자가 알아서 걸러줌]
```

### 3. 논의 1
```
🧙 "세상의 기록을 살펴보았네.
    자네가 가려는 길을 먼저 걸은 자들의 이야기일세."

   [데이터 카드들이 모닥불 옆에 펼쳐짐]
   • 1인 AI SaaS 1년 생존율: ~%
   • 유사 서비스 매출 레인지: ~
   • 초기 투자 없이 시작한 창업자 중 ~%가...

🧙 "이 중, 자네에게 가장 무겁게 느껴지는 것은?"

   [카드를 탭하여 선택]
```

### 4. 관점 분석 (구슬)
```
🧙 "이제 수정구슬을 보여줄 차례일세.
    어떤 눈으로 세상을 보고 싶은가?"

   [구슬 10개가 빛나며 나타남]
   💰 금화의 구슬 — 돈의 흐름이 보입니다
   🧭 나침반의 구슬 — 3년 뒤의 갈림길이 보입니다
   🎯 거울의 구슬 — 자네가 왜 망설이는지 보입니다
   ＋ 더 많은 구슬 보기...

   [사용자가 3개 선택]

🧙 "금화, 나침반, 거울... 흥미로운 조합이군."

   [애니메이션: 세 구슬이 빛나며 각각 이미지를 보여줌]
   [내부: Claude / GPT / Gemini가 각각 독립 분석]

   💰 금화의 구슬이 보여주는 것:
   "실패 시 손실: 최대 ~원. 기회비용: 같은 시간에 취업했으면 ~원.
    하지만 학습 자산은 ~로 환산 가능. 손익분기: 유료 ~명."

   🧭 나침반의 구슬이 보여주는 것:
   "3년 후 시나리오 A: 창업 지속 → ~. 시나리오 B: 취업 전환 → ~.
    비슷한 사람 100명 중 ~명이 A를 선택."

   🎯 거울의 구슬이 보여주는 것:
   "자네가 '목숨을 걸어도 되냐'고 물은 것 자체가 흥미롭군.
    이미 마음은 정해졌으나, 실패의 두려움이 허락을 구하게 만드는 것일세.
    이것을 '현상유지 편향'이라 하지."

   ⚡ 불일치 지점:
   "금화의 구슬은 '리스크 있다'고 하고,
    거울의 구슬은 '안 하는 게 더 리스크'라 하는군.
    이 갈림길이 자네 고민의 핵심일세."
```

### 5. 논의 2
```
🧙 "세 구슬의 이야기를 들었네.
    어떤 구슬의 말이 가장 가슴에 와닿았는가?"

   [💰 금화] / [🧭 나침반] / [🎯 거울]

   "혹시 빠진 것이 있다면 말해보게."
   [직접 입력] / [없어요, 이대로 좋아요]
```

### 6. 토론
```
🧙 "좋아. 그럼 구슬들끼리 이야기를 나눠보게 하지."

   💰→🎯: "현상유지 편향이라 했지만, 객관적으로 자금이 부족한 건 사실이야."
   🎯→💰: "자금 부족은 사실이지만, 자네가 말하는 '손실'에 경험의 가치가 빠져있어."
   🧭: "둘 다 맞아. 핵심은 '완전한 올인'이 아니라 '단계적 검증'이 가능한가야."

   [불일치가 수렴하는 지점 강조]
```

### 7. 논의 3
```
🧙 "구슬들의 토론이 끝났네. 어떤가?"

   [동의해요, 정리해주세요]
   [다른 구슬로 다시 보고 싶어요] → 4단계로 복귀
   [추가로 하고 싶은 말이 있어요] → 입력 후 추가 토론 1라운드
```

### 8. 검증
```
[내부: Judge 모델이 전체 논리 흐름 검증]
[문제 발견 시: "현자가 한 가지 더 짚어주겠네..."]
[문제 없으면: 바로 결론으로]
```

### 9. 결론 + 다음 단계
```
🧙 "오늘 자네의 이야기를 들여다보았네."

   [상황 요약]
   [선택지 A: 리스크 ~, 보상 ~]
   [선택지 B: 리스크 ~, 보상 ~]
   [핵심 갈림길: ~]
   [자네의 성향: 발화 패턴 기반 ~]

🧙 "오늘은 여기까지일세.
    분석은 이미 끝났어. 자네 마음속 결론도 났을테지.

    결정은 자네가 하는걸세.
    자네는 이미, 답을 알고 있지 않은가?"

   [잘 모르겠어요...] / [사실, 맞아요]

→ [사실, 맞아요]:
🧙 "그래. 알고 있었군. 이제 움직일 차례야.
    어떤 걸 해보겠나?"

   [~하기] / [~하기] / [~하기]

→ 선택 후:
🧙 "좋아. 언제까지 해볼건가?"

   [내일] / [다음 주] / [조만간엔 어렵겠어] / [날짜 지정]

→ 선택 후:
🧙 "그래, [날짜]에 다시 보지. 기다리고 있겠네."

   [모닥불이 서서히 작아지며...]
   [화면이 어두워지며 세션 종료]

→ [잘 모르겠어요...]:
🧙 "그것도 답일세. 모르겠다는 것 자체가 아직 정보가 부족하다는 뜻이지.
    다음에 올 때, 이것만 알아오게."

   [구체적 과제 1개 제시]
   [날짜 선택]

🧙 "그때 다시 이야기하세. 모닥불은 꺼지지 않는다네."
```

## 리텐션 = 캐릭터가 기다리고 있음

- [약속한 날짜]에 푸시: "🧙 현자가 기다리고 있습니다"
- 돌아오면: "왔군. [과제]는 해봤는가?"
  → [했어요] → "어떻게 됐나?" → 후속 분석 세션
  → [못했어요] → "왜 못했는지가 다음 고민이 되겠군. 이야기해보게."
- 3개월 누적: "자네가 5번의 갈림길에서 매번 '안전한 쪽'을 골랐더군. 알고 있었나?"

## 분위기 설계 (Ritual UX)

**레퍼런스**: "모험가여, 여기서 쉬고 가요" 도트 모닥불 영상 (40만+ 조회)
→ 기능이 아닌 **의식(ritual)**이 사람을 끌어들이고, 머물게 하고, 돌아오게 함

### 비주얼 (현자 테마 기준)
- 도트 아트: 모닥불, 오두막, 두루마리, 수정구슬
- 리서치 중: "현자가 두루마리를 펼치고 있습니다..."
- 구슬 선택: 구슬들이 빛나며 떠다니는 연출
- 분석 중: 선택한 구슬이 이미지를 보여주는 연출
- 토론: 구슬들이 빛을 주고받는 연출
- 종료: 모닥불이 서서히 꺼짐

### 사운드
- 세션 중: lo-fi 앰비언트 + 모닥불 ASMR
- 구슬 선택: 크리스탈 효과음
- 분석 완료: 두루마리 펼치는 소리
- 종료: 모닥불 꺼지는 소리 + 여운

### 캐릭터별 세계관 분기
- 🧙 현자: 도트 오두막 + 모닥불 + 구슬 → RPG 감성
- 💼 비서: 미니멀 전략실 + 데이터 카드 + 렌즈 → 노션 감성
- 🔥 코치: 트레이닝룸 + 스코어보드 + 망치 → 에너지 감성
- 🌙 친구: 카페 + 음료 + 냅킨 메모 → 일상 감성

## 기술 구조

```
리서치: Tavily API (무료 1,000회/월) or Perplexity API
구슬 1: Claude Sonnet (분석)
구슬 2: GPT (독립 분석) — 같은 프롬프트, 다른 모델
구슬 3: Gemini (독립 분석) — 같은 프롬프트, 다른 모델
Judge:  Claude Opus or GLM-5 (검증)
캐릭터: 프롬프트 분기 (톤+세계관만 다름, 분석 로직 동일)
비주얼: 도트 아트 에셋 + CSS 애니메이션 + Web Audio API
```

## 차별화 — 왜 이건 다른가

| | ChatGPT | 타로 앱 | 마인드카페 | **풀림(끝판왕)** |
|---|---------|--------|----------|----------------|
| 분위기 | 흰 화면 | 신비로움 ✅ | 의료 느낌 | **모닥불 + 구슬 + 현자** ✅ |
| 분석 | 1모델 | 없음 | 1상담사 | **이종 N모델** ✅ |
| 리서치 | 없음 | 없음 | 없음 | **실시간 검색** ✅ |
| 검증 | 없음 | 없음 | 없음 | **Judge 모델** ✅ |
| 산출물 | 대화 | 운세 카드 | 감정 기록 | **리스크/보상/확률/성향** ✅ |
| 결론 | "신중히 하세요" | "이렇게 될 것" | "힘드시겠어요" | **"자네는 이미 답을 알고 있지 않은가?"** ✅ |
| 이후 | 없음 | 없음 | 다음 상담 예약 | **"기다리고 있겠네"** ✅ |
| 재미 | ❌ | ✅ | ❌ | ✅ |
| 실질 | ✅ | ❌ | ✅ | ✅ |

**타로의 재미 + AI의 실질 = 아무도 안 한 조합**

## 이것이 풀림의 시작이다

> "의사결정 도구"가 아니다.
> "삶의 안식처"다.
> 지친 모험가가 모닥불 앞에 앉아,
> 수정구슬로 세상을 들여다보고,
> 현자의 질문에 스스로 답을 찾는 곳.
>
> 결정은 자네가 하는걸세.
> 자네는 이미, 답을 알고 있지 않은가?
