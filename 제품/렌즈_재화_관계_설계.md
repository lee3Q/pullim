## 결정: 렌즈와 재화는 완전 분리

| 테마 | 분석 렌즈 (관점) | 재화 (비용) |
|------|-----------------|------------|
| 모험가 | 수정구슬 | **불씨** 🔥 |
| 달빛정원 | 꽃봉오리 | **달빛** 🌙 |
| 전략실 | 분석 렌즈 | **크레딧** 💳 |

### 왜 분리하는가

"구슬"이 렌즈와 재화를 동시에 의미하면:
- "리서치에 구슬을 쓴다" — 어떤 관점의 구슬? (리서치는 렌즈와 무관)
- "구슬 3개 선택"(관점) vs "구슬 3개 소모"(비용) — 같은 단어, 다른 뜻
- "주 50구슬" — 50회 분석? 재화 50단위?

분리하면 이 혼동이 전부 사라짐.

---

## 핵심 원리

```
렌즈(수정구슬/꽃봉오리/분석렌즈) = 항상 10개. 사라지지 않음. "관점"이니까.
재화(불씨/달빛/크레딧)           = 소모품. 세션 단계를 열 때 쓰임.
```

- 렌즈 = 고르는 것 (무료)
- 재화 = 쓰는 것 (소모)
- 1불씨 = 1달빛 = 1크레딧 (가치 동일, 표시만 다름)

## 점진적 소모 흐름 (모험가 기준)

```
[잔여 불씨: 🔥🔥🔥🔥🔥]

1. 입장 + 듣기: 무료
   🧙 "모험가여, 오늘은 무슨 바람이 불어 찾아왔는가?"

2. 리서치:
   🧙 "세상의 기록을 살펴보겠네. 불씨 하나로 두루마리를 펼치겠나?"
   [🔥 두루마리 펼치기] / [넘어가기]
   → 잔여: 🔥🔥🔥🔥

3. 구슬 선택 (무료):
   🧙 "어떤 눈으로 세상을 보고 싶은가?"
   → 수정구슬 10개 표시, 3개 선택 (비용 없음)

4. 구슬 분석 (불씨로 "비춤"):
   🧙 "금화의 구슬이 있구나. 불씨를 비춰볼까?"
   [🔥 금화 비추기] → 분석 결과
   → 잔여: 🔥🔥🔥

   🧙 "나침반과 거울도 기다리고 있네."
   [🔥 나침반 비추기] / [여기서 정리]
   [🔥 거울 비추기] / [두 개로 충분해요]

5. 토론 (불일치 발견 시):
   🧙 "구슬들이 다른 말을 하는군. 부딪혀볼까?"
   [🔥 토론 열기] / [넘어가기]

6. 결론: 무료
   🧙 "모든 구슬이 비춰졌네. 정리해주겠네."
```

### 달빛정원 기준

```
[잔여 달빛: 🌙🌙🌙🌙🌙]

2. 리서치:
   🌿 "편지함을 열어볼까요? 달빛 하나가 필요해요."
   [🌙 편지함 열기] / [넘어가기]

4. 꽃봉오리 분석:
   🌿 "금화의 봉오리가 있네요. 달빛을 비춰볼까요?"
   [🌙 금화 비추기]
```

### 전략실 기준

```
[잔여 크레딧: 💳💳💳💳💳]

2. 리서치:
   🏙️ "리포트를 조회하겠습니다. 크레딧 1이 필요합니다."
   [💳 리포트 조회] / [넘어가기]

4. 렌즈 분석:
   🏙️ "금화 렌즈를 적용하겠습니다. 크레딧 1."
   [💳 금화 적용]
```

## 소모 구조

| 단계 | 재화 | 비고 |
|------|------|------|
| 입장 + 듣기 | 0 | 무료 |
| 리서치 | +1 | "두루마리/편지함/리포트" |
| 구슬 선택 | 0 | 관점 고르기는 무료 |
| 구슬 분석 1개 모델 | +1 | 추가 모델당 +1씩 |
| 토론 | +1 | 불일치 발견 시에만 제안 |
| Judge + 결론 | 0 | 무료 |

결과:
- 가벼운 고민: 1~2 재화 (~50~100원)
- 중간 고민: 3~4 재화 (~150~200원)
- 무거운 고민: 5~6 재화 (~250~300원)

---

## 구독/충전 구조

- 유료 (9,900원/월): 주 50 재화, 일 제한 있음
- 무료: 주 10 재화 + 광고 4회 시청 = 1 재화
- 품질은 동일 — 사용 횟수로만 차등
