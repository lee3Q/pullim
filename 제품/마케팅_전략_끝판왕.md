# 마케팅 전략 — 끝판왕 "삶의 안식처"

> 날짜: 2026-03-20
> 기반: B1 경쟁분석 + 끝판왕 파이프라인 설계 + 수익모델 심화설계
> 핵심 질문: "삶의 안식처"를 어떻게 팔 것인가?

## 1. 포지셔닝 — 시장의 빈 칸에 정확히 꽂기

### 1-1. 한줄 포지셔닝

**"타로의 재미 + AI의 실질 = 아무도 안 한 조합"**

더 구체적으로:
- 타로 앱처럼 신비롭지만, 진짜 데이터로 분석한다
- ChatGPT처럼 똑똑하지만, 프롬프트 없이 선택만 하면 된다
- 상담사처럼 깊지만, 1/10 가격에 24시간 열려있다

### 1-2. 타겟 페르소나 (3개)

| 페르소나 | 설명 | 진입 채널 | 전환 트리거 |
|---------|------|----------|-----------|
| **방황하는 모험가** | 25세, 이직/진로 고민. 밤 11시 인스타 타로 릴스 보다가 유입 | 인스타그램/틱톡 | "타로보다 실질적이네?" |
| **지친 전략가** | 32세, 창업자/프리랜서. 의사결정 피로. 링크드인에서 발견 | 링크드인/블로그 | "모닥불 앞에 앉으니까 생각이 정리되네" |
| **힐링 탐험가** | 22세, 대학생. 연애/학업 고민. 에브리타임에서 추천 봄 | 에브리타임/유튜브 | "모닥불 분위기 좋고, 무료인데 진짜 도움 됨" |

## 3. 콘텐츠 전략 — "의식을 파는 마케팅"

### 3-1. 핵심 원칙

풀림은 **기능을 팔지 않는다. 의식(ritual)을 판다.**

| ❌ 기능 마케팅 | ✅ 의식 마케팅 |
|-------------|-------------|
| "3개 AI 모델이 분석합니다" | "세 개의 수정구슬로 세상을 들여다보세요" |
| "의사결정 정리 문서 자동 생성" | "현자의 두루마리가 펼쳐집니다" |
| "멀티 에이전트 파이프라인" | "모닥불 앞에서 답을 찾는 시간" |

### 3-2. 콘텐츠 유형

#### 체험 콘텐츠 (핵심)
- "나의 실제 이직 고민을 현자에게 물어봤다" — 전 과정 스크린 녹화
- "점신 vs 풀림 — 같은 고민, 다른 답" — 비교 체험
- "MBTI 결과와 구슬 분석, 어떤 게 더 정확했나?" — 자기이해 비교

#### 감성 콘텐츠
- 모닥불 ASMR + "오늘 고민 있나요?" 60초 릴스
- 구슬 10개 소개 시리즈 — "이 구슬로 세상을 보면?" 각 30초
- 세계관 아트워크 공유 — 도트 아트 캐릭터/배경

#### 교육 콘텐츠
- "의사결정 피로란 무엇인가" — 블로그 SEO
- "AI가 답을 주면 왜 더 불안해지는가 (AIUA)" — 링크드인
- "타로에 돈 쓰는 이유 = 혼란의 정리" — 심리학 콘텐츠

### 3-3. 바이럴 엔진 — 세션 공유 카드

**가장 비용 효율적인 성장 채널.**

1. 세션 종료 → "현자의 두루마리를 공유하시겠습니까?"
2. 도트 아트 스타일 OG 이미지 자동 생성
   - 선택한 구슬 3개 아이콘
   - 핵심 갈림길 한 줄 요약
   - "자네는 이미 답을 알고 있지 않은가?" 시그니처 문구
3. 카카오톡/인스타 스토리/트위터 공유
4. 공유된 카드를 본 사람 → "이게 뭐야?" → 풀림 유입

**예상 바이럴 계수**: 유료 사용자 200명 × 20% 공유율 × 3명 도달 = 월 120명 자연 유입

## 4. 가격 커뮤니케이션

### 4-1. 앵커링 전략

**"타로 카페 한 번 값으로, 한 달 동안 현자와 이야기하세요"**

| 비교 대상 | 가격 | vs 풀림 |
|----------|------|--------|
| 타로 카페 1회 | 2-5만 원 | 여정(9,900원) 2-5달 = 타로 1회 |
| 포스텔러 심층 사주 1회 | 3,000-20,000원 | 여정 1달 = 사주 1회 비용 |
| O2O 심리상담 1회 | 5-15만 원 | 현자(19,900원) 2.5-7.5달 = 상담 1회 |
| 커피 한 잔 × 2 | ~10,000원 | 여정 1달 |
| BetterUp AI 코칭 | 기업 전용 (개인 불가) | 풀림 = 개인도 9,900원부터 |

### 4-2. "늦은 밤 전환" 시나리오

1. 밤 11시, 혼자. 내일 출근이 두렵다.
2. "풀림" 검색 or 인스타에서 본 모닥불 영상 클릭
3. 무료 세션 → 현자와 대화 → "이거... 진짜 도움이 되네"
4. 세션 끝 → "다음 고민도 현자와 이야기하고 싶으신가요?"
5. 9,900원 → "만원도 안 하네" → 결제
6. **만원 이하 = 심야 감정 상태에서 결제 저항 최소**

## 5. 경쟁사 실수에서 배운 것

| 경쟁사 | 실수 | 풀림의 대응 |
|--------|------|-----------|
| **Co-Star** | 공격적/부정적 푸시 알림 → 정신건강 우려 | 현자의 톤 = 따뜻하고 존중. 트롤링 절대 금지 |
| **The Pattern** | 과도한 페이월 → 무료 가치 하락 → 커뮤니티 반발 | 무료도 "와, 이게 무료?" 경험 보장. 라이트 파이프라인이지만 세계관 100% |
| **Pi** | 감성만 → 돈 안 됨 → MS에 흡수 | 의식 + 실질 산출물(정리 문서) + 행동 약속 → 지불 가치 명확 |
| **Woebot** | D2C → 수익화 실패 → B2B 피벗 | 초기부터 B2B(대학 진로상담센터) 확장 로드맵 포함 |
| **Replika** | 기능 변경/가격 인상 → 커뮤니티 반발 | 요금 정책 일관성, 사전 고지 원칙 |

## 6. KPI 대시보드

### 12개월 목표 (정식 출시 = 10월 기준)

| 지표 | 출시 후 3개월 (12월) | 출시 후 6개월 (3월) | 출시 후 12개월 (9월) |
|------|---------------------|---------------------|---------------------|
| 노출 | 5,000명 | 20,000명 | 50,000명 |
| 가입 (무료) | 100명 | 400명 | 1,000명 |
| 유료 전환 | 10명 | 50명 | **200명** |
| 전환율 | 10% | 12.5% | 20% |
| MRR (여정 9,900원 + 현자 19,900원 혼합) | ~130,000원 | ~650,000원 | ~2,580,000원 |
| 공유 카드 생성 | - | 100장/월 | 300장/월 |

> 협약기간(~2027.2) 내 목표: 유료 200명. 여정 70% + 현자 30% 믹스 기준 MRR ~258만 원, 연 ~3,100만 원.

### 핵심 추적 지표

1. **무료→유료 전환율**: 목표 20%, 최소 10% (5%에서도 BEP 가능)
2. **세션 완주율**: 9단계 중 몇 단계까지 진행하는가
3. **공유율**: 세션 완료자 중 카드 공유 비율
4. **D7/D30 리텐션**: 7일 후, 30일 후 재방문율
5. **감정 온도계 변화량**: 세션 전후 평균 감정 변화
