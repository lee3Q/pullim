# 무료 티어 설계 — "모험" 티어

> 날짜: 2026-03-20
> 기반: 비용구조_구슬재화_확정 (250원/세션 보수적) + 수익모델_심화설계 + 끝판왕_파이프라인_설계
> 핵심 변경: ~~라이트 파이프라인(단일 모델)~~ → **풀 파이프라인 동일, 구슬 횟수만 제한**
> 교차검증: Claude + GLM-5 (2자)
> eCPM 리서치: Perplexity (Tenjin·Unity·Pollfish·Tapjoy 데이터 기반)
> 상태: **확정**

---

## 0. 설계 원칙

**"와, 이게 무료?" → 유료 전환**

1. 세계관 경험 100% 동일 (모닥불, 현자, 구슬, 의식)
2. 분석 품질 100% 동일 (이종 모델 풀 파이프라인)
3. 차등은 **구슬 수량 + 부가 기능** — "더 자주, 더 편하게 쓰려면 구독"
4. 무료에서 충분히 감동 → 자발적 전환 (강제 차단 아님)

## 1. 무료 재화 배분

### 1-1. 구슬 배분 구조

| 구분 | 무료 (모험) | 유료 (여정, 9,900원) | 프로 (현자, 19,900원) |
|------|------------|-------------------|---------------------|
| **주간 배분** | 10구슬 | 50구슬 | **120구슬** |
| **월간 환산** | ~40구슬 | ~200구슬 | **~480구슬** |
| **일 사용 상한** | 6구슬 | 15구슬 | **35구슬** |
| **광고 추가 획득** | ✅ (일/주 상한) | ❌ | ❌ |
| **미사용 이월** | ❌ (주 리셋) | 50% (상한 25, 1주 한정) | 100% (상한 60, 1주 한정) |
| **히스토리** | 30일 | 무제한 | 무제한 |
| **결론 저장/공유** | 화면 열람만 | 다운로드+공유 | 다운로드+공유 |
| **위클리 체크인** | ❌ | ✅ | ✅ |

> 유료 티어 상세 (구슬 수, 이월, 차등 요소): 구독티어_재설계.md 참조 (확정)

> 구슬 배분 10개는 **A/B 테스트 대상** (8 vs 10). Claude·GLM-5 모두 "약간 관대할 수 있음" 판정.

### 1-2. 구슬 소모 매핑

| 파이프라인 단계 | 구슬 소모 | 비용 |
|---------------|----------|------|
| 입장 + 듣기 | **무료** | 0원 |
| 리서치 (Tavily + 요약) | +1구슬 | ~40원 |
| 구슬 분석 (1개 모델) | +1구슬 | ~25원 |
| 추가 모델 분석 (각) | +1구슬 | ~25원 |
| 토론 (불일치 합성) | +1구슬 | ~50원 |
| Judge + 결론 | **무료** | 0원 |

### 1-3. 무료 사용자 시나리오

| 고민 무게 | 구슬 소모 | 비용 | 주간 가능 횟수 |
|----------|----------|------|-------------|
| 가벼운 (리서치 + 1모델) | 2구슬 | ~65원 | 5회 |
| 보통 (리서치 + 2모델) | 3구슬 | ~90원 | 3회 |
| 무거운 (리서치 + 3모델 + 토론) | 5구슬 | ~165원 | 2회 |
| 풀 (전 단계) | 6구슬 | ~215원 | 1회 + 잔여 4구슬 |

### 1-4. 왜 이월 없는가

- 이월 허용 시 구슬을 모아서 한 달에 한 번 몰아 쓰기 → 주기적 방문 동기 사라짐
- 주 단위 리셋 = **"매주 모닥불이 구슬을 채워준다"** 세계관 프레이밍
- "이번 주 구슬이 남았는데... 한 번 더 해볼까?" → 습관 형성
- ⚠️ GLM-5 지적: "남은 구슬 리셋" 손실감 → 리셋 전 알림("구슬이 내일 사라집니다")으로 완화

## 2. 무료 vs 유료 차등

### 2-1. 핵심 차등: 구슬 수량

| | 무료 | 유료 |
|--|------|------|
| 파이프라인 | **풀 (이종 모델)** | **풀 (이종 모델)** |
| 주간 구슬 | 10개 | 50개 |
| 배수 | 1x | 5x |

### 2-2. 부가 기능 차등 (교차검증 후 추가)

Claude·GLM-5 모두 "구슬 수량만으로 전환 동기 부족할 수 있음" 지적 → 세계관 파괴 없는 부가 기능 차등 추가:

| 기능 | 무료 | 유료 | 전환 동기 |
|------|------|------|----------|
| **히스토리** | 30일 | 무제한 | "3달 전 고민, 지금은 어떻게 됐지?" |
| **결론 다운로드** | 화면 열람만 | PDF/이미지 저장+공유 | "기록으로 남기고 싶은데" |
| **위클리 체크인** | ❌ | ✅ | "현자가 매주 기다리고 있습니다" |
| **광고** | 있음 (선택적) | 없음 | 쾌적함 |

> 세계관 파괴 없이 "편의성"으로 차등 → "분석 품질 동일" 원칙 유지

### 2-3. 왜 품질 차등을 버렸는가

1. **"와, 이게 무료?"의 본질**: 품질이 낮으면 감동 없음 → 전환 없음
2. **기술적 단순함**: 라이트/풀 두 파이프라인 유지 = 코드 복잡도 2배
3. **설명 가능성**: "무료는 단일 모델" → 사용자가 이해 못함 / "무료는 주 10구슬" → 직관적
4. **도덕적 정합성**: "AI가 답을 주지 않는다"면서 무료에겐 싸구려 분석? → 세계관 파괴

## 3. 광고 모델

### 3-1. 리워드 광고 위치 — "모닥불로 가는 길목"

세션 **중간** 광고 = 몰입 파괴 → **절대 금지**

| 광고 위치 | 타이밍 | 세계관 프레이밍 | 형태 |
|----------|--------|--------------|------|
| **세션 시작 전** | 고민 입력 후, 리서치 시작 전 | "현자를 만나러 가는 중..." | 리워드 비디오/오퍼월 |
| **구슬 충전소** | 구슬 부족 시 (별도 메뉴) | "모닥불에 장작을 더 넣으시겠습니까?" | 리워드 비디오/오퍼월 |
| **세션 완료 후** (선택) | 결론 확인 후 | "다음 여정을 위한 준비" | 리워드 비디오 |

### 3-2. 구슬 획득 방식 — 오퍼월/설문형 (eCPM 리서치 반영)

리서치 결과, **웹에서 리워드 비디오 eCPM은 비현실적으로 낮지만, 오퍼월/설문형은 eCPM이 10-50배 높다**. 따라서 "광고 N회 시청" 모델을 폐기하고 **미션 완료형**으로 전환.

| 획득 방식 | 구슬 보상 | 예상 수익 (풀림) | 세계관 프레이밍 |
|----------|----------|---------------|--------------|
| **설문 참여** (30초-2분) | 1구슬 | 50-200원/건 | "현자가 모험가의 의견을 구합니다" |
| **오퍼월 미션** (앱 설치 등) | 2-5구슬 | 100-500원/건 | "모험가 길드의 의뢰를 완수하세요" |
| **리워드 비디오** (15-30초) | — | — | MVP에서 제외 (웹 지원 불가) |

| 항목 | 수치 |
|------|------|
| 일 설문/오퍼월 상한 | 3건 (= 3-5구슬) |
| 주 상한 | 9건 (= ~12구슬) |
| 주 최대 구슬 (배분+획득) | 10 + ~12 = **최대 ~22구슬** (오퍼월 보상에 따라 유동) |

**변경 근거** (eCPM 리서치 + 교차검증):
- **웹 리워드 비디오 불가**: AdMob = 앱 전용(정책 위반 시 계정 정지), Meta Audience Network = 2020년 웹 지원 종료
- **오퍼월 eCPM $400-1,500**: Tapjoy 한국 사례(롯데멤버스 L.Point)에서 광고 수익 20배, eCPM 10배 상승 실증
- **설문형 eCPM 최대 $200** (Pollfish): 리워드 비디오 대비 5-20배
- 구슬 비용(35원) 대비 설문 1건 수익(50-200원) = **흑자 가능**
- MVP에서도 광고 수익이 비용을 상쇄할 수 있음 → 경제성 대폭 개선

### 3-3. 웹앱 광고 구현 — 단계별 전략

| 단계 | 시점 | 방식 | 기대 수익 |
|------|------|------|----------|
| **MVP** | 4-7월 | 오퍼월(Tapjoy/Persona.ly) + 설문형(Pollfish/오픈서베이) | 건당 50-500원 |
| **성장** | 8-12월 | PWA → 네이티브 전환 → AdMob 리워드 비디오 추가 | eCPM $22-29 |
| **스케일** | 1년+ | 하이브리드 미디에이션(AdMob+AppLovin+Unity) + 자체 스폰서십 | $15-30+ |

## 4. 무료 남용 방지

### 4-1. 3중 상한 체계

| 상한 유형 | 무료 | 유료 | 목적 |
|----------|------|------|------|
| **일 구슬 사용** | 6구슬 | 15구슬 | 하루 폭식 방지 |
| **주 구슬 배분** | 10구슬 | 50구슬 | 핵심 차등 |
| **일 미션(설문/오퍼월)** | 3건 | N/A | 어뷰징 방지 |
| **주 미션** | 9건 | N/A | 주간 획득 상한 |
| **주 최대 구슬** | ~22구슬 (10+미션) | 50구슬 | 절대 상한 |

### 4-2. 계정 악용 방지

| 위협 | 대응 |
|------|------|
| 다중 계정 (멀티어카) | 이메일/전화번호 인증, 디바이스 핑거프린트 |
| 봇 미션 완료 | 오퍼월 콜백 검증 + 세션 행동 패턴 체크 |
| 미션 어뷰징 | 오퍼월 네트워크 자체 fraud 감지 + 이상 패턴 감지 |
| 무한 무료 계정 순환 | 신규 계정 첫 주는 5구슬로 시작 (2주차부터 10구슬) |

### 4-3. "온보딩 구슬" 전략

| 시점 | 구슬 | 의도 |
|------|------|------|
| 첫 가입 | +3구슬 보너스 | 첫 세션 즉시 체험 유도 |
| 첫 주 | 5구슬 배분 | 어뷰징 방지 (2주차부터 정상 10구슬) |
| 친구 초대 | +2구슬 (양쪽) | 바이럴 루프 |
| 첫 유료 전환 | +10구슬 보너스 | 전환 보상 (GLM-5 제안: "잔여 2배" 변형) |

## 5. 전환 유도 UX — "강요 없는 갈증"

### 5-1. 구슬 부족 시 (핵심 전환 트리거)

세션 진행 중 구슬이 부족할 때:

```
[분석 단계]
🧙 "흥미로운 고민이군. 나침반의 구슬도 들여다보고 싶은데..."

   [구슬이 부족합니다]

   🔮 미션을 완료하고 구슬 얻기 (설문 1건 = 1구슬)
   ✨ 여정 티어로 업그레이드 (주 50구슬)
   ➡️ 이대로 결론으로 가기 (현재 분석만으로 정리)
```

> **핵심**: "이대로 결론 가기"를 항상 제공 → 강제 차단 아님. 단, 추가 분석의 **맛**을 본 후이므로 갈증 발생

### 5-2. 전환 제안 타이밍 (세계관 맥락)

| 트리거 | 전환 메시지 | 세계관 맥락 |
|--------|-----------|-----------|
| **구슬 부족** (세션 중) | "더 깊이 보고 싶다면, 여정을 시작하세요" | 현자가 더 해줄 이야기가 있는데... |
| **주간 구슬 소진** | "이번 주 구슬을 다 썼습니다. 다음 주에 만나요" | "모닥불은 꺼지지 않는다네" |
| **풀 분석 완료 후** (감동 피크) | "매주 이렇게 이야기하고 싶다면?" | 결론 후 여운 화면에서 |
| **3회 사용 후** (습관 형성) | "벌써 3번째 방문이군. 자주 오는 모험가에겐..." | 현자가 알아봄 |
| **불일치 발견 시** (가치 피크) | "구슬들의 의견이 갈렸네. 토론을 열어볼까?" | 가장 흥미로운 순간에 구슬 소모 → 갈증 |
| **히스토리 30일 만료 시** | "지난 고민의 기록이 곧 사라집니다" | 기록 보존 동기 |

### 5-3. "늦은 밤" 전환 시나리오 (킬러 플로우)

```
밤 11시, 스트레스 상태로 풀림 접속
→ 첫 가입, 보너스 3구슬 + 주간 5구슬 = 8구슬
→ 무거운 고민 선택 (리서치+3모델+토론 = 6구슬)
→ 풀 파이프라인 체험 → "와, 이게 진짜 도움이 되네"
→ 세션 끝 → 남은 2구슬
→ "다음 고민이 생기면 2구슬로는 가벼운 분석만 가능합니다"
→ 9,900원 → "만원 이하네, 그냥 결제하자"
→ 즉석 전환 + 보너스 10구슬
```

### 5-4. 안티패턴 — 절대 하지 않는 것

| ❌ 안 함 | 이유 |
|---------|------|
| 결론을 가리거나 워터마크 | 무료에서도 풀 품질이 원칙 |
| 팝업으로 구독 강요 | UX 파괴 → 이탈 |
| 카운트다운/긴급성 연출 | 사행성 느낌 → 세계관 파괴 |
| 무료 세계관 차별 (다른 톤/비주얼) | "무료도 동일한 의식" 원칙 위반 |
| 광고 미시청 시 세션 차단 | 광고는 **선택적** 구슬 충전 수단 |

## 6. 경제성 시뮬레이션 (교차검증 반영)

### 6-1. 무료 사용자 1인당 월간 손익 (오퍼월/설문형 수익 반영)

| 시나리오 | 구슬 사용 | 비용 | 미션 수익* | 손익 |
|---------|---------|------|----------|------|
| 소극적 (배분만, 미션 0) | 12구슬/월 | ~420원 | 0원 | **-420원** |
| 보통 (주 8구슬, 설문 주 3건) | 32구슬/월 | ~1,120원 | 900원 | **-220원** |
| 적극적 (주 15구슬, 미션 max) | 60구슬/월 | ~2,100원 | 2,700원 | **+600원** |

*설문 건당 보수적 75원 적용 (Pollfish eCPM $200 → 건당 ~$0.20 → 27원, 오퍼월 건당 ~150원 가중 평균)

> 핵심 변화: **오퍼월/설문형은 리워드 비디오 대비 수익이 10-50배** → 적극적 무료 사용자는 **흑자 가능**
> 평균 무료 사용자: **월 ~200원 적자** (리워드 비디오 기반 800원 적자에서 대폭 개선)

### 6-2. 전환율별 손익분기 (오퍼월 수익 반영)

무료 N명 중 1명이 유료(여정) 전환 시:

| 전환율 | 무료 적자 (N명) | 유료 이익 (1명) | 넷 | 판정 |
|--------|---------------|---------------|-----|------|
| 20% | 5명 × 200원 = 1,000원 | ~8,150원 | **+7,150원** | ✅ 여유 흑자 |
| 15% | 6.7명 × 200원 = 1,340원 | ~8,150원 | **+6,810원** | ✅ 흑자 |
| 10% | 10명 × 200원 = 2,000원 | ~8,150원 | **+6,150원** | ✅ 흑자 |
| 5% | 20명 × 200원 = 4,000원 | ~8,150원 | **+4,150원** | ✅ 흑자 |
| **2.5%** | **40명 × 200원 = 8,000원** | ~8,150원 | **±0** | ⚖️ **BEP** |

> **손익분기 전환율 ≈ 2.5%** — 이전 9.8%에서 대폭 개선
> 한국 B2C freemium 평균 3-5% (GLM-5 지적) 대비 **충분한 여유**
> 오퍼월/설문형 수익이 무료 티어 적자를 대부분 상쇄하기 때문

### 6-3. 네이티브 전환 후 시나리오 (8월~)

| 시나리오 | 구슬 획득 수익 | 리워드 비디오 추가 | 무료 손익 | BEP |
|---------|-------------|-----------------|---------|-----|
| MVP (웹, 오퍼월+설문) | 월 ~600원 | — | ~-200원/인 | 2.5% |
| **네이티브** (위 + AdMob $29) | 월 ~600원 | 월 ~1,200원 | **+1,000원/인** | **0%** (무료만으로 흑자) |

> 네이티브 전환 시 무료 사용자도 흑자 → **완전한 freemium 모델 성립**
