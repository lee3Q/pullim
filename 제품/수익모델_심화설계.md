> 비용 증가가 크지 않은 이유: 이종 모델 호출이 추가되지만, GPT/Gemini는 Sonnet과 비슷하거나 저렴. Judge를 Opus 대신 Haiku/GLM-5로 운용하면 비용 관리 가능. Tavily는 무료 1,000회/월.

### Judge 모델 선택지

| Judge 모델 | 세션 비용 | 장단점 |

| Opus (프리미엄) | ~300-500원 | 깊은 검증, 프로 티어 전용 |

**전략**: 스탠다드 = Haiku Judge, 프로 = Opus Judge → 티어 차별화의 실질적 근거

## 2. 수익 모델 — 광고+구독 이중 모델

### 2-1. 왜 광고를 추가하는가

v3의 무료 티어(월 1세션)는 전환 동기가 약했음:
- 1세션 해보고 "괜찮네" → 다음 고민까지 2주 → 구독 안 함
- 광고 모델은 **즉각적 재사용**을 가능하게 함
- "광고 보기 귀찮다" = 구독 전환 동기

**끝판왕의 "의식(ritual)" 경험과 광고의 긴장관계**:
- 세션 중간에 광고 삽입 → 몰입 파괴 → ❌ 절대 금지
- **세션 시작 전**에만 리워드 광고 → "모닥불로 가는 길목" 프레이밍 가능
- "현자를 만나러 가는 중..." 로딩 화면 = 광고 시점

### 2-2. 티어 설계

| 티어 | 가격 | 풀 세션 | Quick | 파이프라인 | 테마 | 광고 |
|------|------|---------|-------|----------|------|------|
| **모험** (무료) | 0원 | 광고 시청 시 월 3회 | 월 5회 | 라이트 (단일 모델) | 모험가만 | 있음 |
| **여정** (스탠다드) | 9,900원/월 | 월 8회 | 무제한 | **풀 (이종 모델)** | 모험가만 | 없음 |
| **현자** (프로) | 19,900원/월 | 월 20회 | 무제한 | **풀 + Opus Judge** | **3테마 전체** | 없음 |

> 티어 네이밍을 세계관에 맞춤 → "모험 → 여정 → 현자"

#### 무료 "모험" 티어 상세

- 광고: 세션 시작 전 리워드 비디오 1회 (15-30초)
- 파이프라인: 라이트 버전
  - 구슬 3개 선택은 동일 (의식적 경험 보존)
  - 내부적으로 Sonnet 1개가 3관점 시뮬레이션 (비용 ~300원)
  - 리서치 단계 생략 (기존 지식 기반 분석)
  - Judge 검증 생략
- 결론 문서: 제공하되 "풀 분석은 여정 티어에서" 워터마크

**핵심 설계 원칙**: 무료도 "와, 이게 무료?" 경험이어야 전환이 일어남. 파이프라인 단계를 빼되, **세계관 경험(모닥불, 현자, 구슬)은 100% 동일**.

#### 스탠다드 "여정" 티어 상세

- v3의 7,500원에서 **9,900원으로 인상** (이유 아래)
- 이종 모델 풀 파이프라인: 구슬 3개 = 실제 3개 모델
- 리서치 에이전트 포함
- Judge: Haiku (충분한 품질, 비용 효율)
- 히스토리 + 위클리 체크인

**9,900원 근거**:
1. 비용 증가 (300원 → 350원/세션) → 마진 보전
2. "만원 이하" 심리적 가격대 유지
3. 포스텔러 심층 사주 1회(3,000-20,000원) = 풀림 1달
4. 넷플릭스 스탠다드(13,500원)보다 저렴

#### 프로 "현자" 티어 상세

- Opus Judge → 체감 품질 차이 (더 깊은 검증, 더 날카로운 불일치 포착)
- **3테마 전체 언락** → "달빛정원에서 같은 고민을 다시 봤는데 느낌이 다르더라"
- 월간 패턴 리포트 (개인화 인사이트)
- 우선 응답 (동시접속 많을 때)

## 3. Unit Economics (끝판왕)

### 3-1. 세션당 손익

| 티어 | 세션 비용 | 세션 가격* | 순이익/세션 | 마진 |
|------|----------|----------|-----------|------|
| 모험 (무료) | ~300원 | 광고 ~40원 | **-260원** | 적자 (전환 투자) |
| 여정 (9,900원/8세션) | ~350원 | 1,238원 | **+888원** | **72%** |
| 현자 (19,900원/20세션) | ~550원 | 995원 | **+445원** | **45%** |

*세션 가격 = 월 구독료 ÷ 포함 세션 수

> 프로 티어는 세션당 마진이 낮지만, 실제 사용량은 20세션 중 8-12세션 수준으로 예상 → 실질 마진 60-70%

### 3-2. 실사용 기준 마진 (핵심)

사용자는 포함 세션을 전부 쓰지 않음. SaaS 평균 실사용률 50-60%.

| 티어 | 포함 | 실사용 예상 | 실제 변동비 | 실질 마진 |
|------|------|-----------|-----------|----------|
| 여정 | 8세션 | 4-5세션 | 1,400-1,750원 | **82-86%** |
| 현자 | 20세션 | 8-12세션 | 4,400-6,600원 | **67-78%** |

**Quick Mode** (모든 유료 티어 무제한):
- 비용 ~30-50원/건, 하루 평균 0-1회 사용 가정
- 월 추가 비용: ~0-1,500원
- 실질 마진에 미미한 영향

### 3-3. BEP 재계산

| 항목 | 금액 |
|------|------|
| 고정비/월 | ~85,000원 (Vercel Pro + 도메인 + Tavily Pro + 기타) |
| 여정 순이익/인 (실사용 기준) | ~8,150원 |
| **BEP** | **~11명** |

> v3 BEP 15명 → 끝판왕 BEP 11명 (가격 인상 효과)

### 3-4. 무료 티어 손익분기

무료 사용자 1명당 월 손실: ~800원 (세션 3회 × ~300원 - 광고 ~100원)

> 광고 수익 추정 근거: 한국 리워드 비디오 광고 eCPM $10-30 [출처: ironSource/AppLovin 2025 한국 벤치마크 보고서 범위, Appsflyer 2024 모바일 광고 벤치마크]. 노출당 ~15-45원, 보수적으로 **~30-40원/회** 적용. 세션 시작 전 광고 1회 + 세션 완료 후 배너 1회 = 세션당 ~30-40원.

유료 전환율 20% 가정 시:
- 무료 5명 중 1명이 여정으로 전환
- 무료 5명 손실: 4,000원
- 유료 1명 이익: 8,150원
- **넷 이익: +4,150원** → 무료 티어는 수익에 기여

유료 전환율 10% (보수적) 시:
- 무료 10명 중 1명 전환
- 무료 10명 손실: 8,000원
- 유료 1명 이익: 8,150원
- **넷 이익: +150원** → 손익분기 전환율 ≈ 10%

## 4. 3테마 프리미엄 전략

### 4-1. 테마의 수익화 가치

"같은 분석, 다른 세계관"은 개발 비용이 낮고 지불 의향이 높은 이상적 프리미엄 요소:

- 개발 비용: 프롬프트(톤/용어) + CSS(색상/에셋) + BGM → 코드 아키텍처 동일
- 지불 의향: 게임 스킨과 동일한 심리 — "기능은 같지만 내 취향"
- 커뮤니티 효과: "나는 달빛정원파" → 소속감 → 리텐션

### 4-2. 테마 출시 전략

| 시점 | 테마 | 전략 |
|------|------|------|
| MVP (4-7월) | 모험가만 | 핵심 파이프라인 검증에 집중 |
| 정식 (8-9월) | + 달빛정원 | 여성 타겟 확장. 프로 티어 전용으로 출시 → 업그레이드 동기 |
| 스케일 (10-12월) | + 전략실 | 직장인/창업자 타겟. 역시 프로 전용 |

### 4-3. 테마 확장 가능성 (향후)

커뮤니티 투표로 신규 테마 추가 → "내가 뽑은 테마가 만들어진다" → 소속감+참여감

후보:
- 🎪 서커스단 (유머+위트 감성)
- 🏯 동양 선비 (사자성어+고전 감성)
- 🚀 우주정거장 (SF 감성)
- 시즌 한정 테마 (할로윈, 크리스마스)

## 6. 가격 앵커링 (마케팅용)

### 끝판왕 관점 재설계

| 비교 대상 | 가격 | 풀림과 비교 |
|----------|------|-----------|
| O2O 심리상담 1회 | 5-15만 원 | 풀림 프로 1달 < 상담 1회 |
| 포스텔러 심층 사주 1회 | 3,000-20,000원 | 풀림 여정 1달(8세션) = 사주 1회 비용 |
| 타로 카페 방문 1회 | 2-5만 원 | 풀림 여정 2달 < 타로 1회 |
| 넷플릭스 스탠다드 | 13,500원 | 풀림 여정이 더 저렴 |
| 커피 한 잔 × 5 | 25,000원 | 풀림 여정 2.5달 |

**킬러 카피**: "타로 카페 한 번 값으로, 한 달 동안 모닥불 앞에서 현자와 이야기하세요"

### "늦은 밤 전환" 시나리오

Gemini 분석에서 나온 "충동 구독의 마지노선" 활용:
1. 밤 11시, 스트레스 상태 → 풀림 접속
2. 무료 세션 진행 → 현자와 대화 → "와, 이게 진짜 도움이 되네"
3. 세션 끝 → "다음 고민도 현자와 이야기하고 싶으신가요?" → 9,900원 구독 버튼
4. 만원 이하 = 결제 저항 최소 → 즉석 전환
