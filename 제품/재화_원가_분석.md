## 2. 파이프라인 단계별 원가

```
입장 + 듣기       → 무료
리서치             → +1구슬  (검색+요약+검증)
구슬 분석 (모델 1개) → +1구슬  (추가 모델당 +1구슬)
토론               → +1구슬  (불일치 시에만)
Judge + 결론       → 무료
```

### 무료 (주 10구슬 = 월 40구슬)

| 항목 | 수치 |
|------|------|
| 원가 | 40 × 65 = 2,600원/월 |
| 광고 수익 | ~400-800원/월 |
| 순 적자 | ~1,800-2,200원/인 |

### BEP

- 고정비: ~85,000원/월
- 유료 순이익/인 (50구슬 기준): 9,900 - 3,250 = **6,650원**
- **BEP: 85,000 ÷ 6,650 ≈ 13명**

## 6. Thinking 토큰 운영 지침

| 단계 | Thinking | 이유 |
|------|---------|------|
| 입장/듣기 | OFF | 템플릿 응답 |
| 리서치/검증 | OFF | 검색 결과 정리 |
| 논의 | OFF | 대화형 응답 |
| **분석 (4a/4b/4c)** | **ON (500~1,000t)** | 핵심 분석 품질 |
| 불일치/토론 | 선택적 | 품질 테스트 후 결정 |
| Judge | OFF | Haiku는 thinking 비활성 |
| 결론 | OFF | 정리 작업 |

> GLM-5 지적: thinking 1,500t는 낙관적, 복잡한 고민 시 3~5K 가능.
> **대응: max_thinking_tokens 파라미터로 상한 설정. 비용 예측 가능성 확보.**
