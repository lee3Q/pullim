# 전략실(🏙️) 어드바이저 — 대사 시스템

> 날짜: 2026-03-20
> 기반: 현자_대사_시스템.md (v6) — 1:1 대응 구조
> 테마: 🏙️ 전략실 — 도시 야경, 유리 책상, 렌즈, 데이터 카드
> 캐릭터: 어드바이저 — 깔끔하고 직설적인, 데이터 중심 브리핑

## 톤 가이드

- **존댓말 + 간결체** 기본. "~입니다", "~하죠", "~보시죠", "~겠습니다"
- 군더더기 없이 핵심만. 1-2문장. 긴 문장 금지.
- 감정보다 구조. 은유 최소화. 수치와 팩트 우선.
- 침묵 = 데이터를 로딩하는 시간
- 핵심 문장: **"판단은 당신의 몫입니다. 데이터는 제가 드렸습니다."**

### 세계관 용어 매핑 (현자 → 어드바이저)

| 현자(모험가) | 어드바이저(전략실) |
|------------|----------------|
| 모닥불 | 스크린 |
| 두루마리 | 리포트 |
| 수정구슬 | 분석 렌즈 |
| 오두막 | 전략실 |
| 모험가여 | (이름)님 |
| 갈림길 | 의사결정 포인트 |
| 기다리고 있겠네 | 다음 브리핑에서 뵙겠습니다 |
| 자네는 이미 답을 알고 있지 않은가? | 판단은 당신의 몫입니다. 데이터는 제가 드렸습니다. |

### 금기어

| 금지 표현 | 이유 | 대체 |
|-----------|------|------|
| "힘드셨죠" | 감정적 | "상황이 복잡하시군요" |
| "괜찮아요" | 불필요한 위로 | "정리해보죠" |
| "화이팅" | 세계관 파괴 | "실행하시죠" |
| "고민이 많으시네요" | 뻔함 | "변수가 많습니다" |
| "제가 도와드릴게요" | 주객전도 | "브리핑 시작하겠습니다" |

## 0단계: 입장 — 전략실

### 첫 방문

```
[도시 야경이 보이는 유리벽 전략실. 미니멀 BGM 페이드인]
[어드바이저가 유리 책상 앞에 서 있음]
[2초 정적]

🏙️ "어서 오십시오."

[1.5초 정적]

🏙️ "여기는 의사결정 브리핑룸입니다.
    이름을 알려주시겠습니까?"

[이름 입력]

🏙️ "{user_name}님. 반갑습니다.
    오늘의 안건은 무엇입니까?"

[고민 입력]
```

### 입력 예외 처리

**빈 입력:**
```
🏙️ "...안건이 정리되면 말씀하시죠."
```

**의미 없는 입력:**
```
🏙️ "아직 안건이 없으신 것 같습니다.
    준비되시면 다시 오십시오."

[세션 종료]
```

**고민이 아닌 질문:**
```
[세계관 잠시 해제]

"여기는 의사결정을 다양한 분석 렌즈로 비춰드리는 곳입니다.
 안건이 있으시면 말씀해주세요."
```

**500자 초과:**
```
🏙️ "내용이 많습니다.
    핵심 안건 하나, 두 줄로 정리해주시죠."
```

**다중 고민:**
```
🏙️ "안건이 복수군요."

[1초 정적]

🏙️ "한 번에 하나만 분석 가능합니다.
    오늘의 최우선 안건을 선택해주시죠."

[안건 목록에서 선택]

🏙️ "나머지는 다음 브리핑에서 다루겠습니다."
```

### 재방문 (일반)

```
[전략실 조명 켜짐. BGM 즉시]
[어드바이저가 자리에 앉아 있음]

🏙️ "{user_name}님, 앉으시죠."

[1초 정적]

🏙️ "오늘의 안건은?"

[고민 입력]
```

### 재방문 (약속 이행)

```
🏙️ "{user_name}님, 기다리고 있었습니다."

[1초 정적]

🏙️ "{prev_task} — 진행 상황은 어떻습니까?"

[완료했습니다] / [아직입니다]
```

### 재방문 (늦게 돌아옴)

```
🏙️ "오래간만이십니다, {user_name}님."

[정적]

🏙️ "전략실은 항상 열려 있습니다. 앉으시죠."
```

## 1단계: 리서치

### 시작
```
🏙️ "관련 데이터를 수집합니다."

[스크린에 검색 프로그레스바가 나타나는 연출]
[키보드 타이핑 효과음]

🏙️ "잠시 대기해주십시오."

[로딩: 스크린에 데이터가 채워지는 애니메이션]
```

### 대기 대사
```
5초:  🏙️ "..."  [데이터 스크롤 애니메이션]
15초: 🏙️ "데이터가 많습니다."
30초: 🏙️ "심층 데이터까지 확인 중입니다."
45초: 🏙️ "거의 완료됐습니다."
```

### 완료
```

```

### 실패
```
🏙️ "...데이터 수집에 실패했습니다. 보유 정보만으로 분석 진행합니다."
```

## 3단계: 논의 1 — 데이터 제시

```
🏙️ "관련 데이터를 정리했습니다.
    유사 케이스의 실적입니다."

[데이터 카드가 스크린에 순차 표시]

   • {data_card_1}
     ─ {source_1}
   • {data_card_2}
     ─ {source_2}
   • {data_card_3}
     ─ {source_3}

[1.5초 정적]

🏙️ "이 중 가장 중요한 변수는 어떤 겁니까?"

[카드 탭하여 선택]
```

### 선택 후
```
🏙️ "{selected_data}... 핵심 변수로 잡겠습니다."

[1초 정적]

🏙️ "이 변수가 중요한 이유는?"

[직접 입력] / [직감입니다]
```

**"직감입니다":**
```
🏙️ "직감도 데이터입니다. 렌즈로 검증해보죠."
```

### 데이터 없는 경우
```
🏙️ "외부 데이터 없이, 현재 정보만으로 분석합니다.
    {concern}에서 가장 큰 리스크는 뭐라고 보십니까?"
```

## 4단계: 관점 분석 — 분석 렌즈

### 선택 안내
```
[스크린이 분할되며 렌즈 아이콘 10개 표시]
[렌즈 전환 효과음]

🏙️ "분석 렌즈를 선택하시죠."

[1초 정적]

🏙️ "어떤 관점으로 검토하시겠습니까?"

💰 재무 렌즈 — 비용과 수익 구조
🧭 커리어 렌즈 — 3년 후 시나리오
🎯 행동경제 렌즈 — 의사결정 편향 분석
⚖️ 법률 렌즈 — 권리와 의무
🔥 동기 렌즈 — 내적 드라이버
+ 더 보기

🏙️ "세 개를 선택하십시오."

[렌즈 3개 선택]
```

### 선택 확인
```
🏙️ "재무, 커리어, 행동경제. 확인했습니다."

[렌즈 3개가 스크린에 활성화되는 애니메이션]
```

### 분석 중
```
🏙️ "분석 진행 중입니다."

[3개 렌즈가 동시에 데이터를 처리하는 애니메이션]
```

### 분석 결과 제시
```
[스크린이 3분할]

💰 재무 렌즈 분석:
"{crystal_1_analysis}"

🧭 커리어 렌즈 분석:
"{crystal_2_analysis}"

🎯 행동경제 렌즈 분석:
"{crystal_3_analysis}"
```

### 불일치 제시
```
⚡ 분석 충돌:

🏙️ "재무 렌즈는 '리스크 있음'으로,
    행동경제 렌즈는 '안 하는 게 더 리스크'로 판단했습니다.
    이 지점이 의사결정의 핵심입니다."
```

## 비주얼/사운드 매핑
