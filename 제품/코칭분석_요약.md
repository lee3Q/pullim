# 코칭분석 핵심 요약 (2026-03-07)
> 원본: ~/study/main/창업/제품/코칭분석_복원_2026-03-07.md

## 파이프라인 변경
- 7단계 분석형 → 3단계 대화형 (듣기→풀기→착지)
- 사용자에게 단계를 보여주지 않음
- 7단계는 McKinsey 컨설턴트의 사고 프로세스에 가까웠고, 고민하는 인간의 내면 프로세스와 괴리

## 내장 코칭 기법
- Mirroring: 사용자의 핵심 단어를 그대로 반사 — 분석/해석 없이 거울 역할. 자기 탐색 촉진
- Powerful Questions: 짧고(15단어 이내), 관점을 전환시키며, 즉답 불가한 질문. 정보 수집 질문과 분리 배치
- Reframing: 프레임(해석 틀) 전환. "실패하면 어쩌지" → "기대와 다른 결과가 나오면"으로 바꿔 선택지 확장

## AI 한계 반영
- 빼는 것: 관계 형성(파트너십), 신체 감각 읽기, 상호 취약성 노출
- 집중하는 것: 언어 패턴 매칭, 불일치 감지(말과 행동의 불일치), 맥락 축적(세션 간 패턴 발견)
- AI는 라포를 형성할 수 없지만, 인지적 정확성 기반 신뢰("이 AI가 내 말을 정확히 이해하고 있다")는 구축 가능

## 결과물 변경
- 점수표+분석 보고서 → 편지형 정리 문서(기본) / 요약 보고서(선택)
- 사용자 시뮬레이션 결과: 감정형(A, C)은 편지 선호, 논리형(B)은 보고서 선호 → 포맷 선택권 필수

## 핵심 비판 (통합비판자)
- "7단계 완주 사용자 10% 미만" → 챗봇 평균 3턴 넘기는 사용자 50% 이하, 7단계는 최소 14턴 → 3단계로 단축
- "6개 모델은 MVP가 아니라 v3" → 단일 모델(Socratic 질문→정리 문서 한 가지 흐름)로 단순화
- 히스토리 축적은 해자가 아님 → 연 1-3회 사용으로는 lock-in 불가, "구조화된 자기 이해의 축적"이 더 강한 해자
- "AI 코치"라 부르지 마라 → 코칭 기법은 내부 엔진으로만, 마케팅에는 "생각 정리 도우미"
- 우뇌적 요소는 MVP에서 빼고 v2에서 감정 개입 높은 세션에만 조건부 투입

## 사용자 시뮬레이션 (3인 피드백)
- 이지은(29세 마케터): "5단계부터 '아직 더 있어?'" → 후반부는 숙제하는 느낌. 감정을 먼저 읽어주는 AI를 원함
- 박준호(34세 공무원): 기계적인 게 오히려 편함. 객관적 데이터/시뮬레이션 부족. 건당 결제 선호
- 김하영(24세 대학생): 스트레스테스트에서 이탈 충동. "결정 강요 없이 함께 있어주기"가 가장 절실
- 공통: 빈 입력창 문제(3명 중 2명 어려움), 다기준평가 표에서 감정 흐름 끊김, "쉬었다 가도 돼" 한마디가 신뢰를 만듦

## 즉시 적용 가능한 5가지 액션
1. Layer 0를 Landing으로 재설계 (에너지 감지 + 페이스 매칭 + 세션 계약)
2. CLARIFY → WANT 전환 ("문제가 뭐야"에서 "원하는 게 뭐야"로)
3. 각 단계에 Powerful Question 1개 + 감각 기반 질문 1개 삽입
4. 불일치 감지 로직 (반복 단어, 톤 변화, 말과 행동의 불일치)
5. Post-Decision Follow-up (결정 후 리마인드 + 의지 점검)
