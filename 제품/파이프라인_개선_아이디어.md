# 파이프라인 개선 브레인스톰

> 날짜: 2026-03-20
> 기반: 끝판왕_파이프라인_설계 + 검증_해결사_종합 + 끝판왕_컨셉확정
> 목적: 현재 9단계 파이프라인의 갭/개선점/신규 아이디어

## 1. 현재 파이프라인 갭 분석

### 1-1. 입력 단계 — 고민 입력의 깊이 문제

**현재**: "모험가여, 오늘은 무슨 바람이 불어 찾아왔는가?" → 텍스트 입력

**갭**:
- 사용자가 고민을 명확하게 표현하지 못하는 경우가 많음
- "뭔가 답답한데 뭔지 모르겠어" → 이걸로 리서치/분석이 가능한가?
- v3 해결사에서 지적: "고민 입력의 질이 파이프라인 전체 품질을 결정"

**개선안**: **프리 소크라테스 (0단계)**
- 고민 입력 후, 본 파이프라인 시작 전 2-3개 분류 질문
- "이 고민은 언제부터였나?" / "가장 두려운 건 뭔가?" / "이상적인 결과는?"
- 세계관 유지: 현자가 "잠깐, 모닥불에 앉기 전에 한 가지만 물어보겠네"
- 이 정보가 리서치 쿼리 + 구슬 분석의 컨텍스트가 됨

### 1-2. 리서치 → 논의 1 전환 — 데이터 과부하 리스크

**현재**: 리서치 결과를 데이터 카드로 펼침 → 사용자가 가장 무겁게 느끼는 것 선택

**갭**:
- 리서치 결과가 5-10개 데이터 포인트 → 선택 피로
- "의사결정 피로를 해결하는 서비스"가 의사결정 피로를 유발하면 안 됨

**개선안**: **데이터 카드 3장 제한 + 더보기**
- 현자가 가장 관련성 높은 3개만 우선 제시
- "더 보고 싶은가?" → 확장
- 카드에 원클릭 반응 (😮 놀랐다 / 😟 걱정된다 / 🤔 의외다) → 감정 데이터 수집

### 1-3. 구슬 선택 → 분석 — 대기 시간

**현재**: 구슬 3개 선택 → 3개 모델이 독립 분석 → 결과 표시

**갭**:
- 이종 모델 3개 병렬 호출 = 최소 5-15초 대기
- 대기 시간 동안 사용자 이탈 리스크

**개선안**: **"구슬이 빛나고 있습니다" 인터랙티브 대기**
- 분석 중 각 구슬이 하나씩 빛남 → 첫 번째 구슬 결과 먼저 표시 (스트리밍)
- 대기 중 미니 인터랙션: "분석하는 동안 하나만 더 물어볼게. 이 고민에서 가장 피하고 싶은 결과는?"
- 이 추가 입력이 토론 단계의 컨텍스트가 됨 → 대기 시간이 데이터 수집 시간이 됨

### 1-4. 토론 단계 — 수동성

**현재**: 구슬끼리 대화 → 사용자는 읽기만

**갭**:
- 사용자가 관찰자로만 있음 → 몰입도 하락 가능
- "구슬들의 토론이 끝났네. 어떤가?" 까지 기다려야 함

**개선안**: **실시간 개입 가능 토론**
- 토론 중 특정 구슬의 발언에 "동의 👍 / 반박 ✋" 버튼
- 사용자가 반박하면 → 해당 구슬이 사용자 관점을 반영해 재반론
- "모험가가 끼어들었군. 좋아, 직접 이야기해보게" → 주체성 강화

### 1-5. 결론 → 이후 — 행동 추적의 구체성

**현재**: "뭘 해보겠나?" → 선택 → "언제까지?" → 약속 → "기다리고 있겠네"

**갭**:
- 행동 약속이 추상적일 수 있음 ("이직 준비하기")
- 추적이 날짜 기반뿐 → 중간 체크 없음

**개선안**: **마이크로 행동 분해**
- "이직 준비하기"를 선택하면 → 현자: "좀 더 작게 쪼개보지 않겠나?"
- → "이력서 업데이트" / "관심 회사 3개 리스트업" / "퇴사 시 재정 시뮬레이션"
- 각각에 날짜 → 중간 푸시 알림: "이력서는 다 썼는가?"

## 2. 신규 기능 아이디어

### 2-1. 음성 입력 모드 🎙️

**컨셉**: "현자에게 직접 이야기하기"
- 텍스트 대신 음성으로 고민 입력 → STT → 텍스트 변환
- 세계관 맥락: "글로 쓰기 어려우면, 그냥 이야기해보게"
- 기술: Web Speech API (무료) or Whisper API (~10원/분)
- **가치**: 밤에 누워서, 산책하면서, 감정이 격한 상태에서 → 타이핑보다 자연스러움

**우선순위**: 높음 (비용 낮고, UX 임팩트 큼)

### 2-2. "비슷한 모험가" 익명 통계 📊

**컨셉**: 비식별화된 집단 데이터로 맥락 제공
- "비슷한 고민을 한 모험가 중 62%가 A를 선택했다네"
- "하지만 6개월 후 만족도가 높았던 건 B를 선택한 쪽이었지"

**구현**: 세션 결론의 선택지+결과를 익명 집계
**주의**: 개인정보보호 + 통계 신뢰성 (최소 N=50 이상 누적 후 활성화)

**우선순위**: 중간 (데이터 축적 후)

### 2-3. 되감기(Rewind) 기능 ⏪

**컨셉**: 파이프라인 중간에 이전 단계로 돌아가기
- 현재 논의 3에서만 "다른 구슬로 다시 보고 싶어요"로 4단계 복귀 가능
- 모든 단계에서 "이전 갈림길로 돌아가기" 가능하게

**세계관**: "현자님, 그 두루마리 다시 볼 수 있을까요?"

**우선순위**: 중간 (기존 UX에서 자연스럽게 확장)

### 2-4. 세션 공유 — "두루마리 보내기" 📜

**컨셉**: 결론 문서를 예쁘게 포맷팅해서 공유
- OG 이미지 자동 생성 (도트 아트 스타일)
- 카카오톡/인스타 스토리용 카드 이미지
- "현자의 두루마리를 공유합니다" 프레이밍

**바이럴 효과**: 공유된 카드를 본 사람 → "이게 뭐야?" → 풀림 유입
**우선순위**: 높음 (마케팅 비용 0원의 바이럴 채널)

### 2-5. 대결 모드 — "두 길의 갈림길" ⚔️

**컨셉**: 명확한 A vs B 고민에 특화된 축약 파이프라인
- "이직 vs 잔류", "A대학 vs B대학", "결혼 vs 더 만나기"
- 구슬 분석이 A 진영 / B 진영으로 나뉘어 직접 토론
- 세계관: "두 갈래 길 앞에 서 있군. 각 길의 끝에 뭐가 있는지 보여주지"

**장점**: 고민 구조가 명확한 경우 더 빠르고 몰입감 높은 경험
**우선순위**: 중간 (MVP 이후)

### 2-6. 감정 온도계 🌡️

**컨셉**: 세션 시작과 끝에 감정 상태 측정
- 시작: "오늘 기분이 어떤가? 모닥불의 색으로 골라보게" (빨강-주황-파랑-보라 스펙트럼)
- 종료: 같은 질문 → 변화량 측정
- 누적 데이터: "3개월간 세션 전후 평균 감정 변화: +2.3" → 리텐션 근거

**부가가치**: 효과 측정 데이터 = 투자자/파트너에게 보여줄 성과 지표
**우선순위**: 높음 (구현 간단, 데이터 가치 높음)

### 2-7. 현자의 서재 (아카이브) 📚

**컨셉**: 과거 세션들을 세계관 안에서 열람
- "두루마리 보관함"에 과거 결론 문서들이 쌓임
- 시간순 타임라인 + 태그(진로, 관계, 재무...)
- "6개월 전 자네는 이렇게 말했지..." → 성장 시각화

**리텐션 효과**: 쌓인 기록 = 이탈 비용 → 록인
**우선순위**: 높음 (v3에서도 계획했던 기능)

## 3. 파이프라인 최적화 아이디어

### 3-1. 적응형 파이프라인 깊이

**현재**: 모든 고민이 동일한 9단계
**문제**: "점심 뭐 먹지"도 9단계? (→ Quick Mode가 커버하지만, 중간 복잡도는?)

**개선**: 3단계 파이프라인
| 복잡도 | 단계 수 | 예시 | 비용 |
|--------|---------|------|------|
| 낮 | Quick (1-2단계) | 점심, 옷, 일정 | ~30원 |
| 중 | 미디엄 (5단계) | 주말 계획, 선물, 취미 | ~150원 |
| 높 | 풀 (9단계) | 이직, 창업, 관계 | ~350원 |

자동 라우팅 (기존 v3 기능 활용) + 사용자 오버라이드 ("더 깊이 보고 싶어")

### 3-2. 구슬 조합 추천

**현재**: 사용자가 10개 중 3개 자유 선택
**문제**: 선택 피로 (10C3 = 120가지)

**개선**: 현자가 추천 조합 1개 제시 + 자유 변경 가능
- "이 고민이라면... 금화, 거울, 나침반을 추천하겠네. 물론 자네가 바꿔도 되네."
- 고민 유형별 최적 조합 학습 → 데이터 축적 후 점점 정확해짐

### 3-3. 불일치 강조 UX

**현재**: 불일치 지점을 텍스트로 설명
**개선**: 시각적 불일치 맵
- 3개 구슬의 결론을 벤다이어그램처럼 시각화
- 겹치는 영역 = 합의, 겹치지 않는 영역 = 핵심 갈림길
- 사용자가 갈림길을 탭 → 해당 불일치에 대한 토론 진입

### 3-4. 후속 세션 자동 연결

**현재**: 세션이 독립적
**개선**:
- 결론에서 "다음에 올 때 이것만 알아오게" → 다음 세션 시작 시 "지난번 과제는 어떻게 됐나?"
- 관련 고민 자동 감지: "이직" 후 "연봉 협상" → "아, 이직을 결정했군. 이번엔 연봉이 고민인가?"
- 세션 체인 → 장기 의사결정 여정 시각화

## 4. 위기 프로토콜 개선

### 4-1. 현재

RED 감지 → LLM 즉시 중단 → 109 안내 (2024.1부터 1393이 109로 통합)

### 4-2. 개선 포인트

- **YELLOW 단계 세분화**: 가벼운 스트레스 vs 심각한 고통 사이의 그라데이션
  - YELLOW-LOW: "좀 지쳤어" → 세션 계속, 톤 부드럽게
  - YELLOW-HIGH: "살기 싫어" (RED 아닌 경우) → 세션 일시 중단, "지금 힘들군. 잠깐 쉬어가도 되네."
- **안전 후 복귀 UX**: RED 후 다음 방문 시 "지난번에 많이 힘들었지? 지금은 어떤가?" → 상태 확인 후 세션 진입
- **긴급 연락처 다국어**: 외국인 사용자 대비 (장기)

## 6. 핵심 인사이트 요약

1. **"의사결정 피로를 줄이는 서비스"가 선택 피로를 만들면 안 된다** → 모든 선택지를 3개 이하로 제한, 현자가 추천 먼저 제시
2. **대기 시간 = 데이터 수집 시간** → 분석 대기 중 추가 질문으로 품질 향상 + 몰입 유지
3. **공유 기능 = 무료 마케팅** → 결론 카드의 바이럴 가능성이 가장 비용 효율적인 성장 채널
4. **감정 데이터 = 성과 지표** → "세션 전후 감정 변화" = 투자자/파트너에게 보여줄 효과 증거
5. **파이프라인은 "일관된 의식"이어야 한다** → 기능 추가 시 세계관 안에서 자연스러운지 항상 검증
