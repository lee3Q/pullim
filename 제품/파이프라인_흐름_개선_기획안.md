# 파이프라인 흐름 개선 기획안

> 작성일: 2026-03-21 | 상태: 초안 | 다음 세션에서 구현

---

## 문제

RESEARCH → DISCUSS_1 구간에서 **정보 검증(factcheck)**이 빠져 있다.

### 현재 흐름 (잘못됨)
```
RESEARCH → 데이터 카드 표시
→ DISCUSS_1 → "어떤 이야기가 마음에 걸려요?" (선호 질문)
→ 사용자 아무거나 선택 → 바로 CRYSTAL_SELECT
```

### 문제점
1. `callJudgeFactcheck` API를 호출하지만 **응답을 버림** (저장 안 함)
2. 팩트체크 결과가 사용자에게 보이지 않음
3. DISCUSS_1이 "선호"를 물어봄 — 검증된 정보 기반 논의가 아님
4. 사용자의 맥락/의견이 다음 분석 단계에 전달되지 않음

---

## 설계 의도 (올바른 흐름)

```
RESEARCH → 데이터 카드 수집
→ JUDGE(factcheck) → 팩트체크 실행 → 결과를 카드에 반영
→ DISCUSS_1 → 검증된 정보 표시 + "이 정보에 대해 어떻게 생각하세요?"
→ 사용자 의견/맥락 입력
→ CRYSTAL_SELECT (정제된 정보 + 사용자 의견을 함께 가지고 감)
→ CRYSTAL_ANALYZE (분석 시 사용자 의견 반영)
```

---

## 구현 계획 (API 수정 없음 — 클라이언트만)

### 1. factcheck 응답 저장

```typescript
// 현재 (응답 버림)
const callJudgeFactcheck = async (cards: DataCard[]) => {
  try {
    await fetch("/api/ultimate/judge", { ... });
  } catch { /* ignore */ }
};

// 변경 (응답 저장)
const [factcheckResult, setFactcheckResult] = useState<{
  passed: boolean;
  issues?: string[];
  verifiedCards?: DataCard[];
} | null>(null);

const callJudgeFactcheck = async (cards: DataCard[]) => {
  try {
    const response = await fetch("/api/ultimate/judge", { ... });
    if (response.ok) {
      const data = await response.json();
      setFactcheckResult(data);
    }
  } catch { /* ignore */ }
};
```

### 2. DataCardList에 검증 상태 표시

- 각 카드에 ✅ 검증됨 / ⚠️ 미검증 배지 추가
- factcheck issues가 있으면 해당 카드에 경고 표시
- 사용자가 "이건 맞나?" 판단할 수 있는 시각적 근거 제공

### 3. DISCUSS_1 흐름 변경

**현재:**
```
캐릭터: "어떤 이야기가 마음에 걸려요?"
선택지: ["네, 그 이야기가 마음에 걸려요", "다른 것이 더 신경 쓰여요"]
→ 바로 CRYSTAL_SELECT
```

**변경:**
```
캐릭터: "정원에서 찾은 이야기를 확인해봤어요. [검증 요약]"
캐릭터: "이 정보를 보고, 어떤 생각이 들어요?"
선택지: ["내 상황이랑 비슷해", "내 경우는 좀 달라", "직접 말하기"]
→ 사용자 응답 수집
캐릭터: "그렇군요. [사용자 의견 반영한 요약]"
→ CRYSTAL_SELECT (사용자 의견이 context에 포함됨)
```

### 4. 사용자 의견을 다음 단계에 전달

```typescript
// DISCUSS_1에서 수집한 사용자 의견
const [userContext, setUserContext] = useState<string>("");

// CRYSTAL_ANALYZE 호출 시 전달
const callAnalyzeAPI = async (crystals: CrystalName[]) => {
  const response = await fetch("/api/ultimate/analyze", {
    body: JSON.stringify({
      sessionId,
      selectedCrystals: crystals,
      listenSummary,
      concern,
      userContext, // ← 추가: 사용자의 맥락/의견
    }),
  });
};
```
