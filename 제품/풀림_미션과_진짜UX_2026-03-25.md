# 풀림의 미션과 진짜 UX — 2026-03-25

> 풀림의 완전히 새로운 시작. 대표 이상규가 직접 시뮬레이션하며 도출한 핵심 철학과 설계 원칙.

---

## 1. 미션: "풀다"의 확장

배달의민족이 "배달"이라는 단어 하나로 음식→꽃→마음까지 확장한 것처럼,
풀림은 "풀다"라는 단어 하나로 확장한다.

```
고민을 풀다        ← 핵심 (고민 상담)
자기를 풀다        ← 자기 분석, 가치관 탐색
긴장을 풀다        ← 심심할 때 이야기 듣기, 직관 게임
관계를 풀다        ← 관계 고민 특화
생각을 풀다        ← 철학/심리학 이야기화
잠재력을 풀다      ← 의사결정 능력 성장
```

풀림은 고민 상담 앱이 아니다. **꼬인 것들을 풀어내는 공간**이다.
고민이 없어도 들어올 수 있다. 들어올 때마다 데이터가 쌓이고, 쌓일수록 정확해진다.

## 2. 핵심 UX 원칙

### 2-1. 단계적 감각화 — 양방향 사다리

기존 상담 앱은 "말해보세요"에서 끝난다. 풀림은 말 못하는 사람도 끝까지 진행 가능하다.

**올라가기 (막막한 사람)**
```
감각 ("이거 좋아?")
  ↑
감각 변형 ("이쪽이 더 끌려?")
  ↑
분석 제안 ("이렇게 보이는데 맞아?")
  ↑
선택지 + 추천 ("리서치 해볼래요?")
  ↑
직접 말하기 (자유 입력)
```

**내려가기 (합리적으로 다 정리한 사람)**
```
직접 말하기 → 분석 끝남 → 더 올라갈 데 없음
  ↓
"구조는 알겠어. 그럼 느낌은?"
  ↓
감각으로 내려감 → 분석에서 못 본 것 발견
```

핵심: 폴백 사다리가 양방향이다. 위로만 가는 게 아니라, 이미 위에 있는 사람은 아래로 데려가서 못 본 걸 보게 해준다.

**시뮬레이션 근거 (대표 직접 테스트):**
- 대표는 "합리적으로 다 해결하는 사람"이지만 번아웃 빈번, 감정적 의존 관계 문제 시 전체 붕괴 경향
- "일이 많은데 괜찮다"고 말했지만, "이도저도 아니게 된 적 있냐"는 질문에 "몇 번 있었지" 선택
- 분석은 끝났는데 감정은 정리 안 된 상태 → 내려가기가 필요한 전형적 케이스

### 2-2. 사용자 모델 — 고정 프로필이 아니라 확률 분포

기존 심리 앱: 검사 → "당신은 INTJ" → 고정
풀림: 세션마다 다른 면을 관찰 → 빈도가 성격

```
세션 1: 합리적 면 80%, 감정적 면 20%
세션 2: 합리적 면 30%, 감정적 면 70%  ← 여자친구 싸운 날
세션 3: 합리적 면 60%, 감정적 면 40%
...
축적 → 이 사람은 대체로 합리적이지만,
       감정적 의존 관계가 흔들리면 전체가 무너지는 패턴
```

사람은 입체적이다. 한 가지 유형으로 고정하면 안 된다.
어떤 면을 자주 보여주냐가 그 사람의 성격이다. 확률 싸움.

### 2-3. 추천은 관찰 도구

추천의 목적은 맞추는 게 아니라 **관찰**하는 것이다.

**추천 선택지를 안 골랐을 때:**
- 데이터 적을 때 → "다른 면을 보여준 것" (기본값)
- 데이터 많을 때 → "오늘의 다른 면" vs "데이터 오류" 판단 가능 (빈도 기반)

추천이 틀리는 것 자체가 시스템을 더 정확하게 만든다.

**시뮬레이션 근거:**
- 풀림이 "이도저도 아니게 된 적 없지?"를 추천했지만, 대표는 "몇 번 있었지"를 골랐다
- 추천이 틀렸기 때문에 오히려 "합리적이라고 했지만 실패 경험이 있다"는 핵심 정보를 얻음
- 틀린 추천 → 더 정확한 프로필

### 2-4. 늘 추천은 달아놔 — 선택 부담 제거

모든 선택지에 추천이 붙는다.
- "뭐라고 불러드릴까요? **추천: 상규님**"
- "반말? 존댓말? **추천: 반말**"
- "어떤 공간이 끌려? **추천: 전략실** (빠르게 결정하는 스타일이네!)"

풀림의 타겟이 "막막한 사람"이니까, 선택지만 던지면 또 막막해진다.
추천을 늘 달아두면 "몰라, 그냥 추천대로" 해도 진행 가능.

## 3. 세계관과 모드

### 3개 테마 유지, 별도 모드 분리 X

| 테마 | 성격 | 원래 의도 |
|------|------|-----------|
| 모험가 | 희망도 패배도 공존하는 공간 | |
| 정원 | 감성적으로 달래주는 느낌 | |
| 전략실 | 딱 업무상으로 하는 느낌 | |

각 세계관 안에서 대화도, 학습도, 자기 분석도 전부 가능하다.
별도 "학습 모드"를 만들지 않는다.

| 진입 상태 | 풀림에서 하는 것 |
|-----------|-----------------|
| 고민 있음 | 대화 → 선택지 → 감각화 사다리 |
| 고민 없고 심심 | 이야기 듣기 → 해석 → 자기 발견 |
| 고민 없고 궁금 | 자기 분석 → 패턴 확인 |

이러면 진입 장벽이 완전히 사라진다:
- ~~고민이 있어야 쓸 수 있는 앱~~ → 그냥 아무 때나 들어올 수 있는 공간

## 4. 철학/심리학 이야기화

### 콘텐츠 소스
저작권 만료(퍼블릭 도메인) 자료 활용:
- 고전 철학: 니체, 키르케고르, 에픽테토스, 노자, 장자, 세네카 등
- 고전 심리학: 프로이트, 융, 아들러, 윌리엄 제임스 등
- 현대 심리학 프레임워크: Big Five, ACT, CBT (학술 공공재)

### 원문이 아닌 이야기로 포장

```
원문: "인간은 자유를 선고받았다" — 사르트르

풀림 버전:
  어떤 사람이 회사를 그만뒀어.
  친구는 "미쳤어?" 하고, 가족은 "어떡해" 했는데,
  본인은 오히려 숨이 트인대.

  이 사람 어떤 것 같아?
  😎 부럽다 | 😨 무섭다 | 🤔 무책임하다 | [직접]
```

- 원문 안 보여줘도 됨. 이야기만으로 충분
- 나중에 "사실 이건 사르트르의 자유론이랑 비슷한 거야"라고 알려주면 학습 효과 + 보상
- 사용자 이야기와 비슷한 것을 들려주면 → "어? 이거 나랑 비슷한데?" → 자기 객관화 자연스럽게
- 테마별로 같은 철학을 다르게 포장 (모험가면 모험 이야기, 정원이면 자연 비유)

### 오답 없는 구조
- 해석에 틀린 답이 없음 → 부담 제로 → 심리테스트 느낌
- 사용자는 학습한다고 느낌 (철학/심리학 지식)
- 풀림은 가치관을 수집 (같은 글을 어떻게 해석하느냐 = 그 사람의 프레임)

### 수집 데이터 → 고민 세션에 직결
```
세션 1: 자유 관련 글에 반응 강함, 통제 관련 글에 저항
세션 5: 관계 관련 글에서 갈등 반복
세션 20: 자율성 최우선 가치, 관계에서는 의존 허용하는 이중 구조
→ 고민 상담 시 자율성 프레임으로 접근, 관계 고민에서는 의존 부정하지 않기
```

## 5. 온보딩 플로우

```
[앱 진입]
  ↓
길잡이: "안녕하세요! 풀림에 오신 걸 환영해요.
        같이 막막했던 꼬인 것들을 풀어나가요."
  ↓
"혹시 원하는 모드가 있나요? 추천해드릴까요?"
  → 모험가 / 정원 / 전략실 + 추천 표시
  ↓
"뭐라고 불러드릴까요? 추천해드릴까요?"
  ↓
"반말로 할까요? 존댓말로 할까요?"
  ↓
"우리 저 언덕만 올라가면 바로 풀림에 들어갈 수 있어요!
 같이 올라가봐요."
  ↓
파악 질문 (기본 5개, 파악 안 되면 더 늘어남)
  — 부족한 데이터로 태도를 결정하는 것보다
    질문이 더 나가는 게 낫다
  ↓
세계관 진입 → 게임식으로 진행
  "고민이 있어?" / "나를 알려주고 싶어?" / "분석받고 싶어?"
  → 계속 선택하며 재미있게 진행
```

### 길잡이 캐릭터 (미확정)
- 세션 중에는 직접 등장하지 않음
- 세션을 모두 듣고 태도를 결정하는 메타 존재
- "밖으로 나가고 싶다", "세션 그만하고 싶다" 할 때 길잡이한테 말하는 구조
- 고정된 멘트는 시스템 처리
- **아직 확정 아님 — 더 고민 필요**

## 6. "텍스트 게임이라고 착각할 만큼"

고민 상담이 아니라, 텍스트 게임이라고 착각할 만큼 부담없고 즐겁게.

- 직접 말하게 할 수 있지만, 그러고 싶지 않은 사람에겐 늘 선택지와 추천선택이 있어서 진행을 계속할 수 있다
- "이건 나중으로 미룰래" → "이건 리서치 해보고 싶어" → "리서치 해도 안되면 분석 받고싶어" → "분석해도 모르면 더 감각적으로 변형 변형 변형" → "이거 좋아?" 느낌으로도 선택 가능 → 아기에게 간식을 주는 느낌까지
- 모드(테마)별로 성격이 달라서 냉소적으로 분석해줄 때도, 희망적으로 분석해주고 달래줄 때도 있음
- 사용자의 피로감을 유발하지 않도록 추천과 모드를 다양하게 제공

## 부록: 시뮬레이션 기록

### 시나리오 1 — 여자친구 고민 (합리적이지만 감정 미정리)

대표 원문:
> 여자친구는 문제가 많아. 잘못된 습관, 정신적 취약성으로 나에게 상처를 많이 입히지. 그러나 서로 좋아하기에, 나는 그런 걸 고치게 하려고 유도하고 여자친구는 자신이 잘못된 걸 알면 그거에 상처받아. 그래서 오히려 내가 상처받고 달래는 구조도 많지. 그러나 이게 힘들고 어려워도 계속 해왔고, 안만나면 괴로울 정도로 유대가 많이 쌓였어. 미래에 언제까지나 같이있을지는 모르겠지만, 적어도 지금 나는 여자친구가 좋아서 만나고 있어. 하지만 문제가 많다는 것도 알고, 언제까지 이럴 수 없다는 것도 알아. 지금 내가 맞다는 확신보다는, 좋으니까 함께 있어. 라는 느낌으로 가는 거야.

설계 발견:
- 일반 앱: "더 말씀해주세요" → "다 말했는데?"
- 풀림: "구조는 알겠어. 그럼 여자친구 생각하면 지금 어떤 느낌?" → 내려가기 작동
- 분석은 끝났는데 감정은 정리 안 된 사람 = 내려가기 대상

### 시나리오 2 — 일이 너무 많다 (빡빡+대단함 공존)

대표 원문:
> 진행중인 일이 너무 많아. (중략) 이도저도 아니게 될까봐 약간 고민. 하지만 이것도 결국 나는 뭐가 있어야 움직이는 스타일이라 내 행동을 유도하게 만들어서 의미가 있다고 생각해. 그렇게 부담감이 있는 것도 아니고, 오히려 난 개쩐다 열심히 산다라고 느끼는 것도 있어.

설계 발견:
- "빡빡한데 대단한 느낌도 있고?" → 슬라이더로 비율 확인
- "이도저도 아니게 된 적 있었어?" → 추천: "없어, 다 해냈어" → 실제 선택: "몇 번 있었지"
- 추천이 틀렸기 때문에 핵심 정보 획득 ("합리적 사람이지만 실패 경험 있음")
- "합리적으로 다 내려버리고 해결책도 있으나, 행동에 있어서 번아웃이 자주 오고, 감정적 의존 관계에 문제가 생기면 전부 망해버리는 입체적인 사람"

### 대표 코멘트
> "아마 다른 사람들도 입체적일 테니, 늘 이 사람은 이렇다 생각하면 안 돼. 다만 추천 선택지를 고르지 않는 건 오늘 그 사람의 다른 면을 보거나, 여태 데이터가 잘못되었거나 둘 중 하나. 데이터가 많이 쌓이기 전엔 다른 면이라고 판단하는 게 맞는 것 같아. 결국 확률 싸움이야. 어떤 면을 많이 보여주냐가, 그 사람의 성격일 테니까."
