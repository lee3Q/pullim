# 데모 피드백 정리

## 피드백 #1 — 26세 여성

**캐릭터 관련:**
- 캐릭터가 동물 같은 게 좋겠다 (달빛정원은 이미 그 방향 구상 중)
- 동물의 숲 같은 귀여운 컨셉이 20대 여성에게 잘 통할 것

**AI 인간 이미지 문제:**
- AI 인간 같은 이미지가 들어있으면 B급 연애게임 느낌이 난다고 함
- 26세 남성도 "AI 연애 느낌"이라고 언급

**시사점:**
- 기존 AI 연애앱이 이미 시장을 먹은 만큼, 비슷하게 가면 안 됨
- 핵심은 UI 문제일 가능성 높음
- 모험가의길 / 전략실 / 달빛정원 각 테마 컨셉에 맞게 텍스트 박스부터 싹 바꿔야 함
- 테마별 UI 차별화가 "연애앱" 인상을 깨는 열쇠
