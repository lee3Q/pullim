### 심각도 분석

**즉시 대응 (제품 철학 위기)**
1. "결과를 안 줘서 답답하다" + "사람들은 사고하는 거 싫어한다" — 순수 소크라틱 모델의 한계가 1회 테스트에서 바로 노출. **질문만 하는 것은 차별화가 아니라 허들이다.**
2. "창의적 시각, 천재적 사고가 필요하다" — 뻔한 질문은 GPT도 한다. 풀림만의 "아, 이건 생각 못했는데?" 모멘트가 없으면 차별점 없음.
3. "보고서로는 부족하다" — 정리 문서가 만족 포인트였지만, 그것만으로는 부족. 더 실질적인 output 필요.

**스코프 확장 시그널 (학생 타겟)**
4. "과제 대필 쉽게" + "시간표/스케줄러" — 학생 유저는 "고민 정리" 너머 "생활 도구"를 원함. 고민상담 단독으로는 학생 시장 못 잡음.
5. "할루시네이션 검증" — 학생들은 AI를 신뢰하지 못함. 검증 레이어가 차별점이 될 수 있음.

**긍정 시그널**
6. 톤은 OK — "무지성 공감은 AI 티가 남. 딱딱해야 할 때 딱딱해야 함" → 풀림의 반말+직설 톤이 적절했다는 간접 확인.

### 상담 대비 비교 (테스터 직접 비교)
> "상담보다는 이게 나았어. 상담 때 공감 받은 게 더 좋긴 했어. 실질적으로 어떻게 할 수 있다는 해결책을 준 부분에서 더 나았다고 생각했어."

| 비교 항목 | 실제 상담 | 풀림 |
|----------|----------|------|
| 공감 | **승** — 상담 때 공감이 더 좋았음 | 열세 |
| 실질적 해결책 | 열세 | **승** — 구체적 행동 제시가 나았음 |
| 종합 | — | **풀림 > 상담** (테스터 직접 판단) |

**제품 시사점**: 풀림의 차별점은 "공감"이 아니라 **"실질적 해결책 도출"**. 공감은 상담사가 이기지만, 구조화된 정리+행동 설계에서 풀림이 우위. 이 축을 강화해야 함. "질문만 하는 AI"가 아니라 **"질문으로 해결책을 만들어내는 AI"**로 포지셔닝.

### 테스터 프로필 인사이트
손정원은 대학생(추정), 밤형, 학교 수업 8시 종료, 부모님과 동거. **학생 타겟층의 실제 니즈를 직접 대변한 피드백.** 특히 "과제 대필", "시간표", "프롬프트 없이 쉽게"는 학생 UX의 핵심 요구사항.

## 개선 제안 (디브리핑 반영 종합)

### 1. 제품 철학 재검토 — "질문만" vs "질문 + 결과"
- 순수 소크라틱(질문만) → **질문 + 중간 인사이트 + 구체적 output**으로 전환 검토
- "결과를 안 줘서 답답하다"는 1명이 아니라 대중의 목소리. 여기서 피벗하지 않으면 리텐션 불가능.
- 제안: 듣기(질문) → 풀기(질문 + **AI 인사이트 1-2개 삽입**) → 착지(정리 + **구체적 행동 플랜**)

### 2. 프롬프트 품질 — "천재적 사고"
- 현재: 뻔한 질문 반복 → "내가 다 생각할 수 있는 것들이잖아"
- 필요: 테스터가 "아, 그 관점은 생각 못했는데" 하는 순간. 리프레이밍의 깊이를 높여야 함.
- 구체적: 질문 생성 시 "테스터가 이미 생각했을 법한 것은 제외" 규칙 추가. 비직관적 관점 전환 강화.

### 3. 속도 개선
- 텍스트 AI 특성상 답변 생성 속도 한계 있음
- 짧은 답변(1-2문장) 유지 + 불필요한 미러링 축소로 체감 속도 개선
- 장기: 스트리밍 UI 적용

### 4. UX/디자인
- "딱딱하다" + "귀여운 캐릭터" → 캐릭터 디자인 + 따뜻한 UI 필요
- 텍스트 기반 CLI 느낌 탈피 → 모바일 앱 UI에서 캐릭터가 말풍선으로 대화하는 형태

### 5. 기능 스코프 (학생 타겟)
- 현재: 고민 정리 전용
- 요구: 과제 도우미 + 시간표/스케줄러 + 고민 정리
- 리스크: 스코프 확장 시 "다 하는데 다 어중간한" 앱이 될 수 있음
- 제안: 코어는 "고민 정리" 유지, 부가 기능은 MVP 이후 검증

### 6. 신뢰/검증
- 학생들의 핵심 불안: "이거 맞아?" → AI가 출력한 것을 사용자가 검증해야 하는 부담
- 제안: 출처 표시, 확신도 표시, "이건 내 추측이야" 라벨링

### 7. 부작용 대응
- AI 답변 복붙해서 친구에게 보내는 사용 패턴 → 윤리 가이드라인 필요
- "AI와 실제 대화의 벽" → 풀림이 대화를 대체하는 게 아니라 연습/준비 도구로 포지셔닝

## 대표 분석 (세션 후 귀가 중 정리)

### 핵심 의문: 대중적 성공이 가능한가?

1. **코칭/상담 자체가 마이너** — 상담을 원하는 사람은 '사람'을 원함. 사람의 시간을 사는 것에 대한 거부감이 AI보다 적음.
2. **품질이 좋아도 안 팔린다** — 유의미한 리프레이밍이 일어났음에도 "GPT랑 뭐가 달라"가 나왔다. 사용자 기대치를 월등히 넘지 않으면 유료 전환 없음.
3. **인지자원 소모가 크다** — 고민을 진지하게 정리하는 건 "재미있는 작업"이 아님. 가벼운 앱 사용 패턴과 정면 충돌.
4. **무료 3회의 함정** — 일반인에게 고민 3개면 충분할 수 있음. 다음달로 미루면 영원히 유료 전환 안 함. 막대한 적자 리스크.
5. **타겟 역설** — AI를 다루는 사람에게는 의미 없음(직접 프롬프트 설계). AI를 못 다루는 사람에게 의미 있으나, 그 사람들이 돈을 낼까?
6. **GPT Pro/Claude Pro 비교** — 솔직히 큰 차이 없음. 구체적 입력에 따라 GPT도 비슷한 결과. 풀림은 "입력 시간을 줄여주는 것"인데, 그 가치를 얼마나 느낄지 미지수.

### 대표 판단
- 피벗은 비현실적 (사업계획서+PPT+테스트까지 온 상태)
- 추가 테스트로 윤곽을 잡아야 함 (내일: 부모님, 교수님)
- 피드백 오염도 인지 (앤두는 온전한 고객이 아님)
- 본인 직접 사용 체험도 필요

### 긴급 안건
