## UX 발견

### 치명적 발견
1. **종료 제안 반복 = 이탈 유발** (턴 13~14)
   - "여기까지 할까?" "오늘 마무리할까?" 반복이 **"네 이야기 듣기 싫다"**로 읽힘
   - 테스터 원문: "뭐 자꾸 마지막이니 여기까지 하니 이딴 말을 계속 하니까 꺼버리고 싶은 마음이 들잖아"
   - **풀림 핵심 철학 "같이 있는 것"에 정면 위배**
   - 개선: 종료는 100% 사용자 주도. AI는 절대 종료 제안하지 않음. "끝나지 않으면 문제가 지속 중인 것"

2. **과잉 보상도 역효과** (턴 14)
   - 종료 제안 피드백 후 "들을게 들을게 계속 말해" 식 반응도 문제
   - "억지로 듣는 느낌" → 진짜 듣는 건 선언이 아니라 상대 말에 반응하는 것
   - 개선: 메타 발언(선언) 최소화, 직전 이야기에 바로 응답

### 주요 발견
3. **StoryDiscovery 3장면 = 설문처럼 느껴짐**
   - 테스터가 Phase 1을 스킵하고 바로 대화 진입 요청
   - "대화를 통해 파악하길 바란다" — 자연스러운 대화 속에서 프로필 추론하는 옵션 필요
   - 개선: StoryDiscovery를 선택적으로. "바로 이야기하기" 옵션 추가

4. **Level 5 자유대화의 힘**
   - 38턴 동안 Level 5 유지. JLPT 고민 → 형과의 비교 → 이별 → 자기 철학 → 풀림의 기원 → 연애관까지 자연스럽게 흘러감
   - 선택지 없이도 대화가 깊어짐 → Level 5가 engagement 높은 사용자에게 매우 효과적

5. **선택지가 맥을 끊을 수 있음**
   - AskUserQuestion 선택지가 자유로운 사고 흐름을 중단시킴
   - 특히 감정적 대화 중 선택지 = 감정에서 분석으로 강제 전환
   - 개선: Level 5에서는 선택지 최소화, 열린 질문 위주

### 확인된 것
6. **Socratic 질문이 자기 결론으로 이끔**
   - "공짜면 접수해?" → 의지 확인
   - "5년 뒤 뭐가 더 아파?" → 우선순위 확인
   - "너를 알게 해준 사람이 떠난 지금, 그 앎은 남아있어?" → 자기이해 확인
   - 테스터가 스스로 "교환학생은 안 가야겠다" 결론에 도달

7. **풀림 철학이 세션 안에서 자연스럽게 드러남**
   - "끊지 않는 것" "같이 있는 것" — 테스터가 직접 정의
   - 세션 자체가 풀림 프로토타입 역할을 함
