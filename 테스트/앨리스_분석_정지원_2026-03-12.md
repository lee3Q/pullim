- 테스터: 정지원 (엄마)
- 날짜: 2026-03-12
- 플랫폼: 앨리스 (학교 제공, 구형 모델, 단일 세션, 메모리 없음)
- 프롬프트: 풀림 핵심 프롬프트 (서윤하 설계, 앨리스_테스트_프롬프트_2026-03-11.md)
- 고민: 자녀들이 서로 편하게 지내지 않아 마음이 쓰임
- 위기 감지: 없음 (GREEN)

## 대화 흐름 관찰
- A/B/C 선택지 구조 + 빈칸 채우기 패턴 정상 동작
- "명절에 만나면 편하게 웃고 떠드는 사이" → 핵심 바람 도출 성공
- "50점" 수치화 → 현실 인정 + 이상 간 거리 명확화
- 0점이 아닌 이유("예의를 갖춘다") → 긍정 자원 발굴
- 감정 직면 ("ㅜ" 한 글자 → AI가 맥락 읽고 자연스럽게 수용)
- 착지: "오늘은 그냥 이 마음 알아준 것만으로 충분하다" 옵션 → B(50점 이유 탐색) 선택 후 마무리

## 테스터 후기
- "저번 게(v2 풀림) 좀 더 좋긴 했다. 구체적이었고."
- "그치만 이것도 좋다. 이것도 만원은 낼 것 같다."

## v2 풀림 vs 앨리스+풀림프롬프트 비교

| 항목 | v2 풀림 (2026-03-10) | 앨리스+풀림프롬프트 (2026-03-12) |
|------|---------------------|--------------------------------|
| WTP | 1~3만원/월 | 만원 내외 |
| 차별화 체감 | "확실히 다른 게 보였어요" | 비교 대상 없음 (첫 경험) |
| 인사이트 | "확실히 새로운 게 있었어요" | 코칭 품질 충분 |
| 가장 좋았던 점 | "선택→토론→리포트 구성 자체" | 언급 없음 (그냥 좋다) |
| 구체성 | 더 높음 (에이전트 3명 다각도) | 상대적으로 낮음 |

## 핵심 결론

**v2가 이겼다. 이유는 프롬프트가 아니라 파이프라인 구조.**

- "더 구체적이었다" = 에이전트 3명이 각자 다른 각도에서 파고든 결과
- 단일 에이전트 프롬프트로는 복제 불가능한 지점
- 앨리스도 유료 가치는 있으나(만원), v2는 1~3만원 → 3배 WTP 차이

**풀림의 모트 = 파이프라인 구조 (선택→토론→리포트), 프롬프트 설계 아님**

## v2 위기 재판정
- 위기 아님
- "구형 모델 + 프롬프트로도 이 정도 품질 가능"은 맞지만,
  사용자가 체감하는 차별점은 **파이프라인 구조**에 있음
- 기억/연속성 모트는 별개로 추가 검증 필요

## 전략 반영 포인트
- PPT/신청서에서 "파이프라인" 차별화 강조 유지 정당성 확보
- "선택→토론→리포트" 흐름 자체가 핵심 UX 자산
- 경쟁 포지셔닝: "GPT + 검색 프롬프트"는 파이프라인 구조 복제 불가
