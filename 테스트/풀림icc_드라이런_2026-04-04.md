- 현상: `run_in_background: true` 실행 시 출력 파일이 비어있는 채로 즉시 반환됨
- 영향: 내면사고 결과를 즉시 읽을 수 없어 다음 응답 생성 지연
- 해결: 동기 실행 (`2>&1` 직접 캡처)으로 전환 → 정상 작동
- 결론: 스킬의 `run_in_background: true` 지시는 현재 환경에서 불안정. 동기 호출 권장.

### 2. 레벨 전환 5턴 내 미발생
- 현상: 5턴 모두 `levelChange: stay`
- 원인: 레벨 전환 조건(3턴 연속 명확 응답 → up)이 5턴 내에 충족되지 않음

- 권고: 드라이런 시 레벨 전환 검증을 위해 8턴 이상 시뮬레이션 권장.

### 3. 위기 감지/금기어 규칙 미검증
- 현상: 페르소나 대사에 위기 트리거 없어 감지 규칙 발동 안 됨
